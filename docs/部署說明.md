# 部署說明（Phase 5E-3、5E-2b）

把遊戲伺服器、Discord Bot 與本機模型放在自己的電腦上，用 Tunnel 讓朋友從外面連進來（`docs/專案計畫.md` 3.1）。Windows 與 macOS 的步驟分成兩節，指令幾乎一樣，差別只在啟動腳本的副檔名。

> 本專案的腳本 **不會下載或安裝任何東西**。uv、Node、Tunnel 工具都要你自己先裝好。

## 0. 會用到的設定檔

| 檔案 | 放什麼 | 進版控 |
|---|---|---|
| `config/server.toml` | 開發模式、帳號資料夾、登入限制、`[network]` 外部網址與可信任的轉發來源、`[llm_health]` 模型 ping 間隔 | 是（不放金鑰） |
| `config/deploy.local.toml` | 伺服器綁定的 `host`／`port`、Tunnel 指令 `tunnel_command`（從 `config/deploy.example.toml` 複製） | 否 |
| `.env`（repo 根目錄） | Discord Bot 的 token、伺服器、身分組、公告頻道 ID（從 `.env.example` 複製；見第 9 節） | 否 |
| `config/bot.local.toml` | 每日公告時間 `[announce]`；也可以放 Bot 的 ID（`.env` 沒填時才用；從 `config/bot.example.toml` 複製） | 否 |
| `config/llm.toml` | 本機模型的網址與模型名 | 是 |

機器相關的值（路徑、埠、Tunnel 指令）都放在設定檔，腳本裡沒有寫死。

## 1. 開服前要做的事（兩邊都一樣）

1. **建置前端**：`pnpm -C client install`、`pnpm -C client build`（產生 `client/dist`；Node 24 以下也可用 `corepack pnpm`，Node 25 起請 `npm install -g pnpm`）。
2. **關掉開發模式**：`config/server.toml` 的 `[accounts]` 把 `dev_mode = true` 改成 `false`（或環境變數 `TRPG_DEV_MODE=false`）。開著時任何人不登入就能動所有角色。
3. **帳號資料夾位置**：預設 `<專案>/saves/accounts`（`saves/` 已在 `.gitignore`）。要放別處就改 `config/server.toml` 的 `[accounts] dir`，或設環境變數 `TRPG_ACCOUNTS_DIR`。世界存檔在 `<存檔資料夾>/world`（`TRPG_SAVE_DIR` 可改存檔資料夾）。**季末重置只清世界，帳號保留**；備份時兩個資料夾都要備。
4. **設管理者**：`uv run python scripts/dev_account.py admin <你的帳號> on`（管理者才能改大世界的 LLM 開關、刪地點留言）。
5. **Tunnel 設定**：複製 `config/deploy.example.toml` 成 `config/deploy.local.toml`，填 `tunnel_command`（見第 4 節）。
6. **外部網址與真實 IP**：`config/server.toml` 的 `[network]`：
   - `public_url`：Tunnel 給你的網址（例 `https://trpg.example.com`）；每日公告會附上。
   - `trusted_proxies`：Tunnel 程式跑在同一台電腦時填 `["127.0.0.1", "::1"]`。**只有**從這些位址來的連線，伺服器才會讀 `CF-Connecting-IP`／`X-Forwarded-For` 當作真實 IP（登入嘗試次數限制用）。空＝不信任任何轉發標頭（沒有 Tunnel 時保持空的）。
7. **檢查**：`uv run python scripts/deploy.py check`，把列出的 ✗ 一項項處理掉。

## 2. Windows

在專案資料夾開三個 PowerShell 視窗：

```powershell
# 視窗 1：遊戲伺服器（照 config/deploy.local.toml 的 host／port）
powershell -ExecutionPolicy Bypass -File scripts\start_server.ps1

# 視窗 2：Discord Bot（先照第 9 節建好 Bot、填好 .env）
powershell -ExecutionPolicy Bypass -File scripts\start_bot.ps1

# 視窗 3：Tunnel（照 tunnel_command）
powershell -ExecutionPolicy Bypass -File scripts\start_tunnel.ps1
```

- 本機模型（vLLM 在 WSL）照舊另外啟動，埠是 `config/llm.toml` 的 `base_url`（預設 8001）。
- 不想用腳本也可以直接下 `uv run python scripts/deploy.py server`（`bot`、`tunnel` 同理）。
- 關機或登出時三個視窗都要重開；要開機自動啟動，可以自己用「工作排程器」排這三個腳本。

## 3. macOS

前置安裝（只做一次；MAC-1）：

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh     # uv（裝到 ~/.local/bin，之後 export PATH="$HOME/.local/bin:$PATH"）
npm install -g pnpm                                  # Node 25 起沒有 corepack；Node 24 以下也可直接用 corepack pnpm
pnpm -C client install && pnpm -C client build       # 建置前端（產生 client/dist）
```

在專案資料夾開三個終端機分頁：

```sh
sh scripts/start_server.sh    # 遊戲伺服器
sh scripts/start_bot.sh       # Discord Bot（先照第 9 節建好 Bot、填好 .env）
sh scripts/start_tunnel.sh    # Tunnel
```

- 本機模型（例：Gemma 4 12B）照 `config/llm.toml` 的 `base_url` 另外啟動；換模型只改 `config/llm.toml`。
- 要開機自動啟動，可以自己用 `launchd` 排這三個腳本。

## 4. Tunnel（工具不指定）

任何能把「外部 HTTPS 網址」轉到 `http://127.0.0.1:<port>` 的工具都可以。下面以 cloudflared 為例，**安裝與登入由你自己做**：

1. 安裝 cloudflared（Windows：官方 MSI 或 winget；macOS：Homebrew），登入你的 Cloudflare 帳號。
2. 建一個名為 `trpg` 的 tunnel，把你的網域指向 `http://127.0.0.1:8000`（照 cloudflared 的官方說明）。
3. `config/deploy.local.toml`：

   ```toml
   [deploy]
   host = "127.0.0.1"
   port = 8000
   tunnel_command = ["cloudflared", "tunnel", "run", "trpg"]
   ```

4. `config/server.toml`：`public_url = "https://<你的網域>"`、`trusted_proxies = ["127.0.0.1", "::1"]`。

只想臨時測試（網址每次都會變）：`tunnel_command = ["cloudflared", "tunnel", "--url", "http://127.0.0.1:8000"]`，啟動後把印出的網址填進 `public_url`。

伺服器維持綁 `127.0.0.1`：外面只能經 Tunnel 進來，不用開防火牆埠。

## 5. 本機模型不可用時

- 伺服器啟動時、之後每 `[llm_health] interval_s` 秒（預設 60）會 ping 本機模型（只在大世界的 LLM 開關開著時 ping）。
- 連不到時：大世界的說書人、情境判定、聊天 **全部改用模板**，遊戲照常；伺服器視窗印出警告「本機模型不可用…」，恢復時印「本機模型恢復可用」；`GET /api/world/llm` 的 `model_available` 是 `false`，畫面上的 LLM 開關會顯示提示。
- 一輪（roguelite）開局時本來就會先探測，連不到那一輪照常用一般技能生成。

## 6. Discord 公告

- 每天 `config/bot.local.toml` `[announce]` 的 `hour` 點（預設 6 點、`Asia/Taipei`）貼今日公告；全服第一個打倒某種精英時貼首殺公告。
- Windows 沒裝時區資料（`tzdata`）時自動改用 `utc_offset_minutes`（預設 480＝UTC+8；台灣沒有日光節約）。
- 看公告文字長什麼樣（不連網、不需要 token）：`uv run python scripts/discord_bot.py preview`。
- 文字模板在 `content/world/announcements.yaml`，可以自己改（變數寫錯會在載入時報錯）。
- 今日目標、世界事件全服進度是之後（5F-1）的資料，現在公告寫「尚未開放」。

## 7. 地點留言（管理）

- 列出：`uv run python scripts/location_notes.py list`（`--location <地點 ID>` 只看某地）。
- 刪除：`uv run python scripts/location_notes.py delete <note_id>`；伺服器開著也可以刪。
- 管理者帳號也可以呼叫 `DELETE /api/world/notes/<note_id>`。

## 8. 備份

停掉伺服器與 Bot 後，複製 `saves/`（或你設定的帳號資料夾與存檔資料夾）整個資料夾即可。

### 8.1 季末重置（5F-5；旗標 5F-R2 更新）

- 伺服器開著：用管理者介面的「季末重置」區塊，或 `POST /api/world/season/reset`（body 的 `force`＝賽季還沒結束也重置）。
- 伺服器停著：`uv run python scripts/season_reset.py --start-date 2026-12-01` 先看 dry-run，確認後加 `--execute`。執行前會自動備份整個存檔資料夾。
- 兩種略過各自獨立，需要哪個加哪個：
  - `--force-season`：賽季還沒結束、循環賽還沒跑完也重置（等於 API 的 `force`）。
  - `--force-server`：偵測到伺服器心跳（`<存檔資料夾>/world/server.lock`）也執行。只在確定伺服器已經不在、心跳檔沒清掉時用；心跳超過 120 秒沒更新會自動視為不在。
- 舊的 `--force` 已拆開，用了會提示改用上面兩個。

## 9. Discord Bot（Phase 5E-2b）

Bot 是獨立的程序：它掛掉或設定缺值，遊戲伺服器照常。它做四件事：玩家用斜線指令領帳號、重設密碼（密碼只用**私訊**傳）；指定身分組被拔或離開伺服器時停用帳號；每天貼今日公告；有新的首殺時貼首殺公告。

### 9.1 建立 Bot（Windows、macOS 一樣，都在瀏覽器）

1. 打開 Discord Developer Portal（`https://discord.com/developers/applications`），按 **New Application**，取個名字。
2. 左邊 **Bot**：
   - 按 **Reset Token**，複製出現的 token（只會顯示一次）。**不要貼到聊天、截圖或 commit**；外洩了就再按一次 Reset Token。
   - **Privileged Gateway Intents**：打開 **SERVER MEMBERS INTENT**（要知道身分組變更與成員離開）。**PRESENCE INTENT**、**MESSAGE CONTENT INTENT** 不用開。
   - **Public Bot** 建議關掉（只有你能邀請它）。
3. 左邊 **OAuth2 → URL Generator**：
   - Scopes 勾 **`bot`** 與 **`applications.commands`**（斜線指令要它）。
   - Bot Permissions 勾 **View Channels**、**Send Messages**（貼公告用）。不需要管理員、管理身分組或讀訊息的權限。
   - 用下面產生的網址把 Bot 邀進你的伺服器。
4. 公告頻道如果有限制權限，確認 Bot（或它的身分組）在那個頻道有「檢視頻道」「傳送訊息」。

### 9.2 拿 ID

Discord「使用者設定 → 進階 → 開發者模式」打開，然後右鍵「複製 ID」：

| 要填的 | 去哪裡複製 |
|---|---|
| `TRPG_DISCORD_GUILD_ID` | 左邊伺服器圖示右鍵 → 複製伺服器 ID |
| `TRPG_DISCORD_ROLE_ID` | 伺服器設定 → 身分組 → 能領帳號的那個身分組右鍵 → 複製身分組 ID |
| `TRPG_DISCORD_ANNOUNCE_CHANNEL_ID` | 公告頻道右鍵 → 複製頻道 ID |

### 9.3 填 `.env`

`.env` 放在專案根目錄（跟 `pyproject.toml` 同一層），已在 `.gitignore`，不會進版控。

Windows（PowerShell，在專案資料夾）：

```powershell
Copy-Item .env.example .env
notepad .env
```

macOS（終端機，在專案資料夾）：

```sh
cp .env.example .env
open -e .env
```

在每個等號後面填值（不要加空白；值可以用引號包起來）：

```
TRPG_DISCORD_TOKEN=<貼上 token>
TRPG_DISCORD_GUILD_ID=<伺服器 ID>
TRPG_DISCORD_ROLE_ID=<身分組 ID>
TRPG_DISCORD_ANNOUNCE_CHANNEL_ID=<公告頻道 ID>
```

- 格式：一行一個 `KEY=VALUE`，`#` 開頭是註解；不支援 `export` 與多行值。
- 讀取順序：**環境變數 → `.env` → `config/bot.local.toml`**（每個值各自取第一個有填的）。舊名 `TRPG_BOT_TOKEN` 等也還能用。
- 每日公告的時間在 `config/bot.local.toml` 的 `[announce]`（沒有這個檔就用預設的每天 6 點 `Asia/Taipei`，見第 6 節）。

### 9.4 檢查與啟動

```sh
uv run python scripts/discord_bot.py check   # 缺什麼會列出來；齊了印「設定齊全」與遮住的 token
uv run python scripts/discord_bot.py run     # 連上 Discord，Ctrl+C 結束
```

- 也可以用第 2、3 節的 `scripts\start_bot.ps1`（Windows）／`sh scripts/start_bot.sh`（macOS），兩者都是 `deploy.py bot` → `discord_bot.py run`。
- 第一次連上時 Bot 會把斜線指令註冊到你的伺服器（立即生效），並重查所有綁了 Discord 的帳號：沒有指定身分組的會被停用（Bot 離線期間的變動）。
- 常見錯誤：
  - 「Discord 拒絕這個 token」：token 打錯或已被重設 → 回 9.1 重設、重填 `.env`。
  - 「Bot 需要 Server Members Intent」：回 9.1 第 2 步打開。
  - 「無法在伺服器註冊斜線指令」：邀請網址沒勾 `applications.commands`，或 `TRPG_DISCORD_GUILD_ID` 不是 Bot 所在的伺服器 → 用 9.1 第 3 步的網址重新邀請。

### 9.5 玩家怎麼用

| 指令 | 作用 |
|---|---|
| `/register` | 領大世界帳號；`username` 可以指定帳號名稱（3～20 字英數底線），不填就用 Discord 名稱轉 |
| `/reset_password` | 重設密碼（之前的登入全部登出） |

- 只有有指定身分組的人能用；回覆只有本人看得到；**帳號密碼用私訊傳**。玩家要在這個伺服器的「隱私設定」打開「允許來自伺服器成員的私人訊息」，不然會收到「私訊失敗」的提示（帳號照建、之後用 `/reset_password` 再拿一次密碼）。
- 身分組被拔或離開伺服器 → 帳號停用；加回身分組**不會自動恢復**，管理者用 `uv run python scripts/dev_account.py enable <帳號>`。
