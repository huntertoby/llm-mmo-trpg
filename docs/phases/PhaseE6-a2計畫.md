## 範圍

1. **鐵匠打造可以指定招牌類型**：
   - 指定招牌類型和技能強化二選一。
   - 只能指定五種之一，不能指定是哪一條。
   - 開關（`signature_enabled`）關著時，這個選項不出現。
   - 指定的 build 詞條放進剩下的 40%；放不下時照現有規則報錯（E6-a1 待決 6）。
2. **附魔台重骰招牌**（8.30 第 3 點）：
   - 只換成同一種的另一條。
   - 費用照一般重骰，和同件其他詞條共用遞增次數。
   - 附魔台的「指定」（花精華）不能指定招牌。
   - `affix_choices` 不再對招牌回傳空（E6-a1 待決 4）。
3. **配方與存檔相容**：`CraftRecipe` 新欄位是空值時不輸出，舊配方碼要逐位元不變。加一個舊配方碼比對測試。
4. **前端打造畫面**：照現有樣式多一個選項，開關關著時不顯示。

## 不做

- 不改引擎，`LOG_FORMAT` 不升。
- 不改 `docs/design/`、`config/` 既有的值。

  - 舊配方碼逐位元相同。
- **測試**（開關打開）：
  - 鐵匠指定類型。
  - 指定類型和技能強化二選一。
  - 剩下的放不下時報錯。
  - 重骰只換同一種。
  - 重骰費用遞增，而且和同件其他詞條共用次數。
  - 附魔台的指定不能指定招牌。
