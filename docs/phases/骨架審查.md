## 2. 要你決定的題目（第一個選項是建議）

每題附：白話、例子、對玩家的價值、規模（小＝加一條資料或條件／中＝新原語或新觸發／大＝新系統）。

### 題 1：加「距離條件」（貼身／遠距）——價值高、規模小
- **問題**：條件只有「相鄰友方」「目標孤立」這類，沒有「我和目標多遠」。近戰和遠程除了射程，沒有「站得近才強」「站得遠才強」的取捨。
- **例**：「抵近射擊：和目標相鄰時暴擊範圍 +2」（弓手冒險貼臉）、「狙殺：距離 5 格以上傷害提高」。
- **A（建議）加兩個條件**：貼身（距離 1）、遠距（距離 ≥ 5，數字工坊調），照一般條件打折預算，組合器、LLM 都能用。06 6.18 G 已有「依距離連續縮放」，這是更簡單的開關版，兩者並存。
- B 不加。

### 題 2：「本回合移動過」幾乎每次都成立——價值高、規模小
- **問題**：移動不花 AP，玩家幾乎每回合都會走幾步，所以這個條件幾乎永遠成立，卻照條件讓預算打折，等於白送折扣。
- **A（建議）改成「本回合移動過至少 N 格」**（N 初值 3，工坊調），走一兩步不算；原本帶這個條件的招照新定義讀。
- B 照舊，只把它的打折調小（數值，工坊）。
- C 照舊不動。
- **屬於改既有條件的定義，要你定。**

### 題 3：閃現加「側變」：換方向、不換強度——價值高、規模小
- **問題**：閃現的選項大多是「純變強」（範圍 +1、距離 +1），大家容易挑同一個最優解；目前只有「收束」「收回家族」是取捨。
- **例**：推 → 拉、單體 → 連鎖但只跳 1 次、直線 → 錐形、近戰改成「先衝過去再打」。強度照預算重算，和原本差不多。
- **A（建議）加一類「側變」小變化**（每次閃現最多出 1 張，混合規則照舊），讓成長變成「挑方向」而不只是「挑最強」。強度下限照舊（整招不低於現在）。
- B 不加。

### 題 4：「吸收表面」：吃掉地上的表面換資源——價值高、規模小～中
- **問題**：地圖互動幾乎被元素技能包辦（造水、結冰、導電、點火）；物理、形態、氣、怒氣這類 build 很少能從地圖拿到好處。
- **例**：「熔心：吸掉腳下的火表面，+2 怒氣」「納氣：吸掉一格水，回一點血並 +1 氣」「吞毒：吸掉毒表面，下一擊附毒」。
- **A（建議）加一個原語「吸收表面」**：移除自己腳下或目標格的一種表面，換成層數、治療、護盾或下一擊附加（照預算）。也順便讓「清理危險地面」多一種做法。
- B 不加。

### 題 5：「雙向協同」：你造的關鍵字被利用時，你也有回饋——價值高、規模中
- **問題**：協同是單向的：製造方（造燃燒的人）搭好舞台，利用方（引爆的人）吃掉收益，製造方什麼都拿不到。多人或隊友協同時，製造方沒有成就感。
- **例**：「餘燼共鳴（被動）：你造成的燃燒被引爆時，你 +1 專注」「潮汐（被動）：你造的水導電時，你回一點法力」。
- **A（建議）加一個觸發時機「你造的關鍵字被利用時」**，給被動與詞條用；每回合最多觸發 1 次。
- B 不加。

### 題 6：「長距離鉤人，只拉到身邊」——價值高、規模小；**牽涉你定過的上限**
- **問題**：推拉上限 2 格（06 6.6）。勾人（Dota 帕吉、LoL 機器人）是辨識度最高的位移招，我們做不出來。
- **A（建議）開一個例外原語「鉤」**：沿直線射程 5，打中第一個單位、把它拉到你身邊（相鄰格），不能拉進致命地形；冷卻長、頭目照現行對位移的規則。一般的推拉照舊 ≤ 2 格。
- B 照舊不做（維持 ≤ 2 格的通則）。
- **改的是已寫入的上限，要你定。**

### 題 7：「戰前佈置」：開戰前免費放一個刻印或陷阱——價值中、規模小
- **問題**：「造水 → 結冰 → 推人」這類搭建型連段要 2～3 回合，一場只有 4～6 輪，常常剛搭好就打完了。
- **A（建議）開戰前（我方起始區內）可以免費放 1 個自己的刻印、陷阱或表面**（要裝備著會做這件事的技能才行；用掉這招的第一次冷卻）。
- B 不加，改成在閃現或詞條給「第一輪冷卻 −1」之類的加速（數值）。
- C 不處理。

### 題 8：「擲骰操控」反應——價值高、規模中
- **問題**：骰子是 TRPG 的靈魂，但反應只能「還擊」或「放效果」，不能改一次正在結算的擲骰（D&D 的 Silvery Barbs、博德之門 3 的吟遊激勵）。
- **例**：「命運之線（反應）：隊友擲出 1～5 時，讓他重擲一次」「厄運低語（反應）：敵人命中你時，逼他重擲取較低」。
- **A（建議）加一個原語「重擲」**，只能放在反應技，每輪 1 次照反應規則；預覽要顯示。
- B 之後再說。

### 題 9：「下一招修飾」——價值高、規模中（建議之後做）
- **例**：Slay the Spire 的「下一張技能打兩次」。「蓄勢：你這回合的下一招範圍 +1」「回聲：下一招重複一次（威力減半）」。
- **A（建議）記下來，等「改造型」與層數系統成熟後再做**：已有「下一次攻擊優勢」、專注（下一招加傷）是同方向的小版本，先看玩家用不用。
- B 現在就做。

### 題 10：「疾病擴散」提前做——價值高、規模小

### 題 11：三選一「新方向」那張，優先給能自己啟動的——價值高、規模小
- **問題**：新方向帶的是你還沒有的關鍵字。如果剛好抽到「利用」那一邊（例：點燃＋撞擊的戰士抽到「對潮濕目標加傷」），手上沒有任何東西會造潮濕，這張就是廢牌，玩家只好一直選加深、橋接，路線很早就定型。
- **A（建議）新方向格打分時，「製造」那邊的卡優先**（自己就能造出這個關鍵字，例：「水彈：小傷害＋目標格造水」），或「同時製造又利用」的卡；純利用的卡排後面。只是挑選模式的打分，不改出題規則。
- B 照現狀。

### 題 12：推、拉、撞擊打到「推不動」的頭目時，改成撞擊傷害——價值高、規模小；**改既有規則**
