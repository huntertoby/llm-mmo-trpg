## 範圍

1. **佈置說明卡**：
   - 左上的技能說明卡改成：「點框起來的起始區裡的一格放下（可選 N 格）。Esc／右鍵取消。」N 是可放的格數。
   - 不再寫顏色。
2. **佈置時的格子資訊卡**：
   - 佈置模式下，滑過可放的格子時不顯示格子資訊卡；滑過其他格子照舊顯示。

4. **`client/src/dev/fixtures/flashChoice.json`**：這個檔已經過期，照它的產生腳本重產。逐項看差異，確認都是 SK-3c 以前的既有變動，寫進報告。
