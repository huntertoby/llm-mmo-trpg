## 4. 摘要表

### 4.1 量測設定

- 重現：`UV_NO_SYNC=1 uv run python scripts/ob6_newbie_sim.py run --per-cell 80 --jobs 4 --candidates current --out <暫存>/run2.json`；重印 `... report <暫存>/run2.json`。
- 每格 80 人走到第 3 步；第 1、2 步輸掉的人另列，依序補人。實際 325 人。
- 種子 `60000 + 格 × 1000 + i`（格 0～3＝火焰、匕首、巨劍、弓），i：火焰 0～80、匕首 0～79、巨劍 0～82、弓 0～80。世界種子、開局種子都用它，角色 ID `ob6c<格>n<i>`。時間固定 `1_793_592_000`（白天）。
- `--jobs 4`，**耗時 126 秒**（第 1 次完整量測每格固定 80 人、320 人 138 秒；分母不足 80，改腳本補人後跑第 2 次。兩次的前 320 人結果相同，表以第 2 次為準）。冒煙（8 人 × 4 組候選）10 秒。
- 走法：建角站霧渡鎮（跳過主城那段，同舊 `f4_newbie_sim.py`）→ `opening_class` → 接 `starter_ferry` → BFS 一次走一格、盡量避開目標以外的視野、碰到就打 → 第 1、2 步 → 走回霧渡鎮 `opening_confirm` → 兩組三選一選第 1 張（325 人都選得進，沒有跳過）→ 第 3 步一路走到 `terrace_clash`，路上每一場都打。雙方都是效用 AI。輸了就停。
- 倒下＝主角收到 `UnitDowned` 或結束時 HP ≤ 0。
