只比品質（正確率、JSON 合格率、退回率），**不量速度**（使用者：「等等測試只能測試聰明程度喔 因為現在是在windows 實際上 mac的 速度 能不能跑是一回事」）。耗時數字只是 Windows 上的參考，不代表 Mac mini。

- 程式碼：兩邊都在 commit `6af12836`（src、content、scripts、tests 相同），題目、種子、重試次數相同。
- 端點：LM Studio `http://127.0.0.1:1234/v1`，用環境變數指定，`config/llm.toml` 沒改。
  - Gemma：`gemma-4-12b-it`。
  - 27B：`swift-1.5-qwen3.8-27b-uncensored-dynamic-mtp`（使用者：「swift 開好了」）。
- 設定：兩邊都 `TRPG_LLM_REASONING_EFFORT=none`（27B 試打確認思考 token 為 0），一次一個請求（`--workers 1`）。
- 第一次的 Gemma 報告（`Gemma-12B品質評估.md`）的 27B 對照不是同場跑的，以本文件為準。
- 原始輸出在開發 PM 的暫存資料夾，沒進版控。

## 細節

### 技能提議

- 兩邊 HTTP 全 200、結束原因全 `stop`，沒有 JSON 錯誤。
- **升級候選兩邊都約一半退回**，差距只有 4 個百分點。主因是兩邊共通的引擎修補與驗證：`budget.weak`、`exclusion.no_cooldown_big_area`。這表示升級候選的退回主要在題目與驗證器本身，換大模型幫助不大。
- 錯誤種類不同：
  - Gemma 最多的是 `value_error`（選填欄位組合，32 次）。
  - 27B 最多的是 `budget.weak`（47 次）與 `keyword.required`（23 次）。27B 格式守得好，但數值偏保守。
- **強制測試與自由測試 27B 明顯好**，退回少約 24 和 5 個百分點。

### 閃現變化

- 退回模板一樣是 8%，玩家都拿得到東西。
- 27B 的「模型湊滿」反而比較少：`flash.note_zh.missing_added` 有 28 次，Gemma 只有 11 次，也就是敘述裡漏寫新增的效果。名稱與敘述較短、較直白。

### 情境判定

- 兩邊都全部一次合格。
- **好答案的給分**：Gemma 多給 −2（25 題），27B 幾乎都給 −1（45 題）。兩種都在規則範圍內，27B 比較保守。
- **注入**：
  - 兩邊都沒有給負的 `dc_shift`。
  - 27B 46 題全部沒勾用心清單；Gemma 有 1 題勾了，但引擎端的檢查已擋下。
  - 27B 對注入比較兇：27 題直接給 +2 加劣勢。

### 說書人

- 兩邊都全部用 LLM。
- 文筆差異：
  - Gemma 的開場較長，會寫 `more_zh` 補充段。
  - 27B 較短、較冷硬，`more_zh` 幾乎都留空。
- 抽樣看到 27B 一個小問題：問灰鬚（greybeard）時，回答用了老鐵的口頭禪「嘿」，`npcs` 也填成老鐵，等於換了一個人講話。Gemma 的抽樣沒有這個問題。
- 注入的聊天兩邊都照角色回絕，沒有照做。

## 結論與建議

- **情境判定、說書人：兩個都夠用**，Gemma 不輸。27B 偶爾會講錯人。
- **閃現：Gemma 略好**，退回率相同。
- **技能提議：27B 明顯好**（強制測試 +24、自由測試一次通過 +26）。升級候選兩邊都約一半退回，問題主要不在模型。
- 建議：
  1. 部署在 Mac mini、只能放一個模型時，用 **Gemma 12B 就可以上線**：大世界的文字都沒問題，技能提議由組合器補位，不會卡住玩家。
  2. 如果 Mac mini 跑得動 27B，技能提議（尤其強制測試的原語）用 27B 品質比較好。`config/llm.toml` 可以為技能另設端點，屬於後期項目。
  3. 升級候選的退回率約 50%，兩個模型都一樣，值得另排一段調 `budget.weak` 的提示或修補，比換模型有效。
- 待決（給使用者／專案 PM）：
  - 正式用哪個模型（`config/llm.toml` 的 `base_url`、`model`、`reasoning_effort = "none"`）。
  - 要不要排一段「升級候選退回率」的調整。
  - gemma-4-31b-it 部署好後，用同一套題目再跑一次。指令：`run_llm_eval.sh <輸出資料夾> http://127.0.0.1:1234/v1 gemma-4-31b-it none`。
