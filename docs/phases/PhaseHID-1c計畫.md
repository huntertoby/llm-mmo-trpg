| 項目 | 決定 |
|---|---|
| `BombOut`（未揭露的隱蔽單位） | 要遮。文字改通用危險提示，`remaining`、`radius` 不送；`unit_id`、`pos`、`tiles`、`explodes` 保留 |

## 範圍外

- 不改隱蔽規則、不改紅框大小、不調霧。
- `種子 2、5` 的格子資訊卡 FAIL 不在本段（另記）。

## 交付項目

1. **「？」徽章整圈完整**：`marks` 是每排一層，整排仍在南邊一排的 `ground` 之下，圓底超出格子下緣幾像素，被南邊地磚蓋掉。要求：整圈完整，**南邊一排站著人時，人照舊蓋得過徽章**。建議比照朝南三角形掛南邊一排的 `under`（6F-21），實作自定。
2. **查其他超出格底的 HUD**：掃描所有可能超出格子下緣的 HUD，例如紅框下緣的金色尖角（`hid1b_move_plain_zoom.jpg` 看起來同因）。同因的一併修，結果列在報告。
3. **`BombOut` 遮罩**：照 PM 決定表。沿用 `hidden_unit_ids`，只在 API 層過濾；引擎預告維持完整。
4. **補拍**：見驗收條件。

## 受影響的既有功能

| 項目 | 影響 | 處理 |
|---|---|---|
| 繪製圖層 | 南排 `under` 的順序 | 既有朝南三角形、遮擋 HUD 的測試原樣通過 |
| 前端讀 `BombOut.remaining`、`radius` | 欄位可能為空 | 型別改可空或走通用文字，`gen:api` 同步，畫面不得出現「undefined」 |
| 已揭露單位、我方的炸彈預告 | 不變 | 測試比對與改前相同 |
| 引擎、內容、重播 | 不變 | `WORLD_RULES_VERSION`、`LOG_FORMAT` 不加一 |

## 行為一致測試

- API 表格測試，**實際跑引擎**：未揭露、已揭露、我方攜帶定時炸彈各一，比對 `BombOut` 各欄位與文字；序列化後的未揭露項目不含倒數、半徑與狀態名。
- 圖層測試：「？」徽章的掛載層與 z 順序：南排有人時人在徽章之上，南排是地磚時徽章在地磚之上。
