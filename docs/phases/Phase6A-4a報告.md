# Phase 6A-4a 完成報告：戰鬥 D 版①（待機不畫格線＋地表併塊）

實作者，2026-11-04。規格：`docs/phases/Phase6計畫.md` 6A-4a 列、`docs/design/05-戰鬥.md` 5.10（#121）、`docs/art/戰鬥D版樣張.md` 第 2、5、6 節。

## 做了什麼

1. **待機不畫格線**
   - `terrainArt.ts` 的 `drawTile` 拿掉每格的極淡格線（`strokeRect`）。
   - `BattleRenderer.ts` 只改一行：沒有貼圖時的退回色塊不再描邊。
   - 高亮機制（可走格、攻擊格、預覽等）完全沒動，6A-4c 可以直接用。
2. **地表併塊**（新檔 `client/src/render/surfaceBlobs.ts`，純函式）
   - 每格的形狀由四鄰與四個斜鄰「是不是同種地表」決定：
     - 和同種鄰格相接的邊（接縫）貼齊格子邊界，補滿；
     - 露在外面的邊內縮 1.5～4.5 單位（`MAX_INSET = 5`），沿邊有起伏；
     - 兩邊都露出的角畫成凸圓角（半徑 10～14）；
     - 兩邊都是接縫、但斜鄰不是同種的角，畫成內凹的小圓角（≤ 5 單位）。
   - 起伏只看格子座標雜湊（`artRandom.hash`），結果固定。頂點上的內縮量只看「頂點座標＋邊的方向」，所以相鄰格的外緣在接縫處接得上。
   - 所有點都在格子內，看起來的範圍和實際判定的格子一致。
   - 外緣只描露在外面的段，接縫不描。
   - `artSpecs.tileArtSpec` 新增 `surfDiag`（斜鄰旗標）。`TileArtSpec.surfDiag` 是選填欄位，沒給時視為同種；貼圖快取鍵已包含它。
3. **各地表的畫法**（`terrainArt.ts` 的 `SURFACE_STYLE`）
   - 每種地表依序畫：填色 → 紋理（裁在形狀內）→ 外緣。
   - 冰：白邊，反光斜線，細裂紋。
   - 油：金褐油光邊，虹彩亮斑，一抹白色油光。
   - 火：橘紅邊加光暈（`shadowBlur`，只在格子貼圖內），中央光暈，火苗。
   - 水：沿用原本的反光線，另加一條很淡的亮邊。
   - 毒、聖光、黑暗、煙霧：沿用原本的顏色與紋理，改成併塊畫法，外緣用同色系的亮邊。
   - 黑暗原本是整格的徑向暈染，現在裁在形狀內。
   - 不認得的地表：灰色併塊。
4. **陷阱**
   - `fieldFx.drawTrapPad` 在原本的踏板外加一圈淡紅虛線圈（`TRAP_HALO_RX/RY`，圈在格子內）。
   - 沒發現的陷阱伺服器本來就不送，所以不畫，照舊。
5. **dev 畫廊**
   - `client/src/dev/surfaceGallery.ts` 是 12×8 的地表併塊場景，包含：八種地表；單格、L 形、中空環、內凹角；冰接油（異種相鄰）；我方陷阱與已揭露的敵方陷阱。
   - 這個場景加在 `fx-gallery.html` 的第二格，沒有新增 html 檔。
