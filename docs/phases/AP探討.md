# AP（行動力）探討（給使用者決定）

> 2026-11-19，玩法 PM。使用者試玩回饋（專案 PM 轉）：「AP不夠用……有些還要2AP 所以我一回合 我可能只能丟個技能跟普攻一下 然後敵人可能 就普攻3下 然後我技能如果MISS了的話 反而一來一往 就感覺不舒服……可以借下回合2AP那種……3AP 這個是不是訂得不好?」
> **提案，設計文件先不改。** 只談規則與機制；數值（AP 數、返還量、上限）都是初值，由你在數值工坊調。沒有跑模擬，第 2 節是紙面算的一個代表回合。

## 0. 結論

- **3 AP 本身不算訂錯，問題在「一回合的成敗押在一顆骰子上」。**
  - 你的回合常是「2 AP 技能＋普攻」，技能一失手，整回合的三分之二就沒了。
  - 敵人是 3 次普攻、3 顆骰子，很少一次全空。平均傷害差不多，但你的回合起伏大得多，所以「一來一往」吃虧的感覺是真的（第 2 節）。
- **其實已經有「留 AP」**：沒用完的 AP 可以留 1 點到下回合，上限 4。程式有做，狀態卡寫「下回合保留 +N」，但不顯眼，你試玩時大概沒注意到。**「預借下回合」目前沒有**，只有技能代價「透支」（施放後下回合少 1 AP）。
- **會給 AP 的東西都很少見**：
  - 「給 AP」是傳說級的改寫規則；
  - 「擊倒返還 1 AP」只有幾招和一條裝備詞條；
  - 5.2 寫的「累積到門檻 +1 AP」詞條沒有做。
  - 平常打怪幾乎碰不到，所以你覺得 AP 的玩法少。
- **建議組合**（各題第一個選項）：
  1. 玩家 4 AP、一般敵人 3 AP；
  2. 新增基本動作「預支」；
  3. 2 AP 以上的技能整招落空時返還 1 AP；
  4. 補一批會給 AP 的內容（不加關鍵字）；
  5. 技能耗費結構不動。
  - 只想小改的話：題 1 選 C（維持 3 AP），靠題 2、題 3 解決大部分不舒服。

## 2. 紙面代表回合（同級、命中 90%；精英 70%）

假設技能每 AP 的價值約等於普攻（設計目標 1.0～1.3，#148 核對）。一回合 3 AP，所以「滿分」大約是 3 份傷害。

| | 你：2 AP 技能＋普攻 | 敵人：普攻 ×3 |
|---|---|---|
| 平均 | 約 2.7 份 | 約 2.7 份 |
| 失去三分之二以上的機率（同級） | **10%**（技能失手） | 2.8%（3 下裡空 2 下以上） |
| 失去三分之二以上的機率（打精英，70%） | **30%** | 21.6% |
| 整回合全空 | 1%（同級）／9%（精英） | 0.1%／2.7% |

→ 平均一樣，但你的回合「一失手就很慘」的機率是敵人的 1.4～3.6 倍，而且你的技能還帶狀態、控制，失手時損失更大。這就是一來一往不舒服的來源。

## 4. 題目之間的關係

- 題 1 選 A 時，題 3 仍建議做，因為精英戰的命中只有約 70%。
- 題 1 選 C 時，題 2 A＋題 3 A 是最小的有感改動。
- 題 5 C 和題 1 A 都在處理「敵人普攻連打」，選一個就好。
- 參考的機制概念：同類戰術 RPG 常見「回合間存 AP」「預支下一回合」「擦傷」「失手漸進命中」，這裡只取概念，名稱、數值照本專案。
