- 不改 `src/trpg/`（Python）、`content/`、API schema（`client/openapi.json`、`schema.d.ts` 不動——另一個 agent 的 OB-3 會重產它們）。
- 不改人形、鳥以外其他身形的既有片段（山豹斑點除外）。

## 交付項目

1. 移植需求第 1、2 節：5 個片段與輔助函式（`kfN`、`plant`、`sweep`、`TAILOVER`、`bendTail`、`pose.split`）、山豹斑點改組、熊的乳白三爪、`frameOf` 確認。
2. 挑法接線（第 3 節）：戰鬥動畫依「普攻／單體近戰技能」選片段；命中時間照表對齊傷害數字與受擊反應（撲咬拉扯有 4 個時間點：以 333 為命中，其餘只是畫面）。
3. 開發頁（`client/dev/` 的異形畫廊或同等頁面）能逐格看這 5 個片段，朝東、朝西。
4. **順手（美術 PM，`docs/art/CB-2b檢查.md`）**：① 移動後緊接同一隻鳥的攻擊時，略過移動結尾的落地與攻擊開頭的起飛，補拍一組連拍；② 確認 `cb2c` `1b`、`1c` 蜥蜴孵化後朝向翻轉只是開發頁手寫狀態、實戰不會，結果寫進報告。
5. 測試：片段長度、格數、命中時間的資料測試；挑法的單元測試（普攻、單體近戰技能、範圍技能、遠程技能各一筆）；減少動態模式。

## 驗收條件

- `corepack pnpm -C client typecheck`、`corepack pnpm -C client test`（vitest 全部）通過；在 `client` 內 `npx vite build` 通過。快照有變時逐類說明原因（預期只有山豹斑點與新片段）。
- **移植需求第 4 節的 7 項，每項都要有截圖**，放 `docs/art/shots/cb3/`，檔名對應項目編號；實機到不了的用開發頁畫出來，並在報告寫「實機未看」。只靠 vitest 的不算通過。
- 截圖用自己啟動的預覽伺服器（不用 8000、8001、8092 埠），網址一律加 `?mute=1`；結束時只關自己啟動的程序。
