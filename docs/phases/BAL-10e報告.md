# BAL-10e 報告：收回家族（#75）——精煉、合體、專注、陷阱與地面格的收束

依 `docs/phases/PhaseBAL計畫.md` 第 5 節實作。設計：`docs/design/06-技能.md` 6.34.4「收束」「收回家族」（含「BAL-10d 定」）。沒有連真模型。

## 做了什麼
1. **接在 BAL-10d 的共用機制上**（`trpg.skillgen.flash_trade`）：
   - `Trade` 多一個可省略的 `knobs`（效果本身威力以外的旋鈕，`index` 指向效果；傳給 `retune(effect_knobs=...)`），合體用它調召喚物 HP。其他欄位（`remove`／`gain`／`core`）與 `apply_trade` 流程不變：拿掉的預算＋40‰ → 目標比例 max(收回前＋40‰, 一般重調的隨機目標) → 只用威力旋鈕重調、強度下限照 6.34.3 → 單發上限 3 倍、超過改減費用、減不動不出。
   - `TRADES` 加 7 個：`refine`、`refine_merge`、`fuse`、`focus_range`、`focus_condition`、`focus_mod_range`、`focus_mod_condition`。各自的「拿掉什麼」寫在新模組 `src/trpg/skillgen/flash_reclaim.py`（`flash_trade` 匯入登錄；`flash_reclaim` 不匯入 `flash_trade`，沒有循環）。
2. **精煉**（主動技、非陷阱、要有主要效果＝第一個傷害／治療／護盾）：
   - `refine`（類別「元素與關鍵字」，前綴「精煉」）：依序試拿掉一個附帶效果（由後往前，閃現加上的通常在後面）——附帶狀態（`apply_status`）、第二關鍵字的製造（`create_surface`、`knock_prone`）、第二元素（和主要效果不同元素的傷害）、第二關鍵字的利用（帶條件的加碼傷害）；最後試拿掉接續段。主要效果不拿。拿掉後原骨架不合適時依序改試 `strike`、`combo`（模板 `skeletons`，同收束）。
   - `refine_merge`（類別「連段」，前綴「精煉」）：和第一個傷害同元素、同對象、沒有條件的其他傷害段全部拿掉，總點數換成那一段的威力。
3. **合體** `fuse`（類別「輔助」照設計表，前綴「合體」）：一次召喚 ≥ 2 隻的召喚技，隻數 −1；剩一隻時拿掉 `count` 與 `power_permille`（schema：一隻時不能低於 1000‰），換到的強度由召喚物最大 HP 旋鈕（照強壯 `summon_toughen` 的階梯 `SUMMON_HP_STEPS`，從目前的值起；沒有加成時從「不加」起）吸收。
4. **專注**（前綴「專注」）：
   - `focus_range`（觸發）：`trigger.max_distance` −1（已是 1 不出）；沒有距離上限時形狀的 `size`／`radius` −1（觸發範圍 +1 的反向）。
   - `focus_condition`（觸發）：反應「被攻擊時 → 被近戰攻擊時」（`hit_by_attack → hit_by_melee`）；技能條件收緊一級：沒有條件 → 加一個（有另一方目標時先試「目標血量低於 50%」、再試「自身血量低於 50%」；只作用在自己身上的只用自身血量）；有「或」→ 拿掉那一支；血量門檻收緊 150‰（不低於 100‰）；狀態、表面等已是最緊，不出。
   - `focus_mod_range`（修正）：「範圍 +n」「射程 +n」的規則 −1；只有 +1 時拿掉那條規則（至少留一條規則）。
   - `focus_mod_condition`（修正）：規則的條件照上面收緊一級（最多 3 份草稿，同條件放寬）。換到的修正幅度用 BAL-10b 修正模板的旋鈕（`flash_ops.RECLAIM_MOD_OP`：細階梯＋`rules.modifier_knobs` 的其他幅度）。
5. **陷阱、地面格的收束**（`converge_single`／`converge_step` 擴充，`convergible` 跟著放寬）：
   - 陷阱：觸發範圍 `trap.shape` 十字／3×3 → 單格；縮小一級 3×3 → 十字（十字再小就是單格，不另出縮小一級）。放置的形狀與骨架不動。
   - 地面格（解讀為持續區域 `zone`）：區域裡有傷害／治療／護盾時也算有威力；收束改技能形狀，`converge_gain` 把區域結算的效果也當威力旋鈕（同接續段的做法，字典是同一批物件）。

7. 腳本：`scripts/flash_reclaim_measure.py`（新）；`scripts/flash_minor_coverage.py` 補新模板的「結構不符」原因。

   - `focus_condition`：`skill_covering_fire@3@1／@11@1／@5@2`。
