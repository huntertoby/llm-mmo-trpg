## 1. 每項做了什麼

### 必修 1：半坐起的手撐在地上
- 檔案：`client/src/render/eventArtAwaken.ts`、`inkDoll.ts`、`inkPose.ts`。
- **武器先收起來**：新函式 `awakenHeroSpec` 把主手和副手拿掉，其他外觀不動。躺著和坐起兩格都套用，避免換格時劍突然消失。
- **上半身後仰**：`lean` 從 -0.42 改成 -0.6，約 34°。
- **兩手在髖部後方打直撐地**：
  - 手肘不彎（`elbow`／`elbowF` 是 0）。
  - 近側的手在髖部後方約 12.5，遠側的手再往後約 4，從近側的手後面露出來。
  - 兩條手臂都往後斜。手掌的下緣落在地面線上；遠側比較遠，接地點在畫面上高約 1px。
- **為什麼要加臂長**：
  - Q 版手臂只到腰，肩到手約 8.9。
  - 上半身後仰 30～35° 時，肩膀離地約 14。
  - 所以原長怎麼轉都碰不到地。
- **臂長怎麼加**：
  - `InkPose` 新增 `reach`／`reachF`（臂長加量，0＝原長）。
  - `inkDoll.limb` 讓上臂、前臂沿各自的方向拉長，寬度不變。
  - 手接在拉長後的末端，手的大小不變。
  - 開場用 `reach` 0.55、`reachF` 1.1（遠側手臂部件本來就比較短，又伸得比較遠）。
  - `reach` 是 0 時，畫布指令和原本完全一樣：`inkDollSnapshot`、`inkDoll`、`inkPose`、`motionClips` 的測試都過。
- **測試**：`client/src/world/rt5d.test.ts` 用追蹤畫布變換的假 context 畫出整張插圖，再量手的位置。
  - 有武器的主角和空手的主角，兩格的畫布指令一樣（武器沒畫出來）。
  - 後仰在 30～35° 之間。
  - 近側、遠側的手都在髖部後方，「手心＋半徑」和地面線的差 ≤ 1.5。
  - 遠側的手比近側的更後面。
  - `rt5c.test.ts` 拿掉 `lean > -0.5` 那一行，改由 rt5d 鎖 30～35°。
- **截圖**：
  - `rt5d_1_halfsit_1600.png`／`_zoom`／`_hero_zoom`
  - `rt5d_1_halfsit_800.png`／`_zoom`／`_hero_zoom`

### 必修 2：1600 寬的夾邊畫面（開發用鏡頭位移）
- 新檔 `client/src/world/devCamera.ts`：

  - 不是 `dev=1`、沒給、格式不對或 0,0 時，回傳 null（沒有位移）。
- `WorldField` 在鏡頭微調之後加上這個位移。正式畫面沒有位移。
- **拍法**：

  2. 往南走 9 格。
  3. 守印人走出畫面上緣，夾到上邊。

  - `rt5d_2_bubble_1600.png`／`_zoom`（`devcam=0,260`，3 倍）：B 站在守印人正下方，夾邊的「！」本來會落在 B 頭上。現在「！」和泡泡挪到 B 左邊，B 的頭露出來。

  - 開發模式的頁面頂端多一條「大世界（測試）」標題列，畫面比正式頁矮一些。
  - 鏡頭推過地圖下緣，所以畫面下方會露出地圖外的深色區。這是開發頁的拍法，正式畫面不會這樣。
- **測試**：`rt5d.test.ts`（只在 dev 模式有效、格式檢查、位移加法）。

### 小修 3：荒原碑身被快捷列蓋住
- **原因**：主角站在西邊時，碑身要往上推約 132 才露出來，超過微調上限 96（`NUDGE_MAX`）。
- **改法**（`hudAvoid.ts`）：
  - `NudgeTarget` 加 `far` 旗標。`WorldField` 把碑身（權重 3 的石碑）標上 `far`。
  - 碑身已經露出一部分、被下方某塊 HUD 蓋住時，多試「碑身下緣剛好貼齊那塊 HUD 上緣」的鏡頭位置（`farStops`）。
  - 這些位置只往上推（鏡頭 y 變大）、只在垂直方向，最多 `NUDGE_FAR` 144（3 格），照樣夾在地圖可捲範圍內，主角也不能被蓋住。
- **結果**：鏡頭 y 從 284.75 推到 417。荒原碑身整個在說明列上面，說明列也不用挪了（`data-shift` 沒有值）。
- **測試**：`rt5d.test.ts` 用實機量到的這一幀輸入：
  - 有 `far` 時碑身整個露出來，推的距離在 96～144 之間。
  - 沒有 `far` 時照舊最多 96，碑身推不出來。
- **截圖**：`rt5d_3_caption_1600.png`／`_zoom`。

### 小修 4：說明列壓在紫水晶燈柱上
- **新函式**（`hudAvoid.ts`）：
  - `captionShiftDecor(cap, must, decor, hud, w)`：先試同時避開碑身／主線的人和裝飾物；找不到位置時，退回只避開碑身和主線的人（RT-5c 的做法）。
  - `lampRect`：源晶燈的範圍，晶石尖到燈座、寬 22。
  - `decorCellRect`：一格大小的花壇。
- **裝飾物**：源晶燈，加上花壇（`field.decor` 的 `flower_bed`）。
  - 只避開燈柱時，說明列往左挪了 142，又壓到燈柱旁的花壇，所以把花壇也算進去。
- **結果**：說明列往右挪 162（`data-shift="162"`），燈柱和花壇都沒被壓到。
- **測試**：`rt5d.test.ts`（壓到燈柱時挪開；沒壓到不挪；燈柱讓不開時退回只避開碑身）。
- **截圖**：`rt5d_4_band_1600.png`／`_zoom`。
