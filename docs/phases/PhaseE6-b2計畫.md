## 範圍

1. **勾選的保存**：
   - 一輪（`trpg-run`）和大世界角色（`trpg-char`）的存檔加上玩家的勾選，給預設值，舊存檔要照讀。版號升不升照各自的規則，報告寫明。
   - 開戰時把勾選帶進 `Loadout.chosen`。
2. **「保留原本生效的」**（E6-b1 待決 1）：換裝時，把換裝前生效的招牌和改寫規則寫進勾選，讓新穿上的標灰。
3. **API**：
   - 角色面板和裝備檢視給出前端要的欄位：招牌種類、是否生效、標灰原因、名額計數。
   - 勾選的寫入端點要檢查合法性：不能超過 3 個，改寫規則最多 1 條，勾的必須是身上有的。
   - 守則 14：只有玩家自己的角色可以勾選。其他單位照現有規則顯示。
   - 重產 OpenAPI 和 `schema.d.ts`。
4. **前端**：照美術移植需求第 1 節第 1～5 項做：
   - 招牌框
   - 類型小圖示，地形規則用新畫的圖
   - 撿到時的一次性強調
   - 大世界掉落的小標
   - 角色面板的勾選（一輪的 `RunHeroPanel` 和大世界「穿戴中」）

   用字照移植需求第 3 節：角色面板裡的灰字用短版，其他地方用長版。
5. **主角面板沒看身上裝備**（WM-1 待決 9）：
   - 先查 `as_run` 沒帶角色裝備是不是會讓大世界主角面板的招牌和數值顯示錯。
   - 會錯就這段一起修，不會錯就在報告寫明理由。
6. **選做**：戰後那行字裡的小牌（移植需求第 1 節第 4 項）。需要後端給結構化的掉落清單。
   - 先估成本，小（大約半天以內）就做，大就不做。
   - 不管做不做，報告都寫一句。

## 不做

- 不改規則，不改數值，不改 `docs/design/`、`config/` 既有的值。
- 打造傳說、世界掉落傳說留給 E6-c2。

## 驗收

- **結果不變**：開關關著、沒有勾選時，下面都要 different=0：
  - 78 場戰鬥
  - 442 招
  - census
  - CLI 快照
- **測試**：
  - 存檔：
    - 讀寫勾選。
    - 舊存檔照讀。
  - 換裝後保留原本生效的。
  - API 擋下不合法的勾選：
    - 超過 3 個；
    - 2 條改寫規則；
    - 勾了身上沒有的。
  - 守則 14：只能勾自己的角色。
  - 前端：
    - 灰字短版、長版各用在哪裡。
    - 名額計數。
    - 已滿時的提示。
    - 一次性強調只播一次。
    - 減少動態時不播。
