# Phase SK-3b 計畫：SK-3 新觸發、重擲接進出題＋玩法答覆

> 來源：玩法交接 4.1.30（46f43db29）；`docs/design/` 06 6.38 第 10～12 點、6.27；`docs/phases/PhaseSK-3報告.md` 的待決和開發 PM 裁定。
> **數字一律是初值，接數值工坊；不試數值，不跑平衡量測。** 接在 SK-2b 之後（SK-2b 改了組合器和 LLM schema）。

## 範圍

1. **「利用」多算兩種**（其餘照現狀）：
   - 條件型：別人的效果因為目標身上有你造的狀態、或目標站在你造的表面上而成立，而且真的生效。6.27 本來就把條件「目標燃燒中」算成利用。
   - 符文被讀取或引爆。
   - 層數不算。敵人或自己利用都算。
2. **每回合最多 1 次**：另做每回合計數，被動和詞條用同一套規則。「回合」指任何一個單位的一個回合。
3. **接進出題**：
   - 新觸發放進被動骨架和裝備詞條；組合器、LLM、挑選模式都可以出；門檻照被動現行規則。
   - 重擲放進反應骨架，只限這兩個時機（隊友失手、敵人命中你）；門檻照反應現行規則。
   - 閃現的「換觸發」先不加新時機。
   - LLM 的觸發清單、反應時機清單、schema、提示詞都要更新（版號跟著升）。
4. **示範技能 4 招**（內建手寫，名字照玩法 PM 定的）：
   - 被動「餘燼共鳴」：你造的燃燒被利用時 +1 專注。
   - 被動「潮引」：你造的水被利用時回 1 法力。
   - 反應「命運偏折」：敵人擲中你時，逼他重擲，取較差的。
   - 反應「幸運低語」：身旁隊友失手時，讓他重擲，取較好的。
5. **工坊白名單**：補上 SK-3 的新數值（`tuning_fields.yaml`）。
6. 重擲、戰前佈置照 SK-3 現狀，不改。

## 驗收

- 相關目錄的測試（分目錄、一次一組、最多 `-n 8`；`tests/llm` 和 `tests/skillgen` 不同時跑）、ruff、format、mypy、lint-imports、前端 tsc 和相關 vitest 都要 0。
- 戰鬥不變比對：不用新觸發的戰鬥 different=0。「利用」多算兩種之後，既有詞條或被動如果因此多觸發，要逐場說明。
- 快照、夾具先預測再逐鍵核對，不整批重產。版號有升就列出。API 有改就重產 OpenAPI。
- 紙面小樣本（`scripts/recipe_census.py` 或 `scripts/wish_coverage.py`）：證明新觸發和重擲做得出來。
- 報告寫在 `docs/phases/PhaseSK-3b報告.md`。
