# 數值工坊（暫名）提案

> 給使用者看的一頁說明（2026-11-12）。技術細節在 `docs/phases/PhaseNW計畫.md`。
> 起因（您的原話）：「數值的調整不要再給你做 反而給我一個數值工仿 讓我可在裡面改各種數值 就不用你們慢慢調了」

## 這是什麼

在遊戲的開發選單裡多一個「數值工坊」。您點選一個敵人或技能，就會看到它的數值：每一欄都有中文名稱、現在的值和一句說明，直接改數字就好，不用碰 YAML 檔。

- **改錯當場就擋**：例如血量填 0、招式名稱打錯，會在那一欄下面用中文說明哪裡不對，不會存進遊戲。
- **改完立刻看效果**：按一下就跑一場小模擬（例如讓 8 種代表性角色各打幾場頭目戰），改前和改後的結果並排顯示：勝率、平均打幾輪、我方倒下率、頭目每招多常放，以及有幾場的勝負因為這次改動翻過來。開始前會先告訴您「要打幾場、大約幾秒」。
- **可以先存草稿**，看「改了哪些、從多少改成多少」的清單，不滿意就整份丟掉。
- **確定後按「寫回」**：數值寫進遊戲的內容檔，並自動留下一筆紀錄（git commit）。之後隨時可以「還原這次」。
- 寫回後要**重開伺服器**，遊戲才會用新數值（模擬不用重開）。進行中的一輪會從頭開始，舊的世界紀錄不能重播；這和平常改內容一樣。

之後的平衡工作：PM 和 agent 只交報表與建議，**數值由您在工坊決定**。

## 分幾段做、每段做完您能做什麼

| 段 | 做完後您能做什麼 |
|---|---|
| **第一段**（分後端、畫面兩次派工，兩次都完成才能用） | 改**所有敵人與頭目**的血量、六項屬性、速度、護甲、法力、耐力、抗性、等級、頭目換階段的血量門檻；跑**頭目戰小模擬**看改前改後；存草稿、看差異、寫回、還原 |
| 第二段 | 加上改**技能**：傷害、消耗、冷卻、範圍、持續回合；改**敵人會放哪些招**；在示範地圖上看某一招被放了幾次、勝率怎麼變；技能強度超出規定區間時會提醒 |
| 第三段 | 加上改 **AI 的判斷權重**、**裝備與道具**數值、**遭遇的敵人陣容與地圖上的敵人數量**；跑**新手任務一路打過去**的模擬看倒下率 |
| 第四段（可不做） | 看自己改過的所有紀錄、把幾個版本的模擬結果放在一起比 |

**第一段先做敵人**：您接下來要調的頭目與新手戰都是敵人數值，而且敵人欄位最單純，最快讓整條路（改 → 擋錯 → 模擬 → 寫回 → 還原）先跑通。

## 安全上的做法（不用您處理，列出來讓您知道）

- 只有您在自己電腦上直接開的瀏覽器能用；朋友從 Tunnel 連進來一律打不開。
- 只能改清單上的數值欄位；文字、外觀、地圖格子、ID 都不能改。
- 寫回前會先備份原檔；任何一步失敗就自動還原。
- 開發 PM 正在合併程式時，寫回會暫時擋下並告訴您「稍後再寫回」，避免兩邊打架。
- 您寫回後，有些自動測試的「固定答案」會跟著變；開發 PM 會派人更新那些測試，**但不會動您的數值**。

## 請您選（每項附建議）

1. **入口放哪？** (a) 開發選單（網址加 `?dev=1`，和技能工坊並排）；(b) 主城裡的某個 NPC。
   **建議 (a)**：主城是玩家看得到的地方，放在開發選單只有您會用到，也最省工。
2. **要怎麼開啟工坊？** (a) 開伺服器時多設一個開關才出現；(b) 開發模式下一律出現。
   **建議 (a)**：開發模式現在預設是開的，多一個開關可避免哪天忘了關、又開了 Tunnel，朋友就能改數值。
3. **寫回時要不要自動留 git 紀錄？** (a) 自動 commit 一筆；(b) 只寫檔，由開發 PM 收；(c) 寫到另一條分支，您再合併。
   **建議 (a)**：每次寫回都有一筆紀錄，可以單筆還原；(b) 容易和 PM 的合併互相干擾，(c) 要您自己合併。
4. **技能強度超出規定區間（第二段才會遇到）怎麼辦？** (a) 警告，您按「我確定」後照樣寫回並登記為例外；(b) 一律不准寫回。
   **建議 (a)**：數值由您決定，但會清楚標出哪一招超出。
5. **小模擬的預設規模？** (a) 小：約 24 場、10～15 秒；(b) 中：約 80 場、30～50 秒。都可以隨時切換。
   **建議 (a) 為預設**，想確認時再按「中」；場數少時數字會跳，結果旁邊會標「樣本小」。
6. **寫回後要不要不重開伺服器就生效？** (a) 要重開伺服器；(b) 不用重開（熱載入）。
   **建議 (a)**：不用重開要改動遊戲伺服器的核心，風險大；模擬本身不用重開就能看。
7. **名字**：「數值工坊」可以嗎？

## 時程

第一段兩次派工（後端、畫面）依序做；您回覆上面 7 項後即可開始。第二、三段等您用過第一段再細排。
