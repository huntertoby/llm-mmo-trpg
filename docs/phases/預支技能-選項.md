# 預支做成技能：細節選項（給使用者決定）

> 2026-11-19，玩法 PM。#168 題 2 改，使用者原話：「喔不 預支 應該是技能不是每個人都能用的」。
> 已經講定、不變的：每回合 4 AP（敵人照單位資料）、保留 1 點、2 AP 以上技能全落空返還 1 AP。
> 數值都是初值，由你在數值工坊調。

## 0. 先說現況

- 現在**已經組得出「預支」**：「給自己 1 AP」（原語 `grant_ap`）＋代價「透支」（下回合少 1 AP），效果正好是本回合 +1、下回合 −1。
  - 但「給 AP」規定**史詩以上**，所以這種招很少見。
  - 透支當代價，會讓這招多出 20% 預算去加別的效果，招會變得怪。
- 技能的 AP 耗費規定 1～3（06 6.3「代價」），**沒有 0 AP 的主動技**。
  - 「施放 1 AP、換本回合 +2」雖然淨值一樣，但讀起來繞。

## 1. 題目（第一個是建議）

### 題 1：怎麼做

| | 做法 | 例子 | 影響 | 工作量 |
|---|---|---|---|---|
| **A（建議）新原語「預支」，主動技 0 AP** | 新原語：本回合 +N AP、下回合 −N AP（N 初值 1）。這個原語的技能**例外允許 0 AP**，同「取消姿態免費」那類例外 | 技能「搶拍」：0 AP，本回合 +1 AP、下回合 −1 AP，冷卻 2 | 讀起來最直接；改 06 6.3 的「AP 1～3」加一個例外 | 中：新原語、驗證器例外、預算計價、AP 列畫法 |
| B 用現有零件 | 給自己 1 AP＋透支代價，照現行規則做 | 史詩技能「借時」：1 AP，自己 +2 AP，透支 | 不改規則，但史詩以上才有；透支的折抵要另外擋 | 小 |
| C 被動「學會預支」 | 裝了這個被動，AP 列才出現預支按鈕（原本美術畫的樣子），每回合可按 1 次 | 被動「寅吃卯糧」 | 美術畫好的按鈕、用字都能用；但每回合都能用，比主動技強，要佔一個被動欄位 | 中 |

### 題 2：去哪拿、幾階、什麼稀有度

| | 做法 | 影響 |
|---|---|---|
| **A（建議）通用池（基礎技能）、稀有起、1 階起、不限武器類別** | 不屬於任何關鍵字（#168 定的「不加關鍵字」）；從升級三選一「新方向」的通用池（10%）、閃現、許願拿到。稀有讓它不算人手一招，但也不會稀少到看不到 |
| B 跟屬性路線走（例：只出在敏捷路線，#110） | 有「快手」的味道，但其他路線永遠拿不到 |
| C 史詩以上 | 跟現行「給 AP」一樣罕見，幾乎碰不到 |

### 題 3：效果、次數、和透支

| | 做法 | 例子 | 影響 |
|---|---|---|---|
| **A（建議）基本款 +1／−1，冷卻 2；閃現可以變化；可和透支疊，AP 最少 0** | 預算約等於 0（不多不少，只是挪時間），所以冷卻與稀有度就是它的代價。閃現大變化可以變成 +2／−2（每場 1 次），或「擊倒時不用還」（收割） | 本回合差 1 點放不出大招就用它 | 有 build 的空間；疊透支時下回合可能只剩 2 AP，是玩家自己的選擇 |
| B 固定 +1／−1，不能閃現 | 一招就這樣，不會變 | — | 最單純，但不成為 build 的一部分 |
| C 每回合都能用（沒有冷卻） | 跟題 1 C 一樣 | — | 等於把 AP 平攤成每兩回合 8 點，偏強 |

### 題 4：許願池許得到嗎

| | 做法 | 影響 |
|---|---|---|
| **A（建議）許得到**：願望對到「增益」＋形狀「自身」時，候選池裡可以有它 | 玩家寫「我想多動一次」「讓我這回合先衝」會許到；照 07 7.6 不另外加標籤 |
| B 許不到，只從升級、閃現拿 | 少一個出口 |

### 題 5：敵人能不能用

| | 做法 | 影響 |
|---|---|---|
| **A（建議）精英、頭目可以帶，一般敵人不帶** | 頭目某回合突然多動一次，是看得到的威脅（AP 列顯示敵人的預支格，玩家知道它下回合會弱）；AI 在湊得出大招時才用 |
| B 敵人都不用 | 最安全 |
| C 都能用 | 雜兵也會預支，節奏亂、看不出重點 |

### 題 6：AP 列的畫法（美術已畫好預支按鈕與預支格）

| | 做法 | 影響 |
|---|---|---|
| **A（建議）拿掉按鈕，保留「預支來的那格」和「下回合少的那格」** | 施放技能後照原畫法顯示借來的格（橘色菱形）和下回合少的格（紅斜線），用字改成「預支來的 AP（下回合 −1）」等。按鈕不需要，技能列施放 |
| B 只有題 1 選 C（被動）時保留按鈕 | 被動解鎖按鈕，原畫法全留 |

## 2. 題目之間的關係

- 題 1 選 C（被動）時：題 3 的冷卻改成「每回合 1 次」；題 6 選 B。
- 題 1 選 B（現有零件）時：題 2 只能是史詩以上（同 C）。
