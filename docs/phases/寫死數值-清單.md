## 2. 建議的搬家分段

- **HC-2 量類（scale 68）**：同一件事（量類要跟 quantity_scale 走），一段做完。
  - a. content 的量類預設值與上下限：`rules.py`（資源池、職業基礎、HP 成長）、`forms.py`（維持費）、`battle.py`（護盾、治療、`_MAX_ATTR`）、`roguelite.py`（起始英雄）。做法：有 YAML 的欄位拿掉程式預設，上下限改成「× quantity_scale」或改由 YAML 驗證。

- **HC-3 前端副本（前端 config 56）**：前端重寫的後端規則改由 API 帶。
  - a. 閃現與技能欄：`run/flash.ts` FALLBACK、`run/flow.ts` SLOT_LIMITS、`ui/SkillCardView` SOURCE_MAX、`gear/affixStatus`、`run/StartPicker`。

  - a. 戰鬥核心：`rules.py`、`battle.py`、`forms.py`、`parts.py`、`equipment.py`、`item_budget.py`（約 260）。
  - b. 技能規則：`skill_rules.py`、`composer_rules.py`、`flash_templates.py`、`skill_pick.py`、`skills/*`（約 330）。
