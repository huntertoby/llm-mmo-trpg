## 3. 瀏覽器驗證紀錄（後端＋建置好的前端 `trpg serve --port 8100`，存檔在 `.scratch_5d1/saves`；大世界 LLM 開關 `enabled: false`＝降級）

1. 建角「阿霧」（火焰法杖；用 API 建，畫面從角色清單進入）：右側顯示「金幣 0・任務幣 0」、背包 0／30、腰包 0／3；霧渡鎮服務列有「商店」。
2. 霧渡鎮 ↔ 渡口石階來回走到遇敵（盜賊 ×2、盜賊盾衛），開戰；主角自己出手（火焰爆＋普攻），第 13 輪打贏。回地點圖：「打贏了（13 輪），獲得 100 經驗。」「獲得 15 金幣（共 15）。」，右側「金幣 15・任務幣 0」。
3. 點地圖走回霧渡鎮 → 「商店」：列出 16 項商品、價格、霧瓶「柳掌櫃好感度到友善才賣」、青竹節「本週剩 5 個」、「每次消費柳掌櫃好感度 +2（每天最多 +4，今天還能 +4）」。小回復藥（20）買鈕停用，滑過顯示共用浮動卡「金幣不夠（要 20，有 15）」。
4. 點「解毒草」的「買」：日誌「在柳記雜貨買了解毒草 ×1（−15 金幣，剩 0）。」「柳掌櫃的好感度 ＋2（2・中立）。」；金幣 0；背包「1／30 格・解毒草 ×1」；好感度說明變「今天還能 +2」。
5. 「整理腰包」→ 解毒草帶 1 →「確定」：背包空、腰包「1／3 個・解毒草 ×1」。
6. 浮動卡（800×600）：滑過腰包「解毒草」→ 卡片貼在上方、不出畫面 → 滑進卡片停留 → 點擊釘住（金框），滑鼠移開不關 → Esc 關閉。卡片內容短，沒有卷軸可捲；1600×900 已驗過商店的停用原因卡。`window.__layoutSmoke.scan()` 回傳空清單。
7. 結束時只停了自己開的 8100 伺服器（TaskStop），關掉自己開的分頁。注意：內建瀏覽器是多個 agent 共用的，第一次驗證用的分頁中途被別的 agent 導到 8110，之後改在自己開的分頁做；那一次因為主角只按結束回合，戰鬥輸了（沒給金幣，符合規則）。

## 5. 待 PM 決定

3. **解毒草的範圍**：要精確「只移除中毒、流血」需要引擎原語（現在用淨化）；是否要加。
4. **回魔藥的戰鬥量**：`restore_resource` 上限 10；要照 25% 就要放寬原語上限（引擎／預算）。
5. **戰鬥畫面的獨立物品欄**（8.17）與道具在沉默時能不能用：排 5D-4。
6. 事件 3「斷崖幫哨兵」交涉付金幣、事件獎勵金幣：解法資料之後補。
7. 規格原本寫「不改 engine」；為了「道具不佔技能欄位」改了 `trpg.content.skills.queries.skill_slot_problems`（content 套件，一行：帶 `item` 標籤的技能不算）並在 `skill_tags.yaml` 加 `item`。引擎本身沒改、`LOG_FORMAT` 不變。
