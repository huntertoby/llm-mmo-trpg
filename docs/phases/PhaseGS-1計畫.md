# Phase GS-1 計畫：護主不獨佔（#171）、「形態」只出在主動題（#172）

> 來源：`docs/玩法決定紀錄.md` #171、#172（87cb6636a），使用者原話「A，形態也照建議補手寫」；`docs/design/06-技能.md` 6.34.5 護主那一點；`docs/技能空格清單.md`；盤點 `docs/phases/盤點-2026-11-21/`。
> 排在 HC-5b 之後：兩段都會改組合器。

## 受影響的既有功能（開工先盤點，寫進報告）

- **出反應技、而且題目指定了關鍵字的地方**：組合器、退回路徑、三選一（挑選模式）、許願、完整技能、測試模式。
- **快照與夾具**：組合器輸出會變，所以 parity、CLI 快照、前端夾具、recipe census 小樣本的基準都要照常重產。重產前先預測哪些鍵會變。
- **出題**：從哪裡抽關鍵字（`skill_pick`、`wish_pick`、`pick_offer` 等）。

## 範圍

1. **#171 護主不獨佔**：
   - 題目指定的關鍵字不是 `summon`、而且是反應題時，**每題只擲一次**要不要用護主，機率是 `recipes.reaction_permille`（250‰）。
     - 這一次要用**獨立的亂數串流**，不能動到原本主串流的取用次數。做法可以參考 SK-3b 的 independent streams。
     - 擲中：先試護主，做不出來再走一般做法。
     - 沒擲中：這一題所有的內部重試都不用護主。
   - 題目指定 `summon`、或沒指定關鍵字的反應題，照舊。伴生（被動）不在這條規則內。
   - 實作細節由實作者定，結果要符合上面的比例。
2. **#172 「形態」只出在主動題**：被動題、反應題抽關鍵字時，不抽 `form`。主動題（含姿態）照舊。這是出題的做法，不改規則；組合器照舊不做形態。
3. **測試**：
   - 護主的比例：用固定種子的小樣本測，例如每格 40 個種子、挑 3 個關鍵字。擲一次、不重擲這件事要有單元測試。
   - 召喚反應 1～4 階都做得出來。
   - 被動題、反應題抽不到 `form`。

## 不做

- 形態 8 招的內容：等使用者看過 `docs/形態補招提案.md` 再另外排。
- 不改護主 3 輪等數值，不動 `docs/design/`。
