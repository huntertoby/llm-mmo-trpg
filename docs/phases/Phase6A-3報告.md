## 1. 交付內容

### 1.1 戰鬥紀錄：浮動提示＋展開＋釘選

- 新增 `client/src/battle/logToasts.ts`（純函式）：
  - `stampArrivals()`：記下每行紀錄出現的時間。剛進戰鬥就有的紀錄、讀檔後補在前面的舊紀錄記成「很久以前」，不會冒出一排舊提示；
  - `liveToasts()`：最新的 3 條（`TOAST_MAX`）、還沒過 6 秒（`TOAST_TTL_MS`）的。最後 1 秒標 `fading`，用 CSS 的 opacity 淡出；
  - 回合分隔行（`turn_started`、`environment_started`、`turn_ended`）不當提示；
  - `nextToastChange()`：下一次要開始淡出或消失的時間，元件只在那個時間點重畫一次，沒有固定間隔的計時器。
- 新增 `client/src/ui/BattleLogDock.tsx`：放在戰場左下（`.log-dock`）。
  - **收起**（預設）：2～3 條浮動提示，寫精簡文字（`summary`，沒有擲骰細節），陣營顏色與符號照舊；下面是紀錄圖示；
  - **展開**：點紀錄圖示就展開完整清單，用原本的 `BattleLog`（分組、擲骰細節、滑過高亮都照舊）。再點一次圖示或按 Esc 收起；
  - **釘選**：展開後標題列有圖釘。釘住後一直顯示完整清單，點戰場、換回合都不會收；釘選狀態記在本機（`trpg.battleLog.pinned`，讀寫包 try/catch）；
  - 取消釘選後，清單先留著，再點圖示或按 Esc 才收起。
- `BattleLog` 只加了 `actions` 欄位（標題列右邊放圖釘），並把 `TONE_MARK` export。
- 右側窄欄（`SidePanel`）不再放紀錄，只剩環境預告。`log` 改成可省略；省略時預告佔滿整欄，收合鈕寫「預告」。

### 1.2 操作說明句：前 3 次之後收進「?」

- 新增 `client/src/battle/opHints.ts`：
  - 次數存在 localStorage 的 `trpg.opHints.v1`，格式是 `{種類: 次數}`；
  - 讀寫都包 try/catch。讀不到、JSON 壞掉、值不是數字，都當作 0 次，照常顯示；寫入失敗就不記；
  - `OP_HINT_LIMIT = 3`。
- 說明句的種類（`OpHintKind`），同一種共用次數：

| 種類 | 句子 | 一次＝ |
|---|---|---|
| `move` | 技能列上方「點選藍色格子移動（N 格），點選紅框敵人攻擊…；右鍵或 Esc 取消選取。」 | 這場戰鬥的一輪 |
| `copy` | 技能列上方「請為複製的技能…或按 Esc 放棄。」 | 這場戰鬥的一輪 |
| `target` | 選取面板「點選格子上的目標（紅框 N 個…）。Esc／右鍵取消。」 | 進入一次選取 |
| `vault` | 「點選紫色格子（攀＝爬上高台…）。Esc／右鍵取消。」 | 同上 |
| `defend` | 「點自己守護自己，或點相鄰的隊友…。Esc／右鍵取消。」 | 同上 |
| `self` | 「對自身施放。」 | 同上 |
| `aside` | 撥開的說明 | 同上 |
| `composite` | 複合技能第 1／2 段的說明 | 同上 |
| `hurl` | 投擲物件、傳送他人、互換的兩段說明 | 同上 |
| `order` | 隊友指令的「…Esc／右鍵取消。」 | 同上 |

- 「等待中……」「戰鬥結束。」「行動點數用完了，但還能調整召喚物…」是狀態句，不算說明句，照常顯示（`actionHintKind()`）。
- 選取面板用 `OpHint`（`client/src/ui/OpHint.tsx`）：
  - 進入選取時決定這次要不要完整顯示，選取中途不會從句子變成「?」；
  - 用元件內的 ref 去重，StrictMode 重跑 effect 也不會多記。
- 技能列上方那一行用 `opHintFullOnce()`：
  - 同一個識別（`battle_id:輪數`）只算一次；
  - 同一輪中途變成「等待中……」再回來，不會多記，也不會變來變去。
- 收起後的「?」用 `PartTip`：滑過出現說明卡（「操作說明／標題／原句」），點一下釘住，觸控點一下開關。

### 1.3 設定：「重新顯示操作說明」

- 戰鬥頂端「版面」彈出面板（目前唯一的設定面板）最下面加了按鈕「重新顯示操作說明」（`OpHintReset`）：
  - 清掉全部次數，並清掉 `opHintFullOnce` 這一頁已經決定過的結果；
  - 按下後顯示「已重設，之後選取時會再顯示 3 次」。

## 4. 待 PM 決定（都已照最保守的做法完成）

1. **「一次」怎麼算**：
   - 選取面板的句子：每進入一次選取（換技能、重新選）算一次；
   - 技能列上方的移動說明：常駐顯示，所以改成「每場戰鬥的每一輪」算一次。照「進入一次就算」的話，一輪內每個動作之後都會算，3 次很快就用完。
2. **哪些算操作說明句**：表格裡的 10 種。狀態句（等待中、戰鬥結束、召喚物還能調整）不收。
   - 兩段選取（投擲物件等）與複合技能第 2 段的句子裡，含有「已選定○○」這類狀態，收起後要滑過「?」才看得到。已選的物件仍可從「重選」按鈕和格子高亮看出來。
3. **右側窄欄只剩預告**：規格只寫紀錄收成左下浮動提示，沒有說窄欄怎麼辦。紀錄移走後，窄欄保留給預告（可以收合）。
4. **800×600 時展開的紀錄會和左上的選取面板疊在一起**：
   - 紀錄最多佔戰場高度的 58%，選取面板疊在上面（z-index 較高），所以不會擋住選取操作；
   - 但兩者都開著時，紀錄上半部會被選取面板蓋住。要不要在選取中自動讓開，請決定。
5. **紀錄的釘選記在本機**，下一場戰鬥、重新整理之後仍是釘住的。規格只寫「釘住就一直顯示」，沒說要不要跨戰鬥保留。
6. **浮動提示用每一行紀錄，不是每一組行動**：一組行動（例如攻擊）的命中、傷害、狀態各算一行，所以一次攻擊可能就佔滿 3 條。
7. **設定的位置**：專案目前唯一的設定面板是戰鬥頂端的「版面」，所以按鈕放那裡。大世界與城鎮畫面沒有設定面板（`WorldScreen.tsx` 不能動）。
8. **精簡小卡的展開方式**：照美術 PM 的結論，滑鼠移到小卡上就展開；觸控沒有滑過，改成點一下開關。精簡版的標題不畫「主角／召喚種類／倒下」標籤與精英徽章，只留名稱。
9. **HP、法力、護盾的說明句放在前端**：伺服器的名詞對照表沒有這三項，限制只能動 `client/`。之後要統一管理文字的話，可以搬進伺服器的對照表。
