# 許願覆蓋表

由 `scripts/wish_coverage.py report` 從 `docs/phases/WC-2資料/buckets.json` 產生（格式 `wish-coverage/3`），不要手改。資料檔不進版控，重產照 `scripts/wish_coverage.py` 開頭的說明（先 `run` 再 `report`）。舊表（WC-1）留在 `docs/phases/許願覆蓋表.md` 對照。

- 標籤：許願池固定清單 41 個（`content/skill_pick.yaml` 的 `wish_tags`；關鍵字＝內容庫的 16 個），配對 820 組。
- 每格：階級 [1, 2, 3, 4] × 稀有度 普通／稀有／史詩；每個（關鍵字或不指定, 種類, 階級, 稀有度）桶用種子 0～39 各跑一次組合器（768 桶）。
- 成功＝做出合法的完整技能，而且這些標籤全部帶到（判定同許願池的 `tag_hits`，關鍵字只看專屬規則）。有關鍵字或種類標籤時照許願池指定給組合器；沒有種類標籤時照主動 70／被動 20／反應 10 加權。
- 被動的骨架至少史詩、反應至少稀有（06 6.12「目前實作」），所以「被動」「反應」在較低稀有度一定是 0。
- WC-2（#167）：願望有元素時另算組合器「換主題元素」的版本，有兩個元素時另算「加第二元素」（2 階起；物理＋元素 1 階起，WC-2b）；效果有召喚時主動另看指定召喚骨架的桶；形態的候選另外放進手寫形態技（有一招全帶到＝100%，每個稀有度欄都一樣）。
- SK-5：效果同時有傷害和治療時，另算打擊、範圍骨架的主動技加上吸血的版本。
- 做不到＝每一格都 0；極低＝最好的一格也不到 2%。
