## 4. 瘦身後的玩法 PM 交接文件骨架（≤ 15 KB）

1. **你的角色與守則**（1 KB）：分工表、4 條守則（已寫入只有使用者能改；改規則行為先問；只 add 自己的檔；回報只放結論）、傳話規則 3 條。
2. **工作流程**（1 KB）：查現況 → 選項表 → 記錄（下一號 #N）→ 使用者「好 寫入」→ 寫 `docs/design/` → 轉開發 PM。
3. **平衡授權**（0.5 KB）：5 條現行規則＋日期，原話見 archive。
4. **現況與待辦**（≤ 5 KB）：只放未結案的事，每列「項目｜現況｜下一步」，結案就刪。
5. **待使用者決定**（≤ 3 KB）：本檔第 6 節的清單，答完就刪。
6. **索引**（0.5 KB）：決定索引檔、archive 檔、設計文件各章在哪。

決定總表與代決表住在 `docs/玩法決定紀錄.md`（新版＝索引＋ #139 起）；原話在 `docs/archive/玩法決定紀錄_#1-#138.md`。
