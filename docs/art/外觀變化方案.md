# 外觀變化方案：同一個種族也長得不一樣（給使用者決定）

美術 PM，2026-11-04 晚。使用者原話（專案 PM 轉達）：「每個種族每個人 都長依樣嗎 有辦法 像其他遊戲 臉型1 臉型2 嗎 或者男女」。

- 樣張：`appearance-vary.png`（`sample/appearance-vary.html`，第 4 節的建角頁可以點）。
- 畫法在 `sample/qDoll.js`，只用 Q 版造型。**不填任何新欄位時，畫面和現在逐像素相同**（已用 `style-compare-3` 整頁比對）。
- **外觀只在畫面上**：不進引擎、不影響任何數值、不影響技能生成。
- 牽涉建角流程和資料欄位，是新功能，要使用者決定。
- **玩法 PM 已看過（11-04 晚）**：資料欄位、API 驗證、建角步驟、快速組合都同意；使用者後來決定不設性別，意見已併入本文。原文在共用筆記「玩法PM-外觀變化意見.md」。

## 現況

- 每個種族只有一組外觀，寫在 `content/races.yaml` 的 `look`。
- 設計文件 09 的 5F-3c 代決寫著「種族沒有可選清單」。玩法 PM 說明：5F-3c 本來就是開發 PM 的代決，還在等使用者確認，所以和本方案沒有衝突，已一起交給使用者。
- 所以同族的每個玩家、每個敵人都長一樣。只有裝備不同。

## 1. 可以選的部位

| 部位 | 選項 | 欄位（建議） |
|---|---|---|
| 臉型 | 圓臉（預設）、蛋臉、方臉、尖下巴 | `face` |
| 眼睛 | 方眼（預設）、圓點、笑眼、大眼 | `eye_style` |
| 睫毛 | 有／無 | `lashes` |
| 眼色 | 6 色 | `eyes`（已有） |
| 髮型 | 短髮、長髮、髮髻、光頭（已有）＋齊肩、馬尾、雙馬尾、刺蝟（新） | `hair`（加 4 個值） |
| 髮色 | 10 色，各族有自己的色票 | `hair_color`（已有） |
| 膚色 | 各族 3～4 色 | `skin`（已有） |
| 鬍子 | 無、鬍渣、八字鬍、山羊鬍、大鬍子 | `beard_style`（`beard: true` 等於大鬍子） |
| 體型 | 標準、纖細、壯碩（疊在種族體型上） | `frame` |

- 所有選項的頭心、大小都一樣，所以種族的耳、角、紋路和頭盔、兜帽照舊對得上。
- 頭盔、兜帽蓋住頭髮的規則照舊。馬尾、雙馬尾從頭盔下露出，兜帽下不露。

### 「粗獷／柔和」快速組合（不設性別）

使用者原話（玩法 PM 轉達）：「算了 先不要有性別 都統一叫名字好了」。所以不存性別，按鈕用中性名稱。

| 按鈕 | 套用 |
|---|---|
| 粗獷 | 體型壯碩、短髮、鬍渣、方眼、無睫毛 |
| 柔和 | 體型纖細、馬尾、大眼、睫毛、無鬍子 |
| 隨機 | 在種族範圍裡抽一組 |
| 種族預設 | 回到該族預設 |

- 按下去只是一次把幾項設好，之後每一項還是可以自己改，不鎖選項。
- **敘事不用性別**（玩法 PM）：說書人對玩家一律稱「你」；戰報、編年史這類需要第三人稱的地方，用角色名字。

## 2. 種族特徵怎麼和選項並存

- **固定不變**（種族特徵）：耳、角、尾巴、獠牙、臉部紋路、鱗、義體半臉、矮人的體型。
- **在種族範圍裡選**：膚色、髮色用各族自己的色票；髮型、鬍子有些族不開放。
- **各族都能選**：臉型、眼睛、睫毛、眼色、體型。

| 種族 | 膚色 | 髮型 | 鬍子 | 備註 |
|---|---|---|---|---|
| 人類 | 4 色 | 全部 | 全部 | |
| 精靈 | 4 色淺膚 | 長、齊肩、馬尾、雙馬尾、髮髻、短 | 無 | 尖耳固定 |
| 狐族 | 3 色 | 短、長、齊肩、馬尾、雙馬尾、刺蝟 | 無 | 獸耳、尾巴跟著髮色 |
| 龍裔 | 3 色 | 短、長、刺蝟、馬尾 | 無、鬍渣、山羊鬍 | 角、龍鱗固定 |
| 矮人 | 3 色 | 短、光頭、髮髻、馬尾、刺蝟 | 預設大鬍子，可選無（全部 5 種） | 矮壯體型固定 |
| 晶能義體人 | 4 色 | 全部 | 無、鬍渣、山羊鬍 | 半臉義體固定 |
| 獸人 | 4 色綠膚 | 短、光頭、刺蝟、馬尾、長 | 無、鬍渣、山羊鬍、大鬍子 | 獠牙固定 |

上表已經玩法 PM 確認，只改矮人一項：原本「一定有鬍子」會和「柔和」的快速組合（無鬍子）衝突，改成預設大鬍子、可以選無。

## 3. 建角時怎麼選

步驟從「名字 → 種族 → 出身」改成「名字 → 種族 → **外觀** → 出身」。

- **左邊**：現在的大紙娃娃預覽，可轉正面、朝東、朝西、背面。
- **右邊**：一排一排點選。順序是種族、臉型、眼睛、髮型、鬍子、體型、膚色、髮色、眼色、睫毛。
- **按鈕**：粗獷、柔和、隨機（在種族範圍裡抽）、種族預設。
- **換種族**：沿用 09 的 5F-5c 規則。新種族也有的選項保留，沒有的改回該族預設。臉型、眼睛、睫毛、體型各族都有，一律保留。
- **種族卡**：仍用種族預設外觀，卡面不變。
- **預設**：不動任何選項就是種族預設，和現在一樣。不想捏臉的玩家可以直接下一步。
- 季末保留外觀（09 已寫「角色名字與外觀保留」），新欄位跟著保留。
- **之後再改**（玩法 PM 建議）：外觀在主城可以隨時免費改；換種族照 #108，花任務幣、每季 1 次。

## 4. NPC 與敵人

**一般敵人**用同一套參數依 id 變化。**具名 NPC（24 位）、頭目、9 名傭兵維持固定外觀，不隨機**（玩法 PM）。做法如下：

- **沒指定外觀時**：用單位 id 的雜湊在種族範圍裡挑（同 6M 的 `seedOf`，FNV-1a）。同一個單位每次都長一樣，每個方向、每場重播也一樣。
- **範本有寫的欄位照範本**：例如頭目的大鬍子、傭兵的髮型，不會被覆蓋。
- **抽的時候先軟性抽「粗獷／柔和」**：再照它挑髮型、鬍子、睫毛、體型，不存性別，不會抽出「睫毛配大鬍子」這種組合。
- **只在前端**：雜湊用單位 id，不碰引擎、不碰亂數狀態，重播的確定性不受影響。
- 樣張第 5 節示範：8 隻同範本的山賊長得都不一樣；頭目每次都同一個樣子。

## 5. 資料欄位（建議，由玩法 PM 定）

- **`DollLook`（後端）**：加 `face`、`eye_style`、`lashes`、`beard_style`、`frame`；`hair` 的 Literal 加 `ponytail`、`twin`、`spiky`、`bob`。全部選填，前端不認得的值當作沒有。
- **`races.yaml`**：每族加 `look_options`，列膚色、髮色、髮型、鬍子可選清單。這會推翻 5F-3c 的「種族沒有可選清單」，要使用者同意。
- **建角 API**：多收一個 `look`，以 pydantic 驗證，並檢查值在該族的 `look_options` 裡。
- **玩家輸入**：只有選項代碼，沒有自由文字，不進 LLM。
