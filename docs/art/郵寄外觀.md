美術 PM，2026-11-04。#136 已寫入（08 8.16、21 21.5：每個城鎮有郵差；主城的交易所第二步才開）。

- 樣張：`mail.png`（`sample/mail.html`）三段：① 三區郵差與郵筒；② 郵寄面板「寄東西」；③ 「收件匣」。

- 全部程式繪製：人物用 C 紙娃娃（`inkDoll`）、頭像用 `portrait.ts`、物品用物品圖示（偷懶自查 G10 移植後）、裝備用 `gearIcon`、面板用共用彈窗（RT-1 區域點綴）。

## 1. 郵差 NPC（三區各一位，系統 NPC）

| 城鎮 | 名字（暫擬，玩法 PM 定） | 外觀 |
|---|---|---|
| 霧渡鎮 | 阿信 | 竹青短外套、皮帽、斜背郵袋 |
| 餘燼集 | 灰鴿 | 鏽橘短外套、皮帽、煤灰、郵袋 |
| 樞島 | 白鷺（精靈） | 藍紫短外套、皮帽、郵袋 |

- 制服同一套，只換區域色：短外套 `coat`（trim 金）、皮帽 `cap`、靴；**郵袋**是新的紙娃娃配件 `mailbag`（米色帆布、斜背帶、黑扣），只畫在郵差身上（`gear.back` 或 NPC 專用配件）。
- 頭像：同一套外觀加 `cap`；荒原加 `soot`。框色照所在城鎮。
- 站在郵筒旁（facility `post`）；**有信時**頭上出現「✉」泡泡（新泡泡圖示 `mail`，做法同任務「！」）。
- 名字與台詞屬內容，由玩法 PM 定；樣張的兩句「寄給誰？對方進城就能領。金幣我抽一成跑腿費，東西不收。」「有你的信。」是示意。

## 2. 郵筒（新物件外觀 `postbox`）

- 方柱、斜頂、投信口、信封牌、腳座；墨線畫法。
- 材質依區域：雲嶺青石帶苔、荒原廢鐵帶鉚釘與鏽痕、主城白石金邊加晶尖。
- 規則同 `low_wall`（擋路、不可破壞）；走到旁邊也能開郵寄面板（和郵差同一個設施）。

## 3. 郵寄面板

共用彈窗（深藍金框、區域點綴），上方郵差頭像與一句話，三個分頁：**寄東西／收件匣 N／退件・過期 N**。

### 3.1 寄東西

| 區 | 內容 |
|---|---|
| 1 寄給誰 | 朋友名單：頭像、名字、所在地、等級；只列朋友，自己帳號的角色不列（8.16） |
| 2 要寄的東西 | 3 格附件（從背包點進來，顯示物品圖示與數量）；下方是背包縮圖列；穿過的裝備、獨特與首殺物品**灰掉**並標「穿過」「獨特」 |
| 3 金幣 | 數字框＋金幣圖示；即時顯示「跑腿費 10%：−N　對方實收 M」 |
| 4 留言 | 一行（40 字） |
| 寄出前檢查 | 對方等級＋2 的裝備上限、對方背包空位、3 級門檻；全過才亮「寄出」；下方小字「14 天內沒領取會退回給你」（天數由玩法定） |

### 3.2 收件匣

- 每封一列：寄件人頭像、名字、寄自哪裡、剩餘天數、留言、附件圖示（含數量）或金幣（已扣稅）；「領取」（背包滿時灰掉並寫原因）、「退回」。
- 退件・過期分頁：同樣式，列出退回來的與過期的。
- 底下一行：「信只能在城鎮的郵差這裡領；N 天沒領會退回寄件人。」

## 4. 移植需求（草案；交易規則照 8.16，由開發 PM 排段）

1. 內容：三區 NPC 檔各加郵差（`portrait` 照第 1 節；`facility: post`）；三張城鎮圖各放一個 `postbox` 物件（`look`）與郵差站位。
2. 前端：`render/inkGear.ts` 加 `mailbag`；`objectArt.ts` 加 `postbox`（三種材質）；泡泡圖示加 `mail`；新面板 `MailPanel.tsx`（三分頁）。
3. 伺服器：郵件的資料與驗證（8.16 的門檻、綁定、稅、退件、過期）是玩法與開發的事，這裡只做畫面。
4. 工作量：外觀 0.25、面板 0.75，約 **1 段**（不含伺服器）。
