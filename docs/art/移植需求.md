## 0. 原則

1. **只動前端繪圖**（`client/src/render/`、`client/src/battle/` 的繪圖資料），不改引擎、事件；仍是 2D 俯視角。
2. **外觀只由資料欄位決定**，對照表各放一處；新內容沒有對照時一律有預設，不得出錯（和 3-12 特效、3-13 對照表同一原則）。
3. **確定性**：紋理變化用「格子座標 → 雜湊種子」，同一格每次畫都一樣；禁止 `Math.random()`。
4. **效能**：地形與物件預先畫成離屏 canvas，再 `Texture.from(canvas)` 當貼圖快取（鍵＝種類＋變體＋鄰格遮罩）；小人依「範本＋裝備組合＋朝向」快取。每格不要每幀重畫 Graphics。
5. 可讀性不能比現在差：陣營色、血條、高亮、預覽、特效、狀態徽章照舊疊在上面。

## 2. 戰場圖層順序（由下往上）

1. 地形底圖（含紋理變體）
2. 高度：越高越亮（沿用 `shadeForHeight` 的規則，但改成疊淡色）
3. 表面（相鄰同種表面連成一片：依四鄰遮罩決定哪邊內縮、哪個角圓角）
4. 陰影：較高的北鄰、西鄰投到本格
5. 崖面：南鄰較低時在本格底部畫 `(高度差 × 5px)` 的立面
6. 極淡格線（`rgba(0,0,0,0.14)`）
7. 既有的光環、持續區域、源泉、陷阱（照舊）
8. 物件（含影子；可燃物右上角小火苗）
9. 高度徽章：只在高度 ＞ 0 時畫「▲N」（取代每格都寫 0）
10. 既有的高亮、預覽
11. 單位：依 y 由上往下排序再畫（下面的人蓋住上面的人），每個單位內部：底圈 → 朝向尖角 → 行動中虛線圈 → 小人 → 代號小標 → 血條 → 既有徽章（炸彈、蓄力、召喚剩餘輪數、倒地）
12. 特效（照舊）

## 4. 單位：紙娃娃小人

### 4.1 圖層（腳底中心為原點，身高約 46px，在 52px 格子裡縮放 1.0，頭會略超出格子上緣）

披風（正面時在身體後）→ 腳（褲子＋鞋）→ 身（含手臂）→ 手（手套或膚色）→ 披風（背面時蓋在身體上）→ 頭（膚色＋臉）→ 頭髮 → 頭部裝備 → 主手 → 副手。背面時武器畫在身體後面。
外框：整個小人畫完後，用剪影往 8 個方向偏 1.3px 塗深色（`#16121a`）當描邊。史詩／傳說另外加紫／金色外光。

### 4.2 朝向

| facing | 畫法 |
|---|---|
| `south` | 正面；主手在畫面左 |
| `north` | 背面：不畫臉，頭髮蓋滿，披風在最上層，主手在畫面右 |
| `east`／`west` | 正面寬度 × 0.9，眼睛往朝向那邊偏，主手在前方 |

底圈外緣另畫一個尖角指向朝向（和現在的箭頭同一個意思）。

### 4.3 裝備欄位 → 圖層

| 欄位（8.10） | 圖層 | 種類（`kind`） |
|---|---|---|
| 主手 | 主手 | `sword`、`greatsword`、`dagger`、`axe`、`bow`、`staff`（錘、長柄、弩待補） |
| 副手 | 副手 | `shield_round`、`shield_kite`、`tome`（雙手武器時空） |
| 頭 | 頭部裝備 | `hood`、`helmet`、`horned_helm`、`wizard_hat`、`bandana`、`crown` |
| 身 | 身＋手臂 | `shirt`、`leather`、`mail`、`plate`、`robe`（`ribs` 給骷髏） |
| 手 | 手 | `gloves`、`gauntlets` |
| 腳 | 腳 | `boots`、`greaves` |
| 項鍊、戒指 ×2 | 不畫 | — |
| （外觀）披風 | 披風 | `cape`；目前不是裝備欄位，可當外觀或身體裝備的附屬 |

每件的顏色：`材質`（布、皮、鐵、鋼、金、木、骨各一組主色／暗色）或指定 `color` → 有元素詞條時混入元素色 45%（例：霜紋鎖甲偏冰藍；法杖寶珠直接用元素色）→ 稀有度史詩、傳說加外光。

### 4.4 紙娃娃要哪些欄位（回答開發 PM 第 1 題）

**結論：3-16b 只需要新增一個欄位 `UnitView.weapon_id`；防具欄位先不加，由前端「外觀表」補。**

| 圖層 | 3-16b 的資料來源 | 之後（有裝備系統時） |
|---|---|---|
| 主手 | **`weapon_id`（新增，只新增欄位）** → 武器外觀表（見下） | 主手裝備 |
| 副手 | 雙手武器（`weapons.yaml` 的 `two_handed`）→ 空；否則外觀表 | 副手裝備 |
| 頭、身、手、腳、披風 | 外觀表，鍵 `template_id` | 頭、身、手、腳裝備（披風可當身體裝備的附屬） |
| 膚色、髮型、髮色、褲色 | 外觀表，鍵 `template_id` | 角色建立時決定 |
| 項鍊、戒指 ×2 | 不畫 | 不畫 |

**武器外觀表**（`weapons.yaml` 的 id → 紙娃娃的主手 kind；元素取 `weapons.yaml` 的 `element`，非 physical 時套元素色，法杖寶珠直接用元素色）：

| `weapon_id` | kind | 退回規則 |
|---|---|---|
| `one_handed_sword` | `sword` | — |
| `greatsword` | `greatsword` | — |
| `dagger` | `dagger` | — |
| `bow` | `bow` | — |
| `fire_staff`、`lightning_staff`、`frost_staff` | `staff`（＋元素） | — |
| 未知 id | 依 `weapon_class`：`melee` → `sword`、`ranged` → `bow`、`focus` → `staff` | 連 class 都沒有 → `sword` |

前端拿不到 `weapon_class` 的話，`weapon_id` 未知時一律 `sword`；或把 `weapon_class` 一起放進 `UnitView`（也只是新增欄位）。

**外觀表**（建議放前端 `render/appearance.ts`，鍵 `template_id`；樣張 `paperdoll.js` 的 `TEMPLATES` 已有 8 個範本可直接照抄）：每筆 = `look`（膚色、髮型 `short|long|none`、髮色、褲色）＋ `gear`（`head`、`body`、`hands`、`feet`、`cloak`、`off_hand`，每件 `{kind, material, color?, element?}`）＋ `rarity?`（頭目用 `epic` 外光）。

**退回規則**（永遠畫得出來）：

1. `template_id` 不在外觀表 → 依陣營用預設外觀：我方 = 布衣＋靴、敵方 = 皮甲＋頭巾＋靴；主手仍依 `weapon_id`。
2. 召喚物（`summon_*`）不在表內 → 骷髏身形（`body.kind = ribs`、`look.skull = true`）。
3. 某欄位的 `kind` 不認得 → 該欄位不畫（不是整個小人不畫）。
4. `material` 不認得 → 布料色；`element` 不認得 → 不套元素色。

**以後（不在 3-16）**：英雄裝備系統上線時，每件裝備加外觀欄位 `appearance: {kind, material, color?}`（`element`、`rarity` 直接用裝備本身的），LLM 生成裝備時一併選 `kind`／`material`（從固定清單選，經 pydantic 驗證）。屆時 `UnitView` 再加 `equipment` 外觀摘要，外觀表退為敵人與預設用。

## 5. 技能圖示（`icons.html`）

### 5.1 技能卡需要的欄位（回答開發 PM 第 2 題）

| 欄位 | 現況 | 需要做的 | 用途 |
|---|---|---|---|
| `skeleton` | 已有，是骨架 id（`strike`、`aura`…） | 不用改（若要改名 `skeleton_id` 也可） | 右下徽章 |
| `rarity_id` | 已有 | 不用改 | 外框顏色 |
| `shape_id` | **沒有**；`shape` 是中文句子，`vfx.ts` 的 `shapeIdOf` 用中文名反查 | **新增**（`skill_shapes.yaml` 的 id；3E-2 本來就要加）。3-16 若不想動 API，可沿用 `shapeIdOf`，但新形狀要記得補中文對照 | 中央主圖 |
| `element` | **沒有**；3-12 特效是在戰鬥事件裡才知道元素 | **新增** `element: str \| null`：後端依「第一個帶 `element` 的效果 → 否則 `tags` 中的元素 → 否則 null」推導；null 代表無元素（支援、位移類），畫紫色預設 | 底色、紋理、左上標誌 |
| `range` | **沒有**；射程在 `shape` 句子裡 | **新增** `range: int \| null`（武器射程為 `null`） | 單體技能分遠程（≥ 2）／近戰 |
| `weapon_req_id` | 已有 | 不用改 | `range` 為 null 時：`ranged` → 遠程，其他 → 近戰 |

上表三個新增欄位（`shape_id`、`element`、`range`）都只是在 `SkillCard` 加欄位，不改引擎。工坊、升級候選、技能列都用同一個 `SkillCard`，所以一次就夠。

### 5.2 規則

- 輸入：見 5.1。
- 圖層：① 元素底色漸層＋淡紋理 ② 形狀主圖 ③ 左上元素標誌 ④ 右下骨架徽章（外框用稀有度色）⑤ 稀有度外框（史詩、傳說雙框）。
- 形狀主圖：遠程單體＝飛行物、近戰單體＝揮砍月牙、單體增益（`aura`）＝目標身影＋上升箭頭、直線＝光束、錐形＝扇形、方陣／十字／環形＝九宮格、連鎖＝三節點閃電線、指定格＝地面圈（召喚＝升起的身影、陷阱＝夾子）、自身＝光環＋身影、友軍範圍＝圓頂＋三人、物件→格＝丟箱弧線、單位對＝兩人＋交換箭頭。
- 退回：未知元素＝紫色六角（`DEFAULT_VFX` 色）；未知形狀＝自身光環；未知骨架＝空心圓徽章。
- 用處：技能列（40px）、技能卡、工坊、反應面板；28px 仍可辨識。
- 快取：鍵＝`元素|形狀|遠近|骨架|稀有度`，同組合共用一張貼圖（不是每個技能一張）。
