## 3. 「前 → 後」四種記號（提案第 2 節表、第 6 節第 2 條）

每列（`.fc-diffs`，grid `16px max-content max-content 14px 1fr`、間距 3/6、13px）：欄位小圖 16＋欄位名（L2）＋「前」（L3）＋金色「→」＋「後」。「後」四種樣式，**不靠顏色也分得開**：

| `direction` | 樣式 | CSS（樣張 `flashChoice.css` 80～93 行） | 例 |
|---|---|---|---|
| `better` 變好 | 實心淡金底塊、亮金粗字，**沒有框** | `color: var(--ui-gold-hi); background: rgb(232 196 106 / 22%); font-weight: 700; padding: 0 7px; border-radius: 4px; line-height: 21px` | 射程 4 格 → **5 格** |
| `cost` 代價 | **沒有底**，琥珀細實線框，前面第⑦批 HUD 警告三角 13px（`WarnGlyph`），琥珀粗字 | `color: var(--ip-warn); background: none; outline: 1px solid rgb(232 180 90 / 80%); outline-offset: -1px; padding-left: 4px; gap: 4px` | 冷卻 2 回合 → ⚠ **4 回合** |
| `worse` 變弱 | 沒有底也沒有框，**主文字色**、一般字重，前面一個 CSS 向下三角（和 13px 警告三角同高） | `color: var(--ui-text); background: none; font-weight: 400`；三角 `width: 0; height: 0; border-left/right: 6.5px solid transparent; border-top: 11px solid currentColor` | 燃燒 5 回合 → ▼ 3 回合 |
| `new` 新加的 | 只用在「前」是「沒有」（`before` 為 `null`）時：「後」前面一顆實心綠「新」（10.5px、`background: var(--ip-good)`、字 `#12261a`、膠囊），底照變好 | `.fc-newtag` | 地面 沒有 → 新 **積水** |

- **框一律用 `outline`**（`outline-offset: -1px`），不用 `border`：加框不增加列高，800 那組才放得下（提案 4.8 第 2 版）。
- 前面有值的換掉（例：種類 主動 → 被動）**不掛「新」**，照 `better`。
- 「變弱」不是「代價」：不要用琥珀、不要加警告三角、不加「變小」兩字。
- 樣張的第五種「待資料」（虛線框＋斜紋小標）**只在樣張，不移植**。
- 一個選項可以同時有 `better` 與 `worse`（一升一降），一列一項各自上樣式（`true1x-rows-opt2-800-x4.png`）。
- 色盲與灰階證明：`marks.jpg`、`true1x-marks-x4.png`（一般、紅色弱、綠色弱、藍色弱、灰階五欄）。

## 4. 選中與都沒選

- **選中**：整張卡 `border-color: var(--ui-gold-hi)`、底 `rgb(232 196 106 / 8%)`、內陰影 `0 0 0 1px rgb(232 196 106 / 25%) inset`；單選圈填滿亮金；大標變亮金。**卡本身不變大**（說明在下固定區）。描框只表示狀態（資訊面板 3.1 第 3 條）。
- 卡的邊框平常是 `1px solid transparent`（選中時不跳 1px）。
- 點整張卡選中；鍵盤可聚焦（`role="radio"`／`aria-checked`，清單 `role="radiogroup"`，方向鍵切換由開發定）。
- 換選另一張時，卸下選單的選擇清掉（同現行 `setUnequip(null)`）。
- **都沒選**：所有卡不描框、單選圈空心；下固定區見 2.3。
- 截圖：`picks-1600.jpg`、`picks-800.jpg`（四個各自選中，分隔線同一高度）、`new-*.jpg`（都沒選）。

## 5. 面板高度與捲動（提案第 6 節第 4 條；資訊面板 11.4 第 8 條）

1. **下固定區給固定的最小高度**：窄版約 57、寬版約 74；有卸下選單時窄版約 83、寬版約 91。面板高＝「都沒選」量一次＋這個高度，不超過 `popupBox` 的 `maxHeight`。點哪個都不跳框、分隔線不動（結果和樣張「五種狀態輪流量取最高」一樣，少一套量測）。
2. 放不下時**只有選項區**在面板內捲；上下固定區不動。上下緣用現行漸隱（`PopupFrame` 的 `markOverflow`／`data-end`）。
3. **選中的那張要整張看得到**：`scrollIntoView({ block: "nearest" })`，**再多留約 20px**（`scroll-margin-bottom: 20px` 或捲完再捲 20），讓卡的下框露出下緣 32px 的漸隱色塊；捲得到底就直接捲到底（`data-end` 收掉漸隱）。內容沒超出時不要捲（樣張第一次踩到：會把清單捲走一截）。
4. 漸隱帶要貼齊捲動區底，不要在漸隱帶下面、分隔線上面再露出一截卡片（提案 11.4 第 6 條提到直向 `stress-800.jpg` 也有約 10px）。
5. 量到的數（樣張，頁面自己量；框下小字）：

| 情況 | 1600（面板 720×700） | 800×600（面板 493×414） |
|---|---|---|
| 使用者截圖那組（base） | 面板 535，可視 294／內容 282，一屏 | 面板 414，可視 238／內容 232，一屏 |
| rows（多列＋變弱） | 一屏（631） | 238／316＝1.33 屏 |
| wrap（大標兩行） | 一屏（600） | 238／331＝1.39 屏 |
| transform（第 3 次＋卸下選單） | 一屏（696，只差 4） | 212／358＝1.69 屏（下固定區 83） |

   壓力情況是示意資料；`changes` 實際出來後列數可能不同，驗收用真資料再量（第 11 節）。
6. **一輪（roguelite）**：`RunFlashPending` 不在 `PopupFrame` 裡（`RunScreen.tsx` 直接放在 `run-main`），頁面本身會捲。三段的版面照做；下固定區用 `position: sticky; bottom: 0`（或開發另定），讓「確定」不用捲到最下面。高度上限、選項區內捲只套在大世界的 HUD 面板。
