## 2. 動畫清單

工作量的單位是「段」，以程式骨架動畫（第 3 節 1-A）為準。

### 2.1 骨架紙娃娃（所有角色動畫的基礎，先做）

**用的就是遊戲現在的 C 畫風紙娃娃**（client 的 `inkDoll`；樣張用同一套畫法的 `storyDoll.js`）。部件、裝備、種族、配色全部照舊，不另外畫人偶。

**現有紙娃娃能不能直接掛骨架？可以，大部分不用重畫。** 第二版樣張就是這樣做的：每個部件的畫法完全不動，只在關節外面包一層旋轉（`storyDoll.setPose`，沒設姿勢時畫出來和原本一模一樣）。逐項評估：

| 部位 | 現況 | 要改什麼 |
|---|---|---|
| 腿（側面） | 已經分成「大腿＋小腿靴」兩塊 | 不用改，直接當髖、膝兩個關節 |
| 腿（正面、背面） | 左右各一塊 | 不用改；走路用上下位移表示抬腳 |
| 身體、頭、頭髮、帽子、耳朵、角、披風、尾巴 | 一起畫在身體座標上 | 不用改；整組以髖為軸前傾，加上起伏 |
| 主手手臂（側面） | 一塊（肩到手） | 樣張直接繞肩轉，夠用；**要加手肘**的話，拆成上臂和前臂兩塊，約 0.25 段 |
| 另一隻手（側面） | 側面沒有畫 | 拉弓、雙手武器要用，**要新增一塊**，約 0.25 段 |
| 主手手臂（正面、背面） | 一塊 | 走路上下擺夠用；正面、背面的出招姿勢要另外做（約 0.5 段） |
| 武器 | 每種武器各有固定的傾斜角度 | **要統一成「握把在原點、作用端朝同一個方向」**，角度交給姿勢決定；client 現有的武器種類要逐一改，並補上缺的種類，約 0.75 段 |
| 形態、異形敵人 | 另一套畫法 | 異形另外做 4 個通用片段：走、撲、受擊、倒下；用身體的伸縮和傾斜做，不拆關節 |

**武器的朝向規則**（第一版的錯：劍柄朝外、槍口朝後）：
- 每種武器一律「握把在手、作用端朝攻擊方向」。作用端是刃尖、槍口、杖頭，弓則是箭的方向。
- 樣張頁首有**自測**：13 種武器在朝東、朝西出招的瞬間，作用端都要在手的前方；正面、背面要握在柄上。第二版全部通過。
  - 13 種武器：劍、刀、魔導劍、成對武器、槍（長兵）、鐮、鞭、拳套、法杖、法球、弓、弩、火槍。
- 正式版把這個自測寫成 client 的單元測試，每次新增武器種類就自動檢查。

**工作量**：從原本估的 2 段調成約 **2.5 段**。
- 關節鉤子：0.5；
- 手肘與另一隻手：0.5；
- 武器規則統一與補種類：0.75；
- 正面、背面的出招姿勢：0.5；
- 異形 4 個片段：0.25（原本另列的 0.5 併進來）。

### 2.3 技能：照技能結構把片段串起來（LLM 不參與）

**原則（使用者原話）**：「照技能骨架怎麼搞就怎麼顯示吧 砍+跳 跟跳+砍 就只差在撥放順序不同啊 不用給llm館阿」
- 技能動畫**完全由引擎決定**：照技能的結構（骨架、原語、效果的順序）和實際發生的事件，把小片段一個個串起來播。
- LLM 不選動畫，也**不新增任何動畫欄位**。
- 任何技能都能播：手做的、工坊組的、LLM 生成的都一樣。

#### (1) 片段從哪裡來

一個技能的動畫是三層疊起來的：
- 起手（施放者的身體動作）；
- 效果（施放者身上的動作，加上特效）；
- 結果（目標身上的反應）。

| 層 | 由哪個欄位決定 | 對應的片段 |
|---|---|---|
| 起手 | **武器種類 × 施放方式**（見下面的起手對照表） | 例：劍＋近身接觸＝蓄力→揮砍；法杖＋飛行物＝詠唱→杖頭射出；魔導劍＋飛行物＝劍指畫符（或揮劍斬出）→劍尖射出 |
| 起手（覆蓋） | 技能有**蓄力、延遲**（`timing`、`activation`） | 詠唱或蓄力加長；延遲技能先播「標記」，到時候再播效果 |
| 效果 | **原語**（`skill_primitives.yaml`，依技能卡上的順序） | 見下表 |
| 結果 | **事件**（引擎回傳的 `steps`） | 受擊、閃避、格擋、倒下、狀態上身（第 2.4 節） |

原語對應的片段：

| 原語 | 施放者的片段 | 特效 |
|---|---|---|
| `damage`、`damage_multiplier`、`delayed_damage` | 用起手決定的出招片段（揮、刺、射、施放） | 由形狀決定，見下面第 (3) 點 |
| `heal`、`shield`、`cleanse`、`revive`、`restore_resource` | 手掌朝目標或舉向天空 | 目標身上往上飄的光點；護盾是一圈罩子 |
| `apply_status`（增益） | 舉手 | 目標腳下一圈光環往上收 |
| `apply_status`（減益）、`dispel`、`steal_buff` | 指向目標 | 目標身上一道狀態色的光 |
| `dash`、`charge_through` | 衝刺：前傾，有殘影 | 路徑上的風線 |
| `leap` | 跳躍：縮腿、拋物線 | 落地揚塵 |
| `teleport`、`shadowstep`、`swap`、`teleport_target`、`swap_any` | 原地淡出，在新格淡入（沿用現有的扭曲特效） | 起點和終點各一個扭曲圈 |
| `push`、`pull`、`knock_prone`、`shockwave` | 推掌或拉的手勢 | 目標播「被推、被拉」（2.2）；倒地播「倒下」 |
| `summon`、`sacrifice_summon` | 雙手往下按 | 地面法陣，召喚物從裡面升起 |
| `create_surface`、`zone`、`blow_surface`、`clear_surface` | 揮手灑出去 | 地表從中心擴散開（2.6） |
| `create_obstacle`、`raise_terrain`、`lower_terrain`、`topple`、`hurl_object` | 跺地或舉起 | 沿用現有的升降補間；被丟的物件走拋物線 |
| `place_trap`、`inscribe`、`detonate_runes` | 蹲下放置，或在空中畫符 | 陷阱、符文出現；引爆時是爆發 |
| `enter_form`、`leave_form` | 變身：一圈光收進身體 | 形態外觀淡入（3J-5） |
| 其他：`refund_ap`、`grant_ap`、`reset_cooldown`、`gamble`、`copy_skill`、`rule_change`、`add_stack`、`consume_stack`、`consume_status` 等 | 沒有身體動作 | 頭上一個小圖示彈一下，沿用浮動字樣 |

#### (1-1) 起手對照表：武器種類 × 施放方式

使用者問：「拿法杖 丟火球跟 魔島劍要依樣嗎」。答案是**特效一樣、起手不一樣**：
- 火球本身、爆炸只由元素和形狀決定，拿什麼武器都一樣；
- 起手由「武器種類 × 施放方式」決定；
- 技能的出發點是武器的作用端：杖頭、劍尖、槍口。

**施放方式**由技能卡上的形狀和射程自動判斷，不新增欄位：

| 施放方式 | 判斷依據（形狀 `shape_id`、射程） |
|---|---|
| 近身接觸 | 單體、錐形、十字等形狀，射程 1 |
| 飛行物、遠程 | 單體、直線、連鎖，射程 2 以上 |
| 自身、範圍 | 自身、周圍、環、己方範圍 |
| 地面 | 指定地格、方陣（以格子為中心） |

**對照表**（「蓄力→揮砍」這類寫法表示片段的順序）：

| 武器種類 | 近身接觸 | 飛行物、遠程 | 自身、範圍 | 地面 |
|---|---|---|---|---|
| 劍、刀 | 蓄力→揮砍（3 種變體） | 劍往前一指→手掌放出（非法系武器放法術） | 劍舉起→身上光環 | 劍尖點地→地面擴散 |
| 魔導劍 | 蓄力→揮砍 | **選項 A：劍指畫符→劍尖射出**／**選項 B：蓄力→揮劍斬出（劍揮到前方時放出）** | 劍舉起、符文發光→光環 | 劍插地→符文擴散 |
| 成對武器 | 交叉蓄力→雙刃連斬 | 雙刃交叉一指→手掌放出 | 雙刃交叉在胸前→光環 | 雙刃點地→擴散 |
| 槍（長兵） | 收→突刺 | 槍尖往前一指→槍尖射出 | 槍立地→光環 | 槍尾頓地→擴散 |
| 鐮 | 蓄力→橫掃 | 鐮刃一揮→刃尖射出 | 鐮刃上舉→光環 | 鐮刃劃地→擴散 |
| 鞭 | 收→甩鞭 | 甩鞭→鞭梢射出 | 鞭在身邊繞一圈→光環 | 鞭打地面→擴散 |
| 拳套 | 收→出拳 | 出拳→拳頭射出（氣功） | 雙拳相擊→光環 | 拳擊地面→擴散 |
| 法杖 | 杖頭一敲 | 詠唱（腳下法陣）→杖頭射出 | 杖舉高→光環 | 杖頓地→法陣擴散 |
| 法球 | 法球一推 | 詠唱→法球射出 | 法球舉高→光環 | 法球往下壓→擴散 |
| 弓 | 弓臂一撞 | 拉弓→放箭（法術技能：箭帶元素） | 弓舉高→光環 | 朝天拋射→落點擴散 |
| 弩 | 弩托一撞 | 舉起瞄準→擊發 | 弩舉高→光環 | 朝地面射→擴散 |
| 火槍 | 槍托一撞 | 舉起瞄準→擊發（後座、槍口火光） | 槍舉高→光環 | 朝地面射→擴散 |
| 空手、不認得的武器 | 收→出拳 | 結印→手掌射出 | 雙手合十→光環 | 手掌按地→擴散 |

規則：
- 起手只看武器種類和施放方式，**不看技能是物理還是法術**；
- 元素只換特效顏色；
- 對照表沒有的組合，退回「空手」那一列。
- 魔導劍的選項 A、B 是第 3 節第 6 題，等使用者選。樣張第 8 區把「法杖火球」「魔導劍 A」「魔導劍 B」並排。

#### (2) 片段怎麼串

1. **照技能卡上部件的順序依序播**。這個順序就是組裝算式的段落和接續（3-18 已有）。
   - 「砍＋跳」＝起手 → 揮砍 → 跳躍；「跳＋砍」＝跳躍 → 起手 → 揮砍。片段完全一樣，只差順序（樣張第 5 區）。
2. **方向和距離由事件決定，不由片段決定**：跳去哪一格、衝到哪裡、推多遠，都讀引擎回傳的落點。所以同一個「跳躍」片段，可以往前跳近，也可以往後跳開。
3. **同時發生的效果**：
   - 一次揮砍打到 3 個人：3 個目標**同時**播受擊。
   - 一招同時有傷害和燃燒：命中那一刻疊「爆發」和「燃燒上身」，不排隊。
   - 規則：同一個事件時間點的結果並排播；施放者身上的片段一次只播一個。
4. **連鎖、反應、反擊**：接在原技能後面，加一個 0.15 秒的停頓，讓人看得出是另一個動作。
5. **起手只播一次**：一招有很多段時，只有第一段播起手。後面的段落如果是同類的出招，就省略蓄力，直接出招。
6. **時間**：每個片段有自己的基本長度（樣張裡是 200～520 毫秒），全部乘上播放速度（沿用 `playback.ts`）。跳過時直接顯示結果。

#### (3) 元素和形狀決定特效

沿用 3-12 的做法，不用改：
- **元素** → 顏色和粒子：火是橘黃火星，冰是青白冰晶，雷是紫黃電弧，物理是白色……（`vfxPalette`）。
- **形狀** → 特效的種類和範圍：
  - 單體近戰：揮砍弧；
  - 單體遠程：飛行物；
  - 直線：光束；
  - 錐形：扇形；
  - 十字、方陣：範圍逐格爆發；
  - 環、周圍：向外的環；
  - 自身：身上的光。
- **起手片段決定「從哪裡發出」**：揮砍弧從武器揮過的路線畫；飛行物從弓、槍口、法杖頭射出。這是骨架動畫才有的新東西，現在都從格子中心發出。

### 2.4 受擊、閃避、格擋、倒下、勝利

| 動畫 | 做法 | 工作量 |
|---|---|---|
| 受擊 | 白閃（約 0.1 秒）、後仰、退半步再回來（樣張第 3 區）；重擊時多一點震動 | 0.1 |

### 2.9 特殊結果的專屬動畫（暴擊、致命一擊、擊殺、格擋成功）

觸發的依據都是**引擎事件上已有的結果**，例如傷害事件的暴擊旗標、目標 HP 歸零、格擋成功。動畫只讀這些結果，不影響結果。

| 結果 | 強化的內容（推薦組合） |
|---|---|
| 暴擊 | 命中前約 0.14 秒放慢到 0.3 倍，命中瞬間停頓約 0.1 秒（hit-stop），畫面震動，弧光加粗變金色，傷害數字放大寫「暴擊」，畫面閃白一下（樣張第 6 區右邊） |
| 致命一擊、擊殺 | 暴擊的全部，加上目標倒下時慢動作，鏡頭往目標稍微拉近再拉回；同一輪只播一次，避免拖慢 |
| 格擋成功 | 停頓 0.06 秒，盾或劍上迸出大火花，「格擋」字樣，攻擊者被彈開半步 |
| 閃避成功 | 殘影多一層，「閃避」字樣 |
| Boss 的大招 | 預告一輪（現有），施放時畫面四周變暗 0.3 秒 |

強化程度給選項（第 3 節第 4 題）：
- 只加特效；
- 特效加停頓；
- 特效加停頓、慢動作和鏡頭。

### 2.10 動作變體（同一個片段有幾種樣子）

1. **每個片段準備幾種變體，播放時挑一種**。例如揮砍有三種：由上往下、由下往上、橫掃（樣張第 6 區）。
2. **變體只影響畫面**：關節角度、弧光的方向和形狀會不同；命中時間點、傷害、範圍、規則一律不變。不同變體的「命中那一刻」要對齊，所以每種變體的 `hitAt` 都一樣，或由串接器對齊。
3. **確定性**：
   - 挑變體不用 `Math.random()`；
   - 公式是：變體＝雜湊（`戰鬥 ID:事件序號:施放者 ID:anim`）÷ 變體數，取餘數；
   - 雜湊用 client `render/inkStyle.ts` 的 `seedOf`（FNV-1a），和墨線抖動是同一套做法；
   - 所以同一場戰鬥的同一個事件，重播、觀戰、重新整理之後看到的都是同一個變體。樣張頁面底下列出了 8 次連續揮砍挑到的變體。
4. **探索與待機**（沒有戰鬥 ID 的時候）：鍵改成「地圖 ID:單位 ID:動作序號」。
5. **建議的變體數**：

| 片段 | 變體數 | 例子 |
|---|---|---|
| 揮砍（刀、劍、斧） | 3 | 由上往下、由下往上、橫掃 |
| 突刺（矛） | 2 | 直刺、下段刺 |
| 出拳 | 2 | 直拳、勾拳 |
| 射擊（弓） | 2 | 站射、半蹲射 |
| 射擊（槍） | 2 | 單手、雙手 |
| 施法 | 2 | 杖指向前方、杖朝天再揮下 |
| 受擊 | 2 | 後仰、側彎 |
| 待機的小動作（NPC） | 3～4 | 轉頭、伸懶腰、職業動作 |
| 其他（位移、治療、召喚、走路……） | 1 | 不做變體，避免讀錯 |

6. **工作量**：
   - 變體只是多寫幾組關節曲線，不用新素材；
   - 9 類片段約多 12 個變體，約 **0.75 段**；
   - 暴擊、擊殺、格擋這類強化約 **0.5 段**（時間扭曲、停頓、震動、鏡頭）。

## 3. 選項（等使用者選）

### 1. 畫法

| | 做法 | 好處 | 壞處 |
|---|---|---|---|
| **A. 程式骨架動畫（推薦）** | 紙娃娃拆成關節，用程式算角度（樣張就是這種） | 換裝、換武器、換種族、LLM 技能全部自動適用；確定性；和現在的 C 墨線畫風一致；不用額外素材 | 動作比較「木偶感」，細膩度靠調曲線 |
| B. 逐格手繪 | 每個動作畫 4～8 張圖 | 動作最自然、最有個性 | 每種裝備、每個種族、每個方向都要重畫，數量會爆炸；LLM 生成的組合無法事先畫好；現在只能用程式繪製，不能下載素材 |
| C. 混合 | 角色用骨架；特效、爆炸、魔法陣這類用逐格或粒子 | 特效可以更華麗 | 兩套系統，要多維護一套 |

## 5. 樣張裡有什麼（`anim.html`，第二版）

0. 頁首的自測表：13 種武器 × 朝東、朝西、正面、背面。
1. 走路四方向，加跑步、潛行。
2. 上樓梯。
3. 受擊：白閃、後仰、退半步、傷害數字。
4. 技能：
   - 揮砍（劍）；
   - 射擊（弓）、射擊（火槍）；
   - 施法（法杖，火）。
   - 另有一格畫出 13 種武器的命中瞬間，朝東、朝西各一排，黃色虛線是手到作用端。
5. 同樣的片段、不同的順序：
   - 「砍＋跳」：先砍，再往後跳開；
   - 「跳＋砍」：先跳近，再砍；
   - 「衝刺＋砍」：換成冰元素，揮砍弧變青白色。
6. 揮砍的 3 種變體（由上往下、由下往上、橫掃）和暴擊版，以及確定性挑變體的例子。
7. 同一個火球，不同的武器：法杖、魔導劍選項 A（劍指畫符）、魔導劍選項 B（揮劍斬出）。

人物就是遊戲的 C 畫風紙娃娃。樣張是在 `storyDoll.js` 加上姿勢鉤子，正式版要在 client 的 `inkDoll` 做同樣的事（第 2.1 節）。
