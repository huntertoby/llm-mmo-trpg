## 使用者決定（2026-10-24）：採用 A 真側面 90°

> 使用者原話：「A」。

## 為什麼現在的側面不像側面

紙娃娃只有「正面」與「背面」兩套畫法。側面＝正面整張**左右壓窄 10%**，再把眼睛往前移一點、把主手副手對調：

- 身體、雙手、雙腳仍然左右對稱地擺著（兩隻手一左一右、兩隻腳並排），沒有前後之分；
- 臉沒有轉向：兩隻眼睛都在、沒有鼻子、耳朵位置不變；
- 盾牌、帽子、披風都還是正面的形狀。

所以看起來像「瘦一點的正面」。

## 4 種新畫法（每種：人類、角魔、狐族、龍裔 × 兩套裝備，附戰場實際大小）

| 畫法 | 樣子 | 紙娃娃結構要改多少 | 裝備層 | 移植 |
|---|---|---|---|---|
| A 真側面 90° | 身體、臉都轉 90 度；鼻子突出、只看到一隻眼、兩腳前後重疊、盾牌變成側邊 | 側面變成第三套畫法：每個部件（身、腳、手、頭、頭髮）都要有側面版 | **全部要畫側面版**（約 60 種裝備造型 × 形制）＋種族部件側面版 | 約 2～3 段 |
| **B 3/4 斜側面（建議）** | 轉一半：看得到身體側面的厚度（背側暗面）、兩隻眼睛一大一小、鼻子微露、手腳前後錯開 | 用「轉向程度」把正面畫法的位置往前移、加暗面，大多數部件**沿用正面畫法加位移** | 多數沿用；頭盔、兜帽、盾牌、披風要加位移規則，少數（巫師帽、寬帽）微調 | 約 1～1.5 段 |
| C 側身＋臉朝鏡頭 | 身體 90 度、臉只轉一半（兩眼都在），表情讀得清楚 | 身體同 A（要側面版），頭同 B | 身體層同 A 要重畫，頭部裝備同 B | 約 2 段 |
| D 步行側面 | A 加跨步（兩腳張開、雙手前後擺）；移動時用 | 同 A，再加走路的姿勢與動畫幀 | 同 A，另要動畫 | 約 2.5～3.5 段（含走路動畫） |

## 對其他東西的影響

| 項目 | 影響 |
|---|---|
| 10 個種族 | 耳、角、尾都要有側面位置：B 用同一套位移規則即可；A、C、D 要各畫側面版 |
| 形態（變身 10 種） | 本來就是真正的側面畫法，**不受影響**；選 B 時人形和形態的側面一致性最好（形態是側身、人是 3/4，玩家能接受） |
| 召喚物 | 野獸、靈、構造體本來就是側面畫法，不受影響；人形召喚物（骷髏、影魅、守護靈）用紙娃娃，自動跟著新側面 |
| 敵人 | 都用紙娃娃，自動跟著新側面 |
| 裝備圖示 | 不受影響（圖示是單獨畫的） |

## 建議

**B 3/4 斜側面**：看得出是側面，又保留臉（兩隻眼睛），成本最低，而且多數裝備不用重畫。之後若要走路動畫，可以在 B 上加「跨步」（D 的做法），另排一段。

樣張的限制：`sideArt.js` 只支援樣張用到的裝備（板甲、皮甲、長袍、布衣、頭盔、兜帽、劍、弓、法杖、圓盾、披風）與三族部件，正式版要涵蓋全部裝備。

## 移植需求（A 真側面）

側面變成紙娃娃的第三套畫法（正面、背面、側面），朝西＝側面左右鏡像。

| 項目 | 側面版的畫法（照 `sample/sideArt.js`） |
|---|---|
| 圖層順序（面向右） | 披風 → 尾巴、背刺 → 遠側腿 → 近側腿 → 遠側手臂 → 身體 → 副手（盾在身前，側邊） → 頭 → 臉部紋路 → 頭髮 → 頭部裝備 → 種族頭部部件（耳、角）→ 近側手臂 → 主手武器 |
| 身體 | 寬度 15 → 10、背側加暗面；前襟、腰扣、胸甲亮片移到前緣 |
| 腿、腳 | 兩腿前後錯開（遠側較暗），鞋尖朝前 |
| 手臂 | 遠側手臂藏在身後、只露一點；近側手臂在身前持主手武器 |
| 頭 | 臉往前移 4.2：一隻眼、鼻子突出、耳朵在頭中後方；頭髮包住後腦 |
| 頭部裝備 | 每種都要側面版：頭盔護鼻片移到前方、兜帽開口往前變窄、巫師帽與寬帽朝前傾…（10 種 kind） |
| 盾 | 變成擋在身前的窄橢圓（側邊） |
| 披風 | 從背後垂下、往後飄 |
| 武器 | 主手武器斜向前；弓在身前；雙手武器、槍等每種 kind 要側面角度 |
| 種族部件 | 見上一節 |

建議分 3 段：① 骨架（身體、腿、手、頭、頭髮、圖層順序）＋側面鏡像；② 頭部裝備、盾、披風；③ 武器各 kind＋種族部件。合計約 2～3 段。召喚物的人形、敵人自動跟著改。
