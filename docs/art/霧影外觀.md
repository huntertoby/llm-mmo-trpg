# 霧影（summon_mist_shade）外觀移植需求

美術 PM，2026-11-03。起因：5F-1b 新增「霧影」，是霧中劍客（`sect_mist_swordsman`）開場召出的分身，HP 6、招式和本體相同。目前霧影沿用殘影（`afterimage`）的畫法：召喚者的紙娃娃、50% 不透明、藍色調、藍色外光。

## 結論

要另外做，不過只是小改。分身仍然是本體的紙娃娃，只換合成方式，不用畫新圖。

殘影畫法不適合霧影，原因有三：

1. **藍色外光違反敵人規則**：「外光只代表頭目」（`敵人外觀.md` 第 1 節）。霧中劍客是懸賞精英，它的分身不該發光，否則玩家會以為分身比本體強。
2. **藍色調是玩家殘影技能的顏色**：敵方分身也用同一個顏色，玩家會分不清是誰的東西。
3. **辨識**：玩家要一眼分出本體（HP 30）和分身（HP 6），才能決定先打哪一個。本體帶「霧隱的」詞綴，本身就有 75% 不透明，和殘影的 50% 太接近。

## 規格（`client/src/render/summonArt.ts`）

1. 人形加一個款式 `mist_shade`：`VARIANTS.humanoid` 加入 `"mist_shade"`。
2. 畫法和殘影相同：用召喚者的紙娃娃（`owner ?? skeleton`），快取鍵也帶召喚者外觀。`summonKey` 和 `artTextures.ts` 裡 `look.variant === "afterimage"` 的判斷，改成「afterimage 或 mist_shade」。
3. `HUMANOID_STYLE.mist_shade = { alpha: 0.55, tint: "#dfe4e2" }`，**不設 glow**。色調用修士色票的月白，霧的灰白色，和殘影的藍色分得開。
4. **腳下散成霧**（霧影唯一新增的畫法）：
   - 合成完後，用 `destination-in` 疊一條直向漸層：
     - 從腳底（`DOLL_FOOT_Y`）往上 14 單位（約小腿以下），不透明度由 0 漸變到 1；
     - 以上全部保持 1。
   - 效果是腳不著地，看起來是霧氣凝成的人形。這是和本體最明顯的差別：本體的腳是實的，腳下有影子。
   - 霧影**不畫地面影子**。
5. **霧影不帶本體的精英記號**：
   - 金環、金菱形、詞綴粒子都不畫；
   - 本體的「霧隱的」75% 不透明也不疊上去，只用第 3 點的 0.55。
6. 內容資料：`summon_mist_shade` 的召喚外觀寫 `body: humanoid, variant: mist_shade`（現在靠 `afterimage` 標籤）。前端遇到不認得的款式時沿用現行規則，退回該體型的預設款，所以先上資料、後上前端也不會出錯。

## 檢查清單（美術 PM 驗收時看）

- 霧中劍客和霧影並排時：
  - 霧影比較淡、偏灰白、腳下散開、沒有影子、沒有金環；
  - 本體有金環和詞綴粒子，腳有踩在地上。
- 霧影沒有任何外光。四個朝向都正確，背面也看得出腳下散開。
- 玩家自己的殘影仍然是原本的藍色調加藍色外光，不受影響。
- 霧影倒下或消失時沿用召喚物現有的處理，不用另外做。

工作量估計：約 0.25 段，可以和 5F-ART1（大十字圖示）併成一段。
