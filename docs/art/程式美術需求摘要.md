# 程式繪製美術：給開發 PM 的需求摘要（美術 PM，2026-10-22）

> 使用者已決定採用程式繪製版（見 `docs/美術PM交接.md` 3.3）。本檔是寫階段規格用的素材；**數值、切段與模型由開發 PM 決定**。
> 樣張（參考實作，Canvas 2D、非模組、未測試）：分支 `claude/art-style-sample-404539` 的 `docs/art/sample/`
> （`compare.html` 對比、`dolls.html` 小人、`icons.html` 技能圖示）；截圖 `docs/art/*.png`。
> 瀏覽器直接開 `file:///…/docs/art/sample/compare.html` 即可，不需伺服器。

## 0. 原則

1. **只動前端繪圖**（`client/src/render/`、`client/src/battle/` 的繪圖資料），不改引擎、事件；仍是 2D 俯視角。
2. **外觀只由資料欄位決定**，對照表各放一處；新內容沒有對照時一律有預設，不得出錯（和 3-12 特效、3-13 對照表同一原則）。
3. **確定性**：紋理變化用「格子座標 → 雜湊種子」，同一格每次畫都一樣；禁止 `Math.random()`。
4. **效能**：地形與物件預先畫成離屏 canvas，再 `Texture.from(canvas)` 當貼圖快取（鍵＝種類＋變體＋鄰格遮罩）；小人依「範本＋裝備組合＋朝向」快取。每格不要每幀重畫 Graphics。
5. 可讀性不能比現在差：陣營色、血條、高亮、預覽、特效、狀態徽章照舊疊在上面。

## 2. 戰場圖層順序（由下往上）

1. 地形底圖（含紋理變體）
2. 高度：越高越亮（沿用 `shadeForHeight` 的規則，但改成疊淡色）
3. 表面（相鄰同種表面連成一片：依四鄰遮罩決定哪邊內縮、哪個角圓角）
4. 陰影：較高的北鄰、西鄰投到本格
5. 崖面：南鄰較低時在本格底部畫 `(高度差 × 5px)` 的立面
6. 極淡格線（`rgba(0,0,0,0.14)`）
7. 既有的光環、持續區域、源泉、陷阱（照舊）
8. 物件（含影子；可燃物右上角小火苗）
9. 高度徽章：只在高度 ＞ 0 時畫「▲N」（取代每格都寫 0）
10. 既有的高亮、預覽
11. 單位：依 y 由上往下排序再畫（下面的人蓋住上面的人），每個單位內部：底圈 → 朝向尖角 → 行動中虛線圈 → 小人 → 代號小標 → 血條 → 既有徽章（炸彈、蓄力、召喚剩餘輪數、倒地）
12. 特效（照舊）

## 4. 單位：紙娃娃小人

### 4.1 圖層（腳底中心為原點，身高約 46px，在 52px 格子裡縮放 1.0，頭會略超出格子上緣）

披風（正面時在身體後）→ 腳（褲子＋鞋）→ 身（含手臂）→ 手（手套或膚色）→ 披風（背面時蓋在身體上）→ 頭（膚色＋臉）→ 頭髮 → 頭部裝備 → 主手 → 副手。背面時武器畫在身體後面。
外框：整個小人畫完後，用剪影往 8 個方向偏 1.3px 塗深色（`#16121a`）當描邊。史詩／傳說另外加紫／金色外光。

### 4.2 朝向

| facing | 畫法 |
|---|---|
| `south` | 正面；主手在畫面左 |
| `north` | 背面：不畫臉，頭髮蓋滿，披風在最上層，主手在畫面右 |
| `east`／`west` | 正面寬度 × 0.9，眼睛往朝向那邊偏，主手在前方 |

底圈外緣另畫一個尖角指向朝向（和現在的箭頭同一個意思）。

### 4.3 裝備欄位 → 圖層

| 欄位（8.10） | 圖層 | 種類（`kind`） |
|---|---|---|
| 主手 | 主手 | `sword`、`greatsword`、`dagger`、`axe`、`bow`、`staff`（錘、長柄、弩待補） |
| 副手 | 副手 | `shield_round`、`shield_kite`、`tome`（雙手武器時空） |
| 頭 | 頭部裝備 | `hood`、`helmet`、`horned_helm`、`wizard_hat`、`bandana`、`crown` |
| 身 | 身＋手臂 | `shirt`、`leather`、`mail`、`plate`、`robe`（`ribs` 給骷髏） |
| 手 | 手 | `gloves`、`gauntlets` |
| 腳 | 腳 | `boots`、`greaves` |
| 項鍊、戒指 ×2 | 不畫 | — |
| （外觀）披風 | 披風 | `cape`；目前不是裝備欄位，可當外觀或身體裝備的附屬 |

每件的顏色：`材質`（布、皮、鐵、鋼、金、木、骨各一組主色／暗色）或指定 `color` → 有元素詞條時混入元素色 45%（例：霜紋鎖甲偏冰藍；法杖寶珠直接用元素色）→ 稀有度史詩、傳說加外光。

### 4.4 資料來源與退回（**需要開發 PM 決定**）

- 目前 `UnitView` 只有 `template_id`、`weapon_name_zh`、`tags`，**沒有武器代碼與裝備**。原型建議：
  1. 前端對照表 `template_id → 外觀＋裝備`（樣張 `PaperDoll.TEMPLATES`，現有 8 個範本已示範）。
  2. 沒有對照時：依陣營用預設外觀，武器依 `weapon_name_zh` 或標籤猜不到就給 `sword`；召喚物用骷髏或通用身形。**永遠畫得出來**。
  3. 之後若 `UnitView` 加 `weapon_id`（或英雄的裝備欄位），對照改成讀資料；這是 API 變更，請排進對應階段。
- 英雄裝備系統上線前，英雄外觀也用範本對照。

## 5. 技能圖示（`icons.html`）

- 輸入：`SkillCard` 的元素（**沿用 3-12 `vfx.ts` 推導元素的同一個函式**）、`shape`（3E-2 加 `shape_id` 後改讀它）、射程（數字 ≥ 2 或武器為遠程 → 遠程）、`skeleton`、`rarity`。
- 圖層：① 元素底色漸層＋淡紋理 ② 形狀主圖 ③ 左上元素標誌 ④ 右下骨架徽章（外框用稀有度色）⑤ 稀有度外框（史詩、傳說雙框）。
- 形狀主圖：遠程單體＝飛行物、近戰單體＝揮砍月牙、單體增益（`aura`）＝目標身影＋上升箭頭、直線＝光束、錐形＝扇形、方陣／十字／環形＝九宮格、連鎖＝三節點閃電線、指定格＝地面圈（召喚＝升起的身影、陷阱＝夾子）、自身＝光環＋身影、友軍範圍＝圓頂＋三人、物件→格＝丟箱弧線、單位對＝兩人＋交換箭頭。
- 退回：未知元素＝紫色六角（`DEFAULT_VFX` 色）；未知形狀＝自身光環；未知骨架＝空心圓徽章。
- 用處：技能列（40px）、技能卡、工坊、反應面板；28px 仍可辨識。
- 快取：鍵＝`元素|形狀|遠近|骨架|稀有度`，同組合共用一張貼圖（不是每個技能一張）。
