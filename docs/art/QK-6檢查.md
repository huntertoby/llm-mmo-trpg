- 看法：`docs/art/shots/qk6/` 全部（35 列並排＋總表、獸耳 3 倍、實機 7 張），由唯讀審查 agent 原尺寸看過。

**結論：通過，沒有必修。** 35 列左右一致（差 0.27～0.48% 反鋸齒）；背面不是鏡像、長髮只在耳後、鬍子背面不畫；獸耳四種前後圖層對；建角與主城預覽同步、800 寬預覽固定在上方；戰場沒有破圖。

## 1. 開發補拍（下一段順手）

1. 戰場同一種範本 ×2 以上（例如兩個盜賊）看得出外觀不同；同一個種子重開，同一個 id 外觀一樣。
2. （可選）盜賊外觀畫廊的 `bandit_archer` 改拿弓；主城 800 補一張臉型、鬍子那幾行在畫面內的截圖。

## 2. 樣張層級的小問題（美術 PM 先修樣張，再請開發照改）

1. 兔尾顏色：髮色和白色各半，橘髮時變成桃色、側面像多一隻手 → 改成固定偏白（米白）＋深一階描邊。
2. 狐耳和狼耳太像 → 狼耳改成灰色內側、耳尖更直更窄、外緣深色加寬；狐耳保留淺色內側＋大三角。
3. 鬍渣側面超出下巴輪廓 → 裁在臉內。
4. 方臉、心形臉背面髮罩外露出膚色邊角 → 背面髮罩跟著臉型放大，不露膚色。

## 3. 決定

- 體型「纖細／壯碩」整個人等比縮放：照收（和樣張一致）。
