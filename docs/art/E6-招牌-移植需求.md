# E6-b2 招牌效果：美術移植需求（給開發 PM）

美術 PM，2026-11-23。樣張是 `docs/art/sample/e6-signature.html` ＋ `e6Signature.js`，說明在 `E6-招牌-美術.md`，裁定在 `E6-招牌-審查.md`。顏色、尺寸、動畫時間都照樣張的程式碼抄，不用重新調。

## 1. 要做的

1. **裝備卡第一行的招牌框**（`ui/gear/GearCardView.tsx`、`styles/gear.css`；說明第 1 節）
   - 放在詞條清單前面。框色＝卡片的稀有度色（稀有 `#6fb4ff`、史詩 `#c58cff`、傳說 `#ffb938`）：1px 細框，左邊 3px 色條，由左往右淡掉的底色。
   - 第一行是類型牌和招牌名。類型牌是 18 px 小圖示加「招牌・〇〇」，不拆行；窄的時候招牌名換到下一行。第二行起是說明，13 px，加 `text-wrap: pretty`。
   - 傳說的類型牌寫「獨特效果・〇〇」，框用傳說金。
   - 標灰：灰框 `#6a6878`、沒有底色、類型牌換深灰，圖示灰階並 50% 不透明。名字用 `.part-tip-line.inactive` 的灰字加刪除線；最後一行寫原因，12 px 灰字。
   - 副標（`gear-card-sub`）一起加 `text-wrap: pretty`。
   - 背包詳情、說明框等用到同一張卡的地方都要套；共用同一個元件，不要每處各寫一份。
2. **類型小圖示**（`render/qIcon/`；說明第 4.1 節）
   - 新動作、新反應、行為改寫、改寫規則四種，直接用現有部件圖：`effect.grant_skill`、`effect.extra_reaction`、`skeleton.modifier`、`effect.rule_change`。
   - 地形規則是新圖「地格」，照 `e6Signature.js` 的 `terrainArt` 移植。
   - 尺寸：類型牌 18、角色面板 16、戰利品小牌 14，都走 tiny 畫法。標灰時用灰階。
3. **撿到時的一次性強調**（說明第 2.3 節）
   - 三選一的畫面剛打開時，每張招牌框各播一次。大世界是背包詳情第一次打開這件時播一次。
   - 動畫內容：類型牌輕彈一下（0.35 秒），框外光暈亮起再收掉（1.1 秒），一道斜光從左掃到右（0.8 秒）。0.25 秒後開始，全部 1.35 秒內結束。
   - 同一件只播一次；減少動態（`prefers-reduced-motion`）時不播；不加音效。
4. **大世界掉落**（說明第 2.2 節）
   - 背包滿時的選擇列：帶招牌的裝備，名字後面加「招牌」小標，附 14 px 類型圖示。
   - 戰後那行字裡的小牌：**選做**，要後端給結構化的掉落清單。開發 PM 估成本：小就做，大就先不做，報告裡寫一句。
5. **角色面板的勾選**（`run/RunHeroPanel.tsx` 和大世界的「穿戴中」；說明第 3 節）
   - 「招牌效果」一節放在裝備圖示列下面。節名後面寫「生效 N／3・改寫規則 N／1」，沒有改寫規則時只寫「生效 N／3」。
   - 每一列是勾選、16 px 圖示、招牌名，後面跟灰色小字「類型・部位：裝備名」。招牌用方框，改寫規則用圓鈕（點另一個就直接換過去）。
   - 沒勾的那列整列標灰，下面寫原因。列的順序照部位，勾選時不跳動。
   - 已經滿 3 個時按沒勾的那列，跳一行提示，用暫定字。
   - 滑過一列，顯示現行裝備圖示的浮動卡。
   - 大世界寬的時候分兩欄。

## 2. 可以接受，不是 bug

- 14 px 時，新反應的箭頭尖端黏在一起，改寫規則和新動作也很像。這只出現在戰利品小牌，旁邊有字。
- 地形規則的圖讀成「一塊草地」，這就是它的意思。
- 斜光很淡。
