## 2. 畫圖 agent 點出的疑慮

- **(a) 自身沒有狀態對驅散，在同一張 96 完整圖示上會不會混**：現在不會。理由有三：
  1. `self_lacks_status` 只能給敵人專用招用（`content/skill_conditions.yaml` 的 `enemy_only: true`）。目前只有界隙閃擊一招，它的效果是傷害與傳送，沒有驅散。
  2. 在 96 上兩者位置固定：條件在左下第一顆，效果排在後面。
  3. 底下的形不同。一個是方旗加右下人形，另一個是箭頭，人形是驅散沒有的。

  不改圖，列為觀察：之後如果有敵人專用招同時帶這個條件與驅散，再排一張 96 看。這一條寫在決定 1。
- **(b) 狼頭在 16、18 的鋸齒毛只剩兩三個亮點**：可以接受。這個尺寸靠來辨認的是「銀灰斜塊＋左上耳尖」，鋸齒本來就不是靠來認的零件。規則 8 本來就允許 ≤14px 圖樣省掉小零件。和目標落單分開靠的是色相與剪影，不靠鋸齒。不必修。
- **(c) 「自身」的人形在 16、18 只剩兩三個像素**：可以接受，建議保留。「自身血量低於」「在自己的符文上」在 18 也是同一個 2～3 像素的米白人形（`parts-b-condition-cost.png` 第 3、13 欄），這是這批「自身」的固定寫法。拿掉它反而和那兩個不一致。嚴格來說，這裡超出規則 8 的「≤14px 只留一個主體」（圖樣 12px 時留了旗、槓、人三樣）。不過這個前例第 4 批已經定案，不算這次新增的違規。要不要統一處理，是決定 2。
- **(d) 要不要做帶狀態的版本**（例：定身的圖加紅槓）：建議**現在不做**，理由有三：
  1. 遊戲端 `skillParts.ts` 的 `conditionPart` 只對 `target_has_status` 帶狀態，做了也要開發改 key 才用得到。
  2. 只有一招、只有一種狀態（`root`），而且是敵人專用招，玩家只在敵人技能說明裡看到。
  3. 戰鬥說明行的文字已經寫「自身沒有狀態：定身」。

  等第二招用到不同的狀態再做，做法照 `target_has_status:<狀態>`：狀態圖縮 0.84，加紅槓與右下人形。另外，情境圖的「現行」欄把界隙閃擊畫成定身圖加問號，看起來像新圖少了資訊，其實遊戲端現在畫的是通用旗，見可修 1。這一條寫在決定 3。

## 可修

1. **情境圖「現行」欄把界隙閃擊畫錯**（`shots/qicons/parts-lw-scene@2x.jpg` 左欄第 3 張，96 左下角與條件行）：樣張頁 `q-icons-parts.html` 的 `swapCond` 只把 id 換成 `target_has_status`，`status: root` 卻留著，所以畫成「定身圖＋問號」。遊戲端 `conditionPart` 只在 id 本來就是 `target_has_status` 時帶狀態，main 上實際畫的是**通用淡紫旗＋問號**。這讓「新圖比現行少了定身」的錯覺出現在對照裡。改法：`swapCond` 換 id 時一併拿掉 `status`，然後重拍 `parts-lw-scene`。
2. **移植說明補三件事**（對照 `git show main:client/src/render/qIcon/parts.ts`）：
   - `core.ts` 的 `Pt` 是 `readonly [number, number]`。`WOLF` 與 `selfLacks` 裡的 `const P = [[…], […]]` 照抄進 TS 會被推成 `number[][]`，strict 模式下過不了 `poly`、`ln` 的型別，要寫成 `const WOLF: Pt[]`、`const P: Pt[]`。
   - 註解裡的「暫代」也要一起改：`parts.ts` 第 256 行（「條件 19 個（LW-1 的 2 個是暫代）」）、第 277～278 行的暫代說明、`qIconSkills.test.ts` 第 69、72 行，以及 `qIconQi2d.test.ts` 第 38 行的註解。`ADDED_PARTS` 照舊不用改：它本來就斷言這兩個在基準裡不存在。
   - 小工具都已經在：`poly`、`ci`、`ln`、`halo`、`OUT` 從 `core.ts` 匯入，`at`、`banner`、`bust`、`CREAM` 在 `parts.ts` 自己的檔裡，簽名和樣張相同。這一點紀錄寫對了。
3. **狼頭的亮面用了兩個色**（`lw-close.png` 30×4）：喉胸 `#eef2f6`、口鼻上緣 `#d6dde6`，加上本色與暗面就是四階，耳內 `#5a6169` 另算。嚴格照規則 2（一個零件最多三階），口鼻上緣可以改用同一個 `#eef2f6`，或拿掉。目測差別很小，改了指紋會變，要重拍 `parts-lw`。
4. **真 1 倍頁的空白「現行」框**（`shots/qicons/true1x/parts-lw-t1.png` 第 3、4 欄的最左格）：被借的兩個本身沒有「現行」對照，留了一個空框，看起來像圖沒畫出來。加一行「＝右邊」或拿掉那一格。
