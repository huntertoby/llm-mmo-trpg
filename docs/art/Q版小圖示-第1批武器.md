| 變體 | 現行怎麼分 | Q 版 |

## 2. 做法重點

- **一張圖兩種框**：圖樣畫在 48×48 格；圓章裡外框粗細＝圓章直徑的 5%，裝備格裡照圖樣邊長的 5%（上限 1.6px）。
- **方向**（規則 12，全批一致）：長條武器握把在左下、作用端在右上（45°）；長槍、霰彈槍槍口朝右上（45°，槍的上方朝左上）；手槍只斜 24°（現行裝備圖示的角度，側面 L 形才看得出來）；拳套、盾、書、法器珠直立；成對武器兩把交叉成 X、握把在下。鐮刃、斧刃在柄的右下那一側（和現行小圖示、人物側面同一邊；現行裝備圖示的鐮刃在另一邊）。
- **圓章裡自動收進圓**：`def()` 量出圖樣離中心最遠的距離，放進圓章時縮到「含外框不超出圓章外緣」（`meta.badge`，多數是 0.97～1；直立塊狀 0.84～0.94；鞭 0.78～0.83）。裝備格不縮。
- **裝備格留白 6%**（風格樣張是 8%）：8% 時 45° 的劍、匕首佔框只有 59%，不到規則 7。
- **≤24px 簡化**：不畫鉚釘、刻線、纏繩紋、次要亮線、扳機護弓（部分）、箭與亮色的弦；弓與弩的弦改成一條深色線（寬 2.8、2.4 單位）畫在外框之上。
- **沒寫 `form` 的錘**畫方頭戰錘（人物與現行小圖示都是方頭）；現行裝備圖示會退回清單第一款「釘頭錘」。兩套現行本來就不一致，見第 7 節。

## 3. 我看到（照 `closeup/qicons/weapons/*.png` 的 4 倍圖與 1 倍最近鄰放大 6 倍圖寫）

**劍**
- 直劍：銀色直刃朝右上、劍尖長、左半一條白亮面，暗銅橫護手，深褐短柄，暗銅圓柄頭。圓章 20px 看得出刃、護手、柄頭三段。
- 彎刀：刃往右下彎成一彎、前段變寬、刀尖斜削，刃背一側暗一階；橢圓小護手、短柄、小圓柄頭。20px 是一片彎月形的亮刃，和直劍分得開。
- 闊劍：刃根部寬、往前收窄的楔形，尖端短；護手兩端往上翹成新月；短柄、一顆大圓柄頭。20px 看得到翹起的護手與柄頭；刃的寬度和雙手劍接近。
- 魔導劍：淡紫刃、紫色導槽、三道白橫槓、齒輪形護手、紫寶石，外面淡紫光暈；裝備格多兩顆白色閃光。20px 橫槓糊掉，靠紫色與齒輪護手認。

**巨劍**
- 雙手劍：寬刃、鈍尖、中間暗槽，金色寬橫護手，深褐長柄，沒有柄頭（沒改）。
- 斬馬刀：單刃寬刀，刀背筆直、刀尖往刀背那側斜上去，右側一條暗面；沒有橫護手，只有一片金色橢圓刀鐔；柄上三道淺色纏紋（32px 以上），柄尾一個金環。20px 看得到圓角刀頭、金刀鐔與柄尾的小金環。整體像一把大菜刀。
- 鋸齒巨劍：雙手劍的刃右邊切出三個大鋸齒，金護手、長柄。20px 看得到三個缺口。

**匕首**
- 短刀：一片三角寬刃（左亮右暗），暗銅橫護手、深褐柄、暗銅柄頭；刃和握柄差不多長。
- 三稜刺：比短刀更細的長錐，中脊左亮右暗；圓盤護手、細柄。20px 和短刀很像，只差刃細一點、護手是圓的。
- 彎匕：波浪形的刃（左右擺三次），斜的護手。20px 是一條歪扭的灰刃，看得出不是直的。

**雙匕首**：兩把同款交叉成 X，握把在下面兩角、刃尖在上面兩角，前面那把外面一圈深色邊。短刀、三稜刺 20px 都是清楚的 X；彎匕兩把的波浪刃在上面張開，像一對牛角，1 倍下不容易認成匕首。

**斧**
- 手斧：木柄、柄底深色纏皮與鐵尾；柄頂右下側一片斧刃，下緣比上緣長（鬍鬚斧），刃口一條白亮面，斧眼深一階。
- 戰斧：斧刃更大，柄頂多一根尖刺、背面多一根短刺。20px 看得出「斧刃＋上面與背面各一個尖」。
- 雙刃斧：柄兩側各一片對稱的斧刃。20px 是蝴蝶形。

**錘**
- 釘頭錘：柄頂一顆鐵球、外面一圈八根短釘、左上白色高光。20px 是帶刺的圓球。
- 戰錘：長方形鎚頭橫在柄頂、中間暗箍、兩塊白色高光（亮面比樣張加高一點）。
- 連枷：短柄、兩節鍊環、斜上方一顆帶刺的球。裝備格看得到鍊環；20px 鍊環糊成柄與球之間的一小段，和釘頭錘的差別只剩「球歪在柄的旁邊、柄比較短」。

**矛**
- 長矛：細木桿、菱形矛頭（左亮右暗）、暗銅箍。
- 戟：頂上一根尖、右下側一片斧刃（刃口亮）、背面一根短刺。
- 三叉戟：一條橫檔上三根尖，中間最長。三款 20px 的頭各是「菱形」「斧加尖」「三根叉」。

**鐮刀**
- 長柄鐮：細長木柄、柄頂往右下彎出去的長鐮刃（上緣一條亮面）、暗銅箍。
- 彎月鐮：同一片主刃，柄的另一側多一片短的反向刃。20px 像十字鎬。
- 鉤鐮：短粗的柄（深色纏皮）、一片彎成問號的鉤刃。

**拳套**（都直立、指節朝上）
- 拳刃：下面一個握緊的鐵拳（一排四個小亮點、深色橫檔、深色護腕），上面一片三角大刃，左亮右暗。20px 像一個帶底座的錐子。
- 鐵拳：樣張那一顆（沒改）。
- 爪：鐵拳上三根往右彎的長爪，每根一條亮面。20px 看得到三根尖。

**鞭**
- 皮鞭：左下一根深褐握柄（兩端暗銅），褐色鞭身繞一個 S 甩到右上、越來越細，梢端一小段米白。裝備格看得出是鞭；圓章 20px 鞭身加外框後偏胖，像一條蟲或蛇。
- 鏈鞭：同一條路徑畫成亮暗交替的鏈節，梢端一顆菱形墜。預設材質是皮，所以是褐白相間，像一條花蛇，不像鐵鍊（材質換成鐵、鋼時是灰白相間，見 `weapons-var.png`）。
- 蛇骨鞭：暗色的索上一節一節朝前的三角刃片，梢端一片大矛頭。裝備格看得到刃片；20px 是一條邊緣帶刺的 S。

**弓**
- 短弓：圓弧木弓臂（外緣一條亮面）、兩端深色弓梢、弧頂深色弓把；圓章 20、24px 沒有箭，兩個弓梢之間一條深色的弦，弦和弓臂之間看得到米色空隙，是「D」形。裝備格搭一支箭（鋼箭頭朝右上、紅箭羽）、白弦拉成淺 V。
- 長弓：弧更長更淺，弓梢是骨白色的小圓。20px 和短弓的差別是「比較長、比較扁」，兩端幾乎碰到圓章邊。
- 反曲弓：弓臂中段往前拱、兩端反過來往前翹，像橫放的「3」；弦從兩端拉直。20px 看得出兩端往外勾。

**弩**
- 輕弩：木弩身（尾端加寬）、一道弧形弩臂、一支箭（鋼箭頭朝右上）；裝備格有白弦成 V，圓章是深色的 V 弦。整體是「十」字加一個箭頭。
- 重弩：弩臂更寬更粗，尾端一個鐵絞盤與金色搖柄頭。
- 連弩：弩臂較窄，弩身上疊一個木箭匣（一道深色橫槽），旁邊一根拉桿與金色握球。三款 20px 都是褐色的十字形，差別在尾端有沒有灰色圓輪、中間有沒有方塊。

**火槍**
- 燧發火槍：木槍托一路包到槍管下、細長鋼管、兩道金箍、機匣上一支深色擊鎚、金色扳機護弓（32px 以上）。
- 獵槍：木槍托、暗色機匣、亮鋼槍管、槍管下一截短護木、暗色扳機護弓。三把裡最素。
- 狙擊火槍：金屬槍托、亮鋼機匣、細槍管、槍口一塊暗色制退器，上面一支深色瞄準鏡（前端一顆青色鏡片），槍管下一副兩腳架。20px 看得到青色亮點與腳架的兩根叉。

**霰彈槍**
- 喇叭槍：槍管往槍口張開成喇叭、口上一圈深色的唇，一道金箍、擊鎚。20px 喇叭口很清楚。
- 雙管：上下兩根粗槍管（中間一道暗縫）、槍口一圈箍、短木托、金色扳機護弓。
- 泵動：一根亮槍管、下面暗色彈倉管、一截淺色木滑套（32px 以上三道紋）、槍托連著往下的握把。20px 和雙管都是「短粗的槍」，差在中段那塊淺褐色。

**手槍**
- 燧發手槍：一整條往下彎的木握把、尾端一顆金色握把帽、亮鋼短管、深色擊鎚。

## 5. 和人物不一致的地方與理由

1. **形制**：人物（`qDoll.js` 的 `QW`、`paperdoll.js`）只分少數形制（魔導劍、釘頭錘、拳刃／爪、戟、三叉戟、塔盾、槍的長短）。彎刀、闊劍、斬馬刀、鋸齒巨劍、三稜刺、彎匕、戰斧、雙刃斧、連枷、彎月鐮、鉤鐮、長弓、反曲弓、重弩、連弩、槍的各形制、權杖、短杖、圖騰杖、包鐵圓盾、卷軸匣、浮空寶珠，在人物手上都是該種類的同一把；圖示照現行裝備圖示的形制畫，材質色與握柄色用人物那一份。
2. **匕首**：人物的護手是深褐（和握柄同色）、沒有柄頭；圖示用暗銅護手與柄頭（和 `qIcons.js` 技能圖示裡那把一致），深色裝備格上才看得到護手。圖示把匕首放大到和劍差不多長（現行也放大 1.5 倍）。
3. **槍**：人物的槍只是一根槍管加握把、木托；圖示多了擊鎚、機匣、轉輪、箍、扳機護弓、瞄準鏡、腳架（都是現行裝備圖示有的零件）。
4. **鞭**：人物的鞭身是深皮色 `#5e3b1f`，圖示用亮一階的皮色 `#8a5a32` 加一條亮線（規則 6）；握柄兩端多了暗銅小圓。
5. **木圓盾**：人物的盾外面多一圈鋼邊（為了和披風分開）；圖示把鋼邊留給「包鐵圓盾」，木圓盾是深木色的邊。盾心同樣是金色。
6. **法書**：人物的書是封面加一條書頁、一顆金圓；圖示多了書脊、書角、書籤、圓章裡的寶石。
7. **斧、錘、矛、鐮**：頭部比人物放大（規則 3 允許），柄底多一段纏皮與鐵尾（斧、錘；樣張的鎚已有）。
8. **拳套**：指節朝上（人物的手垂著），同樣張。拳刃、爪的刃從指節往上伸（人物是往前伸）。
9. **塔盾的預設色**：`kite_shield` 的材質清單只有金屬、預設鐵，所以沒有染色時圖示是灰色；風格樣張那面褐色塔盾是人物範本給了木色。

## 6. 1 倍下仍不好認的

- **鞭（三款）圓章 20px**：像蟲或蛇。鞭身是軟的、沒有固定剪影，加外框後更胖。裝備格 32px 以上可以認。
- **鏈鞭（預設皮材質）**：褐白相間，像花蛇不像鍊。
- **雙匕首・彎匕**：像一對牛角。
- **雙手槍・左輪**：交叉處兩顆轉輪擠在一起。
- **彎月鐮**：像十字鎬。
- **拳刃**：像帶底座的錐子，看不出是套在拳頭上。
- **三稜刺**：認得出是匕首，認不出是「三稜」。
- **弩三款**：認得出是弩，三款之間要看細節。
- **長弓 20px**：兩端離圓章邊只剩一條細縫。

## 9. 給開發移植的重點

1. **介面**：`QIconsWeapons.def(look)` → `{ d, pre, post, meta }`；`look = { kind, form?, material?, element?, keywords?, rarity?, color? }`，欄位和 `gearIcon.ts` 的 `GearLook`、`weaponIcon.ts` 的 `GearItem` 相同，`resolve()` 的退回規則照 `resolveGear()`。`paint(ctx, look, size, res, { frame: "badge"｜"gear"｜"none", motif })` 畫含框的圖。
2. **對應現行兩處**：
   - `weaponIcon.ts` 的 `weaponItemIconCanvas(item, px)`：改成畫 `frame: "none"` 的圖樣（米色圓章仍是 CSS `.weapon-icon`），邊長乘 `meta.badge` 置中。不再需要量外框那一遍（`measure`）。成對武器不要再用 `pairedPart()` 換成單把，直接給 `dual_dagger`／`dual_pistol`。
   - `gearIcon.ts` 的 `drawGear()`：武器與副手（`slotType` 是 `weapon`、`offhand`）改呼叫 Q 版圖樣，四邊留白 6%；外框 `frame()`、關鍵字小圖樣 `motif()` 與 `SMALL_ICON_MAX_PX` 照舊，小圖樣位置用 `meta.spots`（48 格座標）。防具飾品這批沒有，仍走現行。
3. **剪影外框**：`QIcons.render(def, px, res, { ow })` 的做法（先畫色塊、把剪影往外長一圈墊在底下；`pre` 在外框底下、`post` 在最上面）。外框粗細：圓章用圓章直徑的 5%，裝備格用圖樣邊長的 5%，最細 1、最粗 1.6 CSS px。`o.small`＝圖樣邊長 ≤24px。
4. **快取鍵**要含 `kind、form、material、keywords、element、rarity、color、px、frame`。`def()` 第一次會量一次圖樣範圍（兩張 96px 畫布），之後有快取。
5. **依賴**：`qIconsWeapons.js` 用到 `qIcons.js` 的 `H`（畫法小工具）與 `W`（八把樣本）。移植時武器相關的可以併成一個模組；`towerShield`、`daggerArt` 技能圖示（第 2 批）也會用。
6. **沒寫 `form` 的錘**：Q 版畫戰錘。要不要把 `weapons.yaml` 的錘補上 `form: warhammer`，讓裝備圖示與人物一致，請開發 PM 與美術 PM 決定（見下）。

## 10. 要美術 PM 決定的事

1. **鞭的圓章小圖示**：1 倍下像蟲。要不要改成「盤成一圈的鞭」（握柄加一個圓圈，RPG 常見的畫法，但和人物手上垂著的鞭、現行的 S 形都不同）。
2. **沒寫 `form` 的錘畫哪一款**：這批照人物畫方頭；現行裝備圖示是釘頭錘。
3. **鏈鞭、蛇骨鞭的預設材質是皮**（資料檔如此），鍊子是褐色。要不要請玩法／開發把這兩款的預設材質改成鐵，不在美術範圍內，只提出。
4. **元素關鍵字的小圖樣**（>36px 疊在器物上的細線小圖）沒有重畫，疊在 Q 版粗圖樣上偏細。要不要列進之後的批次（它屬於「裝備關鍵字小圖樣 12」，使用者說六類以外先不動）。
5. **裝備格留白從 8% 改成 6%**、**圓章裡自動縮放**兩個做法是否採用；採用的話風格樣張頁的八把（仍是 8%、手寫的 0.86／0.87）要不要跟著改。
6. **成對武器在圓章裡畫兩把**（現行畫單把）是否同意。
