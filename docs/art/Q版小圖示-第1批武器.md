## 2. 做法重點

- **一張圖兩種框**：圖樣畫在 48×48 格；圓章裡外框粗細＝圓章直徑的 5%，裝備格裡照圖樣邊長的 5%（上限 1.6px）。
- **方向**（規則 12，全批一致）：長條武器握把在左下、作用端在右上（45°）；長槍、霰彈槍槍口朝右上（45°，槍的上方朝左上）；手槍只斜 24°（現行裝備圖示的角度，側面 L 形才看得出來）；拳套、盾、書、法器珠直立；成對武器兩把交叉成 X、握把在下。鐮刃、斧刃在柄的右下那一側（和現行小圖示、人物側面同一邊；現行裝備圖示的鐮刃在另一邊）。
- **圓章裡自動收進圓**：`def()` 量出圖樣離中心最遠的距離，放進圓章時縮到「含外框不超出圓章外緣」（`meta.badge`，多數是 0.96～1；直立塊狀 0.8～0.93）。裝備格不縮。第 2 版把這個算法搬到 `qIcons.js`（`Q.badgeScale`），風格樣張的八把同一套。
- **圓章與裝備格可以是不同構圖**（第 2 版）：畫法收到 `o.badge`（畫在圓章裡）。目前只有鞭用到（圓章裡盤成一圈、裝備格是 S 形）；弓只換弦與箭桿的顏色，構圖相同。
- **裝備格留白 6%**（風格樣張是 8%）：8% 時 45° 的劍、匕首佔框只有 59%，不到規則 7。
- **≤24px 簡化**：不畫鉚釘、刻線、纏繩紋、次要亮線、扳機護弓（部分）；弩的弦改成一條深色線（寬 2.4 單位）畫在外框之上。弓（第 2 版）在圓章裡不分尺寸都留箭，弦是 1px 深褐線、箭桿是 1.25px 深褐線，畫在外框之上。成對的左輪在 ≤24px 省掉後面那把的轉輪與扳機護弓。
- **沒寫 `form` 的錘**畫方頭戰錘（人物與現行小圖示都是方頭）；現行裝備圖示會退回清單第一款「釘頭錘」。兩套現行本來就不一致，見第 7 節。

## 3. 我看到（照 `closeup/qicons/weapons/*.png` 的 4 倍圖與 1 倍最近鄰放大 6 倍圖寫）

**劍**
- 直劍：銀色直刃朝右上、劍尖長、左半一條白亮面，暗銅橫護手，深褐短柄，暗銅圓柄頭。圓章 20px 看得出刃、護手、柄頭三段。
- 彎刀：刃往右下彎成一彎、前段變寬、刀尖斜削，刃背一側暗一階；橢圓小護手、短柄、小圓柄頭。20px 是一片彎月形的亮刃，和直劍分得開。
- 闊劍：刃根部寬、往前收窄的楔形，尖端短；護手兩端往上翹成新月；短柄、一顆大圓柄頭。20px 看得到翹起的護手與柄頭；刃的寬度和雙手劍接近。
- 魔導劍：淡紫刃、紫色導槽、三道白橫槓、齒輪形護手、紫寶石，外面淡紫光暈；裝備格多兩顆白色閃光。20px 橫槓糊掉，靠紫色與齒輪護手認。

**巨劍**
- 雙手劍：寬刃、鈍尖、中間暗槽，金色寬橫護手，深褐長柄，沒有柄頭（沒改）。
- 斬馬刀（第 2 版）：一條細長的單刃刀，刀背筆直、刀尖往刀背那側斜上去，右側一條暗面、左側一條白亮線；沒有橫護手，只有一片金色橢圓刀鐔；深褐長柄（32px 以上三道淺色纏紋），柄尾一個金環。刀身比雙手劍窄，20px 看得到斜削的刀尖、金刀鐔、長柄與柄尾的小金環，是一把長柄大刀，不再像菜刀。
- 鋸齒巨劍：雙手劍的刃右邊切出三個大鋸齒，金護手、長柄。20px 看得到三個缺口。

**匕首**
- 短刀：一片三角寬刃（左亮右暗），暗銅橫護手、深褐柄、暗銅柄頭；刃和握柄差不多長。
- 三稜刺：比短刀更細的長錐，中脊左亮右暗；圓盤護手、細柄。20px 和短刀很像，只差刃細一點、護手是圓的。
- 彎匕（第 2 版）：刃只往一側彎一下，刃尖收尖、指向右上；左半亮、右半暗；斜的暗銅護手、深褐柄、圓柄頭。20px 是一片彎彎的尖刃（像小彎刀），和短刀的直三角分得開。

**雙匕首**：兩把同款交叉成 X，握把在下面兩角、刃尖在上面兩角，前面那把外面一圈深色邊。短刀、三稜刺 20px 都是清楚的 X。彎匕（第 2 版）交叉角比另外兩款窄，兩片彎刃的尖都朝上、在上面分開成窄 V，下面是兩個護手與兩根握柄交叉；不再像牛角。20px 兩片刃靠得近，上半有點像一片尖端分岔的寬刃，要靠下面交叉的兩根握柄才看得出是兩把。

**斧**
- 手斧：木柄、柄底深色纏皮與鐵尾；柄頂右下側一片斧刃，下緣比上緣長（鬍鬚斧），刃口一條白亮面，斧眼深一階。
- 戰斧（第 2 版）：一大片斧刃（下緣略長）、背面一根三角短刺，柄頂沒有尖刺。20px 是「一大片斧刃＋背面一個尖」。
- 雙刃斧：柄兩側各一片對稱的斧刃。20px 是蝴蝶形。

**錘**
- 釘頭錘：柄頂一顆鐵球、外面一圈八根短釘、左上白色高光。20px 是帶刺的圓球。
- 戰錘：長方形鎚頭橫在柄頂、中間暗箍、兩塊白色高光（亮面比樣張加高一點）。
- 連枷（第 2 版）：木柄斜放（底下纏皮與鐵尾）、柄頂一個暗色鐵箍，兩顆淺灰的鍊環從柄頂橫拉出去，一顆帶刺的鐵球垂在柄頂的右下方。20px 看得到柄、兩顆亮點、球三段，柄和球之間有一塊米色空隙；圖樣是「ㄱ」字形，和釘頭錘的一直線分得開。

**矛**
- 長矛：細木桿、菱形矛頭（左亮右暗）、暗銅箍。
- 戟（第 2 版）：頂上一根長尖（左側一條亮面），尖的下方右側一片小斧刃（刃口亮）、背面一根短刺，暗銅箍在更下面。20px 是「一根長尖＋兩側各一個小翼」，像十字形的槍頭。
- 三叉戟：一條橫檔上三根尖，中間最長。三款 20px 的頭各是「菱形」「斧加尖」「三根叉」。

**鐮刀**
- 長柄鐮：細長木柄、柄頂往右下彎出去的長鐮刃（上緣一條亮面）、暗銅箍。
- 彎月鐮（第 2 版）：細長木柄，柄頂掛一片超過半圓的大新月刃：月牙的一個尖剛好蓋過柄頂，刃身往右鼓出去再彎回來，另一個尖指回柄的方向；內緣一條亮面、外緣暗一階；沒有反向刃。所有尺寸都是「長柄＋一彎月牙」，像一把割草的大鐮刀，不像十字鎬。
- 鉤鐮：短粗的柄（深色纏皮）、一片彎成問號的鉤刃。

**拳套**（都直立、指節朝上）
- 拳刃（第 2 版）：上面一片扁寬的三角刃（左亮右暗），刃根一條暗色橫檔，橫檔兩端各一根往下的暗色側桿；兩根側桿中間是一顆縮小的鐵拳（四個指節、橫著的拇指、護腕），護腕比側桿長。裝備格看得出「三角刃＋握架＋拳頭」；20px 是一個尖屋頂形，下面的拳頭只剩幾個灰色小塊，像一間小亭子或一個箭頭，認不出拳頭。
- 鐵拳：樣張那一顆（沒改）。
- 爪：鐵拳上三根往右彎的長爪，每根一條亮面。20px 看得到三根尖。

**鞭**
- 皮鞭（第 2 版）：裝備格不變——左下一根深褐握柄（兩端暗銅），褐色鞭身繞一個 S 甩到右上、越來越細，梢端一小段米白。**圓章裡（20、24、28px）改成盤成一圈**：一個粗皮環（中間看得到米色的圓洞）、左下斜伸出握柄、右下垂一小段鞭梢（梢端米白）。20px 是「一個圈＋一根柄」，看得出是盤起來的繩鞭，不再像蟲；也有點像放大鏡或套索。
- 鏈鞭（第 2 版）：裝備格同一條 S 路徑畫成亮暗交替的鏈節（暗節比第 1 版再暗一階），梢端一顆菱形墜。圓章裡是一圈亮暗交替的鏈節圍成環，右下垂兩三節與菱形墜。預設材質是皮，所以是深褐與米白相間；鐵、鋼、銀、骨材質是淺色與深灰相間，不再整條變白（`weapons-var.png`）。
- 蛇骨鞭（第 2 版）：裝備格不變——暗色的索上一節一節朝前的三角刃片，梢端一片大矛頭。圓章裡是暗色的索繞一圈、外緣九片朝外的刃片，右下垂一小段接矛頭。20px 是一個帶柄的齒輪或鋸片，看得出邊緣是刺，但不容易想到鞭。

**弓**
- 短弓（第 2 版）：細的半圓木弓臂（外緣一條亮面）、兩端深色弓梢、弧頂深色弓把，鋼箭頭從弓背穿出去指向右上。圓章裡弦是一條 1px 的深褐細線、拉成淺 V，箭桿是一條更深的褐線從弦到弓把；弦與弓臂之間是一大塊米色（量過：20px 時箭桿旁邊的空隙 4.2px）。裝備格同一個構圖，弦是白的、箭桿淺木色，箭尾多一對紅箭羽。20px 是「半圓弓＋中間一支箭」，不再像腰果。
- 長弓（第 2 版）：弧更長更淺，弓梢是骨白色的小圓，其餘同短弓（20px 空隙 3.5px）。和短弓的差別是「比較寬、比較扁、兩端有白點」。
- 反曲弓（第 2 版）：同一種圓弧，兩端多一小段往外、往前翹的弓梢（Ω 形）；弦掛在翹起來之前的那兩點（20px 空隙 4.2px）。20px 看得出兩端各有一個往外的小勾。

**弩**
- 輕弩：木弩身（尾端加寬）、一道弧形弩臂、一支箭（鋼箭頭朝右上）；裝備格有白弦成 V，圓章是深色的 V 弦。整體是「十」字加一個箭頭。
- 重弩：弩臂更寬更粗，尾端一個鐵絞盤與金色搖柄頭。

## 5. 和人物不一致的地方與理由

1. **形制**：人物（`qDoll.js` 的 `QW`、`paperdoll.js`）只分少數形制（魔導劍、釘頭錘、拳刃／爪、戟、三叉戟、塔盾、槍的長短）。彎刀、闊劍、斬馬刀、鋸齒巨劍、三稜刺、彎匕、戰斧、雙刃斧、連枷、彎月鐮、鉤鐮、長弓、反曲弓、重弩、連弩、槍的各形制、權杖、短杖、圖騰杖、包鐵圓盾、卷軸匣、浮空寶珠，在人物手上都是該種類的同一把；圖示照現行裝備圖示的形制畫，材質色與握柄色用人物那一份。
2. **匕首**：人物的護手是深褐（和握柄同色）、沒有柄頭；圖示用暗銅護手與柄頭（和 `qIcons.js` 技能圖示裡那把一致），深色裝備格上才看得到護手。圖示把匕首放大到和劍差不多長（現行也放大 1.5 倍）。
3. **槍**：人物的槍只是一根槍管加握把、木托；圖示多了擊鎚、機匣、轉輪、箍、扳機護弓、瞄準鏡、腳架（都是現行裝備圖示有的零件）。
4. **鞭**：人物的鞭身是深皮色 `#5e3b1f`，圖示用亮一階的皮色 `#8a5a32` 加一條亮線（規則 6）；握柄兩端多了暗銅小圓。
5. **木圓盾**：人物的盾外面多一圈鋼邊（為了和披風分開）；圖示把鋼邊留給「包鐵圓盾」（兩款才分得開），木圓盾第 2 版改成淺木色的邊（和人物一樣是「邊比盾面亮」，只是不用鋼色）。盾心同樣是金色。
6. **法書**：人物的書是封面加一條書頁、一顆金圓；圖示多了書脊、書角、書籤、圓章裡的寶石。
7. **斧、錘、矛、鐮**：頭部比人物放大（規則 3 允許），柄底多一段纏皮與鐵尾（斧、錘；樣張的鎚已有）。
8. **拳套**：指節朝上（人物的手垂著），同樣張。拳刃、爪的刃從指節往上伸（人物是往前伸）。
9. **塔盾的預設色**：`kite_shield` 的材質清單只有金屬、預設鐵，所以沒有染色時圖示是灰色；風格樣張那面褐色塔盾是人物範本給了木色。

10. **鞭在圓章裡盤成一圈**（第 2 版，美術 PM 決定）：人物手上的鞭是垂著的、裝備格是 S 形，圓章裡是盤起來的；零件與配色相同（握柄、兩端暗銅、鞭身、梢端）。
11. **塔盾頂邊微拱、四角鉚釘**（第 2 版）：人物手上是圓角長方形、沒有鉚釘。
12. **弓搭著箭**（第 2 版）：人物待機時也搭箭；圖示的箭頭比人物的大，圓章裡箭桿與弦是深褐色（人物是淺木色箭桿、白弦，米色底上看不到）。

## 6. 1 倍下仍不好認的（第 2 版，照最終圖）

- **拳刃 20、24px**：尖屋頂形，像小亭子或箭頭；下面的拳頭看不出來。裝備格 32px 以上看得出握架與拳頭。

## 9. 給開發移植的重點

0. **第 2 版有變的地方**：(a) 畫法的 `o` 多了 `badge`（畫在米色圓章裡）與 `u`（1 CSS px 是幾個單位）；圓章要傳 `badge: true`，量 `meta.badge` 時也要用圓章的構圖量（`Q.badgeScale`）。(b) 鞭在圓章與裝備格是兩種構圖。(c) 弓的弦與箭桿在圓章裡是 `post` 的細線（不包外框）。(d) 成對武器的畫法多收到 `o.pair`、`o.rear`。(e) `W.towerShield` 多一個參數 `deco`（武器／裝備圖示傳 `true`，技能圖示不傳）。(f) **請開發在 `content/weapons.yaml` 的錘補上 `form: warhammer`**（美術 PM 決定：沒寫 `form` 的錘照人物畫方頭），裝備圖示、小圖示與人物才會一致；補之前 Q 版的 `resolve()` 仍把沒寫 `form` 的錘當成戰錘。
1. **介面**：`QIconsWeapons.def(look)` → `{ d, pre, post, meta }`；`look = { kind, form?, material?, element?, keywords?, rarity?, color? }`，欄位和 `gearIcon.ts` 的 `GearLook`、`weaponIcon.ts` 的 `GearItem` 相同，`resolve()` 的退回規則照 `resolveGear()`。`paint(ctx, look, size, res, { frame: "badge"｜"gear"｜"none", motif })` 畫含框的圖。
2. **對應現行兩處**：
   - `weaponIcon.ts` 的 `weaponItemIconCanvas(item, px)`：改成畫圓章構圖的圖樣（`Q.render(def, px × meta.badge, res, { ow: outlinePx(px), badge: true })`，不含圓章底；米色圓章仍是 CSS `.weapon-icon`），邊長乘 `meta.badge` 置中。不再需要量外框那一遍（`measure`）。成對武器不要再用 `pairedPart()` 換成單把，直接給 `dual_dagger`／`dual_pistol`。
   - `gearIcon.ts` 的 `drawGear()`：武器與副手（`slotType` 是 `weapon`、`offhand`）改呼叫 Q 版圖樣，四邊留白 6%；外框 `frame()`、關鍵字小圖樣 `motif()` 與 `SMALL_ICON_MAX_PX` 照舊，小圖樣位置用 `meta.spots`（48 格座標）。防具飾品這批沒有，仍走現行。
3. **剪影外框**：`QIcons.render(def, px, res, { ow })` 的做法（先畫色塊、把剪影往外長一圈墊在底下；`pre` 在外框底下、`post` 在最上面）。外框粗細：圓章用圓章直徑的 5%，裝備格用圖樣邊長的 5%，最細 1、最粗 1.6 CSS px。`o.small`＝圖樣邊長 ≤24px。
4. **快取鍵**要含 `kind、form、material、keywords、element、rarity、color、px、frame`。`def()` 第一次會量一次圖樣範圍（兩張 96px 畫布），之後有快取。
5. **依賴**：`qIconsWeapons.js` 用到 `qIcons.js` 的 `H`（畫法小工具）與 `W`（八把樣本）。移植時武器相關的可以併成一個模組；`towerShield`、`daggerArt` 技能圖示（第 2 批）也會用。
6. **沒寫 `form` 的錘**：Q 版畫戰錘。美術 PM 已決定照人物畫方頭，請開發把 `weapons.yaml` 的錘補上 `form: warhammer`（見第 0 點 f）。
