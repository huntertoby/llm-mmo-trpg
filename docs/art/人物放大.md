# 戰場人物放大：美術 PM，2026-10-29

> 使用者試玩後說：「人 變好小喔」（開發 PM 轉達；截圖是戰場放大到每格約 88px，小人只有格高一半多一點、很細）。
> 現況：`paperdoll.ts` `DOLL_SCALE = 0.74`（以 52px 格為準），人約 38～40px，佔格高約 74%。

## 決定

| 項目 | 數字 |
|---|---|
| 人（紙娃娃） | `DOLL_SCALE` **0.74 → 0.92**（×1.24）。52px 格裡人約 48px，佔格高約 92% |
| 超出上一格 | 頭頂可以超出格子上緣，**一般人最多約格高的 20%**（尖帽、龍角再多一點沒關係）；照 y 排序，前排的人蓋住後排的腳，不用另外處理 |
| 形態 | 跟著人一起放大（形態是相對變身前的比例，封頂 1.3 **不變**）；巨人、龍超出上一格最多約 45% 可以接受 |
| 人形召喚物（用 `DOLL_SCALE` 的） | 跟人一樣 |
| 野獸、物件召喚物（縮放 1） | **×1.15**（不跟到 1.24，免得狼和熊比人還大太多） |
| 腳下的光環、HP 條、字母標記 | **不動**（都在腳邊，人變高不影響） |
| 頭頂狀態列 | **跟著頭頂往上移**：人多出來的高度約 `52 × (0.92 − 0.74) ≈ 9.4px`（52px 格），所以 `ROW_Y` 再減 `9.4 × (T/52)`；高瘦、形態的額外上移照舊疊加。召喚物用各自的放大量算 |
| 清晰度 | 貼圖照實際顯示大小畫（`(T/52) × DOLL_SCALE × dpr`），不要畫小再放大；88px 格下不能糊 |

寬度不另外加：C 畫風本來就是細長比例，整體放大後就不會顯得細。

## 驗收

請給我同一個場面（含高台、精靈、矮人、一個形態、一隻召喚物）在 **52px 和 88px** 的前後對照圖各一張；我看頭頂超出、狀態列有沒有壓到頭、會不會糊。

## 3U-2 驗收（2026-10-29，看 `docs/phases/img/3U-2-before／after-52／88.png`）

**放大本身通過**：人佔格高約九成，矮人、精靈體型清楚；熊、龍形態和狼、骷髏召喚物比例合理；88px 下不糊；高台上的人站位正確。

**狀態列要改位置**（開發 PM 問的那點）：放大前其實就有問題，狀態列的三個圖示本來就壓在自己臉上；放大後再往上移，又蓋到上一格單位的腿和 HP 條。只調高度兩邊顧不到，所以改成：

| 項目 | 改成 |
|---|---|
| 位置 | 移到**腳邊**：HP 條正上方、置中，畫在自己的小人之上（只蓋到自己的腳和光環） |
| 大小 | 圖示縮到現在的約 **60%**（88px 格約 20px），間距 1～2px |
| 上移規則 | 拿掉：不再隨頭頂、體型、形態上移（`ROW_Y` 的 9.4、7.8、高瘦、形態加量都不需要） |
| 不動 | 字母標記（左）、召喚物回合數（右）、HP 條；圖示如果碰到字母標記，整排往右讓 |

這樣狀態列永遠不會離開自己的格子，也不會蓋臉。改完請給我同一場面 88px 的圖一張。
