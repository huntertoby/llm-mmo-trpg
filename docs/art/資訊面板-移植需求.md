### 3.2 分頁＋摺疊通用規則（使用者定案；提案 11.4，之後別的面板照這套）
1. **判斷**：面板在 1600×900（720×700，捲動區約 656）放不下「常見最多」的內容就拆；800×600（實量約 493×414，見 3.6）時每個分頁也盡量在一屏內。不能只看現在的假資料。
2. **固定區**（不捲；`PopupFrame` 的 `head`，或捲動區頂端 `position: sticky`——PNL-1a 用後者）：標頭 → 數值籌碼 → 管整個面板的提示（只留粗體結論，次行收進 (i)）或一行摘要 → 分頁列。**800×600 時固定區 ≤ 約 165px**（樣張量到：成長 165、公告板 142）。只管某一頁的提示放進那一頁。**切分頁時捲動區回到頂端（`scrollTop` 設 0；同一頁內不動），必做**：不然捲過的面板切到新的一頁，最上面一行會被固定區蓋住（PNL-1a 驗收必修 1，排在 PNL-1b 開頭修）。
3. **分頁**：2～5 個；名稱沿用原區塊名，另定兩字短名；圖示沿用區塊標頭的 Q 版圖示 16px、不帶底框。照「玩家最常來做的事」排，**預設開第一個；第一個整頁鎖住時改開第一個掛金底數字的，沒有就開第一個沒鎖的**。從別處的提醒點進來直接開對應分頁（功能列「靈感 N」→「靈感閃現」）。超過 5 個就該合併。
4. **分頁內**：還放不下時次要區塊用摺疊、**一次只開一個**，摺起來右邊掛狀態標籤；不做分頁裡再分頁。**分頁上已經掛的數字，頁內不再寫一次**。
5. **狀態記號**（不新增顏色）：金底數字＝有事可做；細框數字＝進度或數量；綠點＝限時的事正在進行；琥珀三角＝警告；金鎖＝整頁都還沒開放（只有一部分鎖住不掛）。純資訊不掛。**鎖住時不掛數字**。每種記號滑過有說明（#42、#43）。
6. **外觀**：分頁列底一條細金線；目前分頁＝和內容同底色、亮金粗體、上緣 2px 亮金條（資料夾耳朵）；其他＝次文字色。
