# 可玩種族：美術可行性評估（美術 PM，2026-10-24，尚未畫樣張）

> 使用者原話（專案 PM 轉達）：「剛剛想到有點可惜的是 敵人種族眾多但是我們只能是人族 因為紙娃娃 然後裝備又要傳的上 還是有辦法」。
> 玩法面（種族能力差異）由玩法 PM 另議；本文件只談外觀。

## 結論

**可行，而且不用重做紙娃娃。** 同一副人形骨架，加「種族部件」（耳、角、尾、膚色、紋路、體型比例），裝備照常疊上去。非人形（四足、無手）不當可玩種族。建議採**方案乙**，分兩段做。

## 1. 現有紙娃娃能不能直接加

可以。紙娃娃的繪製順序是固定的圖層（`paperdoll` 的 `drawFigure`）：

披風（正面）→ 背後的武器 → 腿 → 身體裝備 → 手 → 披風（背面）→ 頭 → 頭髮 → 頭部裝備 → 前面的武器

頭髮已經會看頭部裝備決定怎麼畫（戴頭盔時不畫瀏海），種族部件照同一個做法插進去即可：

| 種族部件 | 插在哪一層 | 備註 |
|---|---|---|
| 膚色 | 既有 `look.skin` | 已支援，只要加色票（灰藍、灰紅、淡綠等） |
| 紋路（鱗片、刺青） | 頭、手之後 | 只畫在露出的皮膚上（臉、手），裝備自然蓋住 |
| 尖耳、鰭耳 | 頭髮之後、頭部裝備前後依規則（下表） | 側面向外伸 |
| 獸耳 | 同上 | 頭頂 |
| 角 | 頭部裝備之後 | 角永遠在最上層 |
| 尾巴 | 腿之前（正面、側面）；披風之後（背面） | 正面從腰側露出一截 |
| 體型比例 | 整個人（含裝備）縮放 | 矮壯：寬 1.12、高 0.88；高大：寬 1.05、高 1.12。不超出格子，HP 條與狀態列位置跟著高度調 |

外觀資料（全部選填，不認得的值＝沒有，不會出錯）：

```
race_look: { skin, ears: none|pointed|beast|fin, horns: none|small|curved|ram,
             tail: none|beast|scaled|demon, pattern: none|scales|marks, build: normal|stout|tall, beard: bool }
```

## 2. 會和種族部件衝突的裝備與處理

規則寫在「頭部裝備的種類」上（每種 kind 一個 `covers` 標記），新增帽子或種族時不用一一配對：

| 頭部裝備 | 遮住哪裡 | 角 | 尖耳／鰭耳 | 獸耳 |
|---|---|---|---|---|
| 頭盔、重盔（helmet、greathelm） | 頭頂＋兩側 | 從頭盔上穿出（畫在最上層） | 從頭盔兩側伸出 | 藏起來 |
| 角盔（horned_helm） | 頭頂＋兩側 | 種族角取代裝飾角，不重複畫 | 伸出 | 藏起來 |
| 兜帽（hood） | 頭頂＋兩側 | 從兜帽穿出 | 藏起來 | 兜帽頂端多兩個凸起（有耳朵的兜帽） |
| 帽子（cap、bandana、crown） | 頭頂 | 帽子變窄、戴在兩角之間 | 伸出 | 從帽子兩側穿出 |
| 寬帽、巫師帽（wide_hat、wizard_hat） | 頭頂 | 帽子抬高、架在角上 | 伸出 | 藏起來 |

其他部位：

| 部位 | 衝突 | 處理 |
|---|---|---|
| 身體裝備（長袍、外套） | 尾巴 | 尾巴從下襬後側露出，不穿過衣服 |
| 披風 | 尾巴（背面） | 背面時尾巴畫在披風之上 |
| 手套、臂甲 | 鱗片紋 | 被手套蓋住就不畫，不需處理 |
| 鞋 | 獸腳 | 不做獸腳（避免和鞋子衝突）；獸族的特徵放在耳朵和尾巴 |

## 3. 三個方案

| 方案 | 內容 | 種族數 | 美術工作量 | 效果 |
|---|---|---|---|---|
| 甲 輕量 | 膚色＋耳朵＋角＋尾巴；頭盔衝突用「角和耳朵永遠在最上層」一條規則處理 | 4～5 | 樣張 0.25＋移植 0.5 段 | 分得出種族，但戴寬帽時角會穿過帽子，看起來怪 |
| **乙 建議** | 甲＋體型比例（矮壯、高大）＋紋路（鱗片、刺青）＋鬍子＋上表的頭部裝備衝突規則 | 6～7 | 樣張 0.5＋移植約 1 段（可分兩段：先部件與衝突規則，再體型與紋路） | 種族一眼可辨，所有裝備都穿得上 |
| 丙 換頭型 | 乙＋不同頭型（蜥蜴人長吻、獸人狼頭） | 8＋ | 2 段以上 | 最像不同種族，但每頂頭盔都要為每種頭型重畫，「裝備穿得上」很難保證；**不建議**，可以留給敵人 |

## 5. 樣張需求（使用者同意方向後再畫）

1. 6 個種族 × 4 套裝備（不穿、板甲＋頭盔、長袍＋巫師帽、皮甲＋兜帽），正面、側面、背面。
2. 衝突特寫：角＋寬帽、獸耳＋兜帽、尾巴＋長袍、矮人＋大盾。
3. 戰場實際大小：6 族並排，和敵人、召喚物、形態擺在一起。
4. 全組合自測：所有種族部件 × 所有頭部裝備，加上未知值，都畫得出來。

工作量約 0.5 段（同方案乙的樣張）。

## 移植估計

種族部件＋衝突規則＋資料欄位＋測試約 1 段，建議分兩段：① 耳、角、尾、膚色、衝突規則；② 體型、臉部紋路、鬍子、獠牙。
