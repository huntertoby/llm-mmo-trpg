# 晶能義體人：辨識記號（樣張，等使用者看過再定）

美術 PM，2026-11-04。延後的美術項目第 2 項。

- 起因：3R-3c 驗收時記下的問題——戰場大小下，晶能義體人只有臉上一小段晶路（`pattern: circuit`），和人類幾乎分不出來。
- 樣張：`cyborg.png`；畫法在 `sample/cyborg.html`，用遊戲的 C 畫風紙娃娃。全部程式繪製。

## 三種記號

| 方案 | 內容 | 戰場大小 | 戴頭盔 | 背面 |
|---|---|---|---|---|
| A. 發光義眼 | 一隻眼換成金屬框的青光義眼，同側臉頰一片金屬片 | 正面、側面看得到一個亮點 | 看得到（義眼在臉上） | **看不到** |
| B. 耳側晶能耳機片 | 兩耳各一片金屬圓片，中間是青光；側面多一根小天線 | 正、背、側都看得到頭的兩側有亮點 | 露在頭盔外側 | 看得到 |
| **C. 義眼＋耳機片＋頸後接口（推薦）** | A 的義眼（不加臉頰金屬片）＋B 的耳機片＋頸後一塊有兩個青光點的接口 | 四個方向都有亮點，而且是三種東西一起，最好認 | 義眼、耳機片都看得到 | 耳機片＋頸後接口 |

**推薦 C**：
- 只有 C 在四個方向、戴頭盔時都認得出來；
- 混在人群裡那一列，C 最容易一眼找到（`cyborg.png` 最下面一列）。

顏色用晶能青 `#4ae0d0`，和種族技「過充」的光一樣；金屬用鐵灰 `#8d969f`。

## 移植需求（使用者定案後再排）

1. **畫法**：
   - 加在 client 的種族部件（`render/inkRace.ts`），條件是 `pattern: circuit`；
   - 現有的臉上晶路照畫，記號疊在上面。
2. **位置**（紙娃娃座標，腳底 0、往上 -y）：
   - 義眼：正面在 x 3.2、側面在 x 4.4，y −41；金屬框半徑 1.9，青光半徑 1.5；
   - 耳機片：正面、背面在 x ±9.4，側面在 x −2.6，y −41.5；半徑 2.3～2.6；側面多一根往後上方的天線；
   - 頸後接口：背面在 (0, −35)，4.4×3.4 的金屬塊，上面兩個青光點；側面在 (−6.6, −35.6) 一個小光點。
3. **頭盔、兜帽**：記號畫在頭盔上面（耳機片露在外側）。
4. **光**：小光暈，不閃動；「外光只代表頭目」只管全身外光，這種小光點不受限。
5. **工作量**：約 0.15 段。
