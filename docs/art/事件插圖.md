## 1. 畫法

- 和實地地圖**同一套畫法**：格子地面、C 畫風紙娃娃、地物。不另外畫一套插畫風格，所以從地圖碰到事件、跳出事件卡時，看起來是同一個世界。
- 每張是 7×3 格的小場景（364×156），四周有暗角，外框金邊，左上角一個事件類型的小牌（圖示＋兩三個字）。
- **背景依區域換**：雲嶺是草地、竹林、石板；荒原是焦土、熔岩、枯木。事件內容不變，敵人的材質跟著區域（霧狼、灰燼犬）。
- 不用亂數：每種事件的場景是固定的。同一種事件要有變化時，照 `動畫方案.md` 第 2.10 節的雜湊挑 2～3 種擺法（之後再做）。

## 2. 十種常見事件

| 事件 | 畫面 |
|---|---|
| 遭遇・伏擊 | 盜賊和野獸從竹林衝出來，頭上紅色「！」；主角在左邊 |
| 寶箱 | 草地上發光的寶箱，旁邊有山石、古松 |
| 古碑 | 石碑上的字發青光，四周有霧，主角走近 |
| 祭壇・機遇 | 石板上的祭壇（荒原換成角魔祭壇），兩座石燈籠，暖光 |
| 村民求助 | 翻倒的運輸車、散落的箱子，村民頭上黃色「！」 |
| 商隊 | 兩輛車、貨箱、營火，商人頭上金幣泡泡 |
| 陷阱 | 草叢裡露出一半的捕獸夾，一道反光 |
| 營火休息 | 夜色、營火光暈，兩個人圍著火 |

## 3. 移植需求（使用者定案後，排進 6C-7）

1. **畫法**：新增 `render/eventArt.ts`，用實地地圖的地面、物件畫法加紙娃娃，畫成離屏貼圖並快取。
2. **資料**：事件定義（`world/events/<區>.yaml`）加選填欄位 `art`（值是上表的場景 ID）。沒寫的事件依事件種類用預設場景；不認得的值退回「古碑」。
3. **工作量**：約 0.75 段。
