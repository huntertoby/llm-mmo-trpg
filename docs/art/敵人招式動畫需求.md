## 1. 動作類型的挑法（第 1、3 題）

盤點的修法是「依技能原語挑」，但有兩招靠原語挑不出來：`skill_battering_ram` 只有傷害和推，`skill_plunging_strike` 只有兩段傷害，都沒有 `dash`、`leap`。

依序判斷，先符合先用：

| 順序 | 條件 | 動作類型 | 例子 |
|---|---|---|---|
| 1 | 有 `summon` | 召喚 | 產下幼蜥 |
| 2 | 有 `teleport`、`shadowstep`、`swap` 類 | 位移 | 閃現 |
| 3 | 有 `dash`、`charge_through`、`leap` | 衝鋒 | 衝鋒撞擊 |
| 4 | 形狀是錐形 | 吐息 | 火牆、硫煙吐息 |
| 5 | 指定招（只影響畫面的小表） | 衝鋒 | 破城衝撞、俯衝斬 |
| 6 | 其他 | 照現行：自身或地面＝範圍，距離 2 以上＝遠程，相鄰＝普攻 | |

- 普攻一律是普攻片段。
- 第 4 條同時修好硫煙獸：`skill_sulfur_breath` 是錐形，貼身放時現在退回獠牙撞。
- 沒有吐息片段的身形照 `attackClipFor` 的退回順序，不用改。
- 第 5 條的小表放哪裡由開發 PM 定；不要讓 LLM 或技能資料多一個動畫欄位。

### 接上後的驗收

這些片段只在樣張上看過，沒有和實際的位移事件一起播過。請每項附一組實機連拍，實機到不了就用開發頁畫：

| 片段 | 要看什麼 |
|---|---|
| 山豹撲擊 | 片段本身的前衝和引擎的 `dash` 位移不能疊加，也不能先退回原地 |
| 甲蟲衝撞 | 不移動的招，身體前衝後要回原位；被撞者的推開時間對齊 |
| 鷹俯衝 | 俯衝落點對準目標，結束後回到飛行高度 |
| 噴岩龜噴吐、硫煙獸吐息 | 噴口朝向目標，朝東、朝西都對 |
| 蜥蜴產卵 | 幼蜥在片段產出的時間點出現，不提早 |
| 魅閃現 | 淡出、淡入和傳送事件對齊，不會在原地多閃一次 |

減少動態的版本照 QK-4 規則。

## 2. 第二種近戰片段（第 2 題）

用特效和顏色區分不夠。特效只換顏色，身體動作還是同一個，等於放寬使用者 11-04 的要求；要放寬得回使用者。

| 身形 | 敵人 | 現有 | 新增的第二種近戰（方向，樣張時可調） |
|---|---|---|---|
| hound | 霧狼、灰燼犬 | 雙咬 | 撲上去咬住、甩頭 |
| feline | 山豹 | 爪擊、撲擊 | 反手上撩爪 |
| bear | 石背熊、焦石背 | 熊掌拍、雙掌震地 | 人立起來、單掌由上往下重拍 |
| boar | 硫煙獸 | 獠牙撞、吐息 | 低頭、獠牙往上挑 |
| lizard | 三種蜥蜴、母獸 | 咬、口吐彈、產卵 | 轉身甩尾 |

**挑法**：普攻固定第一種；單體近戰技能播第二種。同一隻有兩招單體近戰技能時共用第二種，靠元素特效區分，屬於「內容極度相近」。挑法不耗引擎亂數，只影響畫面。

**流程**：照 `美術PM交接.md` 4.1，畫圖 agent 畫樣張、獨立審查、專案 PM 看過、給使用者，通過後交移植規格。等 #149 的招單定案、開發 PM 有 agent 名額再開畫。

**不擋 CB-2**：第二種片段上線前，這 5 款的招暫時共用同一片段。

## 3. 「黏液」（第 4 題）

沿用 ooze 的吐油團片段，只換飛行物和命中的顏色。兩招都是「吐一團東西」，內容極度相近。顏色等玩法 PM 定案新招後決定。

## 4. 異形出招後的原語（第 5 題）

接受。原語片段的身體動作多半是手部動作（推掌、指向、下壓），異形沒有對應的手。衝鋒、召喚、位移由第 1 節的動作類型負責，其餘靠特效。這只談施放者；目標被推、被擊倒的反應不在這題範圍。
