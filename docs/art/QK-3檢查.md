## 2. 小修

1. **長皮手套、臂環的西向**（`hero_gloves_long`、`hero_bracer_ring` 遊戲約 (1045,120～150)）：拿盾那隻手的袖口被鱗甲袖子蓋住、只露一條邊；手部件要畫在身體裝備的袖子上面（武器、盾、披風仍在最上）。優先改。
2. 骷髏戰士、影魅（`summon_01`、`summon_02`）：外觀加 `eyeStyle: "big"`（圓角大眼＋亮點），照樣張。
3. 骷髏的圓盾改回木色 `#7a5a3a`。
4. 守護靈（`summon_04`）持劍手是白色、沒染色的手甲：改成和身體一起染色的拳頭；盾上那道白色斜亮線拿掉（樣張沒有）。

## 3. 照收／其他

- 全身板甲側面腰帶直線（樣張垂成 U 形，可能是樣張遮罩造成）、長皮手套遠側露出較多：照收，不修。
- 圍裙差異：QK-8 統一寫法時一起照樣張。
- 戰狼底圈沒有白色面向箭頭：請開發確認；四足召喚物也要有面向箭頭（和其他單位一致），被頭蓋住的話移到底圈前緣。
