## 1. 要取代什麼

等 LLM 的時候，現在只有按鈕變灰（`busy`），或寫「載入中……」。換成下面的「墨痕等待」：

| 場合 | 位置 | 大小 |
|---|---|---|
| 事件卡：送出情境判定，等說書人回應 | 說書人對話框，右邊墨痕 | 中（80px） |
| 「多講一點」 | 上方字幕列 | 小（24px） |
| NPC 自由聊天 | 對話泡泡裡先出現 NPC 的等待話 | 小（24px） |
| LLM 生成技能（獎勵、閃現選項、工坊） | 技能卡的位置 | 大（120px） |
| 其他需要等伺服器、但不是 LLM 的（開地圖、存檔） | 照舊，不用墨痕 | — |

## 2. 樣子

**墨水暈開**：一個週期 1.8 秒。
1. 墨滴落下（0～0.18）；
2. 落在米色紙上暈開（0.18～0.7）：中心濃墨，外圈三層淡墨羽化，邊緣有幾條細細的滲痕；
3. 淡去（0.7～1），再落下一滴。

- 墨痕形狀由「請求編號＋第幾滴」的雜湊決定（確定性，不用 `Math.random`），每一滴長得不一樣。
- 紙是圓形、邊緣漸淡，不是硬邊的盤子。

**說書人的一句話**：等待時顯示一句**固定在前端的短句**，不是 LLM 寫的，也不另外呼叫 LLM。
- 事件判定：「說書人沉吟片刻，在紙上落下一點墨……」「說書人翻到下一頁。」
- 技能生成：「這一招還在紙上慢慢成形。」「說書人蘸了蘸墨，替你把招式描出來。」
- NPC 聊天：「〇〇想了想……」（〇〇＝NPC 名字）
- 等超過 8 秒：「這段故事長了些，再等一下。」
- 每個場合 4～6 句，照請求編號挑一句；同一次等待中每 4 秒換下一句（淡入淡出）。

**毛筆一劃**：中尺寸時，句子下方有一道金色毛筆劃從左寫到右再淡掉（週期 2.4 秒），表示「還在進行」。不是進度條，不代表百分比。

**完成時**：
- 墨痕收成一點，接著出現結果（說書人的回應、技能卡）；
- 技能生成時，墨痕往外擴成技能卡的外框，再淡入卡面（0.3 秒）。

**失敗時**：墨痕變灰、停住，句子換成「墨乾了，再試一次？」，旁邊是重試鈕。
- 照現有的錯誤處理；
- 模型關閉時，照 6C-7 的「模型關閉」圖示。

## 3. 減少動態

系統「減少動態」時：
- 墨痕不落、不暈，只畫一個靜態墨點；
- 毛筆劃不動；
- 句子照常換，但不淡入淡出，直接換；
- 完成時直接出結果。

## 4. 移植需求（使用者看過樣張後交開發）

1. **元件**：新增 `ui/InkWait.tsx`，畫法放 `render/inkWait.ts`，照 `sample/ink-wait.html` 的 `inkBloom`、`brushStroke`。
   - 用 canvas 和 requestAnimationFrame；
   - 元件卸載就停；
   - 三種大小：24、80、120。
2. **短句**：放 `content/` 的 `narration_wait.yaml`。
   - 內容即資料：場合 → 句子清單，NPC 句子有 `{name}`；
   - 前端照請求編號挑句。
3. **接上**：上面第 1 節的四個場合，在現在 `busy` 為真、等 LLM 回應的地方換成 `InkWait`。按鈕照舊不能點。
4. **不新增伺服器欄位**；請求編號用前端自己的遞增序號。
5. **測試**：
   - 畫法確定性（同編號同時間畫出來一樣）；
   - 減少動態時沒有動畫；
   - 卸載後不再要下一格；
   - 8 秒換「長了些」句；
   - 失敗時顯示重試。
6. **工作量**：約 0.5 段。

- [ ] 四個場合都換成墨痕等待，不再出現「載入中……」。
- [ ] 墨痕落下、暈開、淡去的節奏和樣張一致；每一滴形狀不同。
- [ ] 句子每 4 秒換一句，超過 8 秒換「長了些」。
- [ ] 完成時墨痕收起、技能卡從墨痕外框淡入；失敗時墨乾了加重試。
- [ ] 減少動態時是靜態墨點。
