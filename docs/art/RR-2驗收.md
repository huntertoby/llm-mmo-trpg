## 3. 可修

1. **「▼ 比原本弱」的 ▼ 改用和前 → 後列同一個 CSS 三角**（`rr2r-01-weak-tag-x3.png` 第一張，同一張卡上下對照）：現在小標的 ▼ 9×7、列裡的 ▼ 11×10，同一張卡兩種三角，1 倍下小標那顆像一個點。照 `靈感閃現選擇-移植需求.md` 第 3 節：`border-left/right: 6.5px solid transparent; border-top: 11px solid currentColor`（小標是 12px 字，可以等比縮到 5.5／9.5，但要用同一個畫法）。字重：小標可以維持粗體（它是標籤，要和類別膠囊一樣醒目），只換三角即可。
2. **選中的卡沒有任何一列時是空的**（`rr2r-01-weak-tag-x3.png` 第二張、`c03-*` 第 2 張）：「多等幾回合再用，換這招變強」整招等於現在的卡，前 → 後一列都沒有，選中後只剩一條標題，看起來像收合或資料沒載到。建議沒有任何變化時在卡裡放一行 L3（`#a39d8c`、11.5px）：「和現在一樣」（字交玩法 PM），位置照第一列前 → 後的左緣。這種情況只會在重閃出現（基準是現在的卡），新的閃現不會碰到。

## 4. 接受

- 「可能比現在弱」整句只在 (i) 說明卡（見第 1 節）。
- 選類別面板 ▼ 那行與琥珀說明都寫了「一定要選」（重複）：字，交玩法 PM。
- 卡與卡之間「前」那一欄沒有對齊（每張卡的欄寬跟著自己最長的欄位名）：FL-1b 原本就這樣，不是 RR-2 改的。
- 一般重閃的大變化格轉型保底可能比現在弱、卻沒有小標（RR-2c 待決 c1，玩法 PM 已決定改字、排進下一段）：字與規則，不在美術範圍。
