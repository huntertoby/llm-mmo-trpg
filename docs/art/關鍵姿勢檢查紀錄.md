我看到（3 倍）：
- **A 欄**：兩隻手臂從肩膀斜往外下方伸，和軀幹之間是一大塊背景色三角形，看起來像 A 字。
  - 法杖正面：杖頭光暈的外框和頭髮左上角的外框相接。
  - 劍盾背面：左拳在圓盾的正中央，深色握把從拳頭兩側穿出；盾在身體左外側，右緣碰到左肩甲下方的軀幹邊。
- **B 欄**：手臂往外的角度少了一些，拳頭在腰帶外側一點，腋下到拳頭之間是一條細長的背景色三角形，比 A 窄很多。

  - 杖＋書背面：手臂和長袍之間只在手肘以下露出一條細縫；書的右緣疊到長袍左緣。
  - 劍盾正面：盾的左緣碰到右邊的肩甲和軀幹邊。
  - 劍盾背面：拳頭仍在盾心，盾的右緣疊到軀幹左邊一點。

  - 法杖正面：光暈的外圈蓋住頭髮左上角，比 B 多。
  - 杖＋書背面：手臂疊在長袍上，看不到空隙；書有三分之一左右疊在長袍左緣上。
  - 劍盾正面：盾蓋到軀幹右緣。
  - 劍盾背面：拳頭在盾心，盾蓋住軀幹左邊一段；右手的劍貼著右腰。

## 七、要美術 PM 決定

1. **B 欄取 A 和 C 的中間，不是角度減半。**
   - 角度減半（0.35）時，手臂和軀幹之間只剩拳頭旁 5px 背景色，和 C（3px）幾乎看不出差別，三欄會變成兩種。
   - 所以 B 取 A 和 C 的中間：從現在往小縫收回一半，角度 0.52。
   - 如果要照字面「角度減半」，把 `ARM_SPREAD_SET.B` 改成 0.35 重拍比較圖即可。
2. **C 欄的小縫只出現在拳頭和腰之間。**
   - 肩膀起點（x ±8.5）在軀幹邊緣（±7.5）裡面，手臂只靠轉角度往外，所以空隙是從腋下往下慢慢變寬的三角形。
   - 要讓 2～4px 的空隙從上臂一路到拳頭，得把肩膀往外移，不能只改角度。B 批要不要這樣做，請決定。
3. **B 批套用 B 或 C 時，下面這些要一起處理（這批照規定沒動）：**
   - 法杖正面的光暈會疊到頭髮；
   - 杖＋書背面的手臂會和長袍疊在一起、空隙很小或沒有，書也會疊到長袍；
   - 劍盾正面、背面的盾會碰到或蓋到身體。
4. **拄劍正面放在比較圖裡，三欄都一樣。** 拄劍是兩手在胸前握柄，不受張開角度影響。
5. **其他文件裡還有這個詞。** `武器待機移植需求.md`、`Q版回歸評估.md` 和舊版修正清單裡還有第二種雙手劍姿勢的字樣，這批沒碰（不在 A 批要改的清單裡）。其中 `武器待機移植需求.md` 寫的是「使用者定案：不做」，意思和這批一致。
