## 2. 開發 PM 問的 4 題：決定

1. **6.5.1 加例外（雇用面板技能圖示的說明牌開在下方）**：同意。說明牌只有一行，蓋到下一位頭像上緣不影響辨認；往上開一定蓋名字更糟。例外清單照 `floatCard.ts` 的註解。
2. **出口格的石板縫**：不改。那是地磚本身的縫，沒滑過時也在；綠框填色維持 12%。
3. **遇敵卡頭像原型數值**（36px、人形上半身 62%、異形整隻）：照收。劍陣弟子的髮髻頂端稍微被框切到，可以接受；QK 換 Q 版頭像時再一起看裁法。
4. **Boss 標籤**：介面文字一律繁體中文，改寫「**頭目**」（和 `敵人外觀.md` 的用詞一致），不用英文「Boss」。下一段順手改，不用再拍圖。
