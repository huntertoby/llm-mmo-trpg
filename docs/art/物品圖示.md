# 背包與商店的物品圖示（樣張與移植需求草案）

美術 PM，2026-11-04。給背包、商店、戰後結算、去文字化的背包格用。

- 樣張：`shots/misc/items.png`；畫法在 `sample/items.html`、`sample/itemIcons.js`。全部程式繪製。
- **等使用者看過再定**；細節照美術 PM 的推薦先做，列在交接文件第 6 節的代決（#52～53）。

## 1. 範圍

現有的 `gearIcon`、`weaponIcon` 已經涵蓋武器、防具、飾品。這次補上沒涵蓋的類別，ID 照 `content/world/items.yaml`：

| 類別 | 項目 |
|---|---|
| 藥水與草藥（4） | 小回復藥、中回復藥、回魔藥、解毒草 |
| 投擲瓶（5） | 水瓶、油瓶、霧瓶、冰瓶、火瓶：細長瓶裝對應顏色的液體，右下角是元素標記 |
| 補給（1） | 鋪蓋捲、麵包、水壺 |
| 材料（19） | 粗料、精料、上料（同一個礦石，顏色依品質）；霧晶、雲頂霧晶、符紙灰、丹砂、狼牙、雷羽、餘燼羽、活血骨、青竹節、精華、熔岩核、焦鐵、寒燼、熔心晶、硫磺結晶、黑曜片 |
| 染料（6） | 靛青、朱砂、墨色、翠綠、赭黃、雪白：小罐裝顏料 |
| 貨幣（3） | 金幣、任務幣、源晶碎片 |
| 任務物品（4） | 信件、鑰匙、地圖殘頁、護符（任務物品的通用圖示，個別任務可以指定其中一種） |

## 2. 畫法

- C 手繪墨線（`inkStyle` 的 `ink`、`stroke`），每個圖示畫在 48×48 的框裡。
- **底色依類別**，**外框**：
  - 材料依品質：灰＝普通、藍＝精良、紫＝稀有；
  - 其他類別用類別色：藥水綠、投擲瓶藍、補給金、染料紫、貨幣金、任務橘。
- 稀有的材料加一點光暈；不閃動。
- 背包格右下角寫數量；48 與 28 兩種大小都分得開（樣張最下面）。

## 3. 移植需求（使用者定案後，排進 6A 或 6C-7）

1. **畫法**：新增 `render/itemIcon.ts`，照 `itemIcons.js` 移植；以物品 ID 對到畫法，做成離屏貼圖並快取。
2. **資料**：`items.yaml` 加選填欄位 `icon`（指定畫法 ID）。沒寫的照 `kind` 用該類的預設圖示；不認得的退回一個問號袋子。材料品質讀現有的 `tier`（或稀有度）。
3. **工作量**：約 0.75 段。
