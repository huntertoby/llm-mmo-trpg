## 1. 範圍

### 1.1 要做的
戰場上，單位被**大型前排**擋住一定比例以上時，在被擋住的那一段畫一條陣營色輪廓，受擊時輪廓跟著閃白。

### 1.2 不動的
- 單位、環、HUD、特效的畫法與排序。
- 6F-22 的高台虛線剪影仍然保留，規則見 3.5。
- 被擋者的 HP 條、狀態列，以及輪到行動的黃虛線圈被頭目蓋住的問題：不在這次範圍，使用者還沒表態。

## 2. 定案數字

| 項目 | 定案 |
|---|---|
| 誰算前排 | **大型前排**：身體貼圖在模型像素數像素（alpha ≥ 0.5），面積 ≥ **4000 模型 px²**。目前只有兩位頭目算（灰燼之心 8928、碎晶之主 8220；一般單位 506～1963）。**用面積判斷**，不用「頭目或 huge」的替代判斷，兩種不要混用 |
| 門檻 | 大型前排遮住 ≥ **55%** 開始畫，降到 < **45%** 才拿掉（遲滯） |
| 比例怎麼算 | 被擋者的身體遮罩 M，大型前排身體遮罩的聯集 O。比例＝\|M ∩ O\| ÷ \|M\|，alpha ≥ 0.5 才算。**一律在模型像素算**（1 格 48，原點對齊整數），不隨地圖縮放 |
| 線 | 色線寬 **1.5 螢幕 CSS px**（模型 px＝1.5 ÷ 地圖縮放），從輪廓往內一圈；兩側各襯 **0.75 px** 黑邊 `#16121a` |
| 範圍 | **只畫被擋住的那一段**（∩ O）；露出來的部分不畫 |
| 透明度 | 色線與襯邊先疊成一層不透明的，**整層**再乘 **0.8** |
| 顏色 | `artPalette.ts` 的 `RING[team].stroke`：友 `#a9ccff`、敵 `#ffb3a8`、第三方 `#dcb3ff`；召喚物用 `RING.summon.stroke`（`#8ff0e2`）。不新增色票 |
| 受擊閃白 | k＝當下白閃 ÷ 正在播的片段峰值。色線＝mix(陣營色, 白, k)，整層透明度＝0.8 + 0.2k。峰值：人形受擊 0.85、人形重擊 0.95、異形與頭目受擊 0.9、異形重擊 1.0（照實際片段量化後的值；OCL-1c 依美術驗收 `OCL-1驗收.md` 第 3 節，原寫 0.99）；召喚物照它的身體歸類。出處見紀錄 2.2 表 |
| 圖層 | 用現成的 `silhouettes` 容器：在排與 HUD 之上，在 `hudTop`、`hover`、特效之下 |

## 3. 一定要做對的重點

1. **什麼時候算**：只在擺位改變時算，例如 `draw(model)`、移動結束、換姿勢、轉向，不要每格都算。走路、擊退、出招片段播放中沿用片段開始前的結果，片段結束再算一次。待機用第 0 格的姿勢算。
2. **只比對可能重疊的**：前排要在被擋者南邊 0～3 排，而且外接矩形相交。只算身體，不算環、影子、HUD、特效。alpha 遮罩與面積都照貼圖的鍵快取，同一個鍵只取一次 `getImageData`。
3. **裁切**：前排遮罩只留「照畫的順序疊起來、最上面是大型前排」的像素。畫在大型前排之後的小兵要從遮罩挖掉，外框才不會落在小兵身上（`shots/occlude/9-collide.jpg` 第 4 列）。
4. **閃白做法**：色線用白色畫進貼圖，襯邊用黑色畫；`Sprite.tint`＝mix(陣營色, 白, k)，`alpha`＝0.8 + 0.2k。tint 是相乘，所以黑色襯邊不受影響，不必另做貼圖。k 不可寫死人形的 0.85。
5. **6F-22 舊剪影**：
   - 這次就做：同一個單位這一格有新外框時，不畫舊剪影。
   - 沒有新外框時（前排不是大型、沒達門檻、只被地形擋），舊剪影照畫，**不能先拿掉**。
   - 把崖面、屋頂算進遮擋，再拿掉舊剪影：這是之後另一段的事，不在這次。
6. **不畫外框的**：倒下的人、隱匿中（`concealed`）或資訊被隱藏的敵人。照現有的可見規則，**在算比例之前**先過濾，否則會洩漏位置。
7. **被擋的一方不分種類**：玩家、NPC、異形、頭目、召喚物都走同一條路。
8. 效能預估在紀錄第 6 節第 9 點：擺位改變時 < 1 ms，每格只更新 tint／alpha。
