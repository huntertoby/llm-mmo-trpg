## 0. 結論

1. **遊戲裡面的畫面大致協調**，三種風格放在一起不打架：
   - 人物是 C 墨線繪本；
   - 區域圖、大世界圖是 B 彩繪；
   - 實地地圖是格子地磚；
   - HUD 是金框。
2. **最不協調的是「入口畫面」**：首頁、建角、角色列表、開新一輪、一輪的路線圖。
   - 都還是開發用的灰色表單：沒有框、沒有插圖、建角看不到角色長相；
   - 和遊戲裡面像兩個不同的產品。玩家第一眼就看到這裡，優先度最高。
3. **其次是「同一種東西有兩三套樣子」**：
   - HUD 底色有炭黑和深藍兩套；
   - 主角卡在探索和戰鬥長得不一樣；
   - 彈窗有三種外框；
   - 背包、技能面板是純文字清單，沒有用到已經做好的裝備圖示和技能卡。
4. **開發用的東西外露**：頂列的「大世界（測試）」、「說書人用本機模型」勾選框、戰鬥結算的 `uv run trpg battle replay` 指令。
5. **版面遮蓋**：背包、技能、NPC 面板和遇敵卡都蓋住左上的主角卡（血條）。

## 4. UI-E1 入口畫面換皮（使用者 11-04：「兩個都可以」，已交開發）

- 遊戲名稱未定：標題牌先留「（遊戲名稱）」的位置，名稱放內容或設定檔，之後只改一處。

樣張：`entry-screens.png`（`sample/entry-screens.html`）。

| 畫面 | 做法 |
|---|---|
| 首頁 | 浮島天空背景（大世界圖第 2 版的天空、光束、浮島、雲海；島慢慢漂浮，減少動態時不動）；中間標題牌（襯線字，遊戲名稱待定）；主按鈕「繼續」寫最近的角色、等級、所在地；下面「建立新角色」「roguelite 一輪」「設定」；登入與開發模式放最下面一行小字；地圖下拉、季末重置只在開發模式 |
| 建立角色 | 左：大紙娃娃預覽（照選的種族、出身預設外觀、武器即時更新，◀▶ 轉身）；右：分步驟 1 名字 → 2 種族（種族臉部小圖示，用紙娃娃頭部縮圖；選了之後下面一行寫種族技和環境被動）→ 3 出身（五區紋章與區域色）→ 4 武器（武器小圖示 `weaponIcon`，同名武器不重複列）→ 5 兩個關鍵字 → 起始技能卡（現有技能卡）；按鈕「建立並在主城醒來」（#125） |
| 角色列表、開新一輪、一輪路線圖 | 同一套背景、框、按鈕；角色列表每列加頭像；路線圖的 6 場用節點加連線，Boss 用頭目紋章 |

- 只換外觀，不改建角規則和資料；工作量約 **1 段**。
- 種族臉部圖示和武器圖示都用現成的畫法（`inkDoll` 頭部、`weaponIcon`），不另畫。
- **檢查清單**：
  - [ ] 入口五個畫面都是深藍金框、浮島背景；
  - [ ] 建角換選項時預覽即時更新；
  - [ ] 沒有開發用的東西外露（開發模式除外）；
  - [ ] 武器清單不重複。
