## 2. 兩種風格

| | A 古地圖卷軸 | B 俯視彩繪 |
|---|---|---|
| 底 | 米黃宣紙、邊緣燒黃，上下兩根木軸 | 草綠地面，木框加金線 |
| 山 | 墨線山形加青綠暈染、皴筆 | 明暗兩面的立體山，北邊雪頂 |
| 地景 | 竹林、梯田（一圈圈的田埂）、霧河、冬湖、雲海峽谷和吊橋都用墨線畫；小字標「霧河」「雲海」「梯田」「竹林」 | 同樣的地景上色：梯田帶水光、河是藍色加霧、峽谷裡是雲海、冬湖結冰 |
| 霧 | 宣紙色的霧，上面畫祥雲捲紋 | 白色雲團，北邊的雪峰尖露出雲上 |
| 路 | 紅褐色虛線（古地圖的路線畫法） | 去過的是土黃色的路，沒去過的是白色虛線 |
| 字 | 標楷體墨字；等級用紅色小印章 | 白底圓角小牌；等級用深色小牌 |
| 適合 | 東方仙俠味重，和雲嶺主題最貼 | 好讀、色彩跟戰場地磚接近 |

**美術 PM 推薦：A 卷軸風**。雲嶺是山中修士的主題，卷軸最有味道，霧畫成祥雲也最能讓人一眼看出「這裡還沒去過」。各區可以換紙色和墨色（荒原用焦褐紙、朱砂線）。B 比較好讀，如果使用者覺得 A 的字在竹林上不夠清楚，就選 B。

## 3. 疊在插畫上的東西（兩種風格共用）

| 項目 | 畫法 |
|---|---|
| 去過 | 彩色地點圖示（依種類：城鎮、營地、村落、祭壇、遺跡、精英、異象、頭目、渡口）＋名字＋建議等級 |
| 清空 | 名字右邊一個綠勾 |
| 相鄰但沒去過 | 灰色圖示、「？？？」、建議等級；周圍是薄霧；路是虛線 |
| 更遠 | **整片被霧蓋住**，看不到地點也看不到路；隱藏地點發現前完全不畫 |
| 傳送石 | 地點右邊的藍色晶石（發光）；還沒解鎖＝灰色加小鎖 |
| 任務 | 地點右上方的金色「！」泡泡 |
| 自己 | 地點腳下的藍圈，左上方一根藍色定位釘 |
| 朋友的足跡 | 沿著路的白色腳印，越新越清楚 |
| 圖例 | 右下角 |
| 標題 | 左上角「雲嶺」＋建議等級範圍；右上角指北針 |

- 霧的做法：先把整張霧畫好，再在去過的地點（半徑約 190px）和去過的地點之間的路上挖開；相鄰地點只挖一半，留薄霧。
