## 2. 區域圖的畫法

畫面分三層，由下往上：

1. **地景**（每區一張，程式畫，同一區每次都一樣）：
   - 雲嶺：草地、霧河、冬湖、梯田、竹林、松林、北方雪山、雲海峽谷和吊橋、藥圃、源晶裂痕、斷崖、鎮旁小屋，以及地名小字（霧河、雲海、梯田、竹林）。
   - 荒原：焦土（發光裂縫）、灰河、赤沙、灰泥沼、焦油坑、冷卻井（4 口）、熔岩河和石橋、枯木林、北方岩山、東北火山、廢墟要塞、飄散的火星，以及地名小字（赤沙、灰河、焦土、熔岩河）。
   - 座標一律用 `pos`（0～100）換算，換算法照 `P()`：左右各留 80px、上下各留 70px，畫布 1280×860。
2. **迷霧**：先把整張霧畫好，再挖洞。
   - 雲嶺的霧是白色雲團；荒原的是煙灰色（`fog.base`、`fog.puff`、`fog.shade` 照各區樣張）。
   - 去過（`fog: visited`）：挖開半徑約 190px；兩個去過的地點之間的路上也挖開。
   - 剪影（`silhouette`）：挖一半（約 105px，透明度 0.72），留薄霧。
   - 霧（`fog`）：不挖。
   - 霧畫完後疊上「露出霧上的東西」，只有地景、不洩漏地點：雲嶺是北方雪峰尖，荒原是火山口和噴煙（`afterFog`）。
3. **路與標記**：

| 項目 | 資料 | 畫法 |
|---|---|---|
| 路 | 連線兩端都是去過 | 土黃色的路（外圈深色） |
| 路 | 一端去過、一端剪影 | 白色虛線 |
| 路 | 有一端在霧裡 | 不畫 |
| 去過的地點 | `fog == visited` | 彩色地點圖示（依 `kind`）＋白底名字牌＋深色等級牌（`level_zh`） |
| 清空 | `cleared` | 名字牌右邊綠勾 |
| 剪影 | `silhouette` | 灰色圖示、灰底「？？？」、等級牌；渡口類（gate）不寫等級 |
| 霧裡的地點、未發現的隱藏地點 | — | 不畫 |
| 傳送石 | `stones` | 地點右邊的藍色晶石（發光）；沒解鎖＝灰色加小鎖 |
| 任務 | `quest_marks` 有值 | 地點右上方金色「！」泡泡 |
| 自己 | `current` | 地點腳下藍色橢圓圈，左上方藍色定位釘 |
| 朋友的足跡 | `footprints` 有值 | 白色腳印加深色描邊，畫在通往這個地點的路的後段（約 40%），越接近地點越清楚。有好幾條看得到的路時，選連到的地點 ID 排序最前的那條 |
| 標題 | 區名＋`level_min`～`level_max` | 左上角深色牌 |
| 指北針、圖例 | — | 右上角、右下角 |

- 地點圖示：城鎮、營地、村落、祭壇、遺跡、精英巢穴、異象、頭目、渡口，照 `regionArt.js` 的 `icon()`。秘境（`secret`）發現後用圓圈，之後再補專屬圖示。

## 3. 大世界圖（M）的畫法

- **背景**：藍色到暖色的天空、淡紫色碎界光帶、下方雲海、漂浮碎石。
- **浮島**：方位照 6D-5（西雲嶺、南荒原、北晶冠、東樞市、東南霜潮、主城在中央）。
  - 每座島是不規則的圓形頂面，加島緣厚度、下方倒錐岩塊。
  - 頂面是該區地景的縮小版：
    - 雲嶺：雪山、竹林、梯田、河；
    - 荒原：岩山、火山、熔岩河、枯木、赤沙；
    - 主城：石板十字路、白牆藍頂房屋，中央紫色晶塔。
- **三種狀態**：
  - 已開放（`open`）：彩色，名字牌、等級牌；
  - 未解鎖（`locked`）、之後的賽季（`later`）：灰色剪影、被雲纏住、中央一個鎖頭，名字牌下寫條件（`teleport_problem_zh` 或「之後的賽季」）。
- **浮橋**：主城到已開放的區畫木板橋；到未開放的區是白色虛線。
- **傳送**：可以傳送時，已開放區的名字下面有藍色「傳送到〇〇」鈕。自己所在的區不放鈕，改成藍底「你在〇〇」，島上有自己的藍圈和定位釘。
- 左下圖例：已開放、未開放、自己。
- **第 2 版（11-04，使用者看過說「還行」，採用）**：使用者看第 1 版說「有點廉價感」，重畫成現在的 `world-painted.png`：
  - 光從左上來：有太陽光暈和光束；島的頂面有內緣陰影，左亮右暗。
  - 島下是四色岩層加裂縫、垂根，島緣有厚度；雲嶺有瀑布、荒原有熔岩瀑布流進雲海；島下雲層有投影。
  - 雲有明暗，壓扁成層，不畫一顆顆圓泡泡。
  - 未開放的島：照該區地景畫出來，再去色、罩薄霧，加金框鎖頭徽章，不用灰色色塊加鎖頭小圖。
  - 字牌改成深藍底、金色雙框、襯線字，等級或條件寫在第二行；傳送鈕加小晶石。
  - 碎石改成長草的小浮島；未開放的航線是一串光點；外框四角加金飾。

## 4. 移植需求（給開發 PM 排段）

1. **檔案**：
   - `render/regionMapArt.ts`：共用層（迷霧、路、足跡、圖示、名字牌、等級牌、傳送石、任務、自己、標題、指北針、圖例），照 `regionArt.js` 的 `painted` 分支。
   - `render/regionArtCloud.ts`、`render/regionArtAshen.ts`：兩區地景。
   - `render/worldMapArt.ts`：大世界圖，照 `worldPaintedArt.js`。
   - 用前端現有的確定性亂數（`artRandom.ts`），種子固定，同一區每次畫出來都一樣。
2. **接到現有面板**：`RegionMap.tsx`、`AtlasMap.tsx` 的底圖改成一張 canvas。
   - 地景先畫到離屏 canvas、照區域快取；迷霧和標記在狀態變時重畫。
   - 現有的 DOM 節點留下，當透明的點擊、滑過區（地點說明卡、點傳送石傳送、大世界點島進區域圖、傳送鈕），位置照同一套 `P()` 換算。
   - `art_url` 不用；6C-6 的灰點、雲團、連線樣式拿掉。
3. **資料**：全部用現有欄位，**不新增伺服器欄位**。
   - 區域圖：`fog`、`cleared`、`level_zh`、`current`、`quest_marks`、`footprints`、`stones`；
   - 大世界圖：`atlas.regions` 的狀態與條件、`can_teleport`。
4. **其他區**：晶冠、樞市、霜潮之後開放時，各補一個地景檔（照 `ashenRegionArt.js` 的格式）。共用層不用改。
5. **畫面縮放**：畫布 1280×860，面板等比縮放；字和標記跟著縮放。面板寬小於 900px 時，字牌不再縮小，保持可讀。
6. **工作量**：約 1.5 段。
   - 共用層：0.5；
   - 兩區地景：0.5；
   - 大世界圖：0.5。
