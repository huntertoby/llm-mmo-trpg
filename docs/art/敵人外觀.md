## 1. 規則：外觀由哪些欄位決定

LLM 之後會產生新敵人與變體（9.6.6「LLM 產生變體」），所以外觀一律是**欄位組合**，不是一隻一張圖。

| 敵人類型 | 欄位 | 說明 |
|---|---|---|
| 人形（修士、盜賊、之後的各區居民） | 沿用紙娃娃 `doll`：膚色、髮型、9 格裝備的 kind／form／material／color、種族欄位 | **不加任何新畫法**，只用正式紙娃娃已認得的值組合。家族靠配色區分（見第 2 節） |
| 異形（野獸、熔岩獸、源晶造物、之後的海獸等） | `creature: {body, variant, material, element, size, tint}` | 新畫法，C 畫風，側面朝東，朝西鏡像；正面、背面沿用側面（和形態、野獸召喚物同規則） |
| 精英（任何類型） | `elite`＋`affixes`（精英詞綴 id 清單） | 金色外環＋環前方一顆金菱形＋每個詞綴一個小特效；大小 ×1.15 |
| 頭目（任何類型） | 沿用 `rarity`（epic 紫、legendary 金） | 身體外光（現有規則：**外光只代表頭目**）＋金色外環 |

### 1.1 異形的四個欄位

| 欄位 | 值 | 不認得時 |
|---|---|---|
| `body` 身形 | `hound` 犬狼、`boar` 野豬、`bear` 熊、`flyer` 飛禽（`variant`: `bird`／`bat`）、`crawler` 爬蟲（`variant`: `beetle`／`spider`）、`lizard` 蜥蜴、`serpent` 蛇、`shell` 龜殼、`ooze` 軟泥、`golem` 傀儡、`wisp` 晶靈（浮空）、`pylon` 晶塔（不動） | 畫 `ooze`（一團，什麼都說得通）；variant 不認得畫第一種 |
| `material` 材質 | `fur` 毛皮（背上短毛）、`magma` 熔岩（玄武岩黑 `#3b2c28`＋裂縫透元素光＋火星）、`crystal` 源晶（藍紫 `#9a86ff`＋切面＋背上晶刺） | `fur` |
| `element` 元素 | `palette.ts` 的元素 id | 沒有元素。毛皮：身體混 22% 元素色、眼睛用元素亮色；熔岩：裂縫與眼睛換元素色（預設火）；源晶：身體混 55% 元素色 |
| `size` 大小 | `small` 0.8、`medium` 1、`large` 1.25、`huge` 1.6（賽季頭目） | 1 |
| `tint` | 毛色覆寫（例：北坡狼王的銀白） | 用身形的預設毛色 |

同一個身形換材質就是不同家族的敵人（灰狼／熔岩犬／晶蝕狼），所以 12 種身形 × 3 種材質 × 元素就能長出第一季要的 30～40 種長相，之後加材質（例：霜潮的「珊瑚」、樞市的「黃銅」）就能整批擴充。

### 1.2 精英詞綴的特效（先做 6 種）

| id | 中文 | 特效 |
|---|---|---|
| `berserk` | 狂暴的 | 頭上三團紅色蒸氣＋紅色怒紋 |
| `regen` | 再生的 | 身邊四個綠色小十字 |
| `armored` | 堅甲的 | 背上兩片鐵甲片 |
| `swift` | 迅捷的 | 身後三道速度線 |
| `mirror` | 分身的 | 身後錯開一個 35% 半透明的分身（霧中劍客） |
| `elemental` | 元素的 | 腳邊三簇元素色小火苗（跟著單位的 `element`） |
| 其他 | — | 只畫精英金環，不出錯 |

特效只用到單位的頭位置、身高、身長，所以人形敵人用同一套（人形：頭 (2,-44)、身高 -55、半身長 10）。

## 3. 給開發 PM 的移植需求

建議分 3 小段，順序可換；**大世界的敵人資料還沒排段**，所以第 1 段可以只先接前端與測試範本。

### 第 1 段：異形敵人畫法（約 1 段）

1. 新檔 `client/src/render/inkCreature.ts`：移植 `sample/enemyArt.js` 的 `BODIES`、材質（`palette`、`cracks`、`facets`、`back`）、`resolve`。全部用 `inkStyle.ts` 的 `ink`／`stroke`（確定性抖動，禁止 `Math.random()`）。
2. 內容資料：單位範本可帶 `creature: {body, variant?, material?, element?, size?, tint?}`（純顯示資料，schema 驗證只檢查型別；值不認得時前端退回，**不要**在 schema 擋掉，讓 LLM 產生的值也能畫）。`UnitView` 帶出這個欄位。有 `creature` 時不畫紙娃娃。
3. 畫布：比照召喚物，但要放得下 `huge`（建議 96×96、腳底在下方 12px）；頭頂狀態列用 `top × size × 縮放` 避開。
4. 測試：每種 body × material 畫得出來；不認得的 body／material／element／size 不丟錯（照 `enemies.html` 頁首的全組合自測）。

### 第 2 段：精英與頭目記號（約 0.5 段）

1. `UnitView` 帶出 `elite`（`elite` 標籤）與 `affixes`（精英詞綴 id）。
2. 精英：陣營環外加金環（墨線 2.2px 底＋`#ffbf3a` 1.2px），環前方金菱形；大小 ×1.15。人形與異形都要。
3. 詞綴特效照第 1.2 節（`AFFIX`）；`mirror` 是在本體前先畫一個錯開 (-9,-1)、35% 透明的本體。
4. 頭目：異形也要吃 `rarity` 的外光（照 `renderFigureCanvas` 的做法），並加金環。

### 第 3 段：修士與盜賊的內容外觀（約 0.25 段，等玩法 PM 的名單）

1. 依第 2 節配色寫各範本的 `doll`。範例數值在 `sample/tools/enemy-dolls.html` 的 `MONKS`、`BANDITS`。
2. **敵人範本也要能帶種族外觀**（狐族修士）：目前 `fromDollLook` 只給主角接 `race.look`；敵人範本的 `doll` 允許 ears／horns／tail 等種族欄位，或範本帶 `race`。

### 檢查清單（驗收時看）

- [ ] 52px 格、1 倍：每隻敵人看得出身形；熔岩、源晶、毛皮三種一眼分得開
- [ ] 熔岩獸在暗色地形（灰燼焦土）上看得到：裂縫的亮橘要在
- [ ] 精英金環＋金菱形在 1 倍看得到；頭目外光只出現在頭目
- [ ] 朝西是鏡像；飛禽、晶靈、晶塔腳下有影子、浮空的離地
- [ ] 不認得的欄位值不丟錯（全組合自測）
- [ ] 補師（竹青長袍）在一群修士裡一眼找得到
