## 1. 規則：外觀由哪些欄位決定

LLM 之後會產生新敵人與變體（9.6.6），所以外觀一律是**欄位組合**，不是一隻一張圖。不認得的值一律退回，不出錯（`enemies.html` 頁首全組合自測 4269 種，0 錯誤）。

| 敵人類型 | 欄位 | 說明 |
|---|---|---|
| 人形（修士、盜賊、之後各區居民） | 紙娃娃 `doll`：膚色、髮型、裝備格的 kind／form／material／color、種族欄位 | 盜賊只換配色（現有部件）；修士要補 11 個小部件（第 3 節） |
| 異形（野獸、熔岩獸、源晶造物、傀儡、石靈） | `creature: {body, variant, material, element, size, tint, traits}` | 新畫法，C 畫風，側面朝東、朝西鏡像；正面、背面沿用側面（同形態、野獸召喚物） |
| 精英（任何類型） | `elite`＋`affixes`（精英詞綴 id） | 金色外環＋環前方金菱形＋每個詞綴一個小特效；大小 ×1.15 |
| 頭目（任何類型） | 沿用 `rarity`（epic 紫、legendary 金） | 身體外光（**外光只代表頭目**）＋金環 |

### 1.1 異形欄位

| 欄位 | 值 | 不認得時 |
|---|---|---|
| `body` 身形（14 種） | `hound` 犬狼、`boar` 野豬、`bear` 熊、`feline` 豹、`flyer`（`bird`／`bat`）、`crawler`（`beetle`／`spider`）、`lizard` 蜥蜴、`serpent` 蛇、`shell` 龜殼、`ooze` 軟泥、`golem` 傀儡、`wraith` 霧魅（浮空人形）、`wisp` 晶靈（浮空）、`pylon` 晶塔（不動） | `ooze` |
| `material` 材質（6 種） | `fur` 毛皮、`magma` 熔岩（玄武岩黑＋裂縫透光＋火星）、`crystal` 源晶（藍紫 `#9a86ff`＋切面＋晶刺）、`stone` 青石（`#7f8f94`＋發光刻符＋苔點）、`wood` 木（木紋）、`mist` 霧（62% 半透明） | `fur` |
| `element` | `palette.ts` 的元素 id | 沒有元素。毛皮混 22% 元素色；熔岩、青石的光換元素色；源晶混 40%；霧混 45% |
| `size` | `small` 0.8、`medium` 1、`large` 1.25、`huge` 1.6 | 1 |
| `tint` | 本色覆寫（霧狼的灰白） | 身形預設色 |
| `traits` 特徵 | `mist` 霧氣繞身、`stone_back` 背上石板、`volcano` 背上小火山、`smoke` 黃煙、`core` 胸口熔核、`scar` 疤、`brood` 背負卵囊、`lava_pool` 背負熔岩池、`spots` 斑紋、`sparks` 電光 | 跳過 |

### 1.2 精英詞綴特效

玩法 PM 寫「光效區分」；為了守住「外光只代表頭目」，**一律用小粒子、線條，不讓身體發光**。

| id | 中文 | 區域 | 特效 |
|---|---|---|---|
| `regen` | 再生的 | 雲嶺 | 身邊四個綠色小十字 |
| `mist_hidden` | 霧隱的 | 雲嶺 | 本體 75% 不透明＋身邊幾團白霧（邊緣模糊感） |
| `linked` | 連心的 | 雲嶺 | 頭上一顆青色連心結；**和相鄰同門之間畫青色虛線**（戰場繪製器畫，樣張只畫兩段示意） |
| `berserk` | 狂暴的 | 通用 | 頭上紅色蒸氣＋紅色怒紋 |
| `blazing` | 熾熱的 | 荒原 | 頭上三道橘色熱浪 |
| `hardshell` | 硬殼的 | 荒原 | 背上兩道白色反光 |
| `armored`、`swift`、`mirror`、`elemental` | 堅甲、迅捷、分身、元素的 | 備用 | 鐵甲片、速度線、半透明分身、腳邊元素火苗 |
| 其他 | — | — | 只畫精英金環 |

## 3. 給開發 PM 的移植需求

**大世界敵人資料還沒排段**，以下等使用者確認代決後再排。共 4 小段。

### 第 1 段：異形敵人畫法（約 1 段）

1. 新檔 `client/src/render/inkCreature.ts`：移植 `sample/enemyArt.js` 的 `BODIES`（14 種）、材質（`palette`、`cracks`、`facets`、`runes`、`grain`、`back`）、`TRAITS`、`resolve`。全部用 `inkStyle.ts` 的 `ink`／`stroke`（確定性抖動，禁止 `Math.random()`）。
2. 內容：單位範本可帶 `creature: {body, variant?, material?, element?, size?, tint?, traits?}`（純顯示資料；值不認得時前端退回，**schema 不要擋**，讓 LLM 產生的值也能畫）。`UnitView` 帶出這個欄位；有 `creature` 時不畫紙娃娃。
3. 畫布：比照召喚物，但要放得下 `huge`（建議 96×96、腳底在下方 12px）；頭頂狀態列用 `top × size × 縮放` 避開。
4. 測試：每種 body × material 畫得出來；不認得的值不丟錯（照 `enemies.html` 頁首全組合自測）。

### 第 2 段：精英與頭目記號（約 0.5 段）

1. `UnitView` 帶出 `elite`（`elite` 標籤）與 `affixes`（精英詞綴 id）。
2. 精英：陣營環外加金環（墨線 2.2px 底＋`#ffbf3a` 1.2px），環前方金菱形；大小 ×1.15。人形與異形都要。
3. 詞綴特效照 1.2 節（`AFFIX`）。`mirror` 在本體前先畫一個錯開 (-9,-1)、35% 透明的本體；`mist_hidden` 本體 75% 不透明；`linked` 的虛線由 `BattleRenderer` 畫在「有 linked 的單位」和相鄰同陣營單位之間。
4. 頭目：異形也吃 `rarity` 外光（照 `renderFigureCanvas` 做法），並加金環。

### 第 3 段：修士用的紙娃娃新部件（約 0.75 段）

照 `sample/storyDoll.js`（C 畫風唯一真相來源）移植到 `inkDoll.ts`／`inkGear.ts`／`inkArmor.ts`：

| 部件 | 欄位 | 樣張函式 |
|---|---|---|
| 髮髻 | `hair: "bun"`（`bunBand` 髮帶色，預設朱紅） | `hair()`、`drawBack` |
| 赤膊 | body `kind: "bare"`（膚色軀幹、胸線、腰帶色＝`color`）；手臂也用膚色 | `body()`、`armColor` |
| 念珠 | 新格 `neck` `kind: "beads"` | `beads()` |
| 圍裙 | robe 的 `apron` 顏色 | `body()` |
| 背物 | 新格 `back`：`gourd` 藥葫蘆、`puppet_box` 木偶箱 | `backItem()` |
| 腰掛黃符 | 新格 `waist` `kind: "talismans"` | `waist()` |
| 白紗面罩 | head `kind: "veil"`（70% 半透明兜帽＋面罩） | `headgear()` |
| 白羽披肩 | cloak `form: "feather"`（肩上一圈羽，畫在身體前面） | `mantle()` |
| 劍穗 | sword 的 `tassel` 顏色 | `weapon()` |
| 拂塵、符紙、傀儡線 | main_hand `whisk`、`talisman`、`puppet_cross` | `weapon()` |

`neck`、`back`、`waist` 是只給敵人範本用的外觀格（純顯示，不是裝備格）；不認得的 kind 不畫。

### 第 4 段：內容外觀資料（約 0.25 段，名單定案後）

1. 修士、盜賊三套、異形各範本寫 `doll`／`creature`，數值照第 2 節與兩個樣張頁。
2. 敵人範本也要能帶種族外觀（之後若有狐族敵人）：目前 `fromDollLook` 只給主角接 `race.look`。
3. **鍛疤（荒原精英，人形）外觀未定**：RG 單挑插圖先借荒原隊長剪影，**暫代，外觀定案後插圖剪影自動跟著換**（插圖剪影從單位紙娃娃自動產生；`RG樣張.md` 9.8 第 6 條）。
