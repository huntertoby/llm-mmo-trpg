# 組裝式裝備外觀評估（美術 PM，2026-10-22）

使用者原話：「材料要訂好名字 還是讓llm自由發揮 讓裝備鍛造出不同名稱 外型 達到遊戲宗旨多元性？但外觀好像不太能變或者請美術pm做大量風格類型？」。樣張 `docs/art/sample/gear.html` → `docs/art/gear-assembled.png`。

## 結論：可行，不用大量手繪

紙娃娃本來就是「種類＋材質＋元素＋稀有度」決定外觀（`appearance.ts`），只要再加兩個欄位、一套圖示產生器即可。

外觀 ＝ **造型（kind）× 形制（form）× 材質（material）× 關鍵字（keyword）× 稀有度（rarity）**

| 欄位 | 決定什麼 | 誰決定 |
|---|---|---|
| 造型 | 基本輪廓：劍、斧、杖、盾、戒指… | LLM 從清單選 |
| 形制 | 同造型的變體：直劍、彎刀、闊劍… | LLM 從清單選 |
| 材質 | 主色、暗色：鐵、鋼、金、木、皮、骨… | LLM 從清單選 |
| 關鍵字（#28） | 混入元素色＋小圖樣：點燃＝火苗、冰凍＝冰晶、帶電＝電紋、中毒＝毒泡；杖的寶珠、飾品的寶石換成元素色 | 由詞條自動帶出 |
| 稀有度 | 外框顏色；稀有起右上角標；史詩、傳說有光暈；傳說護手加寶石 | 引擎 |
| 名稱 | 只顯示，不影響外觀 | LLM 自由取 |

不認得的值一律回到預設（劍、鐵、無關鍵字），不會出錯，和技能圖示同一套原則。

## 每個部位幾種造型（第一季）

| 部位 | 造型 | 每種造型的形制 |
|---|---|---|
| 主手 | 劍、巨劍、匕首、斧、錘、矛、弓、杖（8） | 各 3 |
| 副手 | 圓盾、鳶盾、法書、法器珠（4） | 各 2 |
| 身體 | 布袍、皮甲、鎖甲、板甲、外套（5） | 各 2 |
| 飾品 ×2 | 戒指、墜飾、護符、手環（4） | 各 2（只有圖示，紙娃娃不畫） |

合計 21 種造型、約 50 個形制；乘上材質、關鍵字與稀有度，組合超過一萬種，看起來不會重複。

## 要做什麼

| 項目 | 內容 | 工作量 |
|---|---|---|
| 裝備圖示產生器 | 64px 圖示（背包、掉落、比較）；每個造型一個畫法函式，吃上面五個欄位；附測試（全組合畫得出來、不丟例外） | 1 段 |
| 紙娃娃擴充 | 補新造型與形制（錘、矛、法器珠、外套…）；武器、身體也吃關鍵字的小圖樣；稀有度光暈沿用 | 1 段 |
| 資料欄位 | 裝備加 `kind`、`form`、`material` 欄位（pydantic 驗證，清單放 `content/`）；LLM 生成時從清單選 | 開發 PM 併入裝備階段 |

合計約 **2 段**。

## 建議時程

- **圖示產生器跟著裝備系統進遊戲的那一段一起做**：掉落與背包畫面一定需要圖示。
- **紙娃娃擴充可以晚一段**：在那之前，新造型先用最接近的舊造型畫（例如錘先畫成斧）。
- 不用等大世界階段；世界觀定了之後，再依區域補材質與造型即可（見 `世界觀美術意見.md`）。

## 要使用者選的

| 選項 | 做法 | 美術看法 |
|---|---|---|
| **A 名稱自由、外觀欄位從清單選（建議）** | LLM 自由取名（例如「隕鐵霜脊劍」），外觀欄位只能從清單裡選 | 名稱最多元，外觀穩定、不會畫錯 |
| B 材料也固定命名 | 材料是固定名單（鐵、隕鐵、龍骨…），名稱裡一定帶材料名 | 名稱和外觀一對一、最好懂；但名稱比較單調 |

## 多風格：加一層「風格包」（2026-10-22 補充）

使用者原話：「因為世界觀可能很大變化所以量可能很大」。

外觀 ＝ 造型 × 形制 × 材質 × 關鍵字 × 稀有度 × **風格（style）**

- **風格包**是一個資料檔加一組畫法函式，內容有三樣：
  1. 這個風格的造型清單，例如東方有刀、槍、扇、拂塵，魔導科技有晶能槍、手甲。
  2. 每種造型的形制畫法。
  3. 材質色票與紋飾，例如東方是雲紋、流蘇，魔導是符文線、發光管。
- 裝備多一個 `style` 欄位，預設是 `common`。沒有某種造型時，就退回通用版。
- 引擎和規則完全不用動；LLM 一樣只從清單選。

### 跨風格共用（不會因世界觀改變而白做）

| 共用零件 | 說明 |
|---|---|
| 部位與造型「類別」 | 單手刃、雙手刃、長柄、遠程、法器、盾、軀幹、飾品；每個風格只換這些類別的外型 |
| 關鍵字配色與小圖樣 | 點燃、冰凍、帶電、中毒…，和技能圖示、特效共用一份色票，所有風格通用 |
| 稀有度外框、光暈、寶石 | 所有風格通用 |
| 圖示外框、尺寸、光源、外框線 | 所有風格通用 |
| 紙娃娃身體、骨架、圖層順序、朝向 | 所有風格通用；風格只換衣服和武器部件 |
| 畫法框架、驗證與預設、測試 | 所有風格通用 |

### 新增一種風格的工作量

| 內容 | 量 |
|---|---|
| 造型（重新設計輪廓的部分） | 約 8～12 種；其餘沿用通用版、只換紋飾 |
| 紋飾與材質色票 | 1 套 |
| 紙娃娃服裝（頭、身、披風） | 4～6 件 |
| 合計 | **約 0.5～1 段／風格** |

五個風格約 3～5 段，可以一區一區慢慢補。沒有做完的風格先用通用版加上該區的配色，畫面不會壞。

### 世界觀定案前可以先做、不會白做的

1. 通用版的「造型類別」與畫法框架，加上 `style` 欄位（預設 `common`），包含退回通用版的規則。
2. 關鍵字配色與小圖樣、稀有度外框與光暈。
3. 裝備圖示產生器與測試（全組合畫得出來）。
4. 通用版的 21 種造型，屬於奇幻基準，也是所有風格的退路。

先不做的是各風格專屬的造型、紋飾、服裝，等世界觀定案後再一區一區補。工作量估計：上面的「約 2 段」不變（就是這 1～4 項），風格包另計。
