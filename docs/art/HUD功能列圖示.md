## 2. 按鈕狀態

| 狀態 | 畫法 |
|---|---|
| 一般 | 深底、金邊 |
| 滑過 | 亮一點的邊，外加淡淡光暈 |
| 開著（面板打開） | 金底、亮金邊 |
| 停用 | 圖示變灰、半透明（例：還沒存影子） |
| 有未讀 | 右上角紅色數字；只需要提醒、不用數字時用紅點 |
| 開關開著 | 和「開著」一樣（R 潛行中） |

## 3. 滑過說明卡

- 標題列：圖示、名稱、快捷鍵小方塊；
- 第二行：目前狀態（黃字一行），例如「18 / 24 格・金幣 1,240」「潛行中・剩 6 步」；
- 第三行：說明一句；
- 最下面小字是觸控操作：長按 0.4 秒看說明，點一下就打開（6A-1 的定案）。
- 樣式沿用現有的 `Hint` 浮動卡（深底、金邊、圓角 10），寬約 250。

## 4. 移植需求（使用者定案後，併進 HUD 那段）

2. 說明卡用現有的 `Hint`，加上標題列、狀態行兩種樣式。
3. R 的功能照 #120 改成潛行；圖示和說明一起換。
