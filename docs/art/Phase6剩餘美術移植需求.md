## 1. 6B-ART1：城鎮建築與門、室內

### 1.1 建築外觀：`buildings`（只畫）

實地地圖檔加選填欄位：

```yaml
buildings:
  - {kind: tavern, at: [0, 2], size: [6, 4]}   # 左上角、寬高（格）
```

- **資料檢查**：範圍內每一格都是 `wall` 地形，或是 `doors` 的格子。不符合就載入失敗，避免外觀和規則對不上。
- **畫法**：
  - 照 `townTiles.js` 的 `stoneHall()` 與 `explore.js` 的屋舍：立面畫在範圍內，屋頂往上多蓋 1 格。
  - 和單位一樣照最下一列排前後：站在建築北邊的人會被屋頂遮住。頭頂圖示照舊用 DOM，不會被遮。
- **種類**：

| `kind` | 外觀 | 用在 |
|---|---|---|
| `tavern` | 白牆黛瓦，朱紅邊，窗戶有燈光，酒杯招牌 | 霧渡鎮酒館 |
| `smithy` | 白牆黛瓦，掛鐵砧招牌，煙囪冒煙 | 霧渡鎮鐵鋪 |
| `hall` | 白牆黛瓦，書卷招牌 | 霧渡鎮導師堂 |
| `house` | 白牆黛瓦，沒有招牌 | 渡婆的屋子等民宅 |
| `scrap_house` | 廢鐵屋（`ashenTiles.js`） | 餘燼集 |
| `forge_house` | 鍛爐屋，煙囪火光（`ashenTiles.js`） | 餘燼集鐵匠 |

- 主城用的種類在第 2 節。
- 不認得的 `kind` 退回 `house`。
- 招牌只畫圖示，不寫字。

### 1.2 門

- 門格（`doors`）畫在建築正面：木門加門框，門口有入口光圈（`town-tiles.png` 第 4 節）。
- **門打開 0.2 秒**（6A-4g 驗收時答應過的）：
  - 進門時門板往內轉開，和 `doorClips.ts` 的離開片段同時開始；
  - 出門時從開著關回去。
- 隱藏門（`hidden_until`）在揭露前照舊不畫。

### 1.3 室內（7 間：霧渡鎮 2、餘燼集 2、主城 3）

- **房間外框**：照 `townTiles.js` 的 `room()`。
  - 地圖外圈的牆畫成後牆（1.6 格高）和左右牆，室內地圖以外的地方全暗；
  - 下方出口有入口光圈。
- **後牆擺設**：只畫，不佔格，依室內圖裡有哪些設施決定：
  - 有 `tavern`：酒架、壁爐（火光）；
  - 有 `smithy`：兩座鍛爐、武器架；
  - 有 `mentor`：兩座書架、晶石像。
- **地板**：酒館、鐵匠鋪是木板；導師殿是石板，中央鋪紅地毯。餘燼集的室內用荒原配色：鐵灰牆、焦木地板。
- **家具外觀**：物件加選填欄位 `look`（只畫）。規則照原本的 `kind`，不變：

| `look` | 外觀 | 對應的 `kind` |
|---|---|---|
| `barrel` | 酒桶 | `crate` |
| `table` | 圓桌與板凳 | `crate` |
| `bar` | 長吧檯 | `low_wall` |
| `counter` | 櫃檯 | `low_wall` |
| `anvil` | 鐵砧 | `rubble` |
| `forge` | 鍛爐（火光） | `stone_pillar` |
| `candle` | 燭台 | `stone_pillar` |
| `crystal_statue` | 晶石像（發光） | `stone_pillar` |
| `shelf` | 貨架、書架 | `crate` |

- 沒寫 `look` 的照現有物件畫。
- 附魔台（`enchanter` 設施）的格子畫成發光符文繞圈的台子（`town-tiles.png` 第 6 節）。

### 1.4 內容

- 開發照第 1.1 節表格，給霧渡鎮、餘燼集的建築補 `buildings`，給 7 間室內的物件補 `look`。
- 只加這兩個欄位，不移動任何格子。
- 報告列出每張圖加了什麼。

### 1.5 檢查清單

- [ ] 霧渡鎮 4 棟、餘燼集的建築，外觀和樣張一致；招牌只有圖示。
- [ ] 建築範圍內都是牆或門（資料測試）；走路、視線、戰鬥規則和以前一樣（重播測試不變）。
- [ ] 屋頂遮住北邊的人，頭頂圖示不被遮。
- [ ] 進門有 0.2 秒開門，出門關門；隱藏門揭露前不出現。
- [ ] 7 間室內有後牆、擺設、地板、入口光圈；家具外觀照 `look`；附魔台發光。
- [ ] HUD 不擋住室內的 NPC 和櫃檯。
