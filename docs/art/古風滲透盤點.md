# 古風滲透盤點（美術層）

美術 PM，2026-11-04。文字層（技能名、NPC 名、說書人語氣）由玩法 PM 另外盤點，兩份合在一起交使用者。

**使用者原話**（專案 PM 轉）：「覺得整個遊戲的古風味太重 原本不是五界各有特色嗎 整體要多變一點啊 該不會其他也全是古風吧」

**依據**：設計 9.6.5（#42）的碎界五區各有風格：
- 晶冠：奇幻（米白石材、藍紫晶光、金飾）；
- 雲嶺：東方（青石、墨灰、竹青、點朱紅、薄霧）；
- 樞市：魔導科技（鐵板、黃銅、晶能青、符文橘）；
- 荒原：災變（焦土、炭黑、熔岩橘）；
- 霜潮：海境（沙色、淺海藍、浮冰白、珊瑚）。

**樣張**：`region-themes.png`（`sample/region-themes.html`），同一個 HUD 和事件卡在雲嶺、荒原、主城三種主題下的樣子。

## 0. 結論（先講）

1. **全遊戲不是全是古風**。
   - 已經是西式、中性或該區風格的：HUD、大世界圖、主城、荒原、敵人、技能特效。
   - 古風集中在三個地方：
     - **雲嶺本身**：這是對的；
     - **「說書人＝墨與宣紙」這一組全域點綴**；
     - **玩家最先看到的全是雲嶺**。
2. **最大的原因是開場**：
   - 第一季玩家一開始就在雲嶺、霧渡鎮（竹林、黛瓦、道長、斗笠）。前幾個小時看到的全是東方。
   - 荒原、主城要後面才看得到，所以「整個遊戲都是古風」的印象，大半來自這裡。
   - 這屬於玩法和內容的決定（出生地、新手區），列在第 6 節題目 5，交玩法 PM。
3. **真正滲到別區的全域元素不多**，下表標「滲透」的幾項都只換外觀，修起來不大（約 2 段）。
4. **C 墨線繪本不是古風**，是手繪冒險繪本（歐美繪本也是墨線加水彩），**建議保留**，見第 4 節。

## 4. C 墨線繪本算「繪本風」還是「古風」

**判斷：繪本風，不需要改。**

- C 的三個特徵（抖動墨線、水彩溢色、暗面排線）是歐美冒險繪本和插畫書的典型畫法，不是水墨畫。水墨的特徵（留白、墨色濃淡渲染、皴法、毛筆飛白）C 都沒有。
- 人物造型（三頭身、盔甲、皮甲、法師帽、角魔、精靈、矮人）都是西式奇幻。古風感來自**雲嶺的服裝和配件**（斗笠、髮髻、道袍），這些是區域層，本來就該只出現在雲嶺。
- 可以順手微調、但不必要的：墨線從深褐 `#2b1e16` 改成深藍灰，會更中性。
  - 影響範圍：`inkStyle.ts` 一個常數，加上所有快照測試更新；
  - 約 0.25 段；
  - **美術 PM 不推薦**：深褐是「手繪繪本」的溫度，換掉會變冷、變像向量圖。
