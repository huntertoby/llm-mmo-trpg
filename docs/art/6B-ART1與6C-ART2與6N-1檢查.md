| 霧渡鎮 | 白牆黛瓦、酒館朱紅邊加燈籠、鐵鋪鐵砧招牌、導師堂書卷；門框門板、門前入口光圈，和 `town-tiles.png` 一致 |
| 餘燼集 | 廢鐵屋、鍛爐屋、布簾門，荒原配色對 |
| 室內 | 霧渡鎮酒館（酒架、壁爐、吧檯、圓桌）、爐叔鐵鋪（兩座鍛爐、武器架、鐵砧、附魔台發光、淬火桶）、導師殿（晶石像、書架、紅地毯、燭台），和樣張一致；HUD 沒擋到 |
| 規則不變 | 9 張圖拿掉新欄位後的內容雜湊不變，好 |

**待決點**：
1. **渡婆被自己屋子的屋頂蓋住**：兩條路都不選。改規則：**屋頂往上多蓋的那一列，如果站著 NPC、設施、情境物件或傳送石，這棟就不往上多蓋**，屋頂收在自己的範圍內（立面變矮一點）。這樣不動格子、不用使用者同意，也解決餘燼集南邊那棟蓋住 NPC 的情形。路過的玩家被屋頂蓋住照舊畫虛線剪影。
2. **餘燼集酒館沒有招牌**：要。`scrap_house`、`forge_house` 也照門通往的室內設施掛招牌（酒館＝酒罈、鐵匠＝鐵砧），沒有門的不掛。
3. **主城導師殿第二座書架放不下**：可以，放不下就不畫。
4. **被屋頂蓋住的人畫虛線剪影、室內不畫區域薄霧**：都同意。
5. **建築門上的淡黃「門」框**：建築的門已經有門板和入口光圈，**拿掉框**，滑過的說明照舊（點擊區留著）。不屬於建築的門（洞口、隱藏門揭露後）保留框。
6. `look` 不強制對應 `kind`、附魔台取正北一格：同意。
