# C 手繪墨線繪本：移植需求與檢查清單（美術 PM，2026-10-29，交開發 PM）

> 使用者：「幫我問美術 紙娃娃能不能改畫風格 不是小改是大改 先給我幾張樣本」→ 選 C：「C畫風擴畫參考」→ 看過擴畫：「好就這樣」。
> 樣張：`story.png`（頁面 `sample/story.html`）；**畫法以 `sample/storyDoll.js` 為準**（實作時對照它的座標與圖層順序）。比較與評估見 `紙娃娃畫風大改.md`。

## 0. 原則：換畫法，不換規則

- 規則全部不動：`look` 欄位（含 3R 種族欄位）、裝備 `kind／material／color／element／rarity`、頭部裝備 `covers`、主手／副手左右（`handSides`）、真側面轉身（`SideHooks`）、形態規則（`形態外觀.md` 定稿方向）、材質色票、元素混色比例。**不認得的值一律退回預設，不得出錯**。
- 要換的只有「把欄位畫出來」的程式：`client/src/render/paperdoll*.ts`、`dollGear.ts`、形態（3J-5），以及第 6 節的召喚物（待定）。
- 只看規則的測試照舊要過；比對像素或顏色的測試照新畫法更新。
- **不受影響**：技能圖示、裝備圖示、狀態圖示、戰場效果、地形、物件、雲嶺換皮、字型。

## 1. 共用畫法層（新檔，例如 `render/inkStyle.ts`）

照 `storyDoll.js` 開頭的「畫法層」：

| 函式 | 做什麼 |
|---|---|
| `ink(ctx, key, pts, color, opt)` | ① 水彩填色：往右下偏 (0.45, 0.35)、透明度 0.94、邊緣再描一圈 35% 深色 ② 暗面斜排線（裁在形狀內，線寬 0.35、間距 1.3、42% 墨色）③ 墨線描兩次（線寬 w＝0.85 與 0.45w，抖動 0.5／0.85）。`opt`：`w`、`shade:false`（不排線）、`line:false`、`sharp`（尖角形狀不圓滑化）、`alpha` |
| `stroke(ctx, key, pts, w, color)` | 開放的抖動線（腰帶、縫線、嘴、骨架線） |
| `ellPts`、`wobble`、`smooth` | 橢圓取點、抖動、用中點二次曲線圓滑化 |

- **確定性**：抖動的亂數種子＝部件名稱字串的 FNV-1a 雜湊（`seedOf(key)`），再用 LCG。**不准用 `Math.random()`**，否則每次重畫線都會跳。同一部件在不同方向用不同 key（例如 `leg-1`、`leg-far`）。
- **暗面方向**：正面在右（光從左上）；側面、背面在左。
- 墨色 `#2b1e16`。**拿掉現在的黑色剪影外框**（8 方向偏移的深色剪影），墨線取代它。頭目外光照舊，是唯一的身體外光。
- **一定要快取成貼圖**：一隻小人要描很多次線又要裁切排線，每幀重畫太貴。現有 `renderFigureCanvas` 的快取鍵（spec＋facing＋downed）沿用。
- 地面影子改成一排短斜線（`shadow()`），不是深色橢圓。

## 2. 紙娃娃骨架與四方向

座標（腳底 (0,0)，往上是 −y）：頭 (0,−42) 半徑 9.2×8.6；身體 −33～−12.5；腿 −15～0；手在 (±9,−23.2)。頭頂最高到約 −70（尖帽），畫布高度要留夠（現在的 `DOLL_H` 64 不夠）。**戰場縮放**：52px 格用約 0.74 倍，人約 40px 高，和現在一樣。

| 方向 | 圖層順序（下 → 上） | 重點 |
|---|---|---|
| 正面（南） | 影子 → 披風 → 尾巴 → 長髮後片 → 腿 → 身體 → 副手臂＋副手 → 耳（側耳）→ 頭 → 臉 → 頭髮 → 耳（獸耳）→ 頭部裝備 → 角 → 主手臂＋武器＋手 | 主手在畫面左 |
| 側面（東） | 影子 → 披風 → 尾巴（往西）→ 長髮後片 → 遠側手武器 → 遠腿 → 近腿 → 身體 → 盾（側看一條邊）→ 頭（側臉）→ 耳點 → 臉 → 頭髮 → 耳 → 頭部裝備 → 角（遠側暗 25%，近側往前 2.2）→ 近側手臂＋武器＋手 | 西＝左右鏡像 |
| 背面（北） | 先左右對調（主手到畫面右）→ 影子 → 武器（在身體後）→ 腿 → 身體 → 兩手 → 披風 → 尾巴（蓋在披風上）→ 盾背面（木色＋皮帶）→ 側耳 → 頭 → 後腦頭髮（**戴帽也畫**，帽子只蓋頭頂）→ 獸耳 → 頭部裝備 → 角 | 看不到臉、扣環、縫線 |

體型：`stout` 整個人 ×(1.12, 0.88)，`tall` ×(0.96, 1.1)（四方向都要）。倒地姿勢照現行做法旋轉。

## 3. 9 格裝備

樣張畫了：身體 `shirt`／`leather`／`plate`／`robe`、頭 `helmet`／`hood`／`wizard_hat`、腳 `boots`／`greaves`、披風、圓盾。
其他 kind（`mail`、各種外套、`greathelm`、`horned_helm`、`cap`、`bandana`、`crown`、`wide_hat`、手套、臂甲、塔盾⋯⋯）：**沿用現行造型的輪廓，改用 `ink()` 畫**，細節線（甲片、縫線）改成 `stroke()`。顏色照現行 `itemColors()`。項鍊、戒指照舊不畫。

## 4. 武器（含 #34、魔導劍、成對武器）

- 握點：正面主手 (−9,−23.2) 豎起；側面近側手 (4.6,−24)，劍、斧、匕首往前上斜 0.75 rad，法杖、弓直立。
- 樣張畫了 `sword`、`dagger`、`axe`、`staff`（杖頭光暈用元素色，預設 `#8fe3ff`）、`bow`；其他 kind（錘、矛、拳套、鐮刀、鞭、手槍、霰彈槍、法球、弩、圖騰杖、魔導劍）：沿用現行造型＋`ink()`，握法不變。
- **成對武器**：正面副手＝主手武器左右鏡像，在畫面右手；側面副手在遠側手 **(5.6,−27)**，畫在身體後面，比近側手**往前上錯開約 3px**（即 3R-3a 原定的小修，一起做掉）；背面兩把都在身體後面。

## 5. 種族（3R-3a／3R-3b）與形態（3J-5）

**種族**：欄位、10 族資料與龍裔定案版照 `種族與側面移植需求.md` ①。**衝突規則以 `可玩種族評估.md` 第 2 節為準**（例如精靈戴頭盔時尖耳伸出、狐族戴兜帽用有耳朵的兜帽、寬帽遇角要抬高）；樣張為了省事有些組合簡化，不算數。部件位置與形狀照 `storyDoll.js` 的 `tail`、`ears`、`horns`、`face`（鱗片、刺青、晶路、獠牙、鬍子、豎瞳）。
- 3R-3a：耳、角、尾、膚色、衝突規則＋成對武器錯開（第 4 節）。
- 3R-3b：體型、臉部紋路、鬍子、獠牙、龍裔部件（大龍角、龍鱗、豎瞳、粗龍尾＋背刺、鱗色）。

**形態 10 種**：規則照 `形態外觀.md` 定稿方向（全部另畫、帶主角主色、比同類召喚物大一號、不認得的 id 退回原角色＋光環）。
- 樣張畫了熊、狼人、龍（`storyDoll.js` 的 `FORMS`）；其他 7 種（貓、鳥、惡魔、巨人、元素化身、暗影、樹人）**用 `formArt.js` 的輪廓＋`ink()` 畫**。實作者如果需要，美術 PM 可以先補這 7 種的樣張。
- 形態光環改成手繪：元素色虛線橢圓（線寬 1.1、虛線 2.4／1.6）＋18% 同色填色。

## 6. 召喚物（獨立一節，等使用者確認要不要做）

- 17 種的規則照 `召喚物外觀.md`（體型 × 元素 × 大小 × 特徵），輪廓沿用 `summonArt.ts`，改用 `ink()` 畫，拿掉黑色剪影外框，光環與影子同第 1、5 節。
- 人形召喚物本來就用紙娃娃，第 2～4 節做完就會自動換畫風。
- 約 1 段。不做的話，非人形召喚物維持現行畫風（和 C 有落差，但不影響玩法）。

## 7. 建議分段

| 段 | 內容 | 估計 |
|---|---|---|
| C-1 | 畫法層、四方向骨架、樣張畫過的裝備與武器（布、皮、板、袍、頭盔、兜帽、尖帽、靴、脛甲、披風、圓盾、劍、匕首、斧、法杖、弓）、拿掉剪影外框、快取 | 約 1.5 |
| C-2 | 其餘裝備 kind 與武器（含 #34、魔導劍、成對武器的正面與背面） | 約 1～1.5 |
| 3J-5 | 形態 10 種直接用 C 畫（原估 1～1.2 段，不另加） | — |
| 3R-3a／b | 種族直接用 C 畫（原估約 1 段，不另加） | — |
| C-3（待定） | 召喚物 17 種 | 約 1 |

## 檢查清單（驗收時美術 PM 用原尺寸重拍 `doll-gallery`／實戰）

畫法：
- [ ] 墨線兩層、水彩溢色、暗面排線都有；正面暗面在右，側面、背面在左
- [ ] 同一隻小人重畫（換場景、重開頁面）線條完全一樣，不閃
- [ ] 沒有黑色剪影外框；頭目外光仍在；地面影子是斜線
- [ ] 52px 格：人約 40px 高，臉、耳、角、尾、武器分得出
- [ ] 效能：滿場 20 隻小人移動時不掉幀（有用快取）

四方向：
- [ ] 正、側、背、西（鏡像）圖層順序照第 2 節；背面主手在畫面右、看不到臉
