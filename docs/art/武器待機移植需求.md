# 武器專屬待機：移植需求（QK-7，等使用者確認 Q 版方向後交開發 PM）

美術 PM，2026-11-04 晚。使用者原話（專案 PM 轉達）：「要有待機動化 就是沒輪到他它會在那邊晃 每個武器不一樣動作」。

- 樣張：`idle-weapons.gif`（15 種待機，2.4 秒一循環）、`idle-team.gif`（同一隊 5 人不同步）、`idle-weapons.png`（分格）。
- 樣張程式：`sample/idle-weapons.html`（`?t=毫秒` 固定時間、`?reduce=1` 減少動態），定義在 `sample/idleWeapons.js`，畫法用 `sample/qDoll.js`。
- 全部程式繪製，只在前端畫面，不碰引擎與重播。

## 1. 規則

- **誰會晃**：戰鬥中沒輪到行動、站著的單位。
  - 照 6M-4 `idles()` 的條件：倒地、冰凍、正在播別的動畫（`hold`）的人不晃。
  - 輪到行動的人照現行（選單開著時站好）。
- **疊加**：疊在 6M-4 的呼吸上。6M-4 的小動作（張望、伸懶腰）照舊，播小動作時武器待機暫停。
- **相位**：用 `idHash(`${unitId}:weaponIdle`) % 1000 / 1000`，FNV-1a，同 `idleClips.idHash`。
  - 同一個 id、同一個時鐘，永遠是同一格。
  - 同一隊會錯開，見 `idle-team.gif`。
  - 不用 `Math.random`，不讀時間，時鐘照 6M-4 用 ticker 累加的毫秒。
- **減少動態**：開啟時一律站好，光也不脈動。樣張 `?reduce=1` 驗證過，畫面完全不動。
- **量化**：
  - 動作量化成 8 格。同裝備、同朝向、同一格共用貼圖，每人最多 8 × 朝向張。
  - 杖頭光、法球浮沉、符文光是疊加層，不量化，也不換貼圖。

## 2. 15 種待機

`idleWeapons.js` 的 `IDLE` 表，照搬。

| 武器 | 動作 | 循環 | 用到的姿勢鍵 |
|---|---|---|---|
| 劍 | 劍尖輕晃、重心微移 | 2.4 秒 | wpn、arm、hipN/F |
| 劍盾（副手是盾） | 舉盾微晃 | 2.4 秒 | shieldUp、wpn、lean |
| 刀 | 刀尖畫小圈 | 2.4 秒 | wpn、arm |
| 魔導劍 | 劍槽符文光脈動 | 2.4 秒 | glow、wpn |
| 成對武器 | 匕首在手上翻一圈 | 2.4 秒 | wpn（加 2π）、arm |
| 長槍 | 槍尖往前點兩下 | 2.4 秒 | dw、arm |
| 鐮 | 刃緩慢左右擺 | 2.4 秒 | dw、lean |
| 鞭 | 鞭梢甩動 | 1.2 秒 | lash、arm |
| 拳套 | 舉拳原地小跳 | 1.2 秒 | bob、arm、kneeN/F、liftL/R |
| 法杖 | 杖頭光點脈動 | 2.4 秒 | glow、dw |
| 法球 | 法球在掌上浮沉、光脈動 | 2.4 秒 | orbY、glow |
| 弓 | 箭搭在弦上、弓口朝前下，持弓手垂在身側；循環中段把弓抬起來看一下再放下（使用者：「收先不可能是這樣拉弓待機」，舊版拉弦已刪） | 2.4 秒 | nock、arm、dw |
| 弩 | 舉起來瞄一下再放下 | 2.4 秒 | dw、arm |
| 火槍 | 槍口點一下、重心左右換 | 2.4 秒 | dw、hipN/F、lean |
| 雙手劍 | 拄劍（或扛肩，照使用者選的姿勢），重心左右換 | 2.4 秒 | dw、hipN/F、lean |

**新的姿勢鍵**：只影響畫法，`InkPose` 加欄位，6M／6N 的片段不受影響。

| 鍵 | 作用 |
|---|---|
| `shieldUp` | 盾往上抬幾單位 |
| `glow` | 光的強度 0～1：杖頭、法球的光暈加大加亮，魔導劍符文的 shadowBlur 加大 |
| `orbY` | 法球上下位移 |
| `lash` | 鞭梢的波動相位 0～1 |
| `dw` | 武器在手上的角度偏移（有關鍵姿勢的武器不給絕對的 wpn，只給偏移，武器跟著手走） |
| `nock` | 弓待機時箭搭在弦上 |

- **哪個方向播**：側面播完整動作。正面、背面只套 `bob`、`glow`、`orbY`、`shieldUp`、`pull`，手臂與武器角度不變，避免和正面的雙手握法打架。
- **雙手武器的副手**：照 Q 版雙手規則跟著主手走（`qDoll.js` 的 `TWO`）。

## 3. 驗收

- **gif**：15 種在戰場上同時待機，與樣張 `idle-weapons.gif` 並排。要錄靜音的 gif，見品質底線。
- **單元測試**：
  - 15 種都有定義。
  - 同一個 id、同一個時鐘得到同一格。
  - 兩個不同 id 的相位不同。
  - 減少動態時姿勢等於站好。
  - 8 格量化後貼圖鍵最多 8 個。
  - 每一格都照跑 Q 版的武器自測：手在握把上（像素）、作用端在畫布內。
- **效能**：12 人同時待機，FPS 和現在一樣（6R-F 的量法）；貼圖數上限照 6M-4 的快取規則。
- **減少動態**：開啟後站好，截圖和關閉前的站姿逐像素相同。
