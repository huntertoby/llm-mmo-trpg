# 網遊式 HUD 版面（方案，等使用者選）

美術 PM，2026-11-04。

> 使用者原話（專案 PM 轉達）：「還有這些 能用圖式加文字 或者純圖示 還有不要直接一長條往下 在中間畫面的周邊 像網遊一樣」

- 樣張：`hud.png`。畫法在 `sample/hud.html` 和 `sample/hud.js`，疊在可走動的霧渡鎮、渡口石階樣張（`explore.png`）上。全部程式繪製。
- 這次**沒有代決**，請使用者選版面（第 1 節），也可以改對照表裡任何一項（第 2 節）。

## 1. 三種版面

| | A. 四角分散（**推薦**） | B. 底部集中 | C. 極簡純圖示 |
|---|---|---|---|
| 自己（頭像、Lv、HP、法力、經驗） | 左上一張卡：頭像＋HP 條和法力條（帶數字）＋細經驗條 | 底部左邊 | 左上頭像；外圈的紅弧是 HP、藍弧是法力，沒有數字 |
| 隊友（2 名傭兵） | 主角卡下面，小頭像＋名字＋血條 | 左側中間直排，只有頭像和血條 | 主角旁邊的小頭像，外框顏色代表血量 |
| 影子 | 隊友下面一個圖示 | 同 A | 功能圖示裡的一顆 |
| 地名、小地圖 | 右上：地名條＋小地圖（顯示出口、NPC、敵群） | 右上，小一點 | 收成右上的地圖圖示，點了才開；地名只在進畫面時淡入一次 |
| 時間、天氣 | 小地圖下面：圖示＋一個字（午、霧） | 底部右邊 | 純圖示 |
| 金幣、任務幣 | 小地圖下面：圖示＋數字 | 底部右邊 | 收進背包面板 |
| 任務追蹤 | 右側一張可收合的小卡（最多 2 條） | 沒有（收進任務圖示） | 沒有（收進任務圖示） |
| 功能（背包、技能、成長、任務、影子、留言、趕路） | 底部中央一排圖示，帶快捷鍵和未讀數字 | 底部和自己的資訊排在同一條 | 右側直排圖示，打開後面板從右邊滑出 |
| 最近發生的事 | 左下浮動提示：最多 3 條，舊的淡出 | 上方中央一條橫幅 | 沒有常駐（收進留言或紀錄） |

**推薦 A**，理由：
- 最像使用者說的「網遊」：自己在左上、地圖在右上、功能列在底部，是玩家最熟悉的位置。
- 中間和下半部留給畫面。單位、出口、敵群的警戒圈大多在畫面中段，A 擋到的最少。
- 每一項都看得到「圖示加一點數字」，不用點開就知道狀態，又不是整段文字。

另外兩種的取捨：
- **B 底部集中**：資訊全部在一條，眼睛只要往下看；但畫面下方的河、碼頭這類出口會被那一條擋住，而且底條佔掉約 1/7 的畫面高度。
- **C 極簡純圖示**：畫面最乾淨；但 HP、金錢這些常看的東西要點開或靠圓弧猜，新手比較不友善。

各方案都有的共通點：
- 四周的面板都是半透明深底、金邊，和戰鬥的介面同一套。
- 視窗太窄的時候，A 的任務小卡和左下的提示可以自動收成圖示。
- 戰鬥畫面不用這套 HUD，照現在的戰鬥介面；這套只用在城鎮和野外。

## 2. 每一項資訊怎麼呈現（對照表）

呈現方式分三種：
- **純圖示**：只有圖示，必要時加狀態色或小紅點；
- **圖示＋數字**：圖示旁邊一個數字或一兩個字；
- **收進面板**：平常看不到，點圖示或按快捷鍵才打開。

下表以 A 為準。B、C 的位置不同，但呈現方式相同，除非備註另外說明。
