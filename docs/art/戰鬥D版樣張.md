## 2. 待機時的地表畫法（不靠格線）

1. **形狀**：同種地表的相鄰格併成一塊。
   - 邊緣是圓角，有一點不規則（依格子座標雜湊，結果固定），不畫方框。
   - 格與格之間的接縫要補滿。
2. **邊緣**：每種地表有自己的邊緣色，一眼看得出範圍。
   - 冰：白邊；
   - 油：金褐色油光；
   - 火：橘紅色，外加光暈；
   - 水：沿用現有的水面反光線。
3. **紋理**：
   - 冰：反光斜線、細裂紋；
   - 油：虹彩亮斑；
   - 火：火苗；
   - 毒、聖光、黑暗、煙霧：沿用現有的顏色，改用同樣的併塊畫法。
4. **陷阱**（已發現的）：
   - 捕獸夾這類物件圖示，外加淡紅色虛線圈；
   - 沒發現的陷阱照規則不畫。
5. 範圍的實際判定仍是格子。邊緣的不規則只在格子內縮 5 單位以內，**不會超出所屬的格子**，所以看起來的範圍和實際範圍一致。

## 3. 選移動時的路徑（第 5 張，等使用者確認）

1. **路徑沿格子走**：
   - 不用自由曲線，用直線段加圓角接點；
   - 每經過一格，格子中心有一個點，數得出會走幾格。
2. **分段變色**：
   - 一般地面：白色實線；
   - 冰上滑行：藍色虛線（`#1e78d0`）；
   - 踩到陷阱、火：紅色實線；
   - 到不了的後半段：灰色虛線。
3. **特殊格的提示**：
   - 會經過的冰面、陷阱、火、油，加上該地表顏色的外框（冰是藍、危險是紅），地表本身不被蓋住；
   - 路徑旁浮出預估結果的小牌，用圖示加一兩個詞：「滑 1 格」「陷阱 −8・定身」「點燃」「潮濕」。
4. **實際停點**：
   - 如果會被陷阱定住、滑過頭，或被打斷，就在實際停下的格子放紅色驚嘆號泡泡；
   - 原定的終點畫成虛線框加淡影，標「到不了」。
5. **資料**：預估結果要由伺服器提供（路徑預覽 API 回傳每一格的事件），前端不自己算，避免和規則不一致。

## 4. 走過去的動畫

1. **一格一格平滑移動**：每格約 0.12 秒，緩入緩出；轉彎時角色轉身。不要一口氣滑到終點。
2. **踩到特殊地表時，在那一格停頓並播效果**：
   - 冰：腳下冰花，人物以滑行姿勢多滑 N 格，速度比走路快；
   - 陷阱：夾住的動畫，停頓約 0.4 秒，然後跳出傷害數字和「定身」狀態圖示；
   - 火、油：腳下冒火或濺油，然後跳出狀態圖示。
3. **敵方回合**：可以快轉（2 倍速），但特殊地表的停頓保留。
4. 鏡頭：移動中稍微跟著角色；戰鬥區外的暗角不動。

## 5. 其他移植要點（沿用第一版）

1. 平常不畫格線；選移動、選技能時，格子用淡色圓角浮出，範圍外緣加亮線。
2. 戰鬥區外柔和變暗，不另外切場景（配合 #120 的就地開打）。
3. HUD 用版面 A 的戰鬥版：
   - 左上：主角卡，HP、法力、耐力三條；
   - 上方中央：行動順序；
   - 右上：回合、天氣、勝利條件；
   - 底部：技能列；
   - 左下：紀錄浮動提示。
4. 技能卡、單位資訊用去文字化的版本（`去文字化移植需求.md`）。
5. 字母標記只在滑過單位時，或在行動順序列上顯示。

## 6. 檢查清單（使用者確認後，美術 PM 驗收時看）

- [ ] 待機畫面沒有格線，但冰、油、火、水、陷阱的範圍都看得出來，而且和實際判定的格子一致。
- [ ] 選移動時，路徑經過哪幾格數得出來。
- [ ] 經過特殊地表時：路徑變色、有警示外框、有預估結果的小牌。
- [ ] 實際停點和預估一致（由伺服器提供）。
- [ ] 移動動畫一格一格走，踩到特殊地表時有停頓和效果。
- [ ] 選範圍技能時，格線淡淡浮出，命中格清楚。
