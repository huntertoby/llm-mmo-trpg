外框形狀＋框色polarity增益 buff＝綠色圓形、減益 debuff＝紅色圓角方形、中性 neutral（含姿態）＝金色六角形。色盲也能靠形狀分。
圖樣顏色control_group → on_turn_start_damage.element → polarity控制類：硬控（暈眩、冰凍）黃、移動（緩速、定身）藍、心智（恐懼、沉默、嘲諷）紫；持續傷害用元素色；其餘依 polarity（少數保留原本的專屬色）。
圖樣狀態 ID 查表一個狀態一個圖樣，不再重複（下面四組改掉）。不認得的狀態：外框照 polarity，中間畫名稱第一個字。
戰場上排序規則頭頂一排最多 3 個，超過時顯示 2 個＋「+N」。順序：硬控 → 移動／心智控制 → 持續傷害 → 其他減益 → 增益 → 中性；同一級依 ID 排。
身上特效skip_turn、removed_by_element、absorbs_damage、prevents_move、on_turn_start_damage只有 5 類：冰凍＝冰塊、暈眩＝頭上轉星、護盾＝泡泡、定身＝腳下藤蔓、持續傷害＝腳邊元素粒子。其餘只靠圖示，避免畫面太亂。
