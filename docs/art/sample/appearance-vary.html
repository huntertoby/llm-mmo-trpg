Q 版外觀變化：同一個種族也長得不一樣

美術 PM，2026-11-04 晚。使用者原話：「每個種族每個人 都長依樣嗎 有辦法 像其他遊戲 臉型1 臉型2 嗎 或者男女」。這張是方案樣張，還沒決定，給使用者選。全部程式繪製，用 Q 版造型（qDoll.js），不填任何新欄位時和現在一模一樣。外觀只在畫面上，不影響任何數值。方案文字見 docs/art/外觀變化方案.md。

1. 可以選的部位（人類示範；每一格只改一項，其他是預設）

2. 「粗獷／柔和」是快速組合，不是性別：按一下套一組預設，每一項還是可以自己改（使用者決定不設性別）

3. 同一個種族，5 個不同的人（種族特徵固定，其他照種族可選範圍隨機）

種族特徵（耳、角、尾、獠牙、紋路、鱗、義體半臉、矮人的鬍子與體型）一律保留；膚色在種族自己的色票裡選；鱗族沒有頭髮（鰭耳），其他選項照用。

4. 建角頁怎麼選（可以點）名字 → 種族 → 外觀 → 出身

選完種族卡後多一步「外觀」：左邊是現在的大紙娃娃預覽（可轉正面、側面、背面），右邊一排一排點選；「隨機」在種族範圍裡抽一組；「粗獷／柔和」套快速組合。種族換掉時，新種族沒有的選項改回該族預設（例：換成鱗族，髮型改回無）。
