# 世界觀（待決定 #5）美術意見（美術 PM，2026-10-22）

玩法 PM 提的「碎界」五區：每區一句視覺方向，以及程式繪製撐不撐得住。使用者原話：「世界觀 沒想好 但是可能像鳴潮 有奇幻風的城 東方的地方 科技的城市之類的」。

## ① 每區視覺方向

| 區 | 色調 | 地形與物件 | 單位 |
|---|---|---|---|
| 晶冠城邦（奇幻） | 暖米白石材＋藍紫晶光 | 石板、城牆高台、晶柱、書架、法陣地板 | 現有紙娃娃（板甲、法袍）直接適用 |
| 雲嶺（東方） | 青綠、墨灰、霧白，低彩度 | 青石階、竹林、寺院木構、石燈籠、吊橋、霧表面 | 漢服長袍、斗笠、髮髻、刀劍、符紙 |
| 霓虹樞市（科技） | 深藍黑底＋青、洋紅發光線 | 金屬地板、管線、電網、導電地板、升降平台、終端機 | 夾克、護目鏡、機械臂、能量武器 |
| 灰燼荒原（災變） | 焦褐、炭黑＋岩漿橘紅 | 裂地、岩漿、廢墟殘牆、枯木、碎石 | 盜賊（現有）＋破布斗篷、面罩 |
| 霜潮海境 | 冰藍、白、深海藍 | 冰湖、薄冰、浪花、沙岸、礁石、沉船殘骸 | 毛皮、魚鱗甲、三叉戟 |

五區共用同一套畫法（光從左上、深色外框、紙娃娃比例）；區與區之間只換配色和造型，同一個戰場不會看起來像不同遊戲。

## ② 程式繪製撐不撐得住

撐得住。程式繪製的好處是換配色和換部件都很便宜，需要補的東西如下：

| 項目 | 內容 | 段數 |
|---|---|---|
| 區域主題（配色） | `artPalette` 改成「每區一套」，地圖資料加一個 `region` 欄位；地形、表面跟著換色；沒指定時用預設配色 | 0.5 |
| 地形與物件造型 | 每區補 4～6 個專屬物件，既有物件換外型（例如木箱在科技區畫成金屬箱）；沒有對照的就用預設外型 | 每區 0.5，四區約 2 |
| 紙娃娃服裝 | 補東方、科技、海境的服裝部件（身、頭、武器各數件），沿用「種類＋材質＋顏色」規則 | 1～1.5 |
| 技能圖示 | 不用改，由元素與部件決定，和區域無關 | 0 |
| 特效 | 科技區的發光線與電網要加一層 glow | 0.5 |

合計約 4～5 段。可以先做「區域主題」＋一區（建議雲嶺，最好看出差別），其他區慢慢補。

## ③ 難畫與建議

- **最難的是霓虹樞市**：需要發光效果、大量新物件，和中世紀紙娃娃落差最大。建議改成「魔導科技」（符文機械、晶能管線），和奇幻、東方比較搭；或者放到最後做。
- 霜潮海境的潮汐可以直接沿用 3-19 的整格抬高動畫（水位升降），很划算。
- 不建議換掉任何一區。
