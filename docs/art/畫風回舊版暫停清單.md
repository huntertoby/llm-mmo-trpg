# 畫風回舊版：暫停與不受影響清單（交開發 PM 協調）

美術 PM，2026-11-04 晚。使用者決定人物畫風回舊扁平版（原話見 `美術PM交接.md` 2.6）。做法是「舊版的皮＋現行骨架」：只換 `inkStyle.ts` 的畫法層與部件的填色描線，**骨架、姿勢、資料欄位、配件清單全部不變**。

判斷原則：
- **綁畫法**（直接呼叫 `ink`／`stroke` 畫人物部件、或拍人物截圖給使用者看）→ 暫停，等皮換好再做。
- **只碰外觀資料**（`look`／`gear`／`portrait`／`extras` 欄位、站位、設施）→ 照舊，換皮後自動跟著變。
- **和人物無關**（地形、介面、音效、地圖）→ 照舊。
