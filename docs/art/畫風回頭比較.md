# 畫風回頭比較：舊扁平版 vs C 墨線繪本（給使用者決定）

美術 PM，2026-11-04。使用者看舊的狀態圖示畫廊（10-29 以前的扁平紙娃娃）原話：「完蛋我越看越覺得我的決策是錯的 原本好可愛喔」。

- **這份只比較、不改東西**。結論出來前，畫風維持現行 C。
- 樣張：`style-compare.png`（`sample/style-compare.html`）。左欄是當時真正的畫法（`sample/paperdoll.js` 還在，直接呼叫，不是憑印象重畫）；右欄是現行 C（`sample/storyDoll.js`）。同一組角色資料、同一塊地面、同一組狀態圖示，只換人物畫法。四組：戰場（實際大小與 2 倍）、霧渡鎮走路、頭像（5 族＋4 傭兵）、動畫一格（揮砍、施法）。

## 1. 並排看到什麼

| 看點 | 舊扁平版 | C 墨線版 |
|---|---|---|
| 可愛度 | 圓頭、大眼、乾淨色塊，像貼紙或桌遊棋子；**比較可愛** | 頭稍小、墨線抖、有排線，像繪本插畫；可愛度中等，偏「有質感」 |
| 戰場實際大小（52px） | 色塊乾淨，隊伍色、裝備顏色一眼分；**辨識度高** | 排線與墨線在 52px 下變成灰噪，裝備顏色被壓暗；辨識度稍差 |
| 放大 2 倍 | 乾淨但單薄，沒有質感 | 墨線與水彩出來了，**好看** |
| 走路（實地地圖） | 清楚、可愛 | 清楚；人物比地磚「畫得更細」，和地磚的平塗略有落差 |
| 頭像（64／32px） | 圓臉可愛；32px 仍清楚 | 有細節；32px 時排線糊成灰 |
| 動畫 | **沒有關節**：當時只能整隻傾斜加弧光 | 6M／6N 的骨架：手臂、武器、髖、膝各自轉；揮砍、施法、受擊、走路都有姿勢 |
| 和 B 彩繪地圖、碎界中樞 HUD | 扁平色塊和彩繪地圖、深藍金框都搭，像「棋子放在畫上」 | 墨線和彩繪地圖搭，和金框 HUD 搭；只是人物比地圖「手繪感」更重 |
| 和世界觀 | 中性，哪種世界觀都行 | 「說書人手繪的繪本」感，和 LLM 說書人主題最貼 |

**誠實的結論**：舊版在「可愛」和「小尺寸可讀」兩項贏；C 在「放大的質感」「動起來」「和說書人主題」三項贏。使用者覺得舊版可愛，不是錯覺。

## 2. 選項與代價

### 已完成的東西裡，哪些是綁在 C 畫法上的

| 東西 | 怎麼做的 | 換畫法要動多少 |
|---|---|---|
| 人物畫法 `inkDoll.ts`＋`inkStyle.ts`（墨線、水彩、排線） | C 的畫法層 | 換畫法＝換掉這層 |
| 裝備、武器、種族、形態、召喚物、異形（`inkGear/inkArmor/inkWeapons/inkRace/inkForm/inkCreature/inkOffhand/inkSect`，約 10 個檔） | 每個部件用 C 畫法畫 | **部件要重畫**；資料欄位（kind／material／color／rarity／look）不用改 |
| **6M／6N 動畫骨架**（`inkPose.ts`、`motionClips.ts`、`skillClips.ts`、`reactClips.ts`、`attackVariants.ts`…） | 姿勢是「關節角度」，包在 inkDoll 的部件外面轉 | **骨架與片段不用重做**，只要新畫法的部件也掛在同一組關節上（舊扁平版沒有關節，得補上） |
| 頭像 `portrait.ts`、傭兵、NPC、郵差、葛蘭 | 用 inkDoll 的正面頭部放大＋配件 | 跟著人物畫法走，資料不用改；配件（斗笠、護目鏡、疤…）要重畫 |
| 建角種族卡、傭兵頭像、郵差 | 同上 | 同上 |
| 敵人 48 種、頭目 2 種 | 人形用 inkDoll；異形用 inkCreature | 人形跟著走；異形 17 種身形要重畫 |
| 武器小圖示（3T-4）、技能圖示、物品圖示、狀態圖示、HUD 圖示、事件卡墨線圖示 | 獨立的圖示畫法（也是墨線） | **可以不動**（圖示是墨線但不是人物）；要全套一致才動 |
| 事件插圖 10 種、靶場、開場分鏡 | 人物用 inkDoll | 跟著人物畫法走 |
| 地圖、區域插畫、大世界圖、HUD | 和人物無關 | 不動 |

## 3. 美術 PM 的判斷

從四個面向看：

| 面向 | 誰贏 |
|---|---|
| 可讀性（52px 戰場、32px 頭像） | 舊版 |
| 可愛度 | 舊版 |
| 量產成本（已完成的工作、之後每個新部件） | A ＞ D／E ＞ C ＞ B |
| 和世界觀（LLM 說書人、繪本）、和彩繪地圖的搭配 | C |

**推薦：D＋E（維持 C，小尺寸自動變乾淨，頭稍微放大）**，合計約 0.75 段。
- 舊版贏的兩項（可讀、可愛）主要輸在「小尺寸的排線」和「頭身比」，不是輸在墨線本身；D 和 E 剛好補這兩個洞，不用推翻 10-29 的決定，也不用重做部件、頭像、動畫。
- 做完後我會出同一張並排圖（舊版／C／D＋E）再給使用者看一次；如果看了還是想要舊版，再走 C（混合，2～3 段），不建議走 B（5～6 段，等於把 C-1 到 C-3 重做一遍，動畫也要重驗）。

**如果使用者就是要舊版的樣子**：選 C（混合）而不是 B。C 保住骨架與資料，皮換回乾淨色塊，可愛度能回到接近舊版，又比舊版多一層細墨線和影子。

## 4. 要使用者決定

1. 選 A／B／C／D＋E／其他。
2. 若選 D＋E 或 C：做完要不要再看一次並排圖再定稿（建議要）。
