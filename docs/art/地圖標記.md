# 實地地圖標記（移植需求）

美術 PM，2026-11-04。6C-5 驗收時發現格子裡用「足／碑／火／！」文字方塊當標記，和戰鬥 D 版「不畫格子框、用東西自己的形狀」不一致，所以出這份。代決 #58，等使用者看過再定；可以先做。

- 樣張：`docs/art/map-marks.png`；畫法：`docs/art/sample/mapMarks.js`、`map-marks.html`。全部程式繪製，沒有亂數。

## 1. 標記

| 東西 | 畫法 | 滑過說明卡 |
|---|---|---|
| 事件「！」 | 金色泡泡浮在格子上方（上下浮 3px，週期 1.6 秒），地上一圈淡金光 | 「有事發生・碰到就開始」 |
| 營火 | 一圈石頭＋交叉的柴＋火苗（微微晃），地上暖光；今天紮過營就只剩柴和灰 | 「營火・可以紮營」／「今天已經紮過」 |
| 朋友腳印 | 淡白色鞋印，左右腳交替、每格兩步，越舊越淡；不畫格子框 | 「朋友的腳印・名字」＋多久以前 |
| 留言石碑 | 直立石板、三條刻線、一張釘著的紙；有未讀時右上紅點 | 「留言石碑・N 則」 |
| 情境物件提示 | 主角在 1 格內時，物件底下一圈金色虛線呼吸光＋右上小手；離開就不畫 | 物件名稱＋用途一句（原本的卡） |

## 2. 敵人視野

- 和 6A-4g 的遭遇戰場一樣併成一塊：淡紅填色（0.20）、外緣紅色虛線、外角圓角，不畫格子之間的線。
- **格角的黑點拿掉**。「誰在看」改成敵群頭上的一個眼睛圖示（白底紅瞳）。
- 潛行時：視野照規則縮半，填色更淡（0.10）、虛線更短更淡，敵群頭上的眼睛半閉。
- 6C-5 截圖裡，野外巡邏的視野還是格狀紅框加黑點，要換成這個畫法。
