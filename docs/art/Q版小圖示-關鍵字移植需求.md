## 3. 一定要做對的重點

### 3.1 畫幾個、多大
1. **畫的條件**：`px >= 32`，而且有認得的關鍵字。遊戲端 `GearIcon` 只收 32／48／64（背包 42 是 48 經 CSS 縮小）。若有小於 32 的呼叫處（**待開發查證**），美術建議那些尺寸不畫：圓章會小於 13px。
2. **只畫一個圓章**：用 `keywords[0]`，角＝`cornersOf(kind, form)[0]`（3.2）。
3. **直徑** `D = round(px × 0.42 × res) / res`；離格邊 `m = px × 3.6 / 64`；`far = round((px − m − D) × res) / res`、`near = round(m × res) / res`。右下＝(far, far)、左上＝(near, near)、左下＝(near, far)。真 1 倍 32→13、42→18、48→20、64→27。
4. **圓章**：先填 `#16121a` 圓（半徑 D/2），再填內圓（半徑 D/2 − 1 裝置像素），顏色 `mix(KEYWORD_COLOR[kw], "#191b22", 0.72)`（第二色佔 72%）；沒有環。
5. **圖樣**：邊長 `cpx = (D − 2/res) × k`，圖樣格 `cpx × 4/3`，中心對準圓心，用 `blit()` 貼在整數裝置像素上。`cpx ≤ 14` 不包外框，其他包 `outlinePx(cpx)`。

### 3.2 角：例外表 `KEY_CORNER`（不量、不自動換角）
查表順序：`kind/form` → `kind` → 預設。預設是**右下**；右上永遠不放（稀有度色塊在那裡）。

| kind（/form） | 角 | 理由 |
|---|---|---|
| `axe`（3 款） | 左上 | 斧刃在右下 |
| `hammer/flail` | 左下 | 錘頭甩在右下 |
| `scythe/crescent` | 左上 | 月牙刃在右下 |
| `bow`、`crossbow`（各 3 款） | 左下 | 弓臂、弩臂在右下與左上 |
| `shoes`、`boots`、`iron_boots`、`greaves` | 左上 | 鞋尖朝右下 |
| `pendant`（2 款） | 左上 | 墜子在右下 |
| `charm/bone` | 左下 | 獠牙尖朝右下 |
| `circlet/bandana` | 左下 | 頭巾結垂在右下 |
| `cloth_gloves`、`leather_gloves`、`gauntlets` | 左下 | 右下壓掌根；左下只蓋護腕 |
| `dual_dagger/short`、`dual_dagger/stiletto`、`dual_pistol`、`whip`、`longgun/sniper` | 右下 | 寫進表，以免之後改預設時蓋到左上的刃、槍口、鞭梢 |

以樣張的 `KEY_CORNER` 原表為準（上表是摘要）；測試要逐列鎖住。

### 3.4 第二個關鍵字的記號（點版）
1. **條件**：`keywords.length > 1`。3 個以上也只畫同一個記號，記號不表示個數。
2. **大小**：`s = round(D × res × 0.42)`（裝置像素），偶數減 1，最小 7；`w = s / res`。真 1 倍 32／42／48 是 7px，64 是 11px；2 倍時 32→11、42→15、48→17、64→23。
3. **方向** `dir`：
   - 先查 `MORE_DIR_KIND`：手套 3 種是 `[1, 0]`（圓章右邊）；`tome/scroll`、`hat/wide` 是 `[-1, 0]`（圓章左邊）。
   - 查不到時，若角是右下而且是 `isDiag`（造型的 `diag`，加上長槍、霰彈槍），用 `[-1, 0]`。
   - 都不是時照角：右下 `[0, −1]`、左下 `[0, −1]`、左上 `[0, 1]`。
4. **位置**：圓章圓心 `(cx, cy)`，`r = D/2 + w/2 − 2/res`（記號只疊進圓章 2 個裝置像素）。左上角 `x = snap(cx + dir.x × r − w/2)`、`y = snap(cy + dir.y × r − w/2)`（`snap`＝對齊整數裝置像素），再夾在 `[snap(m), snap(px − m) − w]` 之間。
5. **畫法**：畫在圓章**之後**。
   - 先畫外框色 `#16121a` 圓（直徑 `w`），再內縮 1 個裝置像素填 `#191b22`。
   - 中間的點用 `KEYWORD_COLOR[keywords[1]]` **原色**，不混白、不調亮。第二個關鍵字不認得時，點用米白 `#f2e6c8`。
   - 點的大小：在 `s × s` 的裝置像素格裡，`G = s − 4`（`s − 2 ≤ 3` 時用 `s − 2`）。`G ≤ 4` 時用 `fillRect(o, o, G, G)`（`o = (s − G)/2`，真 1 倍是 3×3 的方點）；否則畫半徑 `G/2` 的圓，圓心在牌中心。
6. **只做點版**：不用做 `plus` 那一支，也不用切換常數。使用者已選 B。

## 6. 交使用者時要講明（已知、不擋移植）
1. 裝備格 32 從不畫改成畫一個圓章（1.3 第 1 點）。
2. 點版的記號在 42 偏弱（7px 牌裡的 3px 點）；旁邊有寶石時像鑲嵌的寶石（之後若加鑲孔系統會撞）。
3. 點色只提示大致類別：點燃、撞擊、形態、倒地都是橘杏色，3px 裡分不出來；名稱看說明框。
4. 點燃與中毒只靠橘、綠分（色盲最難分的一對）。
5. 關鍵字色和圓章圖樣有兩處不一致：標記的關鍵字色是紫，圖樣是紅準星；形態的關鍵字色是橘，圖樣是紫掌印。改不改不是這批的事。
6. 同題材不同形：點燃用元素火焰（不是狀態「燃燒」），冰凍用元素冰柱（不是狀態「冰凍」）。
