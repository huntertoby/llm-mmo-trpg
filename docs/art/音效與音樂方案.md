## 3. 格式、大小、音量、無障礙（兩階段共用）

- **格式**：取樣素材用 `.ogg`（Opus），另備 `.m4a`（AAC），照 `canPlayType` 選。合成音不佔檔案。
- **大小預算**：音樂每首 2～3 MB、環境音每區約 1 MB，依區域延後載入；第一次進遊戲只多約 1 MB。
- **四軌**：主音量、音效、音樂、環境，各有滑桿與靜音。預設主 70、音效 80、音樂 50、環境 60（使用者已定）。
- **自動播放**：第一次點擊後才解鎖音訊。
- **同時播放**：
  - 同一個音效最多 3 個；
  - 同一個 `hitAt` 的多個命中只放 1 聲，音量依人數略增；
  - 戰鬥中、說書人字幕出現時，音樂壓低 30%。
- **背景分頁**：預設靜音（可關）。
- **播放速度**：加速時音效不變調；跳過時不補放。
- **減少動態**：聲音照常。但和震動、停頓綁在一起的低頻衝擊（Boss 大招、爆炸）改成柔和版。
- **減少刺耳音效**：設定裡的開關，預設關。打開後拿掉高頻尖音與低頻轟鳴，所有音效上限 −6 dB。
- **不能只靠聲音傳遞資訊**：Boss 預告、輪到我方、任務更新都要有字或圖示。
- **全部靜音**：設定面板一個按鈕，加 `Shift+M`（`M` 已被大世界圖用）。

## 4. 第一階段移植需求（交開發 PM，不需外部素材）

| 段 | 內容 | 工作量 |
|---|---|---|
| **AU-1** 音訊核心 | 原生 Web Audio（不加套件）。四軌混音、設定面板、靜音、`Shift+M`、自動播放解鎖、ducking、同時播放上限、背景分頁靜音、減少刺耳音效開關；延遲載入架構（依區域的清單、`canPlayType` 選格式，現在清單是空的） | 0.75 |
| **AU-2** 合成音庫＋介面音 | `audio/synth.ts`：濾波雜訊、掃頻、FM 鐘與金屬、包絡、短脈衝序列等積木；用積木做第 2.2 節的介面音、第 2.1 節標 ○ 和 △ 的音效（△ 先合成暫代）。每個音效是一筆「參數表」資料，放 `content/audio/sfx.yaml`（內容即資料） | 1 |
| **AU-3** 接上戰鬥與探索 | 戰鬥音效掛 6N 時間軸（起手、出招、命中、結果、原語、狀態、地表），變體照 6N 的雜湊挑；腳步依地表；第 2.3 節標 ○ 的環境音（風、雨雷、火、鐘、打鐵）依區域與室內播放 | 1 |

**合計 2.75 段。**

**做法細節**：
- **確定性**：合成音的隨機成分（雜訊種子、劈啪的時間）用雜湊決定，不用 `Math.random`。同一場戰鬥重播，聲音一樣。
- **音效參數表範例**（`sfx.yaml`）：
  ```yaml
  swing_light: {layers: [{noise: band, freq: [2400, 900], q: 1.2, dur: 0.14, env: [0.005, 0.12]}], gain: -8}
  ```
- **開發頁**：`audio-gallery.html` 列出每個音效，點了就播，可以調參數、複製參數表。我驗收時逐個聽。
- **測試**：
  - 四軌音量的乘法；
  - 靜音；
  - 同時播放上限；
  - 同一 `hitAt` 合併；
  - 確定性（同參數同種子產生的波形一樣，用 OfflineAudioContext）；
  - 減少刺耳音效的上限。

**檢查清單**：
- [ ] 四軌與靜音、`Shift+M` 都有效，設定存得住；第一次點擊前不出聲。
- [ ] 介面音 20 個、戰鬥音效（○、△）在開發頁都聽得到，品質「不刺耳、分得出來」。
- [ ] 戰鬥中音效和動畫對齊（出招的咻在命中前、命中聲在 `hitAt`）。
- [ ] 一次打 5 人不會爆音；跳過時不補放；按住加速不變調。
- [ ] 雲嶺有風聲，荒原有熱風加火，室內有爐火或安靜，雨天有雨。
- [ ] 減少刺耳音效打開後，最大音量下降、沒有尖音。

**產出算不算外部下載**：
- 網站型工具都是在對方網站生成，再下載檔案，**算外部取得素材**；
- 本機模型要先下載權重，也算外部下載；
- 使用者這次回答「先不要」，所以第二階段要等使用者再同意。
- **另外，這幾個工具都要註冊帳號，多半要付費。依規定，agent 不能替使用者建帳號、登入或付款**。實際做法只能是：
  - **使用者自己**操作工具生成、下載，把檔案放進指定資料夾（例如 `client/public/audio/music/incoming/`）；
  - 再由開發做轉檔、切循環點、記錄 `CREDITS.md`。

**推薦：AIVA 最高方案（版權歸使用者）**：
- 最擅長管弦，正好是使用者選的西式奇幻管弦；
- 可以下載 MIDI，開發能精準切循環點、Boss 曲分兩段、調配器；
- 條款是幾家中最明確的「買斷式」，訴訟風險最低。

產出量：10 首加 4 段短樂句，大約一個月的訂閱就夠。
