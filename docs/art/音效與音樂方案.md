# 音效與音樂方案（給使用者決定）

美術 PM，2026-11-04。專案 PM 轉使用者原話：「都做」（精緻化 5 項之一）。

- **現況**：遊戲完全沒有聲音。`client/` 沒有任何音訊程式，相依只有 pixi.js、react、yaml。
- **這份要使用者決定的題目在第 7 節**，每題都附推薦。
- **使用者決定之前**：不下載任何素材，也不新增相依套件。

## 1. 風格

**推薦：東方民樂加輕幻想管弦，「說書人的繪本」感。**

| 元素 | 做法 |
|---|---|
| 主樂器 | 古箏、竹笛、二胡、琵琶，加輕弦樂鋪底和手鼓 |
| 音效質感 | 偏木、紙、墨、布：翻書、毛筆刷過、木魚、小鈴，不用科幻的電子音 |
| 介面 | 輕、短、乾淨：紙張翻動、墨點、小鈴，不搶戲 |
| 戰鬥 | 打擊明確但不刺耳：刀劍用金屬「鏘」加布料的「唰」；魔法用鈴音加風聲 |
| 各區差異 | 雲嶺：笛和古箏，空靈；荒原：低音鼓、琵琶掃弦、熱風；主城：較華麗的弦樂加鐘聲；之後三區（晶冠、樞市、霜潮）各一種主色 |

另外兩個方向：
- 純幻想管弦（西式 RPG）：比較通用，但和 C 墨線繪本、雲嶺的東方感有距離。
- 8-bit 晶片音樂：開發最省，但和畫風完全不搭。

## 2. 完整清單

### 2.1 戰鬥音效（對齊 6N 的動畫時間點）

播放時間一律對齊引擎事件，和 6N 的時間軸同源：音效排程掛在 `skillTimeline` 那一列的開始時間或 `hitAt` 上。

| 類別 | 音效 | 觸發時間點 | 變體數 |
|---|---|---|---|
| 起手 | 蓄力（布料、吸氣）、詠唱（鈴音漸強）、拉弓、上膛、劍指畫符 | 起手片段開始（6N-1） | 每種 2 |
| 出招 | 揮砍（輕、重）、突刺、拳、弓放箭、弩擊發、火槍、法術放出 | `hitAt` 前約 60 ms（揮動聲在命中前） | 每種 3（照 6N-6、6N-7 的變體雜湊挑） |
| 命中 | 刀劍肉擊、鈍器、穿刺、拳、魔法命中（依元素：火、冰、雷、水、毒、霧、聖光、黑暗、物理） | `hitAt` | 每種 3 |
| 結果 | 暴擊（金屬加重、尾音）、擊殺（低音落下）、格擋（鏘加火花）、閃避（風聲）、失手（空揮）、倒下（布料加地面）、復活（上升鈴音）、勝利短號 | 6N-4、6N-5 的觸發點 | 1～2 |
| 原語 | 治療（水晶鈴）、護盾（嗡）、衝刺（風）、跳躍落地、傳送（扭曲）、召喚（地鳴）、地表出現（依種類：火、冰、水、油）、符文刻下與引爆、變身 | 6N-2、6N-3 各片段的開始或 `hitAt` | 1～2 |
| 狀態 | 燃燒（劈啪，循環）、冰凍（結冰一下）、中毒（冒泡）、暈眩（小鳥轉圈）、帶電（滋滋） | 狀態上身時一聲；燃燒的循環音只在有人燃燒時，**全場只放一條** | 1 |
| 地表 | 冰面滑倒、陷阱夾住、火蔓延（每格輕輕一聲，合併上限） | 6N-4、6N-9 | 1 |
| 腳步 | 草、石、土、木、水、冰、沙 | 走路片段每一步（6M-3 的相位） | 每種 3 |
| 系統 | 回合開始、輪到我方、Boss 預告、Boss 大招（低頻壓迫加四周變暗） | 對應事件 | 1 |

約 **110～140 個音檔**（含變體）。

### 2.2 環境音（循環）

| 區 | 環境音 |
|---|---|
| 雲嶺 | 風過竹林、遠處流水、鳥鳴、薄霧（低頻氣聲）；夜裡換蟲鳴 |
| 灰燼荒原 | 熱風、遠處岩漿冒泡、火星劈啪、偶爾的落石 |
| 主城 | 人聲鼎沸（模糊）、遠處鐘聲、水池 |
| 室內 | 酒館：低聲交談、杯子；鐵匠鋪：爐火、偶爾的打鐵聲；導師殿：安靜加燭火 |
| 天氣 | 雨、雷、霧（疊在區域環境音上） |

每區 1 條基底循環加 3～5 個隨機點綴音，點綴音照確定性雜湊排時間，不用 `Math.random`。

### 2.3 介面音

按鈕（輕觸、確認、取消）、開關面板、翻頁（技能卡、戰鬥紀錄）、拿到物品、升級、任務更新、骰子翻滾與停下（成功、失敗）、說書人字幕出現（墨點）、等待中（第 4 份「等待的感覺」的墨水暈開，配一聲很輕的毛筆刷）。約 **20 個**。

### 2.4 音樂

| 曲目 | 數量 | 長度 | 說明 |
|---|---|---|---|
| 標題、建角 | 1 | 2 分鐘循環 | 主旋律（說書人主題） |
| 探索曲 | 每區 1（雲嶺、荒原；之後三區各 1） | 2～3 分鐘循環 | 各區主色樂器 |
| 城鎮曲 | 霧渡鎮、餘燼集、主城各 1 | 2 分鐘循環 | 較輕快 |
| 戰鬥曲 | 一般 2 首（雲嶺、荒原各 1） | 1.5～2 分鐘循環 | 開頭 4 小節要能馬上進入 |
| Boss 曲 | 灰燼之心、碎晶之主各 1 | 2 分鐘循環 | 可以有階段：Boss 換階段時切到第二段 |
| 短樂句 | 勝利、失敗、升級、發現地點 | 3～8 秒 | 不循環 |

第一季約 **10 首加 4 段短樂句**。

## 4. 檔案格式與大小預算

| 種類 | 格式 | 規格 | 預算 |
|---|---|---|---|
| 音效 | `.ogg`（Opus）＋`.m4a`（AAC）備用 | 單聲道 48 kHz，短音 64 kbps | 全部約 **3 MB**；啟動時先載入介面音和共用打擊音（約 0.5 MB），其他依區域延後載入 |
| 環境音 | 同上 | 立體聲 96 kbps，循環 30～60 秒，頭尾無縫 | 每區約 **1 MB** |
| 音樂 | 同上 | 立體聲 128 kbps，循環點寫在檔名旁的 JSON | 每首約 **2～3 MB**；只載入目前和下一個可能要放的曲子 |

- 合計第一季約 **35 MB**，全部延後、依區域載入；第一次進遊戲只多下載約 1 MB。
- 兩種格式並存，是因為 Opus 在部分舊 Safari 上不能播。由開發在實作時用 `canPlayType` 選。
- 程式合成的音效不佔檔案大小。

## 5. 音量分軌與設定

- **四軌**：主音量、音效、音樂、環境。各有 0～100 滑桿和靜音鈕。
- 主音量乘到其他三軌上；設定存在瀏覽器（和現有的播放速度設定同一處）。
- **預設**：主 70、音效 80、音樂 50、環境 60。第一次進遊戲時，在設定按鈕旁提示「可以調整聲音」。
- **自動播放規則**：瀏覽器規定在使用者第一次點擊之前不能出聲，所以音訊在第一次點擊後才開。
- **閃避同時播太多**：
  - 同一個音效同時最多 3 個；
  - 同一個時間點（同一個 `hitAt`）多個目標受擊，只放 1 個命中音，音量依人數略增；
  - 音樂在戰鬥中、說書人字幕出現時，自動壓低 30%（ducking）。
- **切到背景分頁時**：預設靜音，設定裡可以關掉這個行為。
- **播放速度**：跳過、按住空白鍵加速時，音效不變調，只跳過被略過的片段；跳過時不補放。

## 6. 減少動態與無障礙

| 設定 | 聲音怎麼做 |
|---|---|
| 系統「減少動態」 | 聲音照常（聲音不是動態）；但和畫面震動、停頓綁在一起的低頻衝擊音（Boss 大招、爆炸）改成較柔和的版本 |
| 新增「減少刺耳音效」（設定裡的開關，預設關） | 拿掉高頻尖銳音（暴擊尾音、雷）、低頻轟鳴；所有音效上限 −6 dB |
| 視覺替代 | 重要的聲音都有畫面提示：Boss 預告、輪到我方、任務更新本來就有字或圖示，**不能只靠聲音傳遞資訊** |
| 聽障 | 說書人本來就是文字，不做語音；環境中的重要聲音（例如遠處的爆炸）在戰鬥紀錄有一行字 |
| 靜音 | 一鍵全部靜音（快捷鍵 `M` 已被大世界圖用；建議用設定面板的按鈕，或 `Shift+M`） |
