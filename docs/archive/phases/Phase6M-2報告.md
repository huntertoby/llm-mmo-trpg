## 做法

### 1. 武器統一「握把在原點、作用端朝 -y」

**沒有重畫任何武器輪廓**，這是最保守的做法：
- 每種武器記下它的作用端 `tip`，座標用現有的輪廓座標，握把＝手＝原點；
- 由 `tip` 算出「現有座標 → 統一座標」的旋轉 `base`；
- 統一座標下，作用端正好在 `(0, -len)`。

畫的時候：
- **給了 `wpn`**：轉 `wpn + base`，等於在統一座標下轉 `wpn`；
- **沒給 `wpn`**：照現有的傾斜角度 `restLean`，畫布指令和 6M-1 完全相同。

每種武器只有側面、正面兩個預設握法角度：`holdOf ＝ restLean − base`。

**涵蓋範圍**：`KNOWN_KINDS` 的主手、副手武器 kind 全部都有，共 19 種 kind、53 種 kind＋形制。需求指定要補的都在裡面：

| 需求列的武器 | client 的 kind／form |
|---|---|
| 刀 | `sword` 加 `curved` |
| 弩 | `crossbow` 的 3 種形制 |
| 火槍 | `longgun`、`pistol`、`shotgun`，各 3 種形制 |
| 拳套 | `fist` 的 3 種形制 |
| 鞭 | `whip` 的 3 種形制 |
| 鐮 | `scythe` |
| 成對武器 | 兩手各用該武器的座標 |
| 魔導劍 | `sword` 加 `arcane` |
| 法球 | `orb`，副手 |

另外也涵蓋：
- 拂塵、符紙、傀儡線；
- 法杖的 5 種形制。

**作用端的選法**：
- 刃類取刃尖；
- 長柄（斧、錘、矛、戟、鐮）照樣張，取柄的頂端或頭部頂端；
- 槍、弩取槍口、箭頭；
- 弓取箭的方向，`(-6, 0)`；
- 法杖取杖頭的球心；
- 法球取球心；
- 鞭取鞭梢；
- 傀儡線取線的末端（往下垂）。

### 2. `wpn`、`pull`

- **`wpn`**：武器相對手的角度。
  - 用統一座標：0 ＝ 作用端朝上，順時針為正。
  - 武器的絕對角度＝`arm`＋`elbow`＋`wpn`。
  - **只在側面的主手生效**，照樣張 `storyDoll.js` 的 `side && POSE.wpn`。
  - 正面、背面一律用預設握法。
- **`pull`**：弓弦的中點往握把的反方向拉開。
  - 大於 0.5 時搭上一支箭，箭頭在作用端的前方；
  - 四個朝向都有作用。
  - `pull` 是 0 時，弓的畫布指令和原本相同。
- 側面的副手（遠側那隻手）不吃 `wpn`，用預設握法。

### 4. 異形 4 個通用片段

整隻身體以腳底為準做下面這些變化，不拆關節：
- 伸縮：`sx`、`sy`；
- 傾斜：`rot`；
- 位移：`dx`、`dy`；
- 透明度：`alpha`。

每個片段都是時間的純函式，不用 `Math.random()`。

| 片段 | 長度 | 內容 |
|---|---|---|
| 走 `walk` | 900 毫秒，循環 | 一個循環兩步：身體被撐起 1.4、落地時略扁、前後微微搖。浮空的身形改成上下飄 |
| 撲 `pounce` | 520 毫秒 | 先壓低、往後縮 2.5，再拉長、往前上撲出 13（離地 9），落地時壓扁，最後退回原位 |
| 受擊 `hit` | 360 毫秒 | 往後彈 6、往後仰、被打扁一點；開頭有白閃 `flash` |
| 倒下 `fall` | 600 毫秒，停在最後一格 | 往後倒 0.35、塌扁到 45%、變淡到 55%，落地時彈一下 |

- 地上的影子不跟著動。
- 精英詞綴的特效跟著身體動。
- 沒給姿勢時，`drawCreature` 的指令流和原本相同（快照鎖住）。

## 測試結果

- `vitest run src/render src/dev`：42 個檔案、444 項全部通過。
  - 新增 14 項：武器 8 項、異形 6 項。
  - 6M-1 的「`wpn` 沒給＝現有握法」那一項，改成新的意思：「給劍側面的預設角度 0.75 ＝ 沒給」。
- `tsc --noEmit` 通過。
- `pnpm build` 成功，只有原本就有的 chunk 大小提示。
- 畫廊的瀏覽器主控台沒有錯誤。
- vite 用 5295 埠，用完已經停掉。

武器朝向測試的內容：
- 53 種武器在朝東、朝西出招的瞬間，作用端都在手的前方。出招瞬間的姿勢照樣張的揮砍、突刺、射擊、施法片段；檢查 `(tip.x − hand.x) × 朝向 > 1`。
- 正面、背面時，手到作用端的距離＝武器長度。沒設姿勢、站好（REST）兩種都測。
- 統一座標下，作用端在 `(0, -len)`；記下的作用端落在畫出來的輪廓上（3px 內），握把在手上。
- 除了點狀的弓、法球、符紙以外，作用端離握把的距離，至少是武器最遠點的 80%。
- 沒設姿勢、站好時，側面的作用端都不朝後。弓和傀儡線例外，見待決 1。
- 成對武器：主手出招時作用端在前；副手站好時不朝後。
- 新增武器 kind 自動檢查：`KNOWN_KINDS` 裡任何沒有作用端的武器 kind 會讓測試失敗。

## 待 PM 決定（都已照最保守的做法做完）

1. **弓在側面的預設外觀是「弓弦朝前」**：
   - 現有畫法的弓身往 -x 彎，弓弦在 +x，所以箭的方向朝後。
   - 為了維持快照，沒設姿勢和站好時都沿用這個外觀；出招時由 `wpn` 轉到朝前（測試通過）。
   - 要不要把站好時的弓改成「弓身朝前」？改了戰場上的弓會變，需要美術 PM 決定。
   - 傀儡線往下垂，站好時作用端在手的下方，屬於正常外觀。
2. **`wpn` 只在側面主手生效**：照樣張。正面、背面的鏡像規則各武器不同（例如斧頭正面翻轉），如果要支援，需要另外定義正負方向。
3. **長柄武器的作用端取柄的頂端**（照樣張的鐮刀）。斧、戟、鐮的刃其實在柄的側邊。之後技能從作用端發出時，如果想從刃發出，要再調。
4. **圖騰杖側面沿用現有畫法，往前挪 2px**，所以握把離手 2px。測試已經把這個列為例外。
5. **異形受擊的白閃 `flash` 只是資料欄位**：`drawCreature` 不畫白閃，由之後的戰場播放疊上去。畫廊用半透明白色示意。
6. **異形片段還沒接進戰場**：
   - 和 6M-1 的人形姿勢一樣，貼圖快取鍵沒有包含姿勢；
   - 撲擊的位移是原地衝出再退回，實際的移動距離由引擎事件決定，留給之後串接技能時處理。
7. **建立的檔案**：worktree 原本沒有 `node_modules`，`pnpm` 照 lockfile 裝了既有的相依；另外 `uv run` 在 worktree 產生了 `.venv`（已被 gitignore）。兩者都沒有新增相依套件。

沒有新增 `# noqa`（或 eslint 例外）。
