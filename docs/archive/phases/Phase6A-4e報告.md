## 1. 做了什麼

### 1.1 版面 A 戰鬥版

檔案：`screens/BattleScreen.tsx`、`styles/battle-hud.css`。

戰場用滿整個畫面，HUD 疊在四周。舊的頂端列、右側窄欄、三條拖曳分隔線都拿掉了。

| 位置 | 內容 |
|---|---|
| 左上 | 主角卡，沿用 6A-2 的 `Hud`：HP、法力、耐力三條＋圖示列＋「詳細」。選技能時，選取面板（`ModePanel`）接在主角卡下面 |
| 上方中央 | 行動順序（`TurnBar`）：改成圓形小章，有陣營底色、字母、HP 小條；行動中的亮金框。滑過看名稱、HP、召喚資訊 |
| 右上 | 戰況框（新的 `ui/BattleStatusBox.tsx`）：地名、回合數字、天氣圖示、勝利條件圖示（撤離／守點另標剩幾輪）。說明都是滑過看 |
| 右上框下方 | 工具鈕列（`ui/BattleTopBar.tsx` 改成圖示鈕，圖示在新的 `ui/BattleToolIcons.tsx`）：環境預告、反應設定、隊友指令、圖例、版面、存檔（一輪）、離開。彈出面板照舊用 `usePopupMenu` |
| 工具鈕下方 | 依序疊：環境預告面板（點沙漏開關，記住開關狀態沿用舊的窄欄收合設定）、召喚物面板、釘選小卡 |
| 底部 | 技能列＋回合操作（`BattleBottomBar` 拿掉主角卡），置中排成一列 |
| 左下 | 紀錄浮動提示（6A-3），位置在底部列上方 |
| 右下 | 縮放鈕，位置在底部列上方 |

外觀：
- 主角卡、戰況框、工具列、行動順序、技能列、回合操作都改成 `rgba(24,20,16,0.84)` 深底＋`#c8a868` 金邊。
- 選取面板、紀錄展開面板維持原本的深色，沒有改。

地圖可用區域：
- 上方扣掉行動順序列（52px），下方扣掉量到的底部列高度（CSS 變數 `--hud-bottom`，`battle/hudLayout.ts`），左右扣掉兩欄寬（252／224；窄於 900px 時 230／210）。
- 這樣主角卡和戰況框不會蓋住地圖邊上的單位；自動填滿照這個區域算。

6A-4c 的「選取時紀錄縮短」改成用紀錄自己的底邊來算（`useLogRoom`），因為紀錄已經不貼戰場底邊。

「版面」面板拿掉右側窄欄寬、底部列高、主角卡寬三條滑桿（在版面 A 沒有作用），只留地圖縮放、震動、地形卡收合、操作說明重設。

### 1.2 字母標記

- `buildDrawModel` 多一個選項 `{ markers: false }`（`BATTLE_DRAW`）。戰鬥畫面用這個選項，戰場上不畫字母。
- 字母只出現在兩處：行動順序列的小章，以及滑過單位時的資訊卡（`UnitInfo` 本來就有 `unit-badge`）。
- 世界畫面（`fieldModel`）照舊用預設值，沒有影響。

### 1.3 大世界戰鬥的地名

- `battle/placeName.ts`：
  - `worldPlaceName(world)`：實地地圖名優先，再來是地點名；
  - `battlePlaceName(view, place)`：有地點名就用地點名，沒有就用 `map_name_zh`。
- `WorldScreen` 開戰時把 `worldPlaceName(view)` 傳給 `BattleScreen` 的新 prop `placeName`。
- 循環賽重播傳 `null`，照舊顯示地圖名。
- 一輪（roguelite）和工坊不傳，照舊顯示地圖名。
- 地圖檔、戰鬥設定、伺服器都沒動。

## 4. 待 PM 決定（都已照最保守的做法做完）

1. **戰場上的字母只拿掉字，圓底還在**：
   - 字母圓章是 `render/unitSprite.ts` 畫的，照限制不能動 render，所以現在只把字傳成空字串，腳邊還會留一個沒有字的黑色小圓（截圖看得到）。
   - 要完全拿掉，需要在 render 的那段加一行判斷，例如 `if (u.marker !== "")`。建議 6M-3 合併後由開發 PM 排一個小改動。
2. **地圖不蓋到左右兩欄**：
   - 地圖可用寬度扣掉主角卡和戰況框的寬度，避免蓋住地圖邊上的單位（第一版實測主角卡蓋到我方單位）。
   - 代價是 800×600 時地圖縮到約 65%；1040 以上幾乎沒有影響。
   - 樣張是地圖鋪滿、HUD 疊在上面；要改成那樣，只要把 `.board-scroll` 的左右 inset 改回 0。
3. **紀錄放在底部列上方，不和技能列並排**：
   - 800 寬時並排放不下，所以三種大小一律放在底部列上方。
   - 1600 寬時左下角下方會空著。
4. **工具鈕全改成圖示**（滑過看名稱），「離開」也是圖示：
   - 存檔結果原本是工具列旁的文字，改成上方提示列的一則訊息，6 秒後消失。
5. **環境預告的位置**：放在右上工具列下面，可以收合（沙漏鈕）。
   - 預設開關沿用原本窄欄的規則：寬度 1100 以上展開，以下收合；記住的開關也沿用同一個設定值。
6. **循環賽重播顯示地圖名**：重播是過去的比賽，不是現在的地點，所以不帶地點名。
7. **地名來源**：大世界用 `field.name_zh ?? here.name_zh`，和城鎮 HUD 的地名條同一個規則。
8. **沒刪掉的舊東西**：
   - `SidePanel.tsx`、`ResizeHandle.tsx`、`layoutPrefs` 的欄寬與列高、`battle-layout.css` 的舊選擇器，戰鬥畫面已經不用了，但我沒刪，避免影響其他段落；
   - 可以在下一段清掉。
9. **選取面板、展開的紀錄面板沒有換成金邊外觀**：規格只寫四角 HUD，所以這兩個照舊。
