# Phase C-3 報告｜召喚物 17 種換成 C 手繪墨線畫風

規格：`docs/phases/PhaseC畫風計畫.md` 的 C-3；需求 `docs/art/C畫風移植需求.md` 第 1、6 節與檢查清單「召喚物」；規則 `docs/art/召喚物外觀.md`。只動前端，沒動 Python、引擎、`docs/art/`、計畫檔。

## 做了什麼

| 檔案 | 內容 |
|---|---|
| `client/src/render/summonArt.ts` | 非人形五種體型（漂浮靈、構造體、野獸、植物、圖騰）全部改用 `ink()`／`stroke()`／`dot()`（輪廓座標沿用舊畫法）；拿掉 8 方向黑色剪影外框；`bodyCanvas` 只剩「地面影子層＋身體層」。影子改成 `shadow()` 一排短斜線（半寬依體型）；水精水窪與圖騰 `aura` 光環畫在地面層（光環用 3J-5 的 `drawFormAura`：元素色虛線橢圓＋18% 填色，無元素 `#9a86ff`）；藤蔓整體半透明 0.9 改在合成時套用。暗面方向：朝南（正面）在右，其餘在左。公開介面（`resolveSummonLook`、`summonKey`、`drawSummonBody`、`drawSummonGround` 等）不變；不認得的體型／款式／元素／大小／特徵退回預設的規則不變。 |
| `client/src/render/summonArt.test.ts` | 「影子與水窪」那條改成新畫法的三條：影子是短斜線（無橢圓、無填色）、水窪與光環只在地面層、`ink()` 確定性（同外觀兩次畫出的呼叫序列完全相同、含墨色 `#2b1e16`、不含舊外框色 `#16121a`）。其餘既有測試（全組合不丟例外、背面不畫眼睛、朝西鏡像、鷹隼抬高 22、土牆無底圈、快取鍵、人形款式）原樣通過。 |
| `client/src/render/inkForm.ts`／`inkForm.test.ts` | PM 追加小修：樹人 `top` 56.5 → 59.5（頭頂狀態列再上移約 3px，葉冠與狀態列不貼在一起）；加測試鎖定。獨立 commit。 |

人形召喚物（骷髏戰士、影魅、殘影分身、守護靈）本來就用紙娃娃，已是 C 畫風（C-1a／C-1b 已換），這段沒動它們的程式；它們的透明度與外光（`humanoidCanvas`）原樣保留。

## 待 PM 決定

1. **沒有拍「實戰」截圖**：沒有現成的召喚 build 起始包，召喚物在實戰裡走同一個 `BattleRenderer` 與 `buildUnitSprite`（這段沒動），所以只以 gallery 為證；要實戰圖請開發 PM 或美術 PM 驗收時補。
2. **朝南北沿用側面畫法**（野獸）：沿用舊規則，同 3J-5 待決定第 1 點。
3. **暗面方向**：非人形朝南暗面在右、其餘在左（西朝鏡像後暗面會在右側）；若要西朝也在左，要在鏡像時反向。
4. **石塊與木柱用 `sharp` 的四角形**（構造體、圖騰、野獸的腿），看起來比水彩的圓潤部件硬；是刻意的（石頭、木頭），若美術 PM 想要更手繪的圓角再改成 8 點。
5. **光環半徑固定 20**（圖騰 `aura`，貼圖 64 寬），不隨 `size`；圖騰都是 medium，夠用。
6. **影子寬度**：短斜線的半寬由原本橢圓半徑換算（精靈 7、石像 12、傀儡 8、土牆 14、狼 14、鷹 6、圖騰 8、藤蔓 16），是目測值。
7. 人形召喚物（骷髏等）沒動；殘影分身複製召喚者仍走 C 版紙娃娃。
