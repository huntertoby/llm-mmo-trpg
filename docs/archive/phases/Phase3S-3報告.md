# Phase 3S-3 報告｜真側面：武器

## 做了什麼

- 新檔 `client/src/render/paperdollSideWeapon.ts`：純資料。每種主手 kind 在側面的握法（`front` 旗標、抵銷形狀內部旋轉的 `inner`、最後角度 `angle`、手位微調、遠側變暗）。`sideWeaponPose(item, far)` 取姿勢；不認得的 kind 用保守的前傾退回。
- `paperdoll.ts`：`drawWeapon` 多了 `far`、`side` 參數；側面時先套姿勢（形狀本身沿用正面畫法，不重畫），所以形制（錘三種、矛三種、槍／弩各形制…）全部自動涵蓋。新增匯出 `drawWeaponSide`（測試與預覽用）。
- `paperdollSide.ts`：`SideHooks.weapon` 加 `far`；遠側（成對武器的副手）畫在身後，顏色比主手暗 30%、角度與手位錯開，避免兩把疊在一起。
- **種族部件介面（給 3R-3）**：`SideHooks.race?(layer)`，三層 `behind`（披風後：尾、背刺）、`face`（頭後、頭髮前：鬍、獠牙、刺青、義體）、`head`（頭部裝備後：耳、角）；位置規則常數 `SIDE_RACE_ANCHORS`（耳、獸耳近／遠、角底座、尾、臉前半）。本段不畫種族部件。
- doll-gallery 新增「⑦ 側面・武器」五段：近戰與拳套、長柄／鞭／弓／弩、槍、成對武器、朝西。
