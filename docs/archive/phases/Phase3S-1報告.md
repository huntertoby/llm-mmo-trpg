# Phase 3S-1 報告｜真側面紙娃娃：骨架與圖層

## 做了什麼

- 新檔 `client/src/render/paperdollSide.ts`：側面成為紙娃娃第三套畫法（正面、背面之外）。移植自 `docs/art/sample/sideArt.js`（bodyTurn ＝ headTurn ＝ 1）。
  - 圖層順序：披風 → 遠側腿 → 近側腿 → 遠側手臂 → 身體 → 副手 → 頭 → 頭髮 → 頭部裝備 → 近側手臂 → 主手武器。
  - 身體寬 15 → 10、背側 16% 暗面；前襟、腰扣、胸甲亮片移到前緣；長袍、外套、骷髏肋骨各有側面版。
  - 兩腳前後錯開（遠側腿較暗、往前；近側腿往後），鞋尖朝前；靴筒、脛甲、鐵靴照 `bootHeight`。
  - 手臂：遠側藏在身後只露一點；近側往前擺並持主手武器；手套顏色套在手上。
  - 頭：臉往前移 4.2、只一隻眼、鼻子、近側耳朵在頭中後方；頭髮包住後腦（長髮在後）；骷髏只有一個眼窩。
- `paperdoll.ts`：`drawFigure` 在 `east`／`west` 時改走 `drawFigureSideView`；**朝西 ＝ 朝東整張 `scale(-1, 1)` 鏡像**（取代舊的「正面壓窄 10%」）。`south`、`north` 與倒地、外框、發光都不變。`paperdollGear.ts` 只多匯出 `bootHeight`。
- 影響範圍：所有走 `drawFigure` 的單位（英雄、敵人、人形召喚物）。形態、非人形召喚物、圖騰、裝備圖示不經這條路，未改。
- 3S-2／3S-3 的最簡退回（不會畫錯）：
  - 頭盔／角盔：沿用正面頭盔外形（以背面版畫、無護鼻片）＋護鼻片移到前方；兜帽：開口往前移、變窄（樣張版）。其餘頭部裝備 kind（巫師帽、寬帽、便帽、大盔、頭巾、王冠）沿用正面形狀。
  - 盾：窄橢圓擋在身前（大盾較高）。披風：樣張的背後垂下形。
  - 武器：沿用現有畫法（`front = true`），畫在近側手的位置；成對武器、拳套的副手畫在身後露出；書、法球畫在遠側手位置。**不鏡像、不加專屬側面角度**（3S-3 處理）。
  - 種族部件：未做（規格明列不在這段）。
