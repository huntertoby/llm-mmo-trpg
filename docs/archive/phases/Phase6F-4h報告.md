# Phase 6F-4h 報告：「倒地追獵」改成打擊骨架的「追印絆擊」

- 依據：6F-4g 報告待決 1、2（玩法 PM 決定，`docs/玩法PM交接.md` 3.5）。
- 分支：worktree 分支（未 push、未合併）。基底 `11d018d3`（含 6F-4g，`WORLD_RULES_VERSION` 16）。
- 只改 6F-4g 新增的那一招；掀地冷卻 2、手寫補位限近戰照舊。

## 1. 做法

用的是玩法 PM 的**第一個做法**：打擊骨架「對被標記的目標傷害較高＋擊倒」，拿掉「只能對倒地的目標用」。打擊骨架的比例檢查有過，所以不用退到第二個做法。

| | 6F-4g（倒地追獵） | 6F-4h（追印絆擊） |
|---|---|---|
| 骨架 | strike（單一效果） | strike（傷害＋1 個附帶效果） |
| 技能條件 | 目標倒地 | **無** |
| 效果 | 傷害 ×2.4（只傷被標記的目標） | 傷害 ×1.8（只傷被標記的目標）＋**擊倒**（不帶條件） |
| AP／冷卻／耐力 | 2／1／8 | 2／**2**／8 |
| 標籤 | physical、melee、mark | physical、melee、mark、**control** |
| 預算 | 81% | **87%** |

- **ID 沿用** `skill_prone_mark_strike`：
  - 名字裡的 prone、mark 仍然對得上（製造倒地、利用標記）。
  - 改 ID 會讓 3W-R2 閃現對照的「ID 排序等距取樣」整批換位，快照變動大很多；沿用時只變這一招自己的雜湊。
- **名稱**「追印絆擊」照玩法 PM 定的。
- **冷卻 1 → 2**：和碎骨重擊（傷害＋擊倒，冷卻 2）一致。冷卻 1 也過預算（AP 2、冷卻 1、×1.8 是 92%），但帶擊倒的手寫招都是冷卻 2，取保守值。
- **傷害的寫法**：沿用專案裡「利用者：對〇〇的目標傷害較高」的慣例（居高追獵、涉水雷擊等），也就是傷害效果帶條件，**沒被標記的目標只會被擊倒、不受傷**（待決 1）。
  - 打擊骨架的附帶效果最多 1 個，原語也沒有「對某狀態加傷」的欄位，要「基礎傷害＋對標記額外加傷」得放兩段傷害，那就不是例子裡的形狀了，所以沒做。
