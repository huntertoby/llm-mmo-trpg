## 1. 交付內容

只動 `client/`。**沒有改伺服器**：需要的資料（`max_stamina`、`shield`、`tags` 的 `elite`、`traits_zh` 的精英詞綴句…）`UnitView` 都已經有，OpenAPI 不用重產。

### 1.1 共用零件

- `client/src/ui/statusCard.ts`（純函式）：
  - `barData()`：條上的字（「HP 41 / 50」「法力 18 / 30」「耐力 6 / 8」）與說明卡；`barFill()`：填滿比例與護盾段的位置。
  - `heroChips()`／`unitChips()`：一排圖示＋數字；`apChip`、`moveChip`、`reactionChip`、`sourceChip`、`ammoChip`。
  - `statusCorner()`：狀態右下角的字（剩餘回合，沒有回合時寫數值）。
  - `affixBadges()`：精英詞綴徽章（從特性欄的「精英詞綴「X」：…」那一句取出）。
  - `togglePin()`、`pinnedUnitOf()`：釘選邏輯。
- `client/src/ui/StatusCardParts.tsx`：`StatBar`、`StatChipView`、`StatusBadge`、`StackBadge`、`SurfaceBadge`。圖示照 `textless.html` 的 symbol 畫；AP、法力、源力、反應沿用 6A-1 的 `ChipGlyph`。
- `client/src/styles/status-card.css`（在 `index.css` 中排在 `float-card.css` 之後）。
- `SkillIconView.tsx` 只把 `TileCanvas` 改成 export（狀態／表面小圖共用）。

### 1.2 主角狀態卡（`Hud.tsx`）

- 三條一樣粗（都是 `.stat-bar`，16px），條上寫字：
  - HP `#e04a3a`、法力 `#4a8ae0`、耐力 `#c8a030`。
- 護盾：HP 條上疊一段淺藍。條上的字不寫護盾，數字放在說明卡（「HP 41 / 50／護盾 5」）。
- 原本的 `hud-chip` 徽章（AP、移動、反應、源力等文字晶片）和條右邊的「數字」欄都拿掉了。
- 下面一排：
  - AP 圓點（5 點以上改寫數字）、移動（靴子＋數字）、彈匣（有彈匣才畫）；
  - 反應（用過變灰）、源力 3 點；
  - 狀態圖示（右下角寫回合數或數值）、層數（右下角寫層數）、腳下表面。
- 冷卻不再列出（技能列按鈕上已有）。
- 收進「▸ 詳細」（`<details>`）：裝備充能、種族、生效中的傳說、暫時技能、召喚物、持續區域。沒有這些時不畫「詳細」。
- 窄螢幕（< 1100px，例如 800×600）原本是一行字，現在改成「三條橫排＋圖示」一列，沒有「詳細」。
- `statusLine`、`surfaceUnder`、`compactHudText` 照舊 export（其他測試與模組有用到）。

### 1.3 單位小卡（`UnitInfo.tsx`）

- 標題：
  - 隊伍字母徽章，滑過看「我方／敵方／第三方」；
  - 名稱；
  - 「主角／召喚種類／倒下」這類標籤照舊用小字列出；
  - 精英詞綴金色徽章「◆ 狂暴」，滑過看特性欄那一整句；有 `elite` 標籤但沒有詞綴句的（例如盜賊頭目）只寫「◆ 精英」；
  - 圖釘按鈕「釘選／取消釘選」。
- HP 條與耐力條：和主角卡用同一個 `StatBar`，一樣粗、寫字。
- 圖示＋數字：護盾（有才畫）、法力（有上限才畫）、AP、移動、武器（名稱，滑過看武器特性）、彈匣。
- 狀態圖示＋回合數、層數、腳下表面圖示。
- 朝向那一列拿掉了。
- 「▸ 詳細」裡照舊列出其餘資訊，沒有刪：
  - 特性與詞綴說明、Boss 階段、速度、武器特性、彈匣、副手、種族、位置；
  - 召喚者、灌注、模式、光環、形態；
  - 裝備、裝備加成、充能、冷卻。
- 釘選（`BattleScreen.tsx`）：
  - 按圖釘後，小卡放進戰場右上角的 `.unit-pin-dock`。有召喚物面板時，改放在面板左邊；
  - 釘選**跟著單位**，不是跟著格子。資料用播放中的視圖（`shown`），所以敵人回合單位移動、扣血都會即時更新；
  - 同時只能釘一張；再按一次就取消。單位不在戰場上了（例如撤離）就不畫；倒下的單位照常顯示；
  - 原本格子資訊卡的「點一下釘住格子」照舊，兩者分開。小卡右上的圖釘有讓出格子卡的圖釘位置。

### 1.4 說明卡（每條條、每個圖示）

第一行是「名稱 現值」，下面接現有的句子，沒有另外寫新文字：

| 元素 | 說明卡內容 |
|---|---|
| HP 條 | 「HP 41 / 50」＋護盾數字（有護盾時） |
| 法力條 | 「法力 18 / 30」 |
| 耐力條 | 「耐力 6 / 8」＋`actionCardText("stamina")` |
| AP | 「AP 3（下回合保留 +1）」＋HUD 原本的「剩餘行動點數（…）」 |
| 移動 | 「移動 3」＋「剩餘移動點數」＋`actionCardText("move")` |
| 反應 | 「反應 可用／已用」＋HUD 原本的「本輪還能反應嗎」 |
| 源力 | 「源力 1/3」＋HUD 原本的源力說明 |
| 彈匣 | HUD 原本的彈匣說明 |
| 護盾、法力（小卡） | 「護盾 5」「法力 4 / 10」 |
| 武器 | 「武器 名稱」＋`weapon_traits_zh` |
| 狀態 | `statusLine`／`statusText` 的狀態句＋名詞對照表的說明與規則 |
| 層數 | 原本的 `StackTip` 內容 |
| 腳下表面 | 「油（2 輪）」＋名詞對照表的規則 |
| 詞綴徽章 | 特性欄的「精英詞綴「X」：…」整句 |

- 條與圖示用 `Hint` 包住 `<span>`／`<div>`，所以觸控照 6A-1 的規則：沒有動作，點一下就開說明。
- 狀態、層數、表面用 `PartTip`：點一下釘住，觸控一樣可用。

## 4. 待 PM 決定（都已照最保守的做法完成）

1. **裝備充能沒有完全拿掉**：
   - 規格寫「充能、冷卻只畫在技能列」。冷卻在技能列按鈕上本來就有，所以從狀態卡拿掉了；
   - 但裝備充能（靜電之類）的層數目前只有 HUD 顯示，啟動在「更多動作」選單裡，技能列上沒有。直接拿掉會讓資訊消失，所以先收進「▸ 詳細」；
   - 若要畫在技能列，需要另排一段。
2. **HP、法力、護盾沒有說明句**：現有文字裡找不到它們的說明，照「不另寫新文字」的規定，說明卡只寫名稱與現值。需要說明句的話，請玩法 PM 給文字。
3. **AP 圓點只畫目前有的點數**：視圖裡沒有 AP 上限，所以用掉的點不會畫成空心點。AP 為 0 時畫一個空心點並變灰。
4. **層數圖示**：每種層數都用同一個「疊塊」圖示＋右下角數字，名稱看說明卡。要不要每種層數各畫圖示，請美術 PM 決定。
5. **主角卡的「詳細」**：規格沒寫種族、傳說、暫時技能、召喚物、持續區域要放哪裡，為了不刪資訊，都收進「▸ 詳細」。窄螢幕版放不下，所以沒有這些（和改版前的一行字一樣，那時也只寫了種族）。
6. **釘選位置**：放在戰場右上（照 `battle-d.png`）；有召喚物面板時放在面板左邊。800×600 時小卡會蓋住戰場右側一部分，可以隨時取消釘選。
7. **精英徽章文字**：只有 `elite` 標籤、沒有詞綴句的單位（例如頭目），徽章寫「精英」，說明卡也只有「精英」兩字（沒有現成的說明文字）。
8. **既有問題，沒有改**：敵人的冷卻在「詳細」裡會顯示技能 ID（例如 `skill_cleave 2`），因為前端只有主角技能的名稱。這是改版前就有的，要修需要伺服器提供敵人技能名稱。
