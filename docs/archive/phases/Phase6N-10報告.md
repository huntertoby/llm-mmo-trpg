## 做法

### 1. NPC 小動作（接在 6M-4 的待機上）

**呼吸**
- 照 6M-4 的 `breathScale`。

**每人 3～4 種小動作**

| 身分 | 小動作 |
|---|---|
| 鐵匠 | 搥打（舉高、往下搥，來回 3 趟，1.8 秒）、張望、擦汗、伸懶腰 |
| 掌櫃 | 擦桌子（前傾、手來回 2 趟，1.6 秒）、張望、伸懶腰、搔頭 |
| 一般 | 張望、伸懶腰、搔頭 |

- 職業動作在挑選清單裡放了兩到三次，所以出現得比較常。
- NPC 每人 4～7 秒一次，比主角的 7～11 秒勤快。

**挑哪一種**
- 照第 0 節第 3 點，用「地圖 ID:單位 ID:動作序號」的 FNV-1a（`inkStyle.seedOf`）。
- 間隔與偏移用單位 ID 的雜湊錯開。
- 沒有 `Math.random`，也不讀時鐘。

**貼圖量化（照 6M-3）**
- 強度量化成 4 級，來回量化成 3 級，鍵以 `n:` 開頭。
- 測試鎖住：鐵匠 120 秒內最多 30 個鍵（實際更少）。

**身分怎麼來（伺服器沒有 NPC 職業欄位，不新增）**
- 看 NPC 2 格內（切比雪夫距離）有沒有設施：
  - `smithy`、`enchanter` ＝ 鐵匠；
  - `tavern`、`hire`、`shop` 與兩個酒館人物設施 ＝ 掌櫃；
  - 都沒有 ＝ 一般。
  - 兩種都有時，鐵匠優先。
- 套用範圍：只有實地地圖的 NPC。主角、朋友影子、戰場單位照 6M-4 不變。

### 2. 環境動態

| 項目 | 做法 |
|---|---|
| 營火 | 火苗貼圖疊在營火標記上，三個正弦疊起來做閃動，往下風偏一點；暖光是加亮混色的光暈，呼吸週期 1.8 秒 |
| 燈籠 | 酒館屋簷下每扇窗一盞（位置照 `townArt` 的 `lantern`）＋室內 `candle` 燭台：光暈呼吸、閃得輕 |
| 草叢、竹叢 | `grass` 物件的貼圖改成以底邊為軸做斜切，往下風傾、來回擺；每叢相位錯開。雲嶺的 `grass` 畫法就是矮竹叢，所以竹葉也算在內 |
| 酒旗 | 新畫一面酒旗：米白布、朱紅邊、酒罈圖示，不寫字。立在酒館門面右端，4 格貼圖輪流；往西吹時以旗桿為軸翻過來 |
| 水波 | `ice_hole` 地形（冰洞）每格兩圈橢圓波紋，錯開半個週期往外擴散 |
| 薄霧 | 有區域薄霧的地圖（雲嶺，室內除外）：3～12 團霧順著風慢慢漂，出了圖從另一邊回來；霧天更濃 |

- 風向：地圖資料沒有風向，用場景鍵（地圖 ID）的雜湊定東或西，風力 0.6～1.0。天氣名稱有 wind、storm、blizzard 等字時風力加 0.4。
- 新增的貼圖：
  - 光暈、火苗、水波、霧各 1 張，酒旗 4 張，共 8 張；
  - 全部在 `draw` 時取（`ArtTextures` 每輪清掉沒用到的）；
  - 其他效果都是節點的縮放、斜切、透明度、位移，不新增貼圖。
- 只動畫面，地圖資料、規則都沒動。

### 3. 介面動畫

| 項目 | 做法 |
|---|---|
| 傷害數字 | 從 0.6 倍彈過頭再落回 1 倍（前 22%），往上飄，最後 30% 淡出。暴擊從 0.5 倍彈起、停在 1.15 倍（字本來就大一號）。狀態字樣也一起彈 |
| 延遲血條 | 白色殘量放在填色下面，純 CSS 轉場：掉血時停 0.35 秒，再用 0.6 秒縮回；補血時被填色蓋住看不到。套在世界 HUD 的主角與隊友 HP 條、戰鬥 HUD 的 HP 條 |
| 升級 | 同一個角色等級變高時，主角腳下升起光柱、一圈光環、浮出「Lv N」，1.4 秒；HUD 的 Lv 數字沿 X 軸翻一下（第一次畫出來不翻） |
| 拿到物品 | 背包＋腰包＋身上裝備的總數（依物品 ID）變多時，物品圖示從 HUD 中央（鏡頭跟著主角）拋物線飛進背包鈕，0.75 秒，一次最多 3 個、每個晚 0.12 秒出發。放進腰包、穿脫只是換位置，不算拿到 |

- 拿到物品的圖示：裝備是一把劍，其他是布袋，見待決 4。
- 物品飛行是 HUD 裡的絕對定位，z-index 6，不是彈出層，所以符合浮動卡規則（`floatCardRule.test.ts` 通過）。

### 4. 減少動態（`prefers-reduced-motion`）

- 環境動態停在第 0 毫秒的樣子。
- NPC 與所有人的待機都不跑：一律站好、不呼吸，見待決 2。
- 傷害數字直接顯示：不彈、不飄、不淡，到時間收掉。
- 延遲血條沒有轉場，Lv 不翻。
- 光柱靜態顯示 1.4 秒後收掉。
- 物品不飛，直接在背包鈕上出現再淡出。
- 系統設定中途改變時，繪製器會跟著切換。

### 5. dev 頁 `ambient-gallery.html`

- `#all`：
  - 雲嶺小鎮一張圖：酒館、酒旗、燈籠、營火、竹叢、冰洞、薄霧，石師傅（鐵匠）、柳掌櫃（掌櫃）、渡婆婆、小蓮。
  - 下面一排介面動畫，每 3 秒重播：傷害數字、暴擊、治療、延遲血條、Lv 翻動、升級光柱、物品飛進背包。
- `#npc`：只有地圖；`#ui`：只有介面。
- `?anim=0.1`：環境動態放慢 10 倍。`?still=1`：關掉待機與環境動態。
- `window.__pick(0|1)`：把時鐘撥到「鐵匠在搥（0 ＝ 舉高、1 ＝ 搥下）、掌櫃在擦桌子」的那一刻，截圖用。
