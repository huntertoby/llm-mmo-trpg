## 5. 待 PM 決定（都已照最保守的做法做完）

1. **小蓮的位置**：草稿把小蓮放在霧渡鎮，但 18.5 與人設卡都寫在青霧觀（`location: mist_temple_gate`），放在霧渡鎮會讓 NPC 檢查報錯。我照人設卡放在青霧觀山門。
2. **導師青崖**：草稿寫「技能導師青崖（站在街上）」在霧渡鎮，但他的人設卡在青霧觀山門。所以霧渡鎮照 6B-1 只放導師堂設施；青崖本人站在青霧觀山門，那裡不另加導師設施。如果要他兩地都在，得改人設卡（不在這段範圍）。
3. **陷阱坑**（獵戶小屋）：現有地形、物件、表面都沒有陷阱，0.2 第 6 條又不准新增 ID，所以這段不畫，只寫在 YAML 註解。
4. **渡婆的屋子**：「只有門口」。門必須通往室內圖或隱藏地點，所以畫成建築，加上門口的 NPC 與事件點，沒有門。
5. **日夜**：渡口石階的巡邏（草稿：夜晚多一隊）、`lantern_patrol`（夜晚）。`spawns` 與 `event_spots` 沒有日夜欄位，所以一律畫上；事件骨架本身有 `day_phase`，巡邏要不要只在夜晚出現，由 6C-1 決定。
6. **棧道與碼頭**：斷崖幫寨的木棧道、霧渡鎮的碼頭、往荒原的長棧橋都用石地或泥土地形畫，不用 `wooden_bridge` 物件，免得唯一的通路被打斷。測試也檢查「拿掉木橋後照樣走得到」。代價是木棧道燒不掉。
7. **水**：沒有水的地形，所以水田、小溪用水表面（`water`），雲海、峽谷用深淵（`chasm`）。竹叢用 `dead_tree`（擋視線、可燃、可推倒），稻草人、古松也用 `dead_tree`；石祭壇、石棋盤、曬肉架用 `low_wall`；香爐用 `oil_barrel`。外觀等 6B-ART1、6C-ART。
8. **出口方向的微調**：
   - 斷崖幫寨往雨中梯田（草稿「寨西北」）放在西邊緣 y=7～9，因為北邊是峭壁。
   - 霧渡鎮往渡口（草稿「西南」）放在南邊緣的 x=3～4，理由見第 3 節。
   - 其他出口的方向都照草稿第 2 節的表。
9. **營火與事件點的 ID**：營火叫 `campfire_<地點>`。事件點的 id 就是事件骨架 ID。這兩種 ID 6C-5 接的時候可以再改。
10. **傳送石數量的警告**：規格說 6C-4 交件時雲嶺要有「傳送石 3 個加城鎮 1 個」，共 4 個。但 `fields.STONES_PER_REGION` 是 2～3，而且城鎮的也算在內，所以 6C-4 畫完會出現「傳送石 4 個，應為 2～3 個」的警告。要改成「不含城鎮 2～3 個」或改數值，需要改 `src/`，不在本段範圍。
