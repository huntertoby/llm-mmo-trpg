## 1. 「灌」字 → 小水滴（必修 1）

**先試 12px**（只改這個字的下限，其他數字照舊 10px）：`6f13_1_glyph12_1600`、`_1040`、`_800`，以及各自的 `_zoom`。
- 1600 寬讀得出來。1040、800 寬還是一團白（筆畫 21 劃，12px 時筆畫間距不到 1px）。
- 另外 12px 時圓變大，800 寬畫面直徑約 18px，蓋掉身體左半邊；和右上的回合數徽章（約 15px）合起來比格子（31px）還寬，第 2 項的「左右分開」做不到。

**結論：改成程式繪製的小水滴**（`unitSprite.dropPath`）。
- 紫色（照舊用灌注色 `0xc77dff`），加深色描邊和左上一點白色反光，**沒有黑底圓**。
- 選水滴不選藥瓶：灌注的意思是「倒進去」，水滴一眼看得出來；外形只有一個輪廓，10px 時也不會糊。藥瓶要瓶身、瓶口、液面三層，10px 時分不出來。
- 大小：高 12、寬 8.5（世界座標）。地圖縮小時整顆反向放大，畫面上至少高 10px（`MIN_INFUSED_ICON_PX`，和狀態圖示一樣）。
  - 1600 寬：倍率 1，約 15px
  - 1040 寬：約 10px（倍率 1.05）
  - 800 寬：約 10px（倍率 1.29）
- 排位置用的形狀（`badgeShapes`）：下半圓＋外接方框。

## 2. 800 寬擁擠的召喚物（必修 2）

- **有灌注時，狀態列只顯示「+N」**：精簡列（縮放 ≤ 85%，1040 和 800 寬）且有灌注時，圖示全部藏起來，只畫「+N」。
  - N 是全部的狀態數，召喚物的 3 個狀態顯示「+3」。
  - 實作在 `badgeLayout.chooseRowMode`：放中間、靠右、靠左三種，選第一個讓所有徽章都不碰任何東西的。
- **灌注不蓋「+N」**：「+N」的方框是灌注徽章每一層都要避開的形狀（`hard`），不會因為放不下而放寬。
- **兩顆徽章分開**：灌注在左上，回合數徽章在右上（原本就在右上角）。
  - 水滴沒有黑底圓，很窄，800 寬放得進左上角，不碰臉、不碰回合數徽章。
  - 身體露出的比例：用人形的外接框（寬 ±10、腳底往上 44）以 0.25 的格點取樣，兩顆合起來蓋住不到一半（測試鎖住）。
- **截圖（照原檔名覆蓋）**：
  - `6f12_1_infused_summon_800`、`_zoom`
  - `6f12_1_infused_summon_1600`、`_zoom`：水滴取代「灌」，所以 1600 寬也一起重拍
  - 800 寬：左上水滴、右上「3」、腳邊「+3」，三者不重疊，頭和身體看得到。

## 3. 跨格蓋到臉；徽章在「▲N」之上（必修 3）

**相鄰格的臉**（`badgeLayout.neighborFaces`）
- 只有南邊（y 較大）的單位頭會往上伸進這一格。
- 臉照標準人形的頭（`FACE`）。站得比較高時，再往上移高度差 × 6（`tileLift`）。
- 倒下的人不算（躺著）；北邊、左右的不算。
- 很高的格子也會算到兩排以外：▲7 以上才伸得進北邊第二排。
- 繪製器每次重畫時，替每個單位算一次，傳給 `buildUnitSprite`（轉身重建時沿用）。

**排位置**（`placeBadgeTier`）
- 每一層都先避開相鄰格的臉。
- 所有層都放不下，才不管相鄰的臉（`faceOk = false`）。這時徽章畫在那個單位的下層：南邊一排整排畫在後面。
- 自己的臉一律優先。

**圖層順序**
- 每一排多一層 `marks`（Pixi `RenderLayer`），位置在同一排的高度徽章 `badges` 之後、上層霧 `veil` 之前。
- 炸彈、蓄力、灌注徽章在這一層畫：
  - 在同一排的「▲N」之上（美術 PM 的決定）
  - 在南邊一排的單位之下
- 徽章節點照舊是單位圖層的子節點，位置、倍率、透明度跟著單位，只有畫的順序改變。
- 重畫、轉身、走路換排時都會重新接到該排的 `marks`（`RowStack.attachMarks`）。

**截圖**（同一幀，和第 1 項是同一張全圖 `6f13_1_badges_*`）
- **跨格**：`6f13_3_cross_1600_zoom`、`_1040_zoom`、`_800_zoom`
  - 盜賊隊長的炸彈在格子右側，往上讓開，不碰南邊 ▲1 上弓手伸進來的頭。
- **▲N 和徽章在同一格**：`6f13_3_height_1600_zoom`、`_1040_zoom`、`_800_zoom`
  - 弓手站在 ▲1 上，身上有灌注。水滴畫在「▲」三角形上面，右邊的「1」看得到。

## 4. 召喚物操控面板顯示技能名稱（小修）

- 原因：6F-12 截圖時只補了 `infused_skill_id`，沒補名稱，面板就退回顯示 ID。實機時伺服器會給 `infused_skill_name_zh`。
- 改成照這個順序找名稱：伺服器給的名稱 → 技能卡的名稱 →「灌注的技能」。**一律不顯示內容 ID**（`summonControl.infusedSkillName`）。
- 戰鬥畫面的技能卡會去抓召喚物待施放技能的卡片（`useBattleData`）。
- 截圖：`6f13_4_panel_800_zoom`、`6f13_4_panel_1600_zoom`（和 `6f12_1_infused_summon_*` 同一幀）。只補 ID 的狀態下顯示「待施放：寒鎖」。

## 6. 蓄力的「1」蓋住防禦圖示（小修）

- 數字的位置多了兩種（`NumCorner`）：右下（原位）、正下方、左下。同一層裡先試右下，放不下才換。
- 狀態列可以讓位（`chooseRowMode`）：
  1. 原本
  2. 整排靠右、靠左（圖示照舊；召喚物沒有這兩種）
  3. 精簡列才有：只留「+N」
  - 選第一個讓所有徽章都不碰任何東西的。
- 結果（盜賊1：蓄力＋防禦）：三種寬度都是防禦圖示整排靠右，蓄力的「1」換到圓的正下方，圓和數字都不碰防禦圖示。
- 截圖：`6f13_6_charge_1600_zoom`、`_1040_zoom`、`_800_zoom`（同一幀 `6f13_1_badges_*`）。
