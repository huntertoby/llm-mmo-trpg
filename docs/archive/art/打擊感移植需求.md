# 打擊感移植需求（交開發 PM，排在 6N-8 之後）

美術 PM，2026-11-04。專案 PM 轉使用者原話：「都做」（精緻化 5 項之一）。

使用者要的三件事：
1. 鏡頭微震：只在重擊、爆炸、Boss 大招時震，幅度很小；減少動態時關閉。
2. 停頓依傷害分級，一般的重擊也要有短停頓。
3. 最後一擊稍微放慢。

**原則**：只讀引擎事件，不改規則與數值；確定性（不用 `Math.random`、不讀時鐘）；跳過時都不做。

## 1. 現況（要改的地方）

| 項目 | 現在 | 位置 |
|---|---|---|
| 畫面震動 | **每次命中都震**（1 級），暴擊 2 級；升地形輕震 | `battle/vfx.ts` 的 `shake`、`BattleRenderer.playVfx`、`playLift`、`resultEffects.ts` |
| 停頓 | 只有特殊結果：暴擊 0.1 秒、格擋 0.06 秒、擊殺；一步加起來最多 0.2 秒 | `render/hitStop.ts`、6N-5 |
| 震動開關 | 版面設定 `trpg.vfxShake` | `battle/vfxPrefs.ts` |

## 2. 停頓分級

依「這一下扣掉目標最大 HP 的比例」決定。比例＝`damage_dealt` 的實際扣血（`hp_before − hp_after`）÷ 目標最大 HP；一下打多人時取最大的那個。

| 級 | 條件 | 停頓（正常速度） |
|---|---|---|
| 0 | 比例 < 10%，且不是暴擊 | 0 |
| 1 輕 | 10%～25% | 40 ms |
| 2 重擊 | 25%～50% | 70 ms |
| 3 | 50% 以上，或暴擊 | 100 ms（暴擊照 6N-5，不另外疊加） |
| 格擋 | 格擋成功 | 60 ms（照 6N-5） |

- 停頓在 `hitAt` 那一刻開始，凍結畫面上所有片段（沿用 `hitStop.ts` 的 `addFreeze`）。
- 同一個 `hitAt` 只停一次，取最高級。
- 一步加起來的上限從 0.2 秒維持不變；超過時後面的停頓縮短。
- 停頓時間照播放速度縮放（同 6N-5）；按住空白鍵加速時減半；跳過時不停。
- 停頓期間傷害數字照常彈出（數字不凍結），看起來才像「打中定格」。

## 3. 鏡頭微震

**只在下面三種情況震**，其他命中一律不震（取代現在的每次命中都震）：

| 情況 | 判斷 | 幅度 | 長度 |
|---|---|---|---|
| 重擊 | 停頓第 2、3 級 | 2 px | 120 ms |
| 爆炸 | `object_exploded`、`bomb_blast`、`detonate_rune` 事件 | 3 px | 160 ms |
| Boss 大招 | 6N-5 的 Boss 大招判斷 | 4 px | 220 ms |

- **震法**：
  - 衰減的正弦，左右和上下各一個頻率（約 28 Hz 和 22 Hz）；
  - 相位由「戰鬥鍵:事件 seq」的雜湊決定（確定性）；
  - 最後 30% 線性收回 0；
  - 幅度是畫面像素，不隨格子大小放大；
  - 同時有好幾個時取最大的，不疊加。
- 升地形的輕震：保留，但幅度降到 1 px。
- **關閉的情況**：
  - 系統「減少動態」（`prefers-reduced-motion: reduce`）時全部關閉；
  - 版面設定的震動開關關掉時也關閉。
- **減少動態時的替代**：重擊和爆炸改成目標身上的白閃加長 40 ms；Boss 大招只保留四周變暗。

## 4. 最後一擊放慢

**條件**：這一步讓**敵方最後一個單位**倒下（下一個事件是我方勝利的 `battle_ended`），或擊倒 Boss。

**做法**：
- 從出招片段的 `hitAt` 前 120 ms 開始，到 `hitAt` 後 280 ms，播放速度降到 **0.4 倍**；
- 前後各 60 ms 漸變，不要硬切；
- 範圍是全場：片段、特效、粒子一起慢；傷害數字照常速；
- 命中那一刻疊第 3 級停頓（100 ms）和重擊震動；
- 倒下片段照常速播完，再接 6N-5 的勝利。

**次數與時間**：
- 一場戰鬥只放慢一次。
- 一般速度下，整段多出約 0.5 秒。
- 快速播放時減半；跳過時不做。
- 減少動態時不放慢，只保留停頓。

不做鏡頭拉近（6N-5 已定「不做慢動作和鏡頭」，最後一擊只加放慢是使用者這次要的例外，範圍只限這一下）。

## 5. 檢查清單

- [ ] 一般小傷害命中不震、不停；10%、25%、50% 三個門檻的停頓長度照表（測試）。
- [ ] 只有重擊、爆炸、Boss 大招會震；幅度 2／3／4 px，不疊加（測試＋實戰截圖或錄影）。
- [ ] 減少動態時完全不震、不放慢，白閃加長。
- [ ] 最後一擊：全場放慢約 0.4 秒、只有一次；擊倒 Boss 也觸發。
- [ ] 同一場戰鬥重播，震動和停頓完全一樣。
- [ ] 一步的停頓總和不超過 0.2 秒；跳過時沒有任何停頓、震動、放慢。
- [ ] 開發頁 `skill-gallery.html` 加 `#impact`：並排四級停頓、三種震動、最後一擊，可用 `?anim=0.1` 慢放。
