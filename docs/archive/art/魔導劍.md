# 魔導劍（#46）外觀與移植需求（美術 PM，2026-10-24）

依據：玩法 PM（`docs/design/08-裝備.md` 8.11）——單手劍、可搭副手（法書、法器珠）、魔劍士專屬、**沒有主打元素**；建議劍身刻符文、帶源晶藍紫光，和其他劍一眼能分開。
圖：`arcane-blade.png`。畫法：`sample/paperdoll.js`（`sword` 的 `form: "arcane"` 分支）、`sample/arcane-blade.html`。

## 規則

| 欄位 | 值 | 外觀 |
|---|---|---|
| `kind` | `sword`（不新增 kind） | 單手劍的長度與握法 |
| `form` | `arcane`（新形制） | 劍身中線一道**源晶槽**（發光，寬約劍身 40%）＋三個淡白符文刻點；護手換成**黃銅齒輪**（12 齒，`#b08a4a`），中心一顆源晶 |
| 源晶槽與齒輪中心的顏色 | 沒有 `element`：藍紫 `#9a86ff`；有 `element`：元素色 | 樣張主圖是無元素。之後若做「依最近施放的元素變色」，只要傳 element 就會換色 |
| 劍身色 | 預設冷灰 `#8a93a8`（比一般鋼劍暗一點，讓光槽更明顯） | 材質、color 照一般規則可覆寫 |

不認得 `arcane` 的地方（舊版前端、別的畫法）一律退回一般單手劍，不得出錯。

## 移植需求（給開發 PM）

1. `render/paperdoll.ts` 的 `sword` 分支加 `form === "arcane"`：畫法照 `sample/paperdoll.js` 同名分支（源晶槽加 4px 外光、符文刻點、齒輪護手、中心源晶）。
2. 裝備圖示（`gearIcon.ts`）與武器小圖示（`weaponIcon.ts`）都走同一個紙娃娃畫法，所以第 1 點做完就有；確認小圖示 36px 以下時源晶槽仍看得到（必要時槽寬至少 1px）。
3. `weapons.yaml` 魔導劍的 `look`：`{kind: sword, form: arcane, material: steel}`（不填 element）。
4. 測試：`form: arcane` 有／無 element 都畫得出來；未知 form 退回一般劍。

## 檢查清單

- [ ] 戰場實際大小（52px 格）下，魔導劍和一般單手劍一眼分得開（藍紫光槽＋齒輪護手）。
- [ ] 搭法書、法器珠時副手正常顯示；正、側、背三面都對。
- [ ] 有 element 時光槽換成元素色。
