## 0. 原則（同 3-16）

1. **只動前端繪圖**（`client/src/render/`）與外觀清單（`content/`）；外觀不影響任何規則。
2. **外觀只由資料欄位決定**。清單放在 `content/`，不認得的值一律退回預設，**不得出錯**。
3. **確定性**：不用 `Math.random()`。圖示依「外觀欄位＋稀有度＋關鍵字」快取成離屏貼圖。
4. 樣張裡標了 `legacy: true` 的造型不要移植：`gun`（已拆成 `longgun`／`pistol`／`shotgun`）、`gloves`（改用 `leather_gloves`）、`bracelet`（手環已拿掉）。

## 1. 資料欄位（每件裝備）

| 欄位 | 來源 | 不認得時 |
|---|---|---|
| `kind` | 外觀清單（LLM 只能從清單選） | `sword` |
| `form` | 該 `kind` 的形制清單 | 該 `kind` 的第一個形制 |
| `material` | 10 種，且要在該 `kind`（或該 `form`）允許的材質內 | 該 `form` 的預設，沒有就用 `kind` 的預設 |
| `dye`（選填） | 8 色；只對布、皮有效 | 不染色 |
| `style` | 第一季只有 `common` | `common` |
| `keywords` | **由詞條推導**（06 6.27 關鍵字），不是 LLM 填；取前 2 個 | 不認得的跳過 |
| `rarity` | 引擎 | `common` |

清單的完整內容（`kind` × `form` × 可用材質 × 預設）以 `gearArt.js` 的 `KINDS` 為準，建議匯出成 `content/equipment/appearance.yaml`，用 pydantic 驗證。對應的中文名稱也在 `KINDS` 裡。數量：主手 17 種造型、副手 4 種、身體 5 種、頭 5 種、手 4 種、腳 4 種、項鍊 2 種、戒指 1 種。

## 3. 裝備圖示產生器（建議 `render/gearIcon.ts`）

64 × 64 的虛擬格，依顯示大小縮放（背包 64px、欄位 38～46px、卡片 84px）。

**圖層（由下往上）**
1. 圓角底 `#23262d`（2,2,60,60，圓角 9）。
2. 史詩、傳說：中心往外的稀有度色放射光暈。
3. 裁切到內框（3,3,58,58，圓角 8），依造型套縮放係數（`gearArt.js` 的 `draw()` 裡的表：匕首 1.5、劍 1.15……）。
4. 造型本體：每個 `kind` 一個畫法函式，吃 `form` 與配色；外框線 2～2.5px。
5. 關鍵字小圖樣：每個畫法函式回傳 2 個放圖樣的位置。1 個關鍵字時兩處都畫；2 個關鍵字時各畫一處。
6. 稀有度外框：線寬 2.5，傳說 3.5；優良以上在右上角加三角標；傳說多一圈細內框。

**尺寸**（G4 版面，開發 PM 2026-10-22）：欄位格 64px、物品清單 48px、英雄面板 32px。三種尺寸都檢查過（`sample/gear-sizes.html` → `docs/art/gear-sizes.png`，1 倍解析度）：
- 64px、48px：照上面的圖層全部畫。
- **≤ 36px：不畫關鍵字小圖樣**（第 5 層），元素混色和稀有度外框照留，不然小圖樣會糊成一團。快取鍵要包含「是否小圖」。

**特殊規則**
- **成對武器**（`dual_dagger`、`dual_pistol`）：把單把的畫法畫兩次，各縮成 0.78，一把正向、一把左右鏡像，交叉擺放。
- **槍**：槍托固定畫木色 `#7a5232`；材質只影響槍身。
- **圖騰杖**：杖頭兩張刻臉加羽毛，頂端小珠用關鍵字色（沒有關鍵字時是 `#7dffb0`）。
- 畫法函式可以直接從 `gearArt.js` 的 `D.*` 移植；樣張的寫法是 Canvas 2D，移植成 TypeScript 的純函式，參數是 `ctx` 與已驗證的外觀資料。

## 4. 紙娃娃（擴充 `render/appearance.ts`、`render/paperdoll.ts`）

圖層順序照 `移植需求.md` 4.1 不變：披風 → 腳 → 身＋手臂 → 手 → 頭 → 頭髮 → 頭部裝備 → 主手 → 副手。

**4.1 外觀欄位 → 紙娃娃部件**（`gearArt.js` 的 `dollItem()`）

| 欄位 | `kind` → 紙娃娃部件 | 新部件（樣張已畫） |
|---|---|---|
| 頭 | `hood`→`hood`；`hat`：法師帽→`wizard_hat`、寬簷帽→`wide_hat`；`circlet`：頭巾→`bandana`、頭冠→`crown`；`cap`→`cap`（`form: fur` 是毛邊）；`helmet`：鐵盔→`helmet`、角盔→`horned_helm`、全罩盔→`greathelm` | `wide_hat`、`cap`、`greathelm` |
| 身 | 同名；`robe` 的 `short` 下襬較短、`mail` 的 `scale` 畫鱗片、`plate` 的 `half` 沒有肩甲 | `coat`（翻領、開衩、扣子；`cape` 形制多一片肩披） |
| 手 | `cloth_gloves`、`leather_gloves`→`gloves`（`fingerless` 露指、`long` 多一截袖口）；`gauntlets`→`gauntlets`；`bracers`→`bracers`（只包前臂，手露膚色） | `bracers` |
| 腳 | `shoes`（不加高；`wrapped` 畫綁帶）、`boots`（短 2.5／長 4）、`iron_boots`（高 3、鞋尖亮塊）、`greaves`（高 4；`knee` 加護膝） | `shoes`、`iron_boots` |
| 主手 | 同名。火器：`longgun`→長槍、`pistol`→手槍、`shotgun`→霰彈槍 | `hammer`、`spear`、`crossbow`、`longgun`、`pistol`、`shotgun`、`fist`、`scythe`、`whip` |
| 副手 | `round_shield`→`shield_round`、`kite_shield`→`shield_kite`（`tower` 是長方形大盾）、`tome`、`orb` | 塔盾、`orb` |
| 項鍊、戒指 | 不畫 | — |

- **配色**：材質色；有 `dye` 就用染色；元素關鍵字對應紙娃娃的 `element`（點燃→fire、潮濕→water、帶電→lightning、冰凍→ice），混色 45%（沿用現有規則）。
- **成對武器**：主手、副手各畫一把單把的武器，例如雙匕首畫成兩把匕首。
- **雙手武器、成對武器**：副手欄被占用，紙娃娃不畫副手。
- **頭髮遮蓋**：`helmet`、`horned_helm`、`greathelm`、`hood`、`wizard_hat`、`cap` 會蓋住頭髮頂。
- **拳套**：兩手都畫。

## 5. 測試（建議）

1. **全組合不丟例外**：每個 `kind` × 每個 `form`（含不認得的）× 10 種材質（含不認得的）× 關鍵字（無、各 1 個、2 個、不認得的）× 稀有度，圖示與紙娃娃都要畫得出來。樣張共 133,849 種組合，錯誤 0。
2. **`resolve()` 預設**：不認得的 `kind` 退回劍；布頭盔退回鐵；金屬染色無效；`circlet` 頭冠預設金、頭巾預設布；`bracers` 臂環預設銅。
3. **對照**：`dollItem()` 的對照表涵蓋每個 `kind`；項鍊、戒指回傳 null；成對武器主手、副手各一把。
4. **快取鍵**是穩定的（同樣的輸入產生同樣的字串，不依賴物件屬性順序）。
