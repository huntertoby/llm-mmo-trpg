# UI-E3／UI-E4 驗收（背包、技能面板、雇用面板、出口木牌）

美術 PM，2026-11-05。

- 報告：`docs/archive/phases/PhaseUI-E3報告.md`（main `2f57d0e8`）。
- 審查方式：`uie3_*`、`uie4_*` 共 44 張，由唯讀審查 agent 逐張看原尺寸，沒有抽樣。
- 對照：`全遊戲一致性巡檢.md` #7、#8、#11，以及 `../archive/art/偷懶自查.md` G2、G3、G6。

**結論：不通過，3 項要修。** 背包、技能卡、雇用圖示列、出口木牌的方向都對。出口木牌放在石板和焦土上都搭，看得出是出口，又不搶戲。

## 1. 各項結果

| 項 | 結果 |
|---|---|
| 背包（#7、G2） | 過。空格是灰階剪影，有裝備的格子顯示 gearIcon；6×5＋3；詳情在格子右邊；別大類的弓有橘點 |
| 技能面板（#8、G3） | 卡片過。**花費行換到第二行時，開頭是「・」**（必修 2） |
| 雇用面板 | 圖示列過。**800 寬時版面不一致**（必修 1） |
| 出口木牌（#11、G6） | 過（`uie4_*`） |
| 遇敵卡頭像（#9） | 已另派 UI-E3b，這次不算 |

## 2. 美術 PM 的決定

| 事項 | 決定 |
|---|---|
| A. 在開發頁拍 | 接受。檔名或報告要標明「開發頁」。開發頁的背包和雇用面板少了右上角的「X」，正式遊戲裡要有。雇用面板等正式遊戲拍得到時要補拍一張 |
| B. 名字小牌當過渡 | 接受。斷行不能拆開詞，例如「小回復藥」不能拆成「小回／復藥」；個數數字不能壓在邊框上 |
| C. 戰鬥撤離出口保留「出」框 | 接受。之後在「出」框裡放同款的小路牌圖示，讓兩邊看起來有關聯；記成待辦，這段不做 |

## 3. 修正（UI-E3c）

### 必修

1. `uie3_hire_hover_800`：面板寬約 720px，下緣超出畫面；同一個面板在 `uie3_hire_800` 寬約 512px。查出原因修好，再重拍。
2. 技能面板的花費行（`uie3_skills_*`、`uie3_float_skill_*`）：換行後，第二行開頭不能是「・」。照戰鬥底列的做法，用「…」截斷，或把間隔號留在上一行的行尾。
3. `uie3_bag_gear_1600_zoom` 弓那一格：橘點蓋住了藍色的稀有度角標。兩個要錯開，例如橘點改放左上，或角標往內移。

### 小修

4. 「換裝」標題和「主動 2/6」之間要留空隙，和「技能」那一行一樣（`uie3_skills_1600_zoom`）。
5. `uie3_float_skill_800`：技能卡蓋到主角卡的血條和法力條，要避開。
6. `uie4_tour_02_mist_ferry_800_hover_zoom`：滑鼠移上去時，下面那一格的上緣多出一條直線；第一格同時有白框和綠框兩層，只留綠框。
7. 「往 渡口石階」和「往灰燼荒原的渡口」，「往」後面空不空格要統一，建議都不空。
8. `uie3_bag_cross_confirm_800`：捲動時標題列會跟著捲走。800 寬時，標題列要固定在上方。
9. `uie3_hire_hover_*`：滑過時出現的說明牌蓋住了傭兵名字，要避開名字。
10. 雇用面板「已勾選」那一列的底色是中性深灰，改成深藍系，避免和 base.css 停用狀態的深灰混在一起。
11. 依第 2 節 B：名字小牌斷行不拆詞，個數不壓框。
