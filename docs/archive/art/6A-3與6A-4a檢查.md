## 3. 開發 PM 問的點

| # | 問題 | 決定 |
|---|---|---|
| 6A-3-4 | 800×600 時，展開的紀錄上半部被左上的選取面板蓋住 | **選取時紀錄讓開：縮短，不隱藏**。選取面板開著時，紀錄的最大高度改成「選取面板底下到紀錄底部」的空間（留 8px）；紀錄底部固定，所以是從上面縮。空間不到 3 行時，只顯示最新 3 行（可捲動）。選取結束就回到原本高度。釘住的紀錄也一樣縮，不收起。 |
| 6A-3-1 | 「一次」怎麼算 | 照報告：選取面板每進入一次算一次；技能列上方的移動說明每場每輪算一次。 |

| 6A-3-3 | 右側窄欄只剩預告 | 可以，和 `HUD版面.md` 5.3 一致。 |
| 6A-3-5 | 紀錄的釘選跨戰鬥保留 | 可以。釘選是玩家的版面偏好，跟其他版面設定一樣記在本機。 |
| 6A-4a-1 | 陷阱虛線圈我方、敵方都畫 | 可以（見第 2 節）。 |
