# 畫風回頭比較：舊扁平版 vs C 墨線繪本（給使用者決定）

美術 PM，2026-11-04。使用者看舊的狀態圖示畫廊（10-29 以前的扁平紙娃娃）原話：「完蛋我越看越覺得我的決策是錯的 原本好可愛喔」。

- **這份只比較、不改東西**。結論出來前，畫風維持現行 C。
- 樣張：`style-compare.png`（`sample/style-compare.html`）。左欄是當時真正的畫法（`sample/paperdoll.js` 還在，直接呼叫，不是憑印象重畫）；右欄是現行 C（`sample/storyDoll.js`）。同一組角色資料、同一塊地面、同一組狀態圖示，只換人物畫法。四組：戰場（實際大小與 2 倍）、霧渡鎮走路、頭像（5 族＋4 傭兵）、動畫一格（揮砍、施法）。

## 1. 並排看到什麼

| 看點 | 舊扁平版 | C 墨線版 |
|---|---|---|
| 可愛度 | 圓頭、大眼、乾淨色塊，像貼紙或桌遊棋子；**比較可愛** | 頭稍小、墨線抖、有排線，像繪本插畫；可愛度中等，偏「有質感」 |
| 戰場實際大小（52px） | 色塊乾淨，隊伍色、裝備顏色一眼分；**辨識度高** | 排線與墨線在 52px 下變成灰噪，裝備顏色被壓暗；辨識度稍差 |
| 放大 2 倍 | 乾淨但單薄，沒有質感 | 墨線與水彩出來了，**好看** |
| 走路（實地地圖） | 清楚、可愛 | 清楚；人物比地磚「畫得更細」，和地磚的平塗略有落差 |
| 頭像（64／32px） | 圓臉可愛；32px 仍清楚 | 有細節；32px 時排線糊成灰 |
| 動畫 | **沒有關節**：當時只能整隻傾斜加弧光 | 6M／6N 的骨架：手臂、武器、髖、膝各自轉；揮砍、施法、受擊、走路都有姿勢 |
| 和 B 彩繪地圖、碎界中樞 HUD | 扁平色塊和彩繪地圖、深藍金框都搭，像「棋子放在畫上」 | 墨線和彩繪地圖搭，和金框 HUD 搭；只是人物比地圖「手繪感」更重 |
| 和世界觀 | 中性，哪種世界觀都行 | 「說書人手繪的繪本」感，和 LLM 說書人主題最貼 |

**誠實的結論**：舊版在「可愛」和「小尺寸可讀」兩項贏；C 在「放大的質感」「動起來」「和說書人主題」三項贏。使用者覺得舊版可愛，不是錯覺。

## 2. 選項與代價

| 地圖、區域插畫、大世界圖、HUD | 和人物無關 | 不動 |

## 3. 美術 PM 的判斷

從四個面向看：

| 面向 | 誰贏 |
|---|---|
| 可讀性（52px 戰場、32px 頭像） | 舊版 |
| 可愛度 | 舊版 |
| 量產成本（已完成的工作、之後每個新部件） | A ＞ D／E ＞ C ＞ B |
| 和世界觀（LLM 說書人、繪本）、和彩繪地圖的搭配 | C |

**推薦：D＋E（維持 C，小尺寸自動變乾淨，頭稍微放大）**，合計約 0.75 段。
- 舊版贏的兩項（可讀、可愛）主要輸在「小尺寸的排線」和「頭身比」，不是輸在墨線本身；D 和 E 剛好補這兩個洞，不用推翻 10-29 的決定，也不用重做部件、頭像、動畫。
- 做完後我會出同一張並排圖（舊版／C／D＋E）再給使用者看一次；如果看了還是想要舊版，再走 C（混合，2～3 段），不建議走 B（5～6 段，等於把 C-1 到 C-3 重做一遍，動畫也要重驗）。

**如果使用者就是要舊版的樣子**：選 C（混合）而不是 B。C 保住骨架與資料，皮換回乾淨色塊，可愛度能回到接近舊版，又比舊版多一層細墨線和影子。

## 4. 要使用者決定

1. 選 A／B／C／D＋E／其他。
2. 若選 D＋E 或 C：做完要不要再看一次並排圖再定稿（建議要）。

# 第 2 版（11-04 晚）：公平並排，重估，改結論

使用者看第 1 版第 4 組：「這個問題是沒有套用骨架跟 我們沒有 修正側面問題 才會怪怪的吧」。對：第 1 版拿「沒有關節的舊版」比「有骨架的 C」，動畫那一項不是畫風的差別。

## 5. 公平版樣張 `style-compare-2.png`（`sample/style-compare-2.html`）

- 做法：寫了 `sample/storyDollSkin.js`，是 `storyDoll.js` 的換皮版，**部件、骨架、姿勢、側面（手肘、另一隻手、武器握把）全部同一套**，只換畫法層：
  - 左「舊版的皮」：純色、單層粗輪廓、無排線、無水彩、眼睛放大 1.6 倍、頭 1.12 倍（照舊 `paperdoll.js` 的比例與輪廓粗細）；
  - 中「現行 C」：抖動墨線、水彩溢色、排線；
  - 右「D＋E」：52px 以下關排線、墨線細直、暗面改一道平塗；頭 1.15 倍、眼睛 1.3 倍。
- 三組：動畫四格（揮砍命中、施法詠唱、走路、受擊，側面）、戰場 52px 與 1.6 倍（含狀態圖示）、頭像 64／32px。

**公平並排後看到的**：

| 看點 | 舊版的皮＋骨架 | 現行 C | D＋E |
|---|---|---|---|
| 動畫（同姿勢） | **不輸**：揮砍、詠唱、走路、受擊都一樣清楚，色塊乾淨反而更容易看出動作 | 姿勢相同；排線在動的時候是雜訊 | 大圖維持 C |
| 戰場 52px | **最清楚**：隊伍色、裝備色、狀態一眼分 | 排線糊成灰 | 接近舊版（關排線後） |
| 可愛度 | **最高**（大眼、圓頭、乾淨） | 中 | 中高（頭眼放大，但還有墨線質感） |
| 放大後質感 | 單薄、像貼紙 | **最好** | 同 C |
| 頭像 32px | 清楚 | 排線糊 | 清楚 |
| 和 B 彩繪地圖、碎界 HUD | 搭（棋子感） | 搭 | 搭 |

所以第 1 版的「C 贏在動得起來」要**撤回**：套上同一套骨架後，舊版的皮在動畫上不輸，而且小尺寸更清楚。C 真正贏的只剩「放大後的質感」和「說書人繪本感」。

## 6. 重估：「舊版的皮＋現行骨架」要幾段

先把第 1 版 B 的 5～6 段拆開，看哪些其實不用做：

| 第 1 版 B 估的項目 | 第 1 版估 | 公平版重估 | 為什麼 |
|---|---|---|---|
| 補關節、骨架、姿勢資料 | 0.5＋重驗 1 | **0** | 骨架在 `inkPose.ts`，部件掛在關節上；換皮不碰骨架、不碰 6M／6N 的 70 幾個片段與變體。公平版樣張就是證明：同一個 `setPose` 直接畫出來 |
| 畫法層（`inkStyle.ts` 的 `ink`／`stroke`／`limb`，269 行） | 包在 1.5 裡 | **0.25** | 樣張的換皮只改了 `ink` 和 `stroke` 兩個函式（加 `SKIN` 開關）；正式版一樣，在 `inkStyle.ts` 加一個皮的開關 |
| 部件重畫（`inkDoll/inkGear/inkArmor/inkWeapons/inkOffhand/inkRace/inkForm/inkSect`，約 2,400 行） | 3～4 | **0.5～0.75** | 部件是「多邊形點列＋顏色」，皮只是怎麼填、怎麼描；**點列不用重畫**。要做的是逐一檢查：排線拿掉後哪些部件的暗面要補一道平塗、哪些顏色要調亮（C 把顏色壓暗配排線） |
| 異形 17 種（`inkCreature.ts` 854 行） | 1 | **0.25** | 同上，走同一個 `ink`，跟著換皮；只檢查 |
| 頭像配件（`portrait.ts`） | 0.5 | **0.1** | 同上 |
| 傭兵、NPC、郵差、葛蘭、種族卡、靶場、分鏡重拍 | 0.5 | **0.25** | 資料不動，只是重新截圖給使用者看一次 |
| 武器小圖示、技能、物品、狀態、HUD、事件卡墨線圖示 | 0 | **0（可選 0.5）** | 圖示是獨立畫法，可以不動；要全套一致才換 |

**合計約 1.5 段**（不含圖示），不是 5～6 段。第 1 版高估的原因：把「重畫部件」算成重做 C-1～C-3，但那時是從舊版的點列**重畫**成 C 的點列；現在點列已經是 C 的，只換皮。

同一套估法下其他選項：

| 選項 | 段數（重估） |
|---|---|
| A 維持 C | 0 |
| **B′ 舊版的皮＋現行骨架**（公平版左欄） | **約 1.5** |
| C 混合（舊版比例與色塊＋細墨線、平塗影；公平版右欄去掉排線再把眼放大就是它） | 約 1.5（和 B′ 差別只在描線粗細與頭身，同一條路） |
| D＋E（公平版右欄） | 約 0.75 |

B′ 和 C 其實是同一條路上的兩個刻度（輪廓粗細、眼睛大小），做成**可調參數**後選哪一個只是調數字。

## 7. 改後的結論與推薦

誠實改口：**第 1 版推薦 D＋E 的理由有一半站不住**（動畫不是 C 的優勢），而且 B′ 的成本只有 1.5 段，不是 5～6 段。

重新看四個面向：

| 面向 | 舊版的皮（B′）| C | D＋E |
|---|---|---|---|
| 可讀性（52px、32px） | 最好 | 差 | 好 |
| 可愛度 | 最高 | 中 | 中高 |
| 量產成本 | 1.5 段，之後每個新部件省掉排線與溢色的調校 | 0 | 0.75 段 |
| 世界觀搭配 | 中性，和說書人感弱一點；和彩繪地圖、碎界 HUD 都搭 | 最貼說書人 | 同 C |

**推薦：B′（舊版的皮＋現行骨架），做成可調的「皮」參數，約 1.5 段。**
- 使用者覺得可愛的那個東西，是舊版的**皮**，不是舊版沒有骨架；皮可以換回來而且不貴。
- 戰場和頭像的小尺寸可讀性是這個遊戲最常看的畫面，B′ 在這裡最好。
- 說書人感可以留在**不是人物的地方**：事件插圖的框、羽毛筆等待、墨線圖示、區域插畫，這些都不動。人物用乾淨的皮反而讓「畫」和「棋子」分得清楚。
- 做法上把皮做成參數（輪廓粗細、要不要排線、水彩、頭身比、眼睛大小），先出三個刻度（B′／C 混合／D＋E）的實機截圖給使用者挑，再定稿。

**如果使用者仍偏好 C 的質感**：選 D＋E（0.75 段），小尺寸問題也能解。

## 8. 要使用者決定

1. 選 B′（舊版的皮）／C 混合／D＋E／A 維持。
2. 選前三者之一時：先做成可調參數，出實機截圖三個刻度再定稿（建議要）。
