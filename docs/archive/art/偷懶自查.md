# 偷懶自查（美術 PM 自己回頭審）

美術 PM，2026-11-04。使用者原話（專案 PM 轉）：「讓他自己審核之前有沒有類似情況」。

**起因**：使用者連續指出三處：
- 建角的種族圓臉（「太簡陋了吧」）；
- 首頁背景（「背景也是 美術有偷懶的情況」）；
- 建角武器全是「/」（「這些也都沒有武器圖示」）。

**範圍**：
- `docs/art/` 下所有樣張（png 與 `sample/` 頁面）；
- 已做進遊戲的美術：開發 PM 實機巡檢的 64 張 `tour_*`，加上各段的驗收截圖。

Boss 戰沒有實機截圖，已請開發補拍，補拍後再補進這份。

**判準**（五類）：
- **A** 幾何占位冒充成品；
- **B** 已有素材沒用；
- **C** 品質低於同類已定案美術；
- **D** 主元素做了、配角草草帶過；
- **E** 驗收只看截圖沒看細部。

**嚴重度**：
- **第一眼**：玩家一進遊戲就看得到；
- **常見**：常用畫面；
- **少見**：少數情況才遇到。
