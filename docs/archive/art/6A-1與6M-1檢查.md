美術 PM，2026-11-04。方法：看報告與截圖（`6a1_*.jpg`、`6m1_*.jpg`），這次沒有自己開實戰。

## 6A-1 技能卡減字：通過

- 對照 `去文字化移植需求.md` 第 7 節：
  - 常駐 3 行：名稱，圖示＋數字列，效果數字；
  - 「詳細」展開後，原本的資訊都在：稀有度與類型、費用、形狀、組裝算式、關鍵字、效果、算式；
  - 三選一的候選卡也是同一張卡；
  - Shift 固定和圖釘都有。
- 開發 PM 問的 3 點：

| 問題 | 決定 |
|---|---|
| 縮放屬性的正式圖示 | 畫好了：`docs/art/shots/misc/attr-icons.png`（`sample/attr-icons.html`）。六種屬性各一個 C 手繪墨線小圖示：力量＝手臂、敏捷＝羽毛、體質＝心、智力＝書加星、感知＝眼、意志＝火焰；外圈顏色依屬性。技能卡上用 16～20px，旁邊照舊寫屬性名 |
| 第 2 行另外放法力、耐力、HP、源力、每場次數 | 可以。順序：AP → 法力 → 耐力 → HP → 源力 → 冷卻 → 射程 → 時機 → 每場次數；超過一行就換行，不縮小 |
| 非緊湊卡的大圖示 72 → 56 | 可以。卡片變矮，三選一並排時剛好 |

## 6M-1 骨架紙娃娃：通過

- 對照 `動畫移植需求.md` 第 7 節：
  - 沒設姿勢時逐像素不變（報告有快照測試）；
  - 前傾、跨步、屈膝、舉手、彎手肘、兩手前伸都正常，狐族的尾巴和雙匕首也跟著動；
  - 正面、背面抬腳加擺手，起伏正常；
  - walk、run、sneak 三種循環的抽樣和樣張一致。
- 開發 PM 問的 1 點：
  - **側面的另一隻手畫成較暗的膚色點、不畫手套**：可以。補一條：如果手部有裝備（手套、護手），就用該裝備顏色的暗色，和主手一致。
- 另外看到：「舉起主手」「跑步」時劍的方向還是舊的固定角度，劍尖會朝後。這是 6M-2（武器統一朝向）的範圍，等 6M-2 交件時一起看前後對照。
