## 4. 「整體卡通化」的搭配檢查

人物變成乾淨色塊後，其他已定案的東西搭不搭。只有人物畫法換，其餘先不動；要推翻使用者已選的方向時先回專案 PM。

| 項目 | 現況 | 搭不搭 | 修法 |
|---|---|---|---|
| B 俯視彩繪區域圖、大世界第 2 版 | 柔和漸層、有光影的彩繪 | **搭**：卡通人物站在繪本地圖上是常見組合（人是「棋子」，地圖是「畫」） | 不動 |
| 碎界中樞 HUD（深藍金框、襯線字牌） | 偏正式 | **搭**，但襯線標題牌和圓頭大眼人物放一起略嚴肅 | 不動；RT-1 四角飾件做出來後再看一次 |
| 羽毛筆等待動畫 | 羊皮紙、羽毛筆 | **搭**（道具不是人物） | 不動 |
| 事件插圖 | 地磚＋人物＋物件 | 人物自動跟皮後**搭** | 重拍 |
| 地磚與物件（雲嶺、荒原、主城、室內） | 平塗帶紋理，物件有墨線 | **搭**：地磚本來就是平塗；物件的墨線在平塗人物旁邊不突兀（舊版時期就是這套） | 不動 |
| 武器小圖示、技能圖示、物品圖示、狀態圖示、HUD 圖示 | C 墨線小圖示（抖線、排線） | **半搭**：圖示有排線、人物沒有，放同一個畫面會有兩種質感；但圖示是獨立系統，單看也成立 | **先不動**；SK-2 做完看實機截圖，若明顯不一致再排 0.5 段把圖示的排線拿掉（同一個 `skin` 開關，圖示也走 `inkStyle`，改法一樣） |

| 說書人頭像 | C | 跟皮 | SK-2 |
