# 矮牆改畫（美術 PM，2026-10-22）

使用者原話：「矮牆圖示不夠明顯」。樣張 `docs/art/sample/lowwall.html` → `docs/art/low-wall.png`。不需要使用者選。

**原因**：現行的矮牆是淺灰欄杆加灰色底座，沒有外框，和石地板幾乎同色；縮小後只剩一條橫線。

**改法**（取代 `objectArt.ts` 的 `lowWall`；座標以 52 的虛擬格為單位）：

| 部位 | 位置 | 顏色 |
|---|---|---|
| 壓頂石（頂面） | y 從 `T×0.30` 起，高 `T×0.16`；最上面 2px 亮邊；每 26px 一條 1px 縫 | `#d8c7a2`，亮邊 `#f2e6c8`，縫 `rgba(76,61,42,0.6)` |
| 正面（錯縫磚） | 接在壓頂石下面，高 `T×0.26`；分兩排，磚寬 17px，上下排錯開半塊 | `#86704f`，磚縫 `#4c3d2a`（1.5px） |
| 外框 | 外輪廓 2px，相連的那一側不畫；壓頂石和正面之間一條 1px 線 | `#241c13` |
| 投影 | 往右下偏 4px，高 7px | `rgba(0,0,0,0.42)` |
| 左右留白 | 不相連的一側內縮 4px，相連的一側畫到格邊 | — |

- 相連規則沿用 `joinL`／`joinR`，不用改。
- **和 3-19 整格抬高相容**：矮牆是物件貼圖，跟著所在格的頂面一起抬高即可，不用額外處理。
- 暖色石塊和土牆、石柱、冰牆的顏色都不同，不會撞色。
