# 專案計畫：開放世界與敘事（第 9 節）

> 本檔為 `docs/專案計畫.md` 的一部分，總覽與守則見該檔。

## 9. 開放世界與敘事（後期規劃）

### 9.1 階層式說書人

| 層級 | 模型 | 頻率 | 職責 |
|---|---|---|---|
| 世界 GM | 大 | 每小時遊戲時間，非同步 | 讀取全服事件摘要與模擬狀態，產生世界事件與劇情鉤子 |
| 場景／副本 GM | 中大 | 即時 | 一個隊伍或場景的互動與敘事 |
| NPC 代理 | 小 | 高頻 | 日常對話，只帶人設、記憶與當下情境 |

場景之間的影響透過世界狀態與事件日誌傳遞，不讓 LLM 彼此直接對話。

### 9.2 狀態驅動任務（storylet）

- 世界由可量化狀態組成：陣營聲望、村莊安全度、物資、NPC 心情與目標。
- 世界模擬讓狀態自行變動（陣營擴張、商路、怪物遷徙）。
- 任務是「需求」的產物；同一需求有多種解法，選擇會再改變狀態。
- 任務結構與獎勵由系統模板決定，LLM 只負責包裝敘事與 NPC 動機。

```json
{
  "need_id": "village_food_shortage",
  "region": "ashford",
  "trigger": { "stat": "food", "lt": 30 },
  "solutions": ["escort_caravan", "clear_bandits", "find_alt_source"],
  "reward_template": "tier2_common",
  "expires_in_hours": 48
}
```

### 9.3 後果分層與位面

| 層級 | 內容 | 呈現 |
|---|---|---|
| 個人 | NPC 態度、私人劇情線 | 個人位面 |
| 隊伍／公會 | 共同完成的劇情 | 群體位面 |
| 伺服器 | 多人累積的大型行動（守城成敗） | 世界 GM 定期結算後改變共享世界 |

世界狀態支援「同一區域多個版本的覆蓋層」，玩家進入區域時依其旗標合成看到的世界。

### 9.4 體驗密度三層

1. **開放野外**：一般探索與戰鬥，LLM 在背景生成事件與 NPC 對話。成本低、量大。
2. **NPC 互動**：自由文字對話，可說服、威脅、交易，結果透過工具落到聲望與任務狀態。
3. **故事副本／GM 場景**：完整 TRPG 模式，場景 GM 全程主持。最貴，集中投放。

### 9.5 記憶與一致性

每次 LLM 呼叫依序組裝 context：
1. 固定系統提示（GM 風格、規則、可用工具）——放在前綴以利 prompt caching
2. 世界聖經中與此地相關的條目（檢索）
3. 當前場景狀態（從引擎讀取，不從聊天紀錄推斷）
4. 在場角色與 NPC 的相關記憶（知識圖譜 ＋ 向量檢索）
5. 最近幾輪對話 ＋ 本場景摘要

輸出後經 **canon 驗證器**（規則 ＋ 小模型）檢查是否提及已死 NPC、地理錯誤、違反設定；違反則重新生成。場景結束時由摘要管線壓縮為長期記憶。

### 9.6 賽季大世界：精簡的魔獸世界式運作（2026-10-22 決定，見 `docs/archive/玩法決定紀錄_1-138.md` #29）

> 目標情境見 `docs/專案計畫.md` 1.2（5～10 位朋友、共享世界、賽季制、每季大 Boss、現金獎勵）。使用者原話：「一輪5場只是測試 實際上應該會像魔獸世界那個方式來運作」。roguelite 一輪（7.1）只是戰鬥與技能的測試原型。題材不綁定（世界觀待決定）。

#### 9.6.1 主城與小鎮

| 地方 | 功能 |
|---|---|
| **主城**（1 座；大世界圖上畫在五區中央的浮島，#120） | 排行榜與 Boss 擊殺紀錄（以確定性重播驗證）、Boss 進度與封印、公告板（世界事件、懸賞）、整備（換技能組、配點、休息）、看朋友的 build 與編年史、許願池、技能工坊（只開放靶場試玩與改造自己已有的技能） |
| **區域小鎮**（每區 1 座） | 任務起點、傳送點、區域商人、區域懸賞；由 NPC 撐場面 |

- 交易第一季不做（避免朋友之間輸送資源影響獎金公平）；鐵匠與裝備見 08（Phase 5）。
- **主城的技能與裝備設施**（2026-11-02，#94、#95，使用者：「好 寫入」）：
  - **技能導師**（NPC）：集中提供閃現、重閃、溶掉、傳承（06 6.34）；可以請 LLM 給 build 建議（只是建議）。每區導師各有一條任務鏈，算在已定的區域任務鏈配額內（07 7.6），不另外多給技能；導師不賣技能。
  - **魔導書**：完整技能的實體——主線、機遇、許願池給的完整技能以一本書出現，讀了就學會、綁定；同時是技能圖鑑（技能族譜、閃現紀錄）。只是包裝，取得數量不變；敵人不掉魔導書。
  - **鐵匠、附魔台**：見 08 8.26.1。

**地點種類**（內容由玩法 PM 設計，資料定義）

| 種類 | 內容 |
|---|---|
| 營地 | 敵人據點；戰鬥，勝利條件輪替（全滅、撤離＝護送或突圍、守點＝防守） |

| 精英巢穴 | 懸賞目標，先打倒的人拿大獎 |

**隱藏地點的感知判定**（#112）　（原 9.6.11，2026-11-06 併入）
- 「靠近」＝玩家走到 **相鄰地圖上隱藏入口的 3 格內**（#120）時，自動擲一次 d20＋感知修正。
- DC ＝ 10＋隱藏地點建議等級÷2（無條件捨去；例：丹爐洞 5 級＝12、鶴歸崖 6 級＝13）。
- 同一個角色對同一個隱藏地點，**每天（早上 6 點刷新）只判定一次**；失敗沒有懲罰。朋友的影子不能代替判定（9.6.4）。

#### 9.6.3 任務結構

| 類型 | 內容 | 互動 |
|---|---|---|
| 賽季主線 | 劇情章節，導向本季 Boss；章節獎勵含劇情技能（7.6） | 各自推進 |
| 區域任務鏈 | 每區一條，3～6 步；結尾給該區主題的技能三選一 | 各自推進 |
| 隱藏任務 | 由情境判定成功、探索秘境或行為條件（例：在某地點用火擊殺 5 名敵人）觸發 | 先發現的人可在地點留下線索 |
| 懸賞板 | 每日刷新；精英或稀有敵人先打倒的人拿大獎，其他人拿小獎 | 競爭 |
| 世界事件 | 全服合作目標（例：3 天內清掉 30 場侵蝕戰鬥）；成功開放新區域或削弱 Boss，失敗則世界惡化 | 合作 |
| Boss 封印 | 全服累積封印鑰匙才解鎖 Boss；解鎖時間事先公告，全員同時開打 | 先合作、後競賽 |

**人少時世界不空**：共享世界狀態（朋友清掉的營地、打通的道路大家都看得到）；地點上的足跡與留言（「某某在這裡打倒了精英」）；**朋友的影子**——可以招募朋友的 build 當 AI 隊友，或在世界事件中遇到它（沿用隊友 AI）。賽季 Boss 戰例外：只准系統傭兵（9.6.8，#87）；影子強度不超過招募者（#87）。

**第一季範圍建議**：主城＋2 個區域＋主線＋懸賞板＋Boss；其餘逐季加入。整體是 Phase 5 以後的多段工程。

#### 9.6.4 情境判定（2026-10-22 決定，見 `docs/archive/玩法決定紀錄_1-138.md` #31）

> 使用者原話：「llm 給你一個情境 然後你回答你怎麼解決 然後 按屬性判定 給你相對的獎勵或懲罰」

像 TRPG 的技能檢定。和許願池（7.6）、文字輸入差異化（`玩法PM交接.md` #3）共用同一條安全流程，是文字輸入最早落地的地方。

1. **情境**：來自 **情境模板**（content 資料）：基準難度、**允許的屬性**（2～3 種，例：力量破門、敏捷攀爬、感知找機關）、獎勵表與懲罰表。LLM 只依模板與世界狀態寫情境敘述。
2. **玩家回答**：用文字描述怎麼解決，放在 `<player_input>` 內。**第一次送出即定案**，不能重打來換判定。
3. **LLM 提議**（pydantic 驗證）：從允許的屬性中選一個、方法分類（力取、智取、潛行、說服……），難度只能在基準 **±2** 內調整；回答明顯行不通時可以提議「劣勢」。
4. **引擎判定**：檢查提議合法，擲 d20＋屬性修正（亂數由種子、玩家、情境衍生，可重播），結果分 **成功／部分成功／失敗** 三段。
5. **獎懲**：從模板的表中照結果挑選，**有預算上限**。LLM 不能產生表外的獎勵。
6. **敘述**：LLM 只負責敘述結果。

**公平原則**（現金獎勵）：
- **文筆不換強度**：文字只決定「用哪個允許的屬性、什麼方法」；加成只來自玩出來、核對得到的事實（線索、互動、交換條件，見下表「創意加值」，#85 修訂），不看文字好壞；介面列出玩家持有的線索與和該 NPC 的往來，可點選引用。
- **獎勵不給永久戰力**：只給任務幣、經驗、補給、線索、通往隱藏地點或機遇的入口、短期 buff；新技能只透過機遇（橫向、同預算）。
- 所有判定寫入事件日誌（第一季不設每日次數上限，見 9.7）。

**規則**（2026-10-22 使用者決定：「照建議」）

| 項目 | 決定 |
|---|---|
| 創意加值 | **用心清單，最多 +2**（2026-11-02，#85，使用者：「好 寫入」）：LLM 從固定清單勾選，每項必須指出一筆引擎核對得到的事實，核對不到不算：①用到自己查到的線索 ②用到 NPC 的喜好或過去互動 ③提出拿得出來的交換條件 ④方法針對情境弱點。每項 +1，同一情境同項只算一次。只用在情境判定與 NPC 說服、威脅；不影響戰鬥與永久戰力；獎勵仍照預算表。防範：玩家文字放 `<player_input>`；LLM 只輸出清單項目＋事實編號，引擎逐筆核對；第一次送出即定案；提議寫進事件日誌，重播照紀錄 |
| 用心清單的引擎驗證（2026-11-03 代決，Gemma 評估 13/30 注入回答被誤勾後） | LLM 勾的每一筆事實，玩家原文都要出現該事實的關鍵詞（名稱、線頭、NPC 名字、弱點文字或 content 別名），找不到的那一筆直接拿掉、其餘照算、不重試；「針對弱點」要原文提到弱點且方法在弱點允許的方法內。同義詞不交給 LLM 判斷 |
| 用心清單細節（5C-3d 後代決） | 玩家點選引用的事實，介面會把名稱插進回答原文；「NPC 往來」認 NPC 名字、別名，以及和該 NPC 有關的線頭文字與別名；LLM 提示裡寫明「勾選的事實，玩家原文要提到」；別名放在 content，避免太寬的單詞（例：「人情」「名字」） |
| 一筆事實一項（5C-3e、5C-3f 代決） | 同一條線頭只算一項：有 NPC 的線頭、而且該 NPC 在這次事件裡時算「往來」，其他（含 NPC 不在場）算「線索」 |
| 結果分段 | **成功／部分成功／失敗** 三段 |
| 失敗懲罰 | **依情境危險度分級**，最重到「受傷或敵人增援」；輕的是失去補給、下一場戰鬥帶 debuff |
| 每日次數 | **第一季不設上限**（2026-10-22 使用者：「不防爆肝」，見 #32） |
| 朋友的影子代替判定 | **不行**（2026-11-02 #89 確認）；但帶著影子時，用心清單可以引用「影子的專長」當一項事實 |
| 模板來源 | 情境判定是 9.6.7 事件骨架的一種解法；第一季每區先寫約 15～20 個骨架（#89，使用者：「好 寫入」） |
| 種族加值 | 每個種族有 1 類方法 +1（例：獸耳族攀爬跳躍；矮人機關、源晶裝置；海民游泳、航海），各族清單在大世界開發時定（#89）；加值只有 +1、不和其他保底疊成必過，DC ≤ 10 的模板要有前置門檻、獎勵只給線頭或資訊（#140，07 7.7 種族平衡原則） |

#### 9.6.5 世界觀：碎界五區（2026-10-23 決定，見 `docs/archive/玩法決定紀錄_1-138.md` #42）

> 使用者原話：「戰場配對 2 題和碎界 4 題都採用 A」

- **碎界**：源晶核心崩裂，世界碎成漂浮的界域；各界域保留不同的文明風格，技能的力量來自源晶的頻率（LLM 用語見 `content/llm/world_shattered.yaml`）。名稱與描述日後仍可由 LLM 重新生成。
- **五區**：

#### 9.6.6 敵人家族與多樣性（2026-11-02 決定，見 `docs/archive/玩法決定紀錄_1-138.md` #82）

> 使用者原話：「A＋B＋C＋D ⏎ 在哪裡會遇到精英  B ⏎ 其他都照建議」；寫入：「好 寫入」。

| 項目 | 決定 |

| 遠程上限 | 每場遠程敵人數量有上限（數值待大世界開發時定），避免集火主角（BAL-13b） |

| 盾兵（#162） | 新敵人定位：站在弓手前面，替相鄰的弓手擋遠程攻擊；玩家繞側面或推開、撞開。每區一種（雲嶺：觀內持盾弟子；荒原：熔殼甲兵） |
| 精英單挑（#162） | 精英巢穴的精英開戰前提出單挑：**接受**＝一對一，隊友在外面等、精英身邊的小怪不參戰；**拒絕**＝照原本全隊打、小怪也上。**兩邊獎勵完全一樣**（精英必掉、經驗都照舊，沒有單挑加成；使用者：「補師QQ」——補師、輔助打不贏單挑，不能讓他們少拿）。單挑的好處是少了小怪，獨狼 build 整場成立（06 6.37）；敵人也套獨狼，單挑精英可以帶「獨狼時變強」的招。第一季每區先 2 場 |

| LLM 產生變體 | 之後（Phase 4／5）：LLM 依模板組合變體與詞綴、寫名字與台詞；數值由引擎依預算決定，不開新規則 |

**一般營地混進精英**（玩法 PM 定，使用者「好 寫入」）：
1. **開戰前看得到**：進入營地時先顯示敵方陣容（含精英與詞綴），玩家可以選擇 **撤退**，不開戰、不扣任何東西；地點圖上不事先標示，保留驚喜。
2. **強度有上限**：混進的精英以該地點的建議等級為準，不另外加等級；一場最多 1 名。
3. **獎勵**：打贏照精英給（較多材料、靈感），和精英巢穴相同。

第一季（兩區）約 30～40 種長相（2 族 × 8～10 種＋中立族群 12～18 種），加上變體與混族組合後玩起來更多。

#### 9.6.7 城鎮與大世界體驗（2026-11-02 決定，見 `docs/archive/玩法決定紀錄_1-138.md` #85）

> 使用者原話：「我想聊城鎮體驗 互動 跟大世界體驗」；「6 個小題 建議」；3a：「如何生成能一環套一環的大世界」；5b：「第一季先只做「帶影子」」；寫入：「好 寫入」。

**城鎮**
1. **酒館**（主城）：看朋友的足跡與戰報、聽 NPC 講本週傳聞；傳聞會指向機遇或隱藏地點的線索。
2. **休息**：只有城鎮與營火能完全回復、換技能（現行規則不變）。

**NPC 互動**
3. **自由聊天只換資訊**：線索、隱藏任務入口、傳聞；不換道具、經驗、戰力。
4. **說服、威脅走情境判定＋用心清單**（修訂 #31「沒有創意加值」）：見 9.6.4。
5. **好感度**：每個 NPC 有好感度，玩家看得到；只影響對話內容與任務分支，不影響數值。

**LLM 說書人**
6. **野外事件＝事件骨架＋線頭**：
   - 骨架是 content 資料：誰（NPC／族群）、想要什麼、阻礙、賭注、可選解法（戰鬥、情境判定、交涉、放棄）。
   - LLM 依世界狀態挑骨架、填角色與動機、寫故事；引擎驗證合法性（角色存在、地點對、解法在清單內）；獎勵照地點建議等級的預算表。
   - **線頭**：事件結束時依結果留下 0～2 條未解線頭（頭目逃走、商人欠人情、封印鬆動），存進世界狀態；產生下一個事件時優先接線頭。每人約 5 條上限、約 3 天到期（到期也是一種結局，例：頭目坐大成精英）。數值待大世界開發定。
   - **後果寫回資料**：聲望、地點狀態、NPC 狀態；下一個事件從這些資料長出來。
   - **朋友共享**：世界級線頭（放走的頭目、鬆動的封印）出現在所有人的世界；個人線頭（欠你的人情）只屬於自己。
   - 事件出現頻率由引擎依移動步數與種子決定（#120：一步＝進入一張地圖；事件以「！」放在地圖上，走過去碰到才開），LLM 不能自己多生事件；線頭只能由事件結果產生。
   - 之後（Phase 5 以後）：LLM 可提議新骨架，經驗證器＋人工審核才加入資料。
7. **旁白短**：**畫面上方一行字幕、幾秒後淡出；NPC 用頭上的對話泡泡；紀錄預設收起；換地圖只顯示地名**，可點「多講一點」（2026-11-04 #120 修訂，見 `docs/design/21-探索地圖與城鎮.md`）。
8. **記憶**：說書人記得玩家的重要選擇與戰績（例：上次放走的盜賊頭目回來報仇），只影響劇情，不影響數值。

**地點圖的移動與探索**
9. **移動**：**在實地地圖上走，走出口銜接；敵人看得見、會巡邏，碰到或被看見就開打，可以繞開；花補給「潛行」縮小敵人視野**（2026-11-04 #120 修訂，見 `docs/design/21-探索地圖與城鎮.md`）。
10. **發現隱藏地點**：靠近時感知判定（#120：走到相鄰地圖上的入口 3 格內）、情境判定成功、任務線索、朋友的足跡。
11. **補給**：野外紮營要用，用完只能回城補；不會餓死。

**和朋友互動**
12. **看得到彼此**：城裡看得到線上的朋友，可點開 build、編年史；野外看得到朋友的足跡（#120：實地地圖上的標記，也顯示在區域圖；城裡朋友的角色每次進城更新位置，不即時同步）。
13. **同場戰鬥**：目標是線上 **2～3** 人同場（2026-11-02 #97 修訂：一隊 3 人，每個真人佔一個隊伍位）；**第一季先只做帶朋友的影子**，多人同場排在之後。
14. **不能送道具**（第一季不交易），可以分享打造配方碼、留言、在地點留提示。

**世界變化**
15. **共享變化**：朋友清掉的營地所有人看到「已清空」（#120：地圖上的敵人消失），一段時間後重生；世界事件失敗時，該區地點建議等級 +1。
16. **日夜與天氣**：會改變遇到的敵人與機遇（例：雷雨夜才出現雷擊點），戰鬥沿用 05 天氣規則。

**野外戰鬥之間的回復**（#113，照已寫入規則延伸，不放寬）　（原 9.6.11，2026-11-06 併入）
- **耐力**：照 #45，戰鬥結束回滿。
- **法力**：照 #47／#84，只在營火（含城鎮）回滿；野外戰鬥之間不回。
- **HP**：野外戰鬥之間不自動回；靠藥水、治療技能、營火或城鎮回滿。全滅時照 9.6.9（回小鎮或營火、HP 回滿、下一場疲憊）。

**營火＝紮營**（#114）　（原 9.6.11，2026-11-06 併入）
- 每區另有 4～6 個固定營火點（#120）。
- 在 **非戰鬥狀態** 的地點（城鎮以外：已清空的營地、村落、祭壇、遺跡、秘境等）花 **1 補給** 紮營，就是一次營火：HP、法力回滿，可以換技能、閃現、重閃、溶掉、傳承、立誓（07 7.6、06 6.34、9.6.10）。
- 敵人還在的營地、精英巢穴、Boss 地點不能紮營。補給量與上限照 9.6.7 第 11 條，數值開發時定。

**好感度**（#116）　（原 9.6.11，2026-11-06 併入）
- 數值 −100～100，分 5 級：**敵視**（≤ −50）、**冷淡**（−49～−10）、**中立**（−9～19）、**友善**（20～59）、**信賴**（≥ 60）。商店解鎖門檻（8.26.1）用級名。

#### 9.6.8 Boss 戰（2026-11-02 決定，見 `docs/archive/玩法決定紀錄_1-138.md` #86、#87）

> 使用者原話：「1.退」；「我剛剛想一個問題如果我是牧師 上限全靠AI 跟人家全點攻擊 打世界BOSS 不公平八」；「如果所有朋友都沒有輔助打法呢 或者大家都練輔助等人練輸出就好」；「感覺BOSS關不准影子 就只准系統傭兵」；寫入：「好 寫入」。

**勝利條件**：頭目倒下，護衛撤退（05 5.8，#86）。

**機制與階段**（#86）
- **區域 Boss**：2～3 個階段，HP 降到門檻就換招式或改變地形（例：雲嶺 Boss 半血時起霧，全場變成濃霧）。
- **賽季 Boss**：同上，再加一道 **解謎**（例：先打碎 3 根源晶柱，本體才吃傷害）。
- 強招一律預告（05 5.7、#82）。

**賽季 Boss 的公平**（#87）
- 現金獎勵只給首殺（9.7），不比個人傷害。
- 賽季 Boss 戰的隊友 **只能用系統傭兵**，不准帶朋友的影子。
- **系統傭兵**：在主城雇用；輸出、守護、輔助、控制各至少 2 種固定 build，事先公布、每個人都一樣；等級、技能階級、裝備預算和主角相同；可以設定 AI 行為（和一般隊友同一套選項）；隊伍人數照一般規則。傭兵各有出身界域，名字與外觀照該區風格（#131）：賽倫（盾衛）、莉瑟（祝禱師）出身晶冠；青鋒（劍客）、回春（醫者）出身雲嶺；鉚釘（守護者）、七號線圈（雷水術士）出身樞市；灰燼瑪菈（火術士）、鏽牙（陷阱師）出身荒原；珊瑚（弓手）出身霜潮；build、職稱不變，~~開局帶賽倫、回春~~ **開局只帶賽倫**（2026-11-12 #154 改，使用者：「照建議」）；新手第 1 步阿岳加入後坐第 2 個隊友位，阿岳離隊後第 2 位留空，正式選定後才能在城鎮雇用其他傭兵（入門期不開放雇用，21 21.5 第 9 點）。
- **預設隊友的出場**（#154）：加入當下各說一兩句台詞（對話框，不另做過場、不給選項），隊伍面板在名字那一列下面加一行來歷。
  - 賽倫：主城工坊靶場按「確定出發」後、傳送霧渡鎮前加入。
    - 守印人：「一個人上路太險。賽倫，你陪這位旅人去霧渡鎮，等站穩了腳步再說。」
    - 賽倫：「盾在我手上，你只管往前走。」
    - 面板來歷：「守印人派來的護衛。正式選定後可以在城鎮換人。」
  - 阿岳：見 18 18.7.1 第 1 步。
  - 已完成開局的舊角色不補播台詞，面板來歷照樣顯示（賽倫的來歷只給開局帶來的那一位；之後在城鎮雇用的傭兵不顯示這行）。
- Boss 依「主角＋傭兵」設計，而且一定有 **需要輔助的時刻**（例：全場每回合掉血、要淨化的詛咒）。
- 上線前用模擬驗證：各 build 當主角、只帶傭兵，打倒 Boss 的機率和輪數差距要在範圍內；差太多就調 Boss，不調 build。
- **通關評分榜**：看通關輪數、全隊存活、有沒有人倒下，只給榮譽稱號；現金仍然給首殺。

**賽季 Boss 以外**（#87）
- 野外、區域 Boss、精英巢穴、懸賞照 9.6.3 可以帶朋友的影子，也可以雇傭兵。
- **影子強度上限照招募者**：借來的影子，等級、技能階級、裝備物品等級都不超過招募者；影子不獨佔，大家可以同時借同一個影子。

#### 9.6.9 隊伍、失敗、新手、帳號與時間（2026-11-02 決定，見 `docs/archive/玩法決定紀錄_1-138.md` #97～#100）

> 使用者原話：「1 2 3 建議」；「4人會不會降低遊戲難度  主角加最多 2 個隊友，共 3 人好了」；「可能可以有2-3個腳色」；「每天幾點更新 早上6.」；「遊戲裡一天多長 30分鐘一天?」；寫入：「好 寫入」。

**隊伍組成**（#97）
- 一隊 **3 人**：主角＋最多 2 名隊友；可以少帶人。難度由敵人的數量與強度決定，敵人依 3 人隊伍設計（07 7.8，數值開發時定）；不帶隊友（獨行）時可用「獨狼」條件的技能與詞條（06 6.37，#156）；各種遭遇的敵方隻數見 9.6.6「遭遇大小」（#155：路邊 1～2、地點戰 2～3、精英與頭目照原設計）。
- 隊友來源：朋友的影子（強度上限照招募者，9.6.8）、系統傭兵、**劇情夥伴**（主線或任務鏈給的 NPC，只在對應任務裡跟著，佔一個隊友位）。賽季 Boss 只准傭兵，依「主角＋2 名傭兵」設計（9.6.8）。
- 傭兵雇用免費；出城前在主城或小鎮選好，野外不能換。

**死亡與失敗**（#98）
- **野外全滅**：回最近的小鎮或營火，HP 回滿；這場沒有戰利品；背包、裝備不掉，經驗不扣；下一場戰鬥帶「疲憊」（例：開場 HP 80%，打完一場就消失）。
