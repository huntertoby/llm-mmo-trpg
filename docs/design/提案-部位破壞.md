# 提案：部位破壞（C 案：頭目仍佔 1 格）

> 狀態：**提案，未寫入設計**。使用者說「好 寫入」後，由玩法 PM 改寫進 `05-戰鬥.md`、`18`、`19`，再刪掉這個檔。
> 來源：使用者原話「其實有沒有一種解法是大型頭目就佔那麼多格 6格之類的 然後可能還可以搞個部位破壞?」。看完 A～D 四案比較後答「外框照做，C 先出設計」（2026-11-12，專案 PM 轉達）。
> 數值：本檔只寫規則與預設比例，實際數值由使用者在「數值工坊」調。

## 1. 一句話

頭目身上有 2～3 個「部位」，各有一條小血條。打掉一個部位，頭目就失去一招，或少一種能力。有些部位要從背後、從高處或遠處，或趁頭目倒地時才打得到。這樣不同 build 各有自己最擅長打的部位。

## 2. 基本規則

1. **部位不是單位**：不佔格、不能被選成移動或位移的對象，也不會擋路。頭目照舊佔 1 格。
2. **打部位不浪費傷害**：打中部位時，傷害照常算進頭目的 HP，同時從部位的小血條扣掉同樣的數字。所以挑部位只是「順便」，不是犧牲輸出。
3. **部位小血量**：用頭目最大 HP 的千分比定。預設每個部位 200‰，同一隻頭目的部位加總不超過 600‰，可以在數值工坊調。
4. **部位可以有自己的防禦**：部位可以帶自己的護甲或元素抗性修正，例如外殼部位護甲高。沒寫就和本體相同。
5. **破了就一直破著**：每個部位只會破一次，效果持續到戰鬥結束。頭目回血、換階段都不會讓部位長回來。破掉時寫一條戰鬥紀錄，並交給說書人敘事。
6. **階段**：階段門檻照舊只看頭目的 HP。每個部位可以標「哪些階段露出」，沒露出的部位打不到；已經破了的部位，換階段後還是算破。
7. **預設打本體**：不選部位就是打本體，和現在完全一樣。

## 3. 打得到的條件（部位上標其中一種）

| 條件 | 意思 | 主要讓誰發光 |
|---|---|---|
| 任何方向 | 能打到頭目就能打這個部位 | 所有人 |
| 從背後 | 攻擊者站在頭目朝向的背後半邊，和背刺同一個判定，近戰、遠程都可以 | 刺客、瞬步、團隊連招（坦克先讓頭目轉身） |
| 從高處或遠處 | 攻擊者比頭目高至少 1 層，或距離 3 格以上 | 弓手、遠程、搶高台的打法 |
| 趁倒地或暈眩 | 頭目身上有倒地、暈眩或冰凍時才露出 | 控制流 |
| 某階段才露出 | 只在指定階段打得到 | 讓戰鬥有「破綻」節奏 |

打不到的部位，畫面上照樣列出，但灰掉並寫原因，例如「要從背後才打得到」。

## 4. 破掉的效果（只用引擎已經有的東西）

- **封住一招**：那一招之後不能再用；如果正在蓄力，蓄力也一起打斷。
- **能力下降**：移動、護甲、命中、某元素抗性其中一項降低。數值由數值工坊調。
- **立刻的控制**：例如倒地 1 回合。頭目原本對這種控制免疫的話，就沒有效果。
- **拿掉一個機制**：例如停止回合開始的自我治療、停止產卵。

一個部位最多帶 2 種效果。

## 6. 和現有規則的互動

- **範圍技、連鎖、彈跳**：只打本體，不打部位。只有單體招才能選部位，給單體 build 一個自己的舞台。
- **持續傷害**（燃燒、中毒、流血）與反應、表面造成的傷害：只扣本體。
- **命中、暴擊、背刺加成**：照現行規則算。「從背後」的部位一樣吃背刺加成。
- **控制與推擠**：頭目的控制免疫、推擠規則都不變。部位破掉帶來的控制，照頭目的免疫判定。
- **召喚物與隊友**：都可以選部位。隊友 AI 的做法見第 7 節。
- **吸血、回饋這類效果**：照實際造成的傷害算，和現在一樣。
- **重播與確定性**：選哪個部位是行動的一個欄位（例如 `target_part`），記在動作列表裡。部位血量存在戰鬥狀態裡，重播結果不變。AI 選部位只用確定性的評分，同分照部位 ID 排序。
- **LLM**：說書人只負責敘事部位破掉，不能決定部位破沒破。

## 7. AI

- **頭目**：
  - 第一版不做特別的「護住部位」行為，靠現行規則就有攻防：被近戰打會轉身、AI 會避免背對敵人。
  - 只加一條：頭目的部位快破時，AI 給「把背轉離背後的攻擊者」多一點分數。
- **我方隊友與影子**：照「破掉的效果價值」挑部位：
  - 能封住頭目下一招、或能打斷蓄力時，優先打部位。
  - 沒有這種情況時，照舊打本體。
  - 部位價值會寫進 AI 價值表，可以在數值工坊調。

## 8. 介面大意

- 頭目的血條下面列出部位的小血條，最多 3 條，各寫名稱。破掉的打叉。
- 選了單體招、點頭目時，在頭目旁跳出小選單：「本體／拂塵／氣海…」。
  - 打不到的灰掉並寫原因。
  - 每一項都寫「破掉會：封住霧中換位」。
  - 直接點本體或按確認，就是打本體，現有操作不變。
- 預覽照現在一樣顯示傷害，多一行「拂塵還剩 12」。
- 部位破掉時有一次明顯的演出（碎片、閃光）和一行戰鬥紀錄。美術要畫部位的位置記號和破掉的樣子，工作量見第 11 節。

## 9. 各 build 怎麼發光（例子）

| build | 在部位破壞裡的時刻 |
|---|---|
| 刺客／瞬步背刺 | 繞到背後打「氣海」，讓真人歸一階段不能再回血 |
| 坦克＋刺客 | 坦克先近戰讓頭目轉身，盜賊再打背後的部位（現行的團隊連招，多一個目標） |
| 弓手／遠程 | 站上高台打灰燼之心的熔岩噴口，讓熔岩不再噴 |
| 控制流（擊倒、暈眩、冰凍） | 把頭目弄倒，隊友趁機打殼縫或腹部 |
| 爆發流 | 等核心露出時一口氣打破，打斷熔心爆或界碎 |
| 水冰流 | 灰燼之心原本的冷卻外殼照舊，和殼縫是兩條路 |
| 範圍、召喚、持續傷害流 | 照舊打本體；他們的時刻在清小怪與源晶柱，不在部位 |

## 10. 第一版做多少（建議）

- **第一版**：只做霧鎖真人、灰燼之心兩個區域頭目，每隻 3 個部位，含規則、引擎、AI、介面和戰鬥紀錄。
- **第二版**：看試玩結果，再加碎晶之主與大型精英（熔核領主、熔爐母獸）。
- **以後**：破部位多掉材料，或掉部位專屬材料。
- **要使用者決定的**：
  1. 第一版是否就是這兩隻。
  2. 打部位的傷害是否照第 2 條也算進頭目 HP（我建議算，不算的話打部位會變成犧牲輸出）。
  3. 範圍技是否只打本體。
