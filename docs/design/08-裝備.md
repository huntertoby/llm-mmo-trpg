# 專案計畫：裝備系統（第 8 節）

> 本檔為 `docs/專案計畫.md` 的一部分，總覽與守則見該檔。

## 8. 裝備系統（Phase 5）

### 8.1 數值分工

| 判定項目 | 主導者 | 說明 |
|---|---|---|
| 命中、技巧成功、暴擊 | 骰子＋小幅修正 | 有界精度 |
| 傷害、血量、抗性 | 裝備數值 | 照 MMO 方式成長 |
| 可做的動作 | 裝備詞條＋技能 | 橫向擴展選項 |

創意加成一律使用不會過時的形式：優勢／劣勢骰、百分比效果、固定回合數的狀態。

### 8.2 裝備與動作解鎖

```json
{
  "id": "item_ashfang_7f3a",
  "name": "灰燼之牙",
  "slot": "main_hand",
  "weapon_type": "greatsword",
  "item_level": 35,
  "rarity": "epic",
  "quality": null,
  "base": { "damage": "2d8", "attack_value": 42, "scaling_attr": "str", "crit_range": 19 },
  "affixes": ["affix_fire_skill_amp", "affix_storm_charge"],
  "granted_actions": ["ignite_object"],
  "tags": ["fire", "ignite", "two_handed"],
  "resonance_tags": ["ash"],
  "requirements": { "str": 14 },
  "provenance": { "source": "drop", "where": "焚毀的村莊", "from": "盜賊頭目", "battle_id": "b_0142" },
  "binding": "on_equip",
  "lore": "從燒毀村莊的強盜頭目身上奪來的劍，刀身仍帶餘溫"
}
```

- `quality`：原型固定為 `null`，鐵匠鋪加入後啟用（見 8.7）。
- `provenance`（來歷）：與技能族譜相同，記錄取得地點、對象與戰鬥，供編年史使用。
- `binding`：`none`／`on_equip`／`on_pickup`，供後期交易與市場使用，原型先保留欄位。**第一季所有物品都是 `on_pickup`**（配合不交易，8.16）（2026-10-22，見 `docs/玩法決定紀錄.md` #33）。

裝備標籤決定解析器可接受的動作：有 `ignite` 才能「用劍點燃地上的油」；鉤爪可拉近敵人或攀爬；盾牌解鎖推擠與掩護；盜賊手套可在戰鬥中偷取物品。

### 8.3 詞條效果語言（與技能共用原語與觸發）

```json
{
  "id": "affix_storm_charge",
  "trigger": "on_hit",
  "effect": { "type": "add_stack", "stack": "static", "amount": 1 },
  "limit": { "max_stacks": 3 },
  "activate": {
    "cost": { "stack": "static", "amount": 3 },
    "ap_cost": 1,
    "effect": { "type": "damage", "dice": "3d6", "element": "lightning" }
  },
  "narrative_tags": ["lightning", "crackling", "storm"]
}
```

結構固定為：**觸發時機 → 條件 → 效果 → 限制 → 啟動（選用）→ 敘事標籤**。

### 8.4 MMO 詞條轉譯表

| MMO 詞條 | 問題 | 回合制轉譯 |
|---|---|---|
| 固定屬性（力量 +20） | 無 | 直接進公式（命中類壓在有界範圍） |
| 攻速、冷卻縮減 | 回合制沒有「秒」 | 先攻加成、冷卻以回合計、累積到門檻給 +1 AP |
| 機率觸發（命中時 10%） | 次數少、不穩定、無感 | 確定性觸發：自然 18+、每第 3 次命中、充能層數 |
| 每秒持續傷害 | 秒 → 回合 | 每回合結算，持續回合數固定 |
| 吸血、反傷 % | 無 | 每次命中結算 |
| 仇恨值 | 沒有仇恨表 AI | 嘲諷：攻擊非嘲諷者時有劣勢 |
| 移動速度 | — | 每回合移動格數 +1 |
| 格擋機率 | 被動無感 | 反應動作：被攻擊時可選擇格擋，消耗耐力 |
| 套裝效果 | 固定套裝會讓所有人刷同一套，build 收斂 | 改用共鳴系統（見 8.9） |

原則：**盡量把被動百分比轉成玩家可主動選擇的東西**（充能、反應、條件觸發）。

### 8.5 掉落管線

1. 引擎依怪物等級、掉落表、稀有度擲出數值與詞條。
2. **物品預算檢查**：每個「物品等級 × 稀有度」有點數上限（初始值：傷害 1 點 = 1、暴擊範圍 +1 = 15、每個 granted_action = 20、改寫規則型詞條 = 40）。
3. LLM 根據詞條與取得情境命名、撰寫描述與傳說。
4. 劇情獨特裝備可由 LLM 提議概念，但數值仍需通過預算檢查。

**強度原則**（2026-10-22，見 `docs/玩法決定紀錄.md` #33）：裝備強度 **主要由物品等級決定**；同一物品等級下，各稀有度的總預算相同，**稀有度只決定預算怎麼分配**（詞條種類較多或較少），和技能「稀有度不增加強度」（06 6.12）同一原則。運氣好拿到的是不同的打法，不是更高的數字。物品等級上限跟著賽季等級上限走。

### 8.6 詞條數量限制

- 詞條數量依稀有度決定（見 8.7）；其中主動或觸發型最多 1–2 條。
- 介面常駐顯示「目前可用的反應與充能」。
- 被動數值類詞條合併為總屬性顯示。

### 8.7 物品等級、稀有度、品質

三個軸各管一件事：

| 軸 | 管什麼 | 說明 |
|---|---|---|
| 物品等級 (`item_level`) | 基礎數值有多高 | 攻擊值、防禦值、傷害照 MMO 方式成長，配合比例命中公式（5.4） |
| 稀有度 (`rarity`) | 有幾條詞條、哪些種類 | 決定「能做什麼」，而不是「數字多大」；同物品等級總預算相同（8.5 強度原則） |
| 品質 (`quality`) | 同一件裝備的小幅浮動 | 基礎數值 ±10%；**延後至鐵匠鋪加入**（材料與鐵匠等級影響品質） |

| 稀有度 | 詞條 | 特色 |
|---|---|---|
| 普通 common | 0–1 條數值詞條 | 基本款 |
| 優良 uncommon | 1–2 條 | 開始出現觸發詞條 |
| 稀有 rare | 2–3 條 | 可能帶 granted_actions |
| 史詩 epic | 3 條，含 1 條技能強化詞條 | 開始影響 build |
| 傳說 legendary | 2 條 ＋ 1 個獨特效果 | 可帶改寫規則型效果；由 LLM 提概念，數值經物品預算驗證 |

### 8.8 詞條四類

| 類別 | 範例 | 顯示 |
|---|---|---|
| 數值詞條 | 力量 +5、火抗 +10% | 合併進總屬性 |
| 觸發詞條 | 命中時累積靜電、擊殺時回復耐力 | 以技能原語 ＋ 觸發時機組成（8.3） |
| 動作詞條 | 點燃物件、鉤爪拉近、盾牌推擠 | 解鎖 granted_actions |
| **技能強化詞條** | 帶 `fire` 標籤的技能傷害 +15%；帶 `push` 標籤的技能距離 +1；施加燃燒時同時產生 oil 表面 | 在技能說明中標示受哪件裝備強化 |

技能強化詞條讓 **裝備放大 build 主題**，同一件裝備對不同 build 的價值不同，是本系統最重要的詞條類別。以標籤選取技能，因此對隨機生成的技能也自動生效。

- **改以關鍵字選取**（2026-10-22，見 `docs/玩法決定紀錄.md` #33）：技能強化詞條的目標用 06 6.27 的關鍵字，例：「你製造點燃時，燃燒 +1 回合」「利用倒地時傷害 +15%」。掉落的詞條偏向該區域的關鍵字。

### 8.9 共鳴（取代固定套裝）

- 裝備帶有 `resonance_tags`（例如 `ash`、`storm`、`shadow`）。
- 同時穿戴 **2 件** 同標籤裝備觸發小共鳴，**4 件** 觸發大共鳴；任何帶相同標籤的裝備都算，不限特定套裝。
- 共鳴效果以資料檔定義（`content/resonance/`），效果使用技能原語並計入預算。
- 與湧現式職業契合：build 偏向某主題時，自然會撿到同主題裝備，共鳴自然成形。
- 固定的命名套裝留給後期特殊副本。
- **`resonance_tags` 直接使用 06 6.27 的關鍵字**，和技能的雙流派共鳴（6.27.4）共用一套 2／4 門檻（2026-10-22，見 `docs/玩法決定紀錄.md` #33）。**第一季不做共鳴**，正式季再加。

```json
{
  "id": "resonance_ash",
  "tag": "ash",
  "tiers": {
    "2": { "type": "modify_status", "status": "burn", "duration_bonus": 1 },
    "4": { "trigger": "on_enemy_death", "condition": { "target_has_status": "burn" },
           "effect": { "type": "create_surface", "surface": "fire", "duration": 2 } }
  }
}
```

### 8.10 裝備欄位

共 9 格：**主手、副手、頭、身、手、腳、項鍊、戒指 ×2**。雙手武器同時占用主手與副手。

- **第一季先 5 格**（2026-10-22，見 `docs/玩法決定紀錄.md` #33）：主手、副手、身體、飾品 ×2；頭、手、腳留到正式季。

### 8.11 武器類型（2026-10-22 擴充，見 `docs/玩法決定紀錄.md` #34）

**原則**：每種武器只有 **一個簡單的小特性**；同一大類的總預算相同，比的是用法，不是數字。雙手武器不能拿副手，這就是取捨。★＝擴充前已有。

| ★雙手劍 | 近戰 | 1 | 力量 | 雙 | 橫掃：普攻同時打目標旁邊 1 格 | 已有（特性待補） |

| 錘 | 近戰 | 1 | 力量／體質 | 雙 | 震退：普攻命中推 1 格（會撞擊） | 第一批 |

**副手**

| 副手 | 縮放屬性 | 小特性 | 批次 |
|---|---|---|---|
| 圓盾 | 力量／體質 | 格擋反應強化 | 第一批 |
| 塔盾 | 體質 | 自身半掩護；移動 −1 | 第二批 |
| 法書 | 智力 | 法術傷害 +10% | 第二批 |
| 法器珠 | 智力／意志 | 法術射程 +1 | 第二批 |

**火器**（使用者原話：「槍先只做單發但要跟弓有鑒別度」「霰彈距離近傷害才高 長槍要遠 不能貼臉 或者貼臉懲罰 受傷傷害低但是有優勢」「再加個手槍 然後考了能不能雙持」）

- **共通**：開火後彈匣變空，**裝填花 1 AP**；**槍聲**：開火會解除自己的隱蔽；**直射**：不能拋射，視線被擋就不能打。單發傷害較高，每回合總輸出和其他武器相同（預算平衡）。
- **長槍**：射程 8，彈匣 1 發。**站定狙擊**：本回合還沒移動時開火，命中 +2、暴擊範圍 +2（可和瞄準疊加）；**直射穿甲**：無視半掩護、穿透目標 25% 防禦；**貼臉懲罰**：相鄰時命中 −2、傷害 −50%；**遠距**：4 格以上傷害 +25%。
- **霰彈槍**：單體，射程 4，彈匣 1 發；傷害依距離 1／2／3／4 格 ＝ 100／75／50／25%；沒有站定與遠距加成，可以邊走邊打。散射（錐形）之後做成技能，不放在武器本身。
- **手槍**：單手（可以搭副手），射程 5，**彈匣 2 發**（開兩槍才要裝填）；移動後開火沒有懲罰，也沒有站定、遠距加成或距離修正。
- **雙手槍**：成對算一件、占雙手；彈匣 4 發（2＋2），1 AP 一次裝滿，開火時用有子彈的那把。
- 彈種（電磁彈、燃燒彈、冰凍彈、標記彈）走技能或詞條，不做彈藥背包。

**雙持**：只做 **雙匕首、雙手槍**，成對算 **一件占雙手的武器**；不開放任意兩把單手武器組合（避免特性組合爆炸）。

**距離定位**

| 距離 | 最強的武器 |
|---|---|
| 1 格 | 匕首、雙匕首、霰彈槍 |
| 2～3 格 | 霰彈槍、矛 |
| 2～5 格 | 手槍、雙手槍（機動、穩定） |
| 3～6 格 | 弩（穿透一排） |
| 4～8 格 | 長槍（站定時） |
| 任何距離 | 弓（最靈活：連射、居高、拋射） |

**和新流派的對應**（06 6.27.3）：烈焰：火法杖、法書、火器；潮雷：雷法杖、法器珠、火器；霜寒：冰法杖、矛；撼地：錘、雙手劍、圓盾；鐵壁：單手劍＋盾、錘、塔盾；影刃：匕首、雙匕首、鐮刀；鷹眼：弓、弩、長槍；聖光：權杖、單手劍＋盾、法書；喚靈：圖騰杖、法器珠、法書；機關：弩、火器、匕首；念動：法杖、法器珠、鞭；血怒：雙手劍、斧、鐮刀。

- 武器類型決定普通攻擊的射程、形狀、傷害骰與縮放屬性。
- **與技能的配合**：技能只能要求武器 **大類**（`melee`／`ranged`／`focus`／`any`），不可要求特定武器，避免出現廢技能；技能生成時參考目前武器類型，讓技能與武器搭配。
- 外觀造型對應見 8.18；#34 新武器的造型美術 PM 已補齊（`docs/art/組裝式裝備.md`、`docs/art/weapons-34.png`）。

### 8.13 裝備取得與節奏（2026-10-22 決定，見 `docs/玩法決定紀錄.md` #33）

| 來源 | 內容 |
|---|---|
| 掉落 | 主要來源；依地點與敵人家族，詞條偏向該區的關鍵字 |
| 任務 | 任務鏈結尾給 **選擇式** 獎勵（三選一部位或詞條），降低運氣成分 |
| 打造 | 用材料 **指定部位＋1 條關鍵字詞條**（8.14） |
| 區域頭目、精英 | 掉史詩 |
| 賽季 Boss | 不掉裝備（它是競賽終點） |

- 兩週的第一季大約換 3 輪：起始（1～3 級）→ 中期（4～7 級）→ 畢業（8～10 級，精英、頭目、打造）。花時間多的人較早畢業，不會無限變強。
- 第一季稀有度只到 **史詩**（普通、優良、稀有、史詩）；詞條以數值與技能強化為主，少量觸發與動作詞條。傳說、品質（鐵匠）、共鳴留到正式季。

### 8.14 材料（2026-10-22 決定，見 `docs/玩法決定紀錄.md` #33）

**6 種**（名稱為暫定名，世界觀定案後統一改名；**材料名稱固定由本文件定，不交給 LLM**）：

| 材料（暫定名） | 來源 | 用途 |
|---|---|---|
| 粗料（通用 1 階） | 1～3 級敵人掉落 | 打造、強化 |
| 精料（通用 2 階） | 4～7 級敵人掉落 | 打造、強化 |
| 上料（通用 3 階） | 8～10 級敵人、精英掉落 | 打造、強化 |
| 精華 | 分解裝備 | 重骰詞條、指定詞條 |
| 區域 A 特產 | 區域 A 的採集點 | 打造帶該區關鍵字的詞條 |
| 區域 B 特產 | 區域 B 的採集點 | 同上 |

- 採集點 **每位玩家各自計算**，不用搶。
- 用途：**打造**（指定部位＋1 條關鍵字詞條）、**重骰** 一條詞條（同一件越骰越貴；結果是確定性的，見 8.20）、**強化** +1～+3。
- 材料 **不拿來改造技能**；技能只從世界來源取得（07 7.6）。

### 8.16 交易（2026-10-22 決定，見 `docs/玩法決定紀錄.md` #33）

### 8.18 命名與外觀（2026-10-22 決定，見 `docs/玩法決定紀錄.md` #33）

- **材料**：名稱固定，由本文件定（8.14），不交給 LLM。
- **裝備**：鍛造或取得的裝備，**名稱與描述由 LLM 依玩家的流派、經歷生成**（Phase 4 起；之前用隨機組合的名稱）。**數值照樣由引擎依預算決定**，LLM 只負責名稱與描述（守則 3）。
- **外觀**：採「組裝式」，使用者選定「名稱由 LLM 自由取、外觀欄位從清單選」（2026-10-22；美術評估見 `docs/art/組裝式裝備.md`）。

- 裝備資料新增 4 個欄位，**LLM 生成裝備時只能從清單選**（pydantic 驗證，清單放 `content/`；不認得的值退回預設：劍、直劍、鐵、common）。名稱只顯示，不影響外觀。

### 8.20 打造的可復刻性（2026-10-22 決定，見 `docs/玩法決定紀錄.md` #33）

> 使用者原話：「但裝備打造應該要有可復刻性」，選 A、C、D。

- **確定性打造（A）**：**配方** ＝ 部位＋物品等級＋稀有度＋指定的關鍵字詞條＋投入的材料組合。其餘詞條與數值由引擎以「配方指紋」為種子產生——同一份配方一定打出同一件裝備，不是抽獎。自己用同樣的輸入重打，結果也相同。
  - 配方指紋用穩定的雜湊（例：配方正規化後的 SHA-256），不用 Python 內建 `hash()`（守則 2）。
- **重骰也是確定性的**：第 n 次重骰某條詞條的結果，由「配方指紋＋詞條位置＋n」決定，可以重現；費用照舊越骰越貴。重骰紀錄成為配方的一部分（配方 ＝ 基礎配方＋重骰序列），所以重骰過的裝備也能被復刻。另可花精華 **指定** 詞條（費用較高），完全沒有隨機。
- **配方分享（C）**：每件打造裝備有 **配方碼**，可以在遊戲內分享或貼到 Discord。朋友用 **自己的材料** 打造，得到同一件裝備（各自綁定）；配方要求的等級、材料不足時不能打。
- **重播驗證（D）**：每次打造與重骰都寫入日誌（配方、材料消耗、重骰序列、引擎版本），和戰鬥一樣可以重播驗證，用來防作弊。
- **名稱與外觀綁定配方**：配方 **第一次** 被打造時，才請 LLM 生成名稱、描述與外觀欄位（8.18），結果和配方指紋一起快取；之後任何人用同一份配方打造，都直接沿用，不再呼叫 LLM。來歷 `provenance` 記錄配方的原創者。
- **掉落的裝備** 不是打造品，沒有配方碼。
- 提醒：配方可以分享後，大家可能複製同一份熱門配方。由於詞條以關鍵字為主，不同流派需要的配方不同，多樣性的影響有限；試玩時觀察。
