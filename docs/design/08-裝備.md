# 專案計畫：裝備系統（第 8 節）

> 本檔為 `docs/專案計畫.md` 的一部分，總覽與守則見該檔。

## 8. 裝備系統（Phase 5）

### 8.1 數值分工

| 判定項目 | 主導者 | 說明 |
|---|---|---|
| 命中、技巧成功、暴擊 | 骰子＋小幅修正 | 有界精度 |
| 傷害、血量、抗性 | 裝備數值 | 照 MMO 方式成長 |
| 可做的動作 | 裝備詞條＋技能 | 橫向擴展選項 |

創意加成一律使用不會過時的形式：優勢／劣勢骰、百分比效果、固定回合數的狀態。

### 8.2 裝備與動作解鎖

```json
{
  "id": "item_ashfang_7f3a",
  "name": "灰燼之牙",
  "slot": "main_hand",
  "weapon_type": "greatsword",
  "item_level": 35,
  "rarity": "epic",
  "quality": null,
  "base": { "damage": "2d8", "attack_value": 42, "scaling_attr": "str", "crit_range": 19 },
  "affixes": ["affix_fire_skill_amp", "affix_storm_charge"],
  "granted_actions": ["ignite_object"],
  "tags": ["fire", "ignite", "two_handed"],
  "resonance_tags": ["ash"],
  "requirements": { "str": 14 },
  "provenance": { "source": "drop", "where": "焚毀的村莊", "from": "盜賊頭目", "battle_id": "b_0142" },
  "binding": "on_equip",
  "lore": "從燒毀村莊的強盜頭目身上奪來的劍，刀身仍帶餘溫"
}
```

- `quality`：原型固定為 `null`，鐵匠鋪加入後啟用（見 8.7）。
- `provenance`（來歷）：與技能族譜相同，記錄取得地點、對象與戰鬥，供編年史使用。
- `binding`：`none`／`on_equip`／`on_pickup`，供後期交易與市場使用，原型先保留欄位。**第一季所有物品都是 `on_pickup`**（配合不交易，8.16）（2026-10-22，見 `docs/玩法決定紀錄.md` #33）。

裝備標籤決定解析器可接受的動作：有 `ignite` 才能「用劍點燃地上的油」；鉤爪可拉近敵人或攀爬；盾牌解鎖推擠與掩護；盜賊手套可在戰鬥中偷取物品。

### 8.3 詞條效果語言（與技能共用原語與觸發）

```json
{
  "id": "affix_storm_charge",
  "trigger": "on_hit",
  "effect": { "type": "add_stack", "stack": "static", "amount": 1 },
  "limit": { "max_stacks": 3 },
  "activate": {
    "cost": { "stack": "static", "amount": 3 },
    "ap_cost": 1,
    "effect": { "type": "damage", "dice": "3d6", "element": "lightning" }
  },
  "narrative_tags": ["lightning", "crackling", "storm"]
}
```

結構固定為：**觸發時機 → 條件 → 效果 → 限制 → 啟動（選用）→ 敘事標籤**。

### 8.4 MMO 詞條轉譯表

| MMO 詞條 | 問題 | 回合制轉譯 |
|---|---|---|
| 固定屬性（力量 +20） | 無 | 直接進公式（命中類壓在有界範圍） |
| 攻速、冷卻縮減 | 回合制沒有「秒」 | 先攻加成、冷卻以回合計、累積到門檻給 +1 AP |
| 機率觸發（命中時 10%） | 次數少、不穩定、無感 | 確定性觸發：自然 18+、每第 3 次命中、充能層數 |
| 每秒持續傷害 | 秒 → 回合 | 每回合結算，持續回合數固定 |
| 吸血、反傷 % | 無 | 每次命中結算 |
| 仇恨值 | 沒有仇恨表 AI | 嘲諷：攻擊非嘲諷者時有劣勢 |
| 移動速度 | — | 每回合移動格數 +1 |
| 格擋機率 | 被動無感 | 反應動作：被攻擊時可選擇格擋，消耗耐力 |
| 套裝效果 | 固定套裝會讓所有人刷同一套，build 收斂 | 改用共鳴系統（見 8.9） |

原則：**盡量把被動百分比轉成玩家可主動選擇的東西**（充能、反應、條件觸發）。

### 8.5 掉落管線

1. 引擎依怪物等級、掉落表、稀有度擲出數值與詞條。
2. **物品預算檢查**：每個「物品等級 × 稀有度」有點數上限（初始值：傷害 1 點 = 1、暴擊範圍 +1 = 15、每個 granted_action = 20、改寫規則型詞條 = 40）。
3. LLM 根據詞條與取得情境命名、撰寫描述與傳說。
4. 劇情獨特裝備可由 LLM 提議概念，但數值仍需通過預算檢查。

**強度原則**（2026-10-22，見 `docs/玩法決定紀錄.md` #33）：裝備強度 **主要由物品等級決定**；同一物品等級下，各稀有度的總預算相同，**稀有度只決定預算怎麼分配**（詞條種類較多或較少），和技能「稀有度不增加強度」（06 6.12）同一原則。運氣好拿到的是不同的打法，不是更高的數字。物品等級上限跟著賽季等級上限走。

### 8.6 詞條數量限制

- 詞條數量依稀有度決定（見 8.7）；其中主動或觸發型最多 1–2 條。
- 介面常駐顯示「目前可用的反應與充能」。
- 被動數值類詞條合併為總屬性顯示。

### 8.7 物品等級、稀有度、品質

三個軸各管一件事：

| 軸 | 管什麼 | 說明 |
|---|---|---|
| 物品等級 (`item_level`) | 基礎數值有多高 | 攻擊值、防禦值、傷害照 MMO 方式成長，配合比例命中公式（5.4） |
| 稀有度 (`rarity`) | 有幾條詞條、哪些種類 | 決定「能做什麼」，而不是「數字多大」；同物品等級總預算相同（8.5 強度原則） |
| 品質 (`quality`) | 同一件裝備的小幅浮動 | 基礎數值 ±10%；**延後至鐵匠鋪加入**（材料與鐵匠等級影響品質） |

| 稀有度 | 詞條 | 特色 |
|---|---|---|
| 普通 common | 0–1 條數值詞條 | 基本款 |
| 優良 uncommon | 1–2 條 | 開始出現觸發詞條 |
| 稀有 rare | 2–3 條 | 可能帶 granted_actions |
| 史詩 epic | 3 條，含 1 條技能強化詞條 | 開始影響 build；**稀有起就有 1 條技能強化**（8.21，2026-10-22） |
| 傳說 legendary | 2 條 ＋ 1 個獨特效果 | 可帶改寫規則型效果；由 LLM 提概念，數值經物品預算驗證 |

### 8.8 詞條四類

| 類別 | 範例 | 顯示 |
|---|---|---|
| 數值詞條 | 力量 +5、火抗 +10% | 合併進總屬性 |
| 觸發詞條 | 命中時累積靜電、擊殺時回復耐力 | 以技能原語 ＋ 觸發時機組成（8.3） |
| 動作詞條 | 點燃物件、鉤爪拉近、盾牌推擠 | 解鎖 granted_actions |
| **技能強化詞條** | 帶 `fire` 標籤的技能傷害 +15%；帶 `push` 標籤的技能距離 +1；施加燃燒時同時產生 oil 表面 | 在技能說明中標示受哪件裝備強化 |

技能強化詞條讓 **裝備放大 build 主題**，同一件裝備對不同 build 的價值不同，是本系統最重要的詞條類別。以標籤選取技能，因此對隨機生成的技能也自動生效。

- **改以關鍵字選取**（2026-10-22，見 `docs/玩法決定紀錄.md` #33）：技能強化詞條的目標用 06 6.27 的關鍵字，例：「你製造點燃時，燃燒 +1 回合」「利用倒地時傷害 +15%」。掉落的詞條偏向該區域的關鍵字。

### 8.9 共鳴（取代固定套裝）

- 裝備帶有 `resonance_tags`（例如 `ash`、`storm`、`shadow`）。
- 同時穿戴 **2 件** 同標籤裝備觸發小共鳴，**4 件** 觸發大共鳴；任何帶相同標籤的裝備都算，不限特定套裝。
- 共鳴效果以資料檔定義（`content/resonance/`），效果使用技能原語並計入預算。
- 與湧現式職業契合：build 偏向某主題時，自然會撿到同主題裝備，共鳴自然成形。
- 固定的命名套裝留給後期特殊副本。
- **`resonance_tags` 直接使用 06 6.27 的關鍵字**，和技能的關鍵字共鳴（06 6.27.7）共用一套 2／4 門檻（2026-10-22，見 `docs/玩法決定紀錄.md` #33）。**第一季不做共鳴**，正式季再加。

```json
{
  "id": "resonance_ash",
  "tag": "ash",
  "tiers": {
    "2": { "type": "modify_status", "status": "burn", "duration_bonus": 1 },
    "4": { "trigger": "on_enemy_death", "condition": { "target_has_status": "burn" },
           "effect": { "type": "create_surface", "surface": "fire", "duration": 2 } }
  }
}
```

**火器**（使用者原話：「槍先只做單發但要跟弓有鑒別度」「霰彈距離近傷害才高 長槍要遠 不能貼臉 或者貼臉懲罰 受傷傷害低但是有優勢」「再加個手槍 然後考了能不能雙持」）

- **共通**：開火後彈匣變空，**裝填花 1 AP**；**槍聲**：開火會解除自己的隱蔽；**直射**：不能拋射，視線被擋就不能打。單發傷害較高，每回合總輸出和其他武器相同（預算平衡）。
- **長槍**：射程 8，彈匣 1 發。**站定狙擊**：本回合還沒移動時開火，命中 +2、暴擊範圍 +2（可和瞄準疊加）；**直射穿甲**：無視半掩護、穿透目標 25% 防禦；**貼臉懲罰**：相鄰時命中 −2、傷害 −50%；**遠距**：4 格以上傷害 +25%。
- **霰彈槍**：單體，射程 4，彈匣 1 發；傷害依距離 1／2／3／4 格 ＝ 100／75／50／25%；沒有站定與遠距加成，可以邊走邊打。散射（錐形）之後做成技能，不放在武器本身。
- **手槍**：單手（可以搭副手），射程 5，**彈匣 2 發**（開兩槍才要裝填）；移動後開火沒有懲罰，也沒有站定、遠距加成或距離修正。
- **雙手槍**：成對算一件、占雙手；彈匣 4 發（2＋2），1 AP 一次裝滿，開火時用有子彈的那把。
- 彈種（電磁彈、燃燒彈、冰凍彈、標記彈）走技能或詞條，不做彈藥背包。
- **武器技也算開火**（2026-10-22 玩法 PM 補充）：拿火器施放「用武器攻擊」的技能時，同樣消耗 1 發、觸發槍聲，並套用站定狙擊、遠距、貼臉、距離衰減等修正；彈匣空時不能施放，要先裝填。法術類技能不受影響。

**雙持**：只做 **雙匕首、雙手槍**，成對算 **一件占雙手的武器**；不開放任意兩把單手武器組合（避免特性組合爆炸）。

**距離定位**

| 距離 | 最強的武器 |
|---|---|
| 1 格 | 匕首、雙匕首、霰彈槍 |
| 2～3 格 | 霰彈槍、矛 |
| 2～5 格 | 手槍、雙手槍（機動、穩定） |
| 3～6 格 | 弩（穿透一排） |
| 4～8 格 | 長槍（站定時） |
| 任何距離 | 弓（最靈活：連射、居高、拋射） |

**常見搭配範例**（參考，不是規則；玩家可以自由搭配）：點燃：火法杖、法書、火器；帶電、潮濕：雷法杖、法器珠、火器；冰凍：冰法杖、矛；撞擊、倒地：錘、雙手劍、圓盾；防守：單手劍＋盾、錘、塔盾；隱蔽：匕首、雙匕首、鐮刀；高處、標記：弓、弩、長槍；治療：權杖、法書；召喚物：圖騰杖、法器珠；陷阱：弩、匕首；念力投擲：法杖、鞭；以血換力：雙手劍、斧、鐮刀。

- 武器類型決定普通攻擊的射程、形狀、傷害骰與縮放屬性。
- **與技能的配合**：技能只能要求武器 **大類**（`melee`／`ranged`／`focus`／`any`），不可要求特定武器，避免出現廢技能；技能生成時參考目前武器類型，讓技能與武器搭配。
- 外觀造型對應見 8.18；#34 新武器的造型美術 PM 已補齊（`docs/art/組裝式裝備.md`、`docs/art/weapons-34.png`）。

### 8.12 防具類型（2026-10-22 改寫，見 `docs/玩法決定紀錄.md` #37）

**原則**：任何角色都能穿任何防具，**沒有屬性門檻**；每種防具是「防禦高低＋一個小特性或代價」，同等級總預算相同，比的是取捨。只有 **身體** 分防具類型。

| 類型 | 防禦（初值） | 敏捷加到防禦 | 小特性或代價 | 戰術用途 |
|---|---|---|---|---|
| 布袍 | 1 | 全額 | 法力上限 +20% | 技能施放次數多 |
| 外套 | 2 | 全額 | 機動：跑步 +1 格（05 5.2）；攀跳不花額外的 2 格移動（05 5.2.2） | 搶高處、搶位置、撤離 |
| 皮甲 | 3 | 全額 | 潛行：獲得隱蔽時持續 +1 回合 | 隱蔽、偷襲、背刺 |
| 鎖甲 | 5 | 最多 +2 | 穩固：被推擊、擊退的距離 −1；潛行有劣勢 | 深淵、岩漿地圖不怕被推下去 |
| 板甲 | 7 | 不加 | 代價：移動 −1、不能攀跳、無法隱蔽；守護時防禦加成從 +25% 變 +50% | 守點、守護隊友；撤離吃虧 |

- 「敏捷加到防禦」讓敏捷高的人自然偏好輕甲，但不禁止任何組合。原本「重甲需要力量門檻」的規定 **取消**。
- 防禦數字是類型之間的相對初值；實際防禦依物品等級成長（8.22），以模擬校正。
- **頭、手、腳**：不分防具類型，是「**小防禦＋詞條**」欄位，各有偏好的詞條方向——頭：揭露、抗致盲、感知判定；手：命中、投擲、互動、裝填；腳：移動、跑步、攀跳、抗推。
- **屬性詞條依防具類型做機率偏好**（使用者原話：「不知道但如果智慧+2的重甲不會怪嗎」→ 選「B可以」）：板甲偏力量、體質；鎖甲偏力量、體質、敏捷；皮甲與外套偏敏捷；布袍偏智力、意志、感知。其他屬性仍有小機率出現；**打造時可以自由指定**。武器與飾品不偏。

### 8.20 打造的可復刻性（2026-10-22 決定，見 `docs/玩法決定紀錄.md` #33）

> 使用者原話：「但裝備打造應該要有可復刻性」，選 A、C、D。

- **確定性打造（A）**：**配方** ＝ 部位＋物品等級＋稀有度＋指定的關鍵字詞條＋投入的材料組合。其餘詞條與數值由引擎以「配方指紋」為種子產生——同一份配方一定打出同一件裝備，不是抽獎。自己用同樣的輸入重打，結果也相同。
  - 配方指紋用穩定的雜湊（例：配方正規化後的 SHA-256），不用 Python 內建 `hash()`（守則 2）。
- **重骰也是確定性的**：第 n 次重骰某條詞條的結果，由「配方指紋＋詞條位置＋n」決定，可以重現；費用照舊越骰越貴。重骰紀錄成為配方的一部分（配方 ＝ 基礎配方＋重骰序列），所以重骰過的裝備也能被復刻。另可花精華 **指定** 詞條（費用較高），完全沒有隨機。
- **配方分享（C）**：每件打造裝備有 **配方碼**，可以在遊戲內分享或貼到 Discord。朋友用 **自己的材料** 打造，得到同一件裝備（各自綁定）；配方要求的等級、材料不足時不能打。
- **重播驗證（D）**：每次打造與重骰都寫入日誌（配方、材料消耗、重骰序列、引擎版本），和戰鬥一樣可以重播驗證，用來防作弊。
- **名稱與外觀綁定配方**：配方 **第一次** 被打造時，才請 LLM 生成名稱、描述與外觀欄位（8.18），結果和配方指紋一起快取；之後任何人用同一份配方打造，都直接沿用，不再呼叫 LLM。來歷 `provenance` 記錄配方的原創者。
- **掉落的裝備** 不是打造品，沒有配方碼。
- 提醒：配方可以分享後，大家可能複製同一份熱門配方。由於詞條以關鍵字為主，不同 build 需要的配方不同，多樣性的影響有限；試玩時觀察。

#### 8.21.2 各類別的定義、例子與預算

**預算單位**：沿用 8.5 的「物品預算點數」。同物品等級各稀有度總預算相同（#33），稀有度只決定可以拆成幾條、可用哪些類別。下列點數是 **初值**，要用模擬校正。

| 已有的點數（8.5） | 傷害 1 點 ＝ 1；暴擊範圍 +1 ＝ 15；每個 granted_action ＝ 20；改寫規則型 ＝ 40 |
|---|---|
| **本檔補充的初值** | 屬性 +1 ＝ 3；最大 HP +4 ＝ 3；單一元素抗性 +5% ＝ 3；防禦值 +2% ＝ 3；命中 +1 ＝ 8；先攻 +2 ＝ 3；移動 +1 ＝ 12；法力上限 +5 ＝ 2 |

##### 8.21.2.1 數值

- 定義：無條件的固定加值，顯示時合併進總屬性（8.6）。
- 例：「力量 +2」「最大 HP +8」「火焰抗性 +10%」「移動 +1」「先攻 +2」。
- 預算：照上表相加。
- 部位：全部；**移動 +1 只出現在身體與飾品**（避免武器變成跑鞋）。

##### 8.21.2.2 條件數值

- 定義：條件成立時才生效的數值。條件只用引擎判定得了的狀態（站位、高度、HP、表面、本回合是否移動）。
- 例：「站在高處時命中 +1」「HP 低於 50% 時傷害 +15%」「本回合沒有移動：防禦 +15%」「站在水中時雷電抗性 +20%」「相鄰沒有隊友時暴擊範圍 +1」。
- 預算：數值點數 × 條件成立率（初值：常見 0.6、偶爾 0.35、少見 0.2），和修正規則的條件倍率同一套。
- 部位：全部。

##### 8.21.2.3 技能強化（關鍵字）——主力

- 定義：目標用 #28 的 **關鍵字** 選取技能（製造某關鍵字的技能、利用某關鍵字的技能），改變其數值、形狀或附帶效果。直接沿用現有 **修正規則**（`applies_to` 以標籤或動作類型選取；`change` 可以加元素、冷卻、傷害、範圍、推擊距離、形狀；`on_hit_effects`）。
- 例：「你製造點燃時，燃燒 +1 回合」「利用倒地的技能傷害 +15%」「製造帶電的技能範圍 +1」「製造冰凍的技能冷卻 −1」「你的撞擊傷害 +1d6」「你的召喚物最大 HP +20%」。
- 預算：修正規則的現有公式：Σ（套用對象每場預估使用次數 × 每次增加的價值 × 條件倍率）。
- 部位：主手、副手、飾品（身體以防禦為主，不放）。

##### 8.21.2.4 普攻附加

- 定義：讓普攻帶元素，或命中後附帶小效果；任何 build 都能用普攻接上協同。
- 例：「普攻帶雷電（製造帶電）」「普攻命中時，目標所在格產生水（製造潮濕）」「普攻命中燃燒中的敵人時，燃燒 +1 回合」「普攻命中時標記目標 1 回合」。
- 預算：普攻每場使用次數 × 附加效果點數。
- 部位：主手。
- 注意：和法杖「普攻帶元素」的小特性重疊；法杖本身已有元素時，此類詞條改為「第二元素」或不出現。

##### 8.21.2.5 武器特性強化

- 定義：只出現在對應武器上，放大或修改 #34 的武器小特性；讓同一種武器也有不同打法。
- 例：
  - 長槍：「貼臉懲罰減半」「站定狙擊的暴擊範圍再 +1」
  - 錘：「震退距離 +1（撞擊照常結算）」
  - 斧：「破甲持續 2 回合」
  - 矛：「藉機攻擊命中時目標移動 −2」
  - 弓：「拋射不受半掩護影響」
  - 弩：「穿透時每多穿 1 人，傷害 +10%」
  - 權杖：「祝禱的回復量 +50%」
  - 圖騰杖：「統御也加召喚物 1 格移動」
- 預算：武器特性的使用頻率 × 增加的價值；不可突破 6.6 的硬性上限（例如推擊距離 ≤ 2，超過改成撞擊）。
- 部位：主手。

##### 8.21.2.6 觸發

- 定義：「當……時：……」，觸發時機用現有 13 種（命中、暴擊、自然 20、擊殺、受傷、回合開始、回合結束、移動、每第 N 次命中、施放帶某標籤的技能、施加某狀態、撞擊、進入表面）。機率觸發一律改成確定性（8.4）。
- 例：「每第 3 次命中：目標倒地」「擊殺時：回 1 AP（每回合 1 次）」「受到近戰傷害時：攻擊者燃燒 1 回合」「回合開始時若站在水中：回 5% HP」「你施加冰凍時：相鄰的敵人緩速」「你的推擊造成撞擊時：施加流血」。
- 預算：每場預估觸發次數 × 效果點數；有每回合上限的打 0.7 折。
- 部位：全部；**每件最多 1 條**（8.6：主動或觸發型 1～2 條）。

##### 8.21.2.7 充能

- 定義：觸發時累積層數，滿層後花層數＋AP 啟動強力效果（8.3 範例）。用現有 `add_stack`／`consume_stack` 與 `content/stacks.yaml`。
- 例：「命中時累積 1 層靜電（上限 3）；花 3 層＋1 AP：對目標造成 3d6 雷電」「受到傷害時累積 1 層怒氣（上限 4）；花 4 層：下次攻擊傷害 ×2」「移動 3 格累積 1 層疾風（上限 2）；花 2 層：本回合移動 +3」。
- 預算：啟動效果點數 × 每場可啟動次數 ＋ 介面負擔加價（初值 +10%）。
- 部位：主手、身體。介面常駐顯示層數（8.6）。

##### 8.21.2.8 代價型（有好有壞）

- 定義：一條詞條同時帶正面與負面；正面可以比同預算多。
- 例：「傷害 +20%，受到的傷害 +10%」「移動 +2，防禦 −15%」「每回合開始失去 2 HP；技能冷卻 −1」「暴擊範圍 +2；命中 −1」「法術傷害 +25%；法力消耗 +50%」。
- 預算：正面點數 ≤ 預算 ＋ 負面點數 × 0.7（負面不是全額抵扣，避免「挑沒影響的缺點」）；負面不能選和自己 build 無關的項目（例如法師拿「近戰傷害 −20%」）——**負面只能從「普遍有影響」的表中挑**。
- 部位：全部。
- 風險：容易被組合成「極端玻璃大砲」；要有疊加上限（8.21.5.2）。

##### 8.21.2.9 動作（granted_actions，正式季）

- 定義：裝備解鎖一個新的主動動作，沿用技能的結構（像一招小技能）。
- 例：「解鎖：鉤爪拉近（1 AP，冷卻 3，拉 2 格）」「解鎖：點燃物件（1 AP）」「解鎖：盾牆（1 AP，在前方產生 1 格暫時障礙）」「解鎖：煙霧彈（1 AP，冷卻 4）」。
- 預算：每個 20 點起（8.5）＋該動作本身的技能預算。
- 部位：主手、副手。
- 需要新機制：裝備授予「常駐技能」（現有 `grant_skill` 是暫時的）。

##### 8.21.2.10 反應（正式季）

- 定義：解鎖新的反應，或強化既有反應（格擋、藉機攻擊、監視射擊）。
- 例：「被遠程攻擊時：可以格擋」「隊友在 2 格內被攻擊時：替他承受（每輪 1 次）」「藉機攻擊命中時：目標倒地」「監視射擊可以觸發 2 次」。
- 預算：每輪預估觸發次數 × 效果點數。
- 部位：副手、身體。
- 需要新機制：裝備授予反應；目前每人只有 1 個反應欄。

##### 8.21.2.11 改變規則（傳說，正式季）

- 定義：沿用 `rule_change`（目前有：火焰治療隊友、可以推動任何物件、流血尾跡、殘影分身）。
- 例：「你的火焰不會傷到隊友，反而治療他們」「你可以推動任何物件，包括石柱」「你移動經過的格子留下流血表面」。
- 預算：40 點起（8.5）；只出現在傳說；同時生效的規則改變最多 1 個（3D 規格）。
- 部位：傳說裝備任一部位。

#### 8.21.5 公平與 LLM

##### 8.21.5.1 誰來組合、誰來命名

| 部分 | 誰決定 | 理由 |
|---|---|---|
| 詞條本身（類別、數值、條件） | **固定詞條表**（content 資料），引擎依預算抽選或由玩家打造指定 | 守則 3：LLM 不能決定數值；固定表可以預先跑模擬 |
| 詞條數值的範圍 | 固定表給上下限，引擎依物品等級擲出 | 同上 |
| 掉落時選哪些詞條 | 引擎依地點、敵人家族、關鍵字權重抽選（確定性種子） | 可重播 |
| 打造時的指定詞條 | 玩家從固定表選（8.20） | 可復刻 |
| 裝備名稱、描述、外觀欄位 | LLM（8.18、8.20），第一次打造時生成並綁定配方 | 只影響顯示 |
| 傳說的「獨特效果」（正式季） | LLM 提議概念，**落在固定的改變規則或改造型清單內**，數值過預算 | 8.5、8.7 |

結論：**詞條不交給 LLM 自由組合**；LLM 只負責名稱與描述。

##### 8.21.5.2 高風險類型與上限（有現金獎勵）

| 風險 | 例子 | 上限建議 |
|---|---|---|
| 百分比疊加 | 5 件都「傷害 +15%」 | 同一個詞條 **可以疊加但遞減**（見 8.21.5.3）；全身「傷害加成」總和上限 **+50%** |
| 減傷疊加 | 抗性、防禦堆滿 | 沿用總減傷上限 75%（05 5.1.1）；單一元素抗性上限 50% |
| AP 回復 | 擊殺回 AP 無限接 | 每回合最多 +1 AP（所有來源合計），沿用 `ap_carry_max` |
| 冷卻縮減 | 冷卻 −1 疊到 0 | 冷卻最低 1 |
| 暴擊範圍 | 疊到 15 起暴擊 | 暴擊範圍最低 18（自然 18～20） |
| 無限連鎖 | 觸發互相觸發 | 沿用 `max_trigger_depth`（06 6.6）；裝備觸發每回合各自最多 1 次 |
| 移動 | 移動 +1 疊到 +4 | 裝備的移動加成合計最多 +2 |
| 代價型極端化 | 全部堆傷害、不顧防禦 | 代價型詞條全身最多 2 條 |
| 打造鑽漏洞 | 指定詞條＋重骰刷到完美 | 打造只能指定 1 條；重骰費用遞增（8.14）；所有過程可重播（8.20） |

##### 8.21.5.3 同一詞條的疊加規則（2026-10-22 使用者決定：「可以疊加但越疊越少」）

- 身上有多條 **相同 id** 的數值型詞條時，依數值由大到小排序（同值依裝備部位固定順序），第 1 條算 **100%**、第 2 條 **50%**、第 3 條 **25%**，第 4 條起 **0%**。最多等於單條的 1.75 倍。以整數千分比計算，結果無條件捨去。
- 只套用在 **數值部分**（數值、條件數值、技能強化與武器特性強化的數字）。**非數值的效果**（觸發、充能、普攻附加的元素、條件解鎖的新效果）無法「打折」，同一 id 只生效 **1 條**（取數值最高的那條）。
- 遞減之後，仍受全部 **硬上限** 約束（下表）；先算遞減，再套上限。

| 硬上限 | 數值 |
|---|---|
| 全身傷害加成（所有來源合計） | +50% |
| 總減傷 | 75%（05 5.1.1）；單一元素抗性 50% |
| 每回合 AP 回復（所有來源合計） | +1 |
| 冷卻 | 最低 1 |
| 暴擊範圍 | 最低從自然 18 起 |
| 裝備的移動加成合計 | +2 |
| 代價型詞條 | 全身最多 2 條 |
| 觸發連鎖 | `max_trigger_depth`（06 6.6）；每條裝備觸發每回合最多 1 次 |

### 8.22 部位預算分配與範例（2026-10-22 決定，見 `docs/玩法決定紀錄.md` #37）

**全身預算**（9 格合計）依物品等級成長，初值：等級 1 ＝ 100 點、等級 5 ＝ 200 點、等級 10 ＝ 350 點。9 格不會比 5 格更強，只是多了搭配的地方。

| 部位 | 比例 | 基礎（傷害或防禦）：詞條 |
|---|---|---|
| 主手 | 30% | 60：40 |
| 身體 | 20% | 60：40 |
| 副手 | 10% | 60：40 |
| 頭、手、腳 | 各 8% | 50：50 |
| 項鍊 | 8% | 0：100 |
| 戒指 ×2 | 各 4% | 0：100 |

- 同一件裝備不論稀有度，總點數相同（8.5 強度原則）；**普通** 把詞條點數全部併進基礎數值，其他稀有度依 8.7、8.21 分配成詞條。
- 預算太小的小部位（例：等級 1 的戒指 4 點），條數依「每條至少 2 點」下修。
- **示意範例**（單手劍、板甲、皮手套、戒指 × 等級 1／5／10 × 4 種稀有度）：`docs/design/草稿-裝備範例.md`；視覺樣張：`docs/art/gear-examples.png`（使用者看過：「Ok我看到了先這樣」）。數字為初值，以模擬校正。

### 8.23 裝備欄位清單（2026-10-22，#37；給 Phase 3G 實作）

| 欄位 id | 中文 | 可放的物品種類 `slot_type` | 備註 |
|---|---|---|---|
| `main_hand` | 主手 | `weapon`（8.11 主手武器） | 必填；空手時視為徒手 |
| `off_hand` | 副手 | `offhand`（圓盾、塔盾、法書、法器珠） | 主手是雙手武器或成對武器時 **被占用**，不能放東西 |
| `head` | 頭 | `head` | 小防禦＋詞條（8.12） |
| `body` | 身體 | `body`（布袍、外套、皮甲、鎖甲、板甲） | 唯一有防具類型的欄位 |
| `hands` | 手 | `hands` | 小防禦＋詞條 |
| `feet` | 腳 | `feet` | 小防禦＋詞條 |
| `neck` | 項鍊 | `neck` | 沒有基礎數值，全是詞條（8.22） |
| `ring_1`、`ring_2` | 戒指 ×2 | `ring` | 同一枚戒指不能裝兩次；兩枚有相同詞條 id 時照 8.21.5.3 遞減疊加 |

- **雙手武器**（雙手劍、錘、矛、拳套、鐮刀、弓、弩、長槍、霰彈槍、法杖、圖騰杖）與 **成對武器**（雙匕首、雙手槍）：裝在 `main_hand`，同時占用 `off_hand`。
- **單手武器**（單手劍、匕首、斧、鞭、手槍、權杖）：只占 `main_hand`，`off_hand` 可以放副手。
- 副手欄不能放第二把武器（雙持只做成對武器，8.11）。
