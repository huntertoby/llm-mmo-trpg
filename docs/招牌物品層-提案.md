# 招牌效果的物品層：要使用者定的規則（玩法 PM，2026-11-23）

> 起因：開發 PM 的 E6 草案（`docs/phases/E6草案.md`）。8.27（#169）定了「稀有、史詩帶 1 條招牌效果，佔 60%」「第一季開放傳說」，做成物品時有 9 處規則沒寫到。
> 每題第一個是建議。數字都是初值，開進數值工坊；PM 不量平衡。
> 已由玩法 PM 照原文代決、不用問的：附魔台的「指定」不能指定招牌（照「打造不能指定是哪一條」）；所有標灰的招牌都不佔 3 個名額；傳說第一版由程式挑效果、取名，LLM 取名另開一段；打造傳說可以指定獨特效果的類型（同一般打造）。

## 第一波（開發要先有答覆）

**招-1 招牌算不算詞條的條數**

現在：稀有 2～3 條、史詩 3 條。招牌固定吃掉 60%，剩下的 40% 本來就放不下 3 條。

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）算進條數** | 稀有＝招牌＋1～2 條，史詩＝招牌＋2 條。 | 史詩長劍：「解鎖鉤爪」＋技能強化＋1 條數值。和傳說「2 條＋1 個獨特效果」一樣多，傳說只是效果更特別（8.27 原意）。 |
| B 不算條數 | 稀有＝招牌＋2～3 條，史詩＝招牌＋3 條。 | 大多放不下，會被縮小；史詩可能比傳說多 1 條。 |

**招-2 低等級、小部位放不下怎麼辦**

1 級主手：招牌用掉 60% 後，剩下的放不下技能強化，要 5 級左右才放得下；1 級靴子剩下的連一條都放不下，整件只到 60%，低於「至少 70%」的下限。

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）招牌優先，剩下的放得下幾條算幾條** | 招牌一定在；放不下技能強化就不放。招牌物品的 70% 下限只看招牌以外、放得下的部分。 | 1 級稀有靴子只有「霜行」一條；5 級稀有長劍＝招牌＋技能強化。低等級常常只有招牌。 |
| B 等級門檻 | 物品到 4 級（初值）才帶招牌，之前照現在的稀有、史詩。 | 前期拿不到招牌。 |
| C 招牌比例隨部位縮小 | 小部位、低等級時招牌改用較低的比例。 | ⚠ 改 8.27「固定 60%、不看等級」。 |

## 第二波

**招-3 附魔台重骰招牌：只換同一種，還是五種都可能**

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）同一種裡換** | 「解鎖鉤爪」只會骰成別的新動作（例如煙霧彈），不會變地形規則。 | 打造時指定的類型不會被重骰洗掉；想換類型就重打。 |
| B 五種都可能，照部位偏向 | 主手重骰可能從新動作變成行為改寫。 | 打造指定類型的價值變小。 |

**招-4 身上超過 3 個招牌時，哪 3 個生效**

8.27 只寫「超過的標灰」；改寫規則衝突你選了「玩家自己選」，3 個的上限沒寫。

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）玩家勾選，和改寫規則同一套** | 角色面板勾 3 個；沒勾過時保留原本生效的，新穿上的標灰，寫「身上已經有 3 個招牌效果生效，這個沒有效果」。 | 換靴子不會讓主手的招牌突然失效。 |
| B 照部位順序取前 3 個 | 主手 → 副手 → 身體 → 腳 → 項鍊。 | 簡單，但換一件可能讓別件失效，不好懂。 |

**招-5 兩件裝備有同一條招牌時（⚠ 兩條你定過的規則要對齊）**

8.27 寫「同 id 只生效 1 條」；兩天後 8.28 你選了「B 疊加」：裝備給的同一招重複會變兩招、冷卻分開，而且 8.28 寫明「8.27 的新動作與新反應都走這條」。新動作、新反應、行為改寫都是裝備給的技能。

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）照後來的 8.28 疊加，佔 2 個名額** | 主手和副手都有「解鎖鉤爪」：兩招鉤爪、冷卻分開，用掉 2 個名額。8.27 那句加註「裝備給的技能照 8.28」。地形規則、改寫規則照舊只生效 1 條。 | 想疊熱門招就得少拿一種別的招牌，有取捨。 |
| B 招牌例外：同 id 只生效 1 條 | 第二條標灰、不佔名額。 | ⚠ 推翻 8.28 的「疊加」對招牌的部分。 |
| C 疊加但只佔 1 個名額 | 兩招鉤爪，名額只算 1。 | 重複反而比不同招牌划算。 |

**招-6 傳說能出在哪些部位**

舊條文「傳說任一部位」；8.27 的招牌只放主手、副手、身體、腳、項鍊。戒指 1 級的預算太小，獨特效果放不下。

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）只出在招牌的五個部位** | 頭、手、戒指抽到傳說時降成史詩。 | 實際掉率比 2% 略低。 |
| B 任一部位 | 傳說戒指幾乎只有獨特效果。 | — |

**招-7 傳說的獨特效果從哪裡挑**

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）招牌清單＋改寫規則＋只給傳說的專屬效果** | 傳說可能拿到一般招牌，也可能拿到只有傳說才有的（例如現有的「慈焰」）。寫內容時由玩法 PM 標哪些限傳說。 | 傳說有機會比史詩特別，又不用另做一整套。 |
| B 只從招牌清單＋改寫規則 | 不做傳說專屬。 | 傳說和史詩差別只剩組成。 |
| C 只從傳說專屬清單 | 一般招牌不出在傳說上。 | 專屬內容要寫很多才夠抽。 |

**招-8 大世界的掉落要不要出傳說**

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）只有精英、頭目的掉落有 2% 是傳說** | 一般戰鬥照舊不出。 | 一般戰鬥本來連史詩都不掉（8.13），直接跳傳說不合節奏。 |
| B 一般戰鬥也 2% | — | 一般戰鬥出傳說比史詩還常見。 |
| C 世界不掉，只能打造 | 傳說只在一輪的三選一和鐵匠出現。 | 大世界少一種驚喜。 |

## 寫內容前再答

**招-9 獨特裝備（首殺、隱藏配方那種）的獨特效果算不算它的招牌**

| 選項 | 內容 | 例子 |
|---|---|---|
| **A（建議）算：獨特效果就是那件的招牌，不另抽** | 算進 3 個名額，計價照 60%。現有 3 條觸發類的獨特效果，等寫內容時改成五種之一。 | 一件不會有兩個主角，也守住「不超過同級史詩」。 |
| B 獨特效果之外再抽 1 個招牌 | — | 比同級史詩多一個效果。 |
| C 照舊，不帶招牌、不算名額 | — | 獨特裝備沒有質變。 |
