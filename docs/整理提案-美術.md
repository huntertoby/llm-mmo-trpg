原則：
1. **現行方向與還沒結案的段落一律保留**：Q 版（第 17 版 B 批）、已交未交件的規格、等使用者確認的代決所附的文件。
2. **已結案的驗收紀錄與已實作的規格** → 搬到 `docs/archive/art/`。它們的內容已經進程式，之後要查看 git 歷史或 archive 就好；交接文件只留一行索引。
3. **被使用者推翻的方向**（C 墨線、只換皮、舊比較） → 搬到 `docs/archive/art/`，不刪，因為交接 2.2「被推翻方向」要能指到原文。
4. **只刪三種東西**：重複的原圖、已被新版取代的對照圖、已作廢畫風的截圖。刪的都在 git 歷史裡找得回來（下表附最後一次改動的 commit）。
5. 搬移用 `git mv`，一併把 `docs/phases/`、程式註解裡的路徑改成新路徑（只動註解與文件，不動程式行為）。

風險等級：**低**＝只有歷史報告或程式註解引用路徑；**中**＝現行文件或樣張頁仍會引用，要一起改；**高**＝設計真相，不能動。
